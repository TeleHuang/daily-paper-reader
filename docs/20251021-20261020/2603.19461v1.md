## 摘要
自我改进的AI系统旨在通过学习改进自身的学习与问题求解过程，从而减少对人类工程的依赖。现有的自我改进方法依赖于固定的、手工设计的元级机制，从根本上限制了此类系统的改进速度。达尔文·哥德尔机（DGM）通过反复生成和评估自我修改的变体，展示了在编码领域中的开放式自我改进。由于评估和自我修改都是编码任务，编码能力的提升可以转化为自我改进能力的提升。然而，这种对齐关系在编码领域之外通常并不成立。我们引入了\textbf{超智能体}（hyperagents），这是一种自指智能体，它将任务智能体（求解目标任务的智能体）和元智能体（修改自身和任务智能体的智能体）集成到一个可编辑的程序中。关键在于，元级的修改过程本身是可编辑的，从而实现了元认知的自我修改，不仅改进了任务求解行为，还改进了生成未来改进的机制。我们通过扩展DGM来实例化这一框架，创建了DGM-超智能体（DGM-H），消除了任务性能与自我修改技能之间领域特定对齐的假设，从而有可能支持在任何可计算任务上实现自我加速的进展。在多个不同领域中，DGM-H随时间推移不断提升性能，并优于没有自我改进或开放式探索的基线方法，以及先前的自我改进系统。此外，DGM-H改进了其生成新智能体的过程（例如持久记忆、性能追踪），而这些元级改进可以跨领域迁移并在多次运行中累积。DGM-超智能体让我们得以一窥开放式AI系统的前景：它们不仅搜索更好的解决方案，还不断改进其寻找改进方法的方式。

## Abstract
Self-improving AI systems aim to reduce reliance on human engineering by learning to improve their own learning and problem-solving processes. Existing approaches to self-improvement rely on fixed, handcrafted meta-level mechanisms, fundamentally limiting how fast such systems can improve. The Darwin Gödel Machine (DGM) demonstrates open-ended self-improvement in coding by repeatedly generating and evaluating self-modified variants. Because both evaluation and self-modification are coding tasks, gains in coding ability can translate into gains in self-improvement ability. However, this alignment does not generally hold beyond coding domains. We introduce \textbf{hyperagents}, self-referential agents that integrate a task agent (which solves the target task) and a meta agent (which modifies itself and the task agent) into a single editable program. Crucially, the meta-level modification procedure is itself editable, enabling metacognitive self-modification, improving not only the task-solving behavior, but also the mechanism that generates future improvements. We instantiate this framework by extending DGM to create DGM-Hyperagents (DGM-H), eliminating the assumption of domain-specific alignment between task performance and self-modification skill to potentially support self-accelerating progress on any computable task. Across diverse domains, the DGM-H improves performance over time and outperforms baselines without self-improvement or open-ended exploration, as well as prior self-improving systems. Furthermore, the DGM-H improves the process by which it generates new agents (e.g., persistent memory, performance tracking), and these meta-level improvements transfer across domains and accumulate across runs. DGM-Hyperagents offer a glimpse of open-ended AI systems that do not merely search for better solutions, but continually improve their search for how to improve.

## 1. 核心问题与研究动机

- **背景**：自我改进 AI 旨在让系统学习改进自身的学习与问题求解过程，从而减少对人类工程的依赖，并可能把科学进步从“人类节奏”转变为“自主加速”。
- **关键瓶颈**：现有自改进架构（包括 DGM 及其衍生工作）普遍依赖**固定的、手工设计的元级机制**（meta-level mechanism）。基础系统只能在元智能体设计所划定的边界内被改进；再叠加“元-元系统”只是把问题向上推移，最终导致无限回归。
- **DGM 的局限**：Darwin Gödel Machine 在编码领域实现了开放式自改进——同一编码智能体既当任务智能体又当元智能体，因此“编码能力提升”可直接转化为“自改进能力提升”。但这一**对齐假设**（任务能力 ≈ 自修改能力）在编码之外通常不成立（如诗歌写作能力提升并不等于改代码能力提升）。此外，DGM 中生成自改进指令的步骤是手工固定、不可修改的，构成自改进速度的瓶颈。
- **核心问题**：如何让系统在**任意可计算任务**上不仅改进任务表现，还能改进“产生未来改进的机制”本身，从而摆脱对手工元级设计与领域对齐假设的依赖？

## 2. 方法论

### 2.1 核心思想
- 提出 **hyperagent（超智能体）**：一种**自指（self-referential）**智能体，把**任务智能体**（求解目标任务）与**元智能体**（修改自身与任务智能体）整合进**同一个可编辑程序**。
- 关键创新：**元级修改过程本身可编辑**，即“元认知自我修改”（metacognitive self-modification）——既改进任务求解行为，也改进“生成未来改进”的机制。
- 智能体被定义为“任意可计算程序”，可包含基础模型（FM）调用、外部工具、学习组件；采用图灵完备的 Python，因此原则上可构造任意可计算机器。

### 2.2 DGM-H 算法流程（文字化描述）
- 在 DGM 的**开放式探索结构**上扩展：维护一个超智能体**档案库（archive）**，初始仅含一个超智能体，随时间不断累积变体。
- 迭代交替两个阶段：
  1. **元认知自我修改**：按概率从档案中选父代，父代生成自身的修改版本（可修改任务智能体、元智能体乃至二者）；
  2. **评估**：对修改后的超智能体做经验评估，编译通过者加入档案。
- **父代选择机制**（手工固定，主实验不开放修改）：
  - 计算当前 top-m（m=3）性能均值作为动态中点 α_mid；
  - 对每个智能体做 sigmoid 变换 s_i = 1/(1+exp(−λ(α_i−α_mid)))，λ=10；
  - 新颖性奖励 h_i = 1/(1+n_i)，n_i 为已成功编译的子代数量；
  - 权重 w_i = s_i·h_i，归一化为类别分布后独立有放回采样。
  - 直觉：偏向高性能且尚未大量繁殖的智能体，兼顾利用与探索。
- **多域联合优化**：同一 run 内可跨域评估，父代选择依据跨域平均性能，元智能体可读取所有任务的评估结果，从而引入共享机制（结构化推理、记忆、错误处理等）。
- **初始超智能体**：基于冻结 FM + 两个工具（bash 执行、文件查看/编辑）；初始任务智能体仅做单次 FM 调用并输出 JSON；初始元智能体仅收到“修改代码库任意部分”的简单指令，刻意保持极简以扩大搜索空间。

## 3. 实验设计

### 3.1 评测领域与 Benchmark
| 领域 | 数据/环境 | 输入→输出 | 指标 | 训练/验证/测试规模 |
|---|---|---|---|---|
| 编码 | Polyglot（Gauthier, 2024） | 仓库+自然语言指令→代码补丁 | Pass@1 | 60 / – / 165 |
| 论文评审 | Zhao et al. (2026)，ICLR/NeurIPS 真实录用数据 | 论文全文→Accept/Reject | 准确率 | 100 / 100 / 100 |
| 机器人奖励设计 | Genesis 仿真 + Go2 四足机器人 + PPO | 任务描述→奖励函数 | 训练后策略的任务得分 | 6 / – / 6 |
| 奥赛数学评分 | IMO-GradingBench（Luong et al., 2025） | 题目+解答+评分细则→{0,1,6,7} | 与专家评分一致率 | 100 / 100 / 100 |

- 采用**分阶段评估**降本：先在小子集（如 10 题）上估计有效性，达标才扩展到全训练集，否则记零分。
- 机器人域特意设置**训练任务（前进）与测试任务（最大化躯干高度）不同**，检验零样本泛化；直接奖励高度会陷入“站高不动”的局部最优，需非短视的奖励设计。

### 3.2 对比方法
- **DGM-H**（本文）
- **DGM-H w/o self-improve**：元智能体固定为初始版本（复现 ADAS 思路），隔离“元级改进”的贡献。
- **DGM-H w/o open-ended exploration**：去掉档案库，新智能体直接替换前代，隔离开放式种群搜索的贡献。
- **原始 DGM**：手工固定指令生成机制，未针对非编码域定制。

- **静态基线**：AI-Scientist-v2 评审智能体（论文评审）、默认奖励函数（机器人）、ProofAutoGrader（数学评分）。

### 3.3 统计与评估协议
- 每个实验 **5 次重复**；报告中位数与 95% bootstrap 置信区间（1000 次重采样）；显著性用 Wilcoxon 符号秩检验。
- 提出 **improvement@k（imp@k）** 指标：固定元智能体，允许其从初始任务智能体出发生成至多 k 个新任务智能体，取最佳者在测试集上相对初始者的性能增益（本文用 imp@50），用于量化“改进能力”。
- **迁移智能体选择**：用后代增长准则 G_γ(i)=（后代相对 i 的性能提升按 γ^距离 折扣的平均），γ=0.6，仅考虑后代≥3 的节点，偏好“能稳定产出强后代”的踏脚石而非单纯高分者。

## 5. 实验数量与充分性

### 5.1 实验规模概览
- **主实验（任务性能）**：4 个领域；Polyglot 80 次迭代，论文评审+机器人联合优化 100 次迭代，数学评分 200 次迭代；每法 5 次重复。
- **消融实验**：无自改进元智能体、无开放式探索两组消融，覆盖论文评审与机器人两域。
- **迁移实验（改进能力）**：imp@50 对比初始智能体、DGM-custom 迁移体、DGM-H 迁移体，目标域为数学评分。
- **累积实验**：DGM-H + transfer 在数学评分上跑 200 次迭代，并与从初始智能体启动的 DGM-H、以及以 ProofAutoGrader 为起点的版本对比；另在完整 IMO-GradingBench 上复核。
- **附加实验**：可修改父代选择机制的初步实验（random / modifiable / score-child-prop 三组，各 5 次）。
- **定性分析**：档案树与进度图（3 个域）、代码 diff 分析、混淆矩阵分析、涌现元级能力（评估分析、算力感知规划、偏差检测、性能追踪、提示模板、持久记忆等）的代码级例证。

### 5.2 充分性与公平性评估
- **较充分之处**：跨 4 个异质领域（编码、主观评审、具身仿真、数学评分），覆盖“可验证/难验证”“语言/非语言”两类任务；消融设计精准对应方法的两大支柱；迁移与累积实验直接检验核心主张；5 次重复 + 置信区间 + 显著性检验；Polyglot 沿用 DGM 完全相同的设置以保证可比。
- **需注意之处**：
  - 部分关键对比**未达统计显著**：DGM-H 优于 DGM-custom（p>0.05）、DGM-H+transfer 优于 DGM-H（p>0.05）、可修改父代选择优于手工机制（p>0.05），结论主要依赖中位数趋势与定性观察。
  - 论文评审与数学评分的“真值”本身含主观性或由 AI 判官近似人类，存在过拟合训练数据的风险（作者为此设了验证集）。
  - 机器人域样本量小（6 次重复评估），方差敏感。
  - 主实验的父代选择、评估协议等外层循环固定，未检验完全自指设定下的表现。

## 6. 主要结论与发现

- **编码域**：DGM-H 训练子集从 0.140 提升至 0.340，完整 Polyglot 从 0.084 提升至 0.267，与原始 DGM（0.140→0.380；0.142→0.307）相当，尽管并未针对编码手工定制。
- **跨域任务性能**：论文评审测试集 0.0→0.710（超过 AI-Scientist-v2 的 0.630）；机器人奖励设计 0.060→0.372（超过默认奖励函数的 0.348），且几乎总能诱导出“跳跃”而非陷入“站高”局部最优，而 DGM-custom 常困于局部最优。
- **DGM 的领域依赖**：原始 DGM 在非编码域几乎为 0，人工定制（DGM-custom）后达 0.590 / 0.348，说明其跨域能力高度依赖人工工程。
- **消融结论**：去掉自改进元智能体或去掉开放式探索，性能均几乎不提升（p<0.05），二者缺一不可。
- **改进能力可迁移**：初始元智能体 imp@50≈0；DGM-custom 迁移体 imp@50≈0；DGM-H 迁移体 imp@50=0.630（p<0.05）——元级改进是**通用且可迁移**的。
- **可累积**：DGM-H+transfer 在数学评分达 0.640（vs 从零启动 0.610，未显著但中位数与置信区间更高）；以 ProofAutoGrader 为起点进一步把完整基准准确率从 0.561 提到 0.601，MAE 从 0.178 降到 0.175。
- **涌现的元认知能力**（未被显式要求）：评估结果分析、算力感知的策略规划（早期激进、后期保守）、分类坍缩的自动偏差检测与纠正（如 99% 接受率→纠正后 63% 准确率）、性能追踪基础设施、提示模板系统、跨代持久记忆（存储洞察、因果假设与计划）。
- **任务级改进的质性规律**：从“态度型提示”（如扮演严格审稿人）转向“结构化流程”（清单、决策规则、多阶段管线）；累积领域知识（环境变量文档、约束、奖励缩放经验）；自动发现评分细则与决策树。

- **跨域覆盖广且含难验证任务**：把主观评审、具身仿真、数学评分纳入同一框架，验证了“无需领域对齐”的论断。

- **安全意识前置**：沙箱、资源限制、断网、人工监督，并专章讨论开放-ended 自改进的安全含义（偏见放大、评估博弈/Goodhart）。

## 8. 不足与局限

- **外层循环仍固定**：父代选择、评估协议等开放式探索组件在主实验中不可修改，与“完全自指”的理想仍有距离；初步的可修改父代选择实验显示其**未能超过手工机制**（虽优于随机），且跨 run 不稳定。
- **任务分布固定**：未实现任务分布/课程的协同演化，限制了“无界”开放式进步的论证强度。
- **统计效力有限**：多项关键对比不显著（DGM-H vs DGM-custom、transfer vs 从零、可修改父代选择），结论部分依赖中位数与定性证据；5 次重复对高方差域（机器人）偏少。
- **评估信号本身的脆弱性**：论文评审与数学评分的真值含主观性/AI 判官近似，存在过拟合与评估博弈（Goodhart）风险；作者亦承认系统会忠实放大数据中的偏见。
