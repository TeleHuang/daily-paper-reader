## 摘要
长时程组合式操作对于真实世界机器人部署已变得日益重要，其中单个任务涉及多个协调的子任务。现有的世界-动作模型（WAMs）联合预测短时程视觉未来和动作，但通常缺乏显式的子任务级推理。我们提出视觉目标条件动作推理（Visual Goal-conditioned Action Reasoning, ViGAR），这是一种分层框架，将操作分解为视觉子目标规划器和子目标执行器。给定当前观测和全局指令，子目标规划器预测下一个子任务的视觉子目标。随后，子目标执行器以预测的子目标为条件，联合生成未来视觉轨迹和动作。两个组件共享预训练的世界模型表征，使任务级规划和动作生成能够受益于共同的物理知识。此外，我们的框架天然支持上下文内学习：使用全局目标图像作为上下文，无需参数更新即可诱导不同的子任务分解和行为。在 RoboTwin Clean2Random 基准上，ViGAR 在 Clean 和 Random 设置下分别取得 82.00% 和 67.02% 的成功率，平均成功率超过最强基线 12.86 个百分点。在五个组合式任务和两个上下文内学习任务上的真实机器人实验进一步证实了 ViGAR 的有效性。

## Abstract
Long-horizon compositional manipulation has become increasingly important for real-world robot deployment, where a single task involves multiple coordinated subtasks. Existing world-action models (WAMs) jointly predict short-horizon visual futures and actions, but typically lack explicit subtask-level reasoning. We propose Visual Goal-conditioned Action Reasoning (ViGAR), a hierarchical framework that factorizes manipulation into a visual subgoal planner and a subgoal executor. Given the current observation and global instruction, the subgoal planner predicts a visual subgoal for the next subtask. The subgoal executor then jointly generates future visual trajectories and actions conditioned on the predicted subgoal. Both components share a pretrained world-model representation, enabling task-level planning and action generation to benefit from common physical knowledge. Moreover, our framework naturally supports in-context learning: using a global goal image as context can induce different subtask decompositions and behaviors without parameter updates. On the RoboTwin Clean2Random benchmark, ViGAR achieves 82.00% and 67.02% success rates under the Clean and Random settings, respectively, surpassing the strongest baseline by 12.86 percentage points in average success rate. Real-world robot experiments on five compositional and two in-context learning tasks further confirm the effectiveness of ViGAR.

## 1. 核心问题与研究动机

- **背景**：真实生产/服务场景中的机器人任务日益呈现"长时程组合式"特征——单个任务由多个需按序协调的子任务构成，且要求策略能泛化到未见场景、物体与空间布局，而非回放训练中的固定序列。
- **现有 WAM（World-Action Model）的局限**：WAM 通过联合预测短时程视觉未来与动作，从稠密视频监督中获得物理落地的动作动力学，具备跨任务、跨环境、跨本体、跨视觉分布偏移的强泛化性；但其公式化目标只提供**局部控制信号**（"接下来可能发生什么"），既无法显式组织跨子任务的行为，也不提供可指定期望进展的**任务级接口**。
- **替代路线的不足**：将决策外置给 VLM 语言规划器（分解为语言子任务）是常见做法，但语言描述常对精确空间结果存在**歧义与欠指定**，而视觉子目标对期望场景构型施加更强约束。
- **核心洞察**：组合式操作可分解为 **长期未来选择（long-term future selection）+ 短期未来实现（short-term future realization）**——WAM 应先显式声明机器人意图达成的目标状态，再生成使之发生的动作。
- **研究目标**：在不牺牲 WAM 世界中心预测与物理泛化能力的前提下，赋予其显式的任务级决策能力。

## 2. 方法论：ViGAR

### 2.1 核心思想与总体框架

- **ViGAR（Visual Goal-conditioned Action Reasoning）**：分层框架，将操作分解为
  - **视觉子目标规划器 Gθ**：由当前观测 + 全局指令（+ 可选全局目标图像）预测下一子任务的视觉子目标图像；
  - **子目标执行器 πWAM_φ**：以子目标为条件，联合生成未来视觉轨迹与机器人动作。
- **共享表示**：两组件均从同一个预训练世界模型（Cosmos3-Nano）初始化，使任务级规划与动作生成共享同一份物理知识。
- **问题形式化**：将组合任务 T 分解为 n 个子任务 T = (T₁,…,Tₙ)，每个子任务配子目标 (ℓᵢ, gᵢ)（文本子任务指令 + 视觉目标状态），策略 π 以 (oₜ, sₜ, ℓᵢ, gᵢ, µ) 为条件预测动作块；子任务完成后推进到 (ℓᵢ₊₁, gᵢ₊₁)。

### 2.2 子目标规划器（Gθ）

- **关键设计选择**：对所有阶段固定 ℓᵢ = ℓ（不生成阶段特定子任务文本），因为子目标图像已提供精确目标状态 grounding，保留全局指令作为一致语义锚点，同时缓解子任务文本生成带来的误差累积。
- **问题建模**：把子目标规划视为 **image editing** 问题——给定子任务 Tᵢ 内的参考帧 oₜ 与全局指令 ℓ，预测子目标图像 gᵢ。
- **子目标前瞻规则（subgoal look-ahead rule）**：Tᵢ 末段的帧在视觉上与 Tᵢ₊₁ 早期帧相似但目标不同（gᵢ vs gᵢ₊₁），若不纠正，推理时会重新生成 gᵢ 并把规划拉回已完成子任务。规则为
  - target(oₜ) = gᵢ₊₁，若 oₜ ∈ Tᵢ 的最后 p%（且 i < n）；否则为 gᵢ。
- **末端执行器 ROI 加权**：将专家末端执行器位置经标定相机投影，取固定尺寸窗口并集形成二值掩码 mᵢ，再 area-pool 至 latent 分辨率得到 ˜mᵢ；权重
  - wᵢ(u) = (1 + λ˜mᵢ(u)) / mean_u′∈Ω(1 + λ˜mᵢ(u′))，且保证 Σ wᵢ(u)/|Ω| = 1；前景:背景权重比约 4:1。
- **训练目标（加权 flow matching）**：
  - 目标 latent x^g₀ = E_v(gᵢ)，参考 latent z_t = E_v(oₜ)；
  - 加噪 x^g_τ = (1−τ)x^g₀ + τε，τ∼U[0,1]，ε∼N(0,I)，flow-matching 目标 v_plan = ε − x^g₀；
  - L_Plan = E[‖√wᵢ ⊙ (Gθ(x^g_τ, τ | z_t, ℓ) − v_plan)‖²₂]。
- **训练细节**：Cosmos3 原生不支持图像编辑，故将其 image-to-video 能力改造为图像编辑——当前观测编码为单个干净条件 latent 帧，目标子目标图像复制四次后 VAE 编码为单个目标 latent 帧；多视角观测与子目标沿帧维拼接。训练时**冻结 reasoner 分支**，只更新 generator 侧参数。

### 2.3 子目标引导的世界-动作模型（πWAM_φ）

- **输入/输出**：以 oₜ、sₜ、预测子目标 (ℓ, ĝᵢ)（以及本体元数据 µ）为条件，联合预测短时程视觉未来 O_{t+1} 与动作块 A_{t+1}。
- **联合 flow matching 损失**：
  - x^v₀ = E_v(O_{t+1})、x^a₀ = A_{t+1}；x^v_τ = (1−τ)x^v₀ + τε_v，x^a_τ = (1−τ)x^a₀ + τε_a；
  - v_vid = ε_v − x^v₀，v_act = ε_a − x^a₀；
  - L_WAM = E[‖v̂^v_φ − v_vid‖²₂ + ‖v̂^a_φ − v_act‖²₂]。
- **子目标注入路径（关键设计）**：
  - *语义路径*：ĝᵢ 经视觉编码器 token 化后送入 reasoner 分支；
  - *几何路径*（**本文采用**）：ĝᵢ 经同一 VAE 编码为干净 latent z^g_i，直接与参考 latent z_t 一起送入 generator 分支，实现像素级 grounding 而非较粗的语义嵌入；指令 ℓ 仍通过 reasoner 分支条件化。
  - 另加**零初始化可学习 goal-role embedding**，以区分 z^g_i 与其他 latent token。
- **训练细节**：动作块时域 H_a = 48，视频时域 H_v = 48、下采样率 4（每次控制查询预测 48 个动作 + 12 帧视频）；训练数据使用 Gθ 对演示生成的预测子目标，语义不一致或视觉畸变的样本替换为 ground-truth 子目标，形成混合监督；reasoner 冻结，generator、modality embedding、动作投影、goal embedding 可训练。

### 2.4 通过全局目标的上下文内任务指定（ICL）

- 将推理时上下文 C 实例化为**全局目标图像 G**（任务终态的世界状态）。
- **训练**：G 取每条演示轨迹的终帧，规划目标为
  - L_Plan−ICL = E[‖√wᵢ ⊙ (Gθ(x^g_τ, τ | z_t, ℓ, G) − v_plan)‖²₂]。
- **推理**：G 替换为用户指定的目标图像，**下游策略 πWAM_φ 不变**（只条件于 ĝᵢ，G 的影响已通过 ĝᵢ 中介）。
