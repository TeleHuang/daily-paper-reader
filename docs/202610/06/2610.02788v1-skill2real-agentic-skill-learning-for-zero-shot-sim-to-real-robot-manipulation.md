## 摘要
将机器人技能从仿真迁移到现实，需要任务知识在感知、动力学与具身形态存在差异时仍然可用。我们提出 Skill2Real，一种智能体式策略框架，它通过共享应用程序接口（API）学习可执行技能。Proposer-Verifier-Governor（PVG，提议者-验证者-调控器）循环利用特权仿真证据来诊断结果并验证更新，同时使所学技能以公开观测和 API 语义为基础。Cerebellum 首先习得局部操作技能；随后 Brain 在 Cerebellum 冻结的情况下学习任务级组合。两种记忆均可迁移到真实机器人，而无需任务策略微调或技能记忆更新。当 GPT-5.6 Sol 在 LIBERO-90 上学习技能时，用 GPT-6 Astra 评估每个冻结检查点，可将 LIBERO-Pro Long 成功率从 2.0% 提升至 56.3%，且无需在 Pro Long 上训练。独立的 Robosuite 训练在七个任务上分别使用 Sol 和 Opus 5 达到 85.1% 和 89.4% 的平均成功率。冻结的、由 Sol 训练的 LIBERO-90 技能在 Astra 上于四个真实世界操作任务中达到 78.75% 的平均完成率。在 LIBERO-90 训练中移除 Verifier 或 Governor，会使最终 Pro Long 成功率分别下降 17.3 和 13.3 个百分点。这些结果支持通过通用机器人接口学习并迁移分层可执行技能。

## Abstract
Transferring robotic skills from simulation to reality requires task knowledge that remains usable across differences in perception, dynamics, and embodiment. We introduce Skill2Real, an agentic policy framework that learns executable skills through a shared application programming interface (API). A Proposer-Verifier-Governor (PVG) loop uses privileged simulation evidence to diagnose outcomes and validate updates, while keeping learned skills grounded in public observations and API semantics. The Cerebellum first acquires local manipulation skills; the Brain then learns task-level composition with the Cerebellum frozen. Both memories transfer to the real robot without task-policy fine-tuning or skill-memory updates. As GPT-5.6 Sol learns skills on LIBERO-90, evaluating each frozen checkpoint with GPT-6 Astra raises LIBERO-Pro Long success from 2.0% to 56.3%, without training on Pro Long. Independent Robosuite training reaches 85.1% and 89.4% mean success with Sol and Opus 5 across seven tasks, respectively. Frozen Sol-trained LIBERO-90 skills achieve 78.75% mean completion across four real-world manipulation tasks with Astra. Removing the Verifier or Governor during LIBERO-90 training lowers final Pro Long success by 17.3 and 13.3 percentage points, respectively. These results support learning and transferring a hierarchy of executable skills through a common robot interface.

## 1. 核心问题与研究动机

- **背景**：零样本仿真到真实（sim-to-real）机器人操作希望把仿真中获得的行为直接部署到物理机器人，无需真机任务训练。但外观、动力学、接触与本体差异使仿真策略难以可靠迁移。
- **长时程操作的额外挑战**：不仅要迁移单个动作，还要可靠执行局部操作技能、把它们组合成任务级行为，并在中间步骤失败时恢复。
- **现有方法的瓶颈**：论文认为核心瓶颈是"如何在不把学习预算耗在任务无关低层表示上的前提下，从仿真特权证据中学到可复用、可组合的任务知识"。
  - 域随机化 / 非对称 actor-critic：通过适配神经策略或表示来提升迁移，但外观类随机化会把大量预算用于建模光照、纹理等与任务无关的变化。
  - 代码生成方法（如 Code as Policies、ProgPrompt）：行为可组合，但只是组装给定原语，并不从经验中习得局部技能与任务策略。
  - 技能库系统（Lifelong Robot Library、ASPIRE 等）：多依赖人工指导或真实执行反馈积累程序。
- **整体含义**：论文主张把 sim-to-real 迁移的"单位"从模型参数改为**可执行的任务知识**——冻结的技能层级通过共享代码接口在仿真与真机之间复用。

## 2. 方法论

### 2.1 核心思想

- 分离"用于监督技能学习的信息"与"执行技能所需的信息"：仿真特权信息可评估与改进行为，但持久化的技能知识只用**公开观测 + API 语义**表达。
- 迁移边界是**共享代码式策略接口** $A=\{a_k\}_{k=1}^K$：策略只通过该接口推理，各后端（仿真/真机）自行实现感知、标定与低层控制。

### 2.2 关键技术细节

- **Proposer**（由基础 VLM $M$ 实例化）按 $c_t \sim \pi_M(c \mid g, o_{\le t}, D_A, S_{cer}, S_{brain})$ 采样可执行程序，仅使用公共信息。
- **Verifier** 利用仿真特权证据诊断执行结果，但被约束只能输出公开可表达的反馈：$e = E_{exec}(\tau, x^{priv}_{0:T})$，$f = \mathrm{Verifier}(\tau, e)$，且要求 $f \in F_{pub}$。
- **Governor** 在后续验证 rollout 上聚合证据 $e_\delta$，仅当验证行为支持所提议改进时才准入更新，防止"单次成功即入库"。
- **两级技能层级**：
  - **Cerebellum（小脑）**：局部操作技能，每条技能由自然语言指导、API 级代码模板、轻量结构化状态描述组成。
  - **Brain（大脑）**：任务级技能，在 Cerebellum 冻结条件下学习如何组合局部技能、规划与恢复。
- **顺序训练**：$S^*_{cer} = \mathrm{TrainStage}(Q_{cer}, \varnothing)$，$S^*_{brain} = \mathrm{TrainStage}(Q_{brain}, S^*_{cer})$；同一 PVG 机制在两个层级复用。
- **部署**：只保留 Proposer + 共享接口 + 冻结的两级记忆；Verifier/Governor 缺席，不做真机任务微调或在线技能记忆更新。

## 6. 主要结论与发现

- **两级层级互补且可迁移**：
  - LIBERO-Pro Long（Astra）：2.

- **两级层级互补且可迁移**：
  - LIBERO-Pro Long（Astra）：从无技能基线 C0 到 Cerebellum 阶段 C3 再到 Brain 阶段 B4，成功率呈阶梯式上升，说明**局部技能的习得**与**任务级组合策略的习得**是两个可分别贡献增益的环节，而非重复收益。
  - 真机四任务：完整层级（Cerebellum + Brain）在 R1–R4 上整体优于任一单层条件，且 R3（算式拼装）与 R4（抽屉操作）这类需要多步组合与中间状态恢复的任务，对 Brain 的依赖最明显；R1 这类单步抓放对 Cerebellum 的依赖最明显。
  - 该模式在 GPT-5.6 Sol 与 Claude Opus 5 两个 Proposer 上同时成立，说明增益不来自某个特定 VLM 的能力上限。
- **PVG（Proposer–Verifier–Governor）三件套的贡献可分离**：
  - 去掉 **Governor** 后，库中会混入由单次成功支持、但在验证 rollout 上不稳定的候选更新，学习曲线出现明显退化。
  - 去掉 **Verifier** 后，Proposer 只能依赖执行是否"跑完"这类粗粒度信号，技能质量提升变慢且更易过拟合到仿真特权条件下的偶然成功。
  - 两者叠加使用时的增益大于各自单独贡献之和，说明"诊断"与"准入"是互补而非冗余的机制。
- **技能知识确实比模型参数更耐迁移**：
  - 在 LIBERO-90 上学到的 Cerebellum 技能冻结后，可直接被 Brain 在 LIBERO-Pro Long 上组合调用，无需重训低层策略。
  - Robosuite 七个任务（含单臂与双臂）各自独立训练也复现了同样的"先技能、后组合"的增益次序，表明该模式不局限于某一任务族。
- **长时程与扰动鲁棒性**：
  - 在 LIBERO-Pro Long 的位置扰动（Pos）与指令扰动（Task）两种设置下，Skill2Real 相对 CaP-Agent0、ASPIRE、Zetta 的领先在**指令扰动**下更为稳定，暗示其优势更多来自"可组合的任务知识"而非"对固定轨迹的记忆"。
  - 需要注意的是，ASPIRE、CaP-Agent0 与 Zetta 的分数引自他人报道，且三者设置（技能库规模、每任务程序数、演化种子数）与本文并不严格对齐，因此这一比较应视为**方向性证据**而非严格控制变量下的结论。
- **对真机外观/光照变化的定性鲁棒性**：附录中给出的真机示例表明，由于策略只通过共享代码接口推理，顶视相机视野内的光照与背景变化不会直接改变策略输入语义，从而避免了外观域随机化所需的巨额仿真预算。
- **总体判断**：论文支持的核心命题是"**把迁移单位从参数改为可执行任务知识**"在长时程操作上是可行且有效的；但它并未证明该方案在所有任务族上都优于基于参数的域随机化方法，也未在匹配计算预算下与后者正面对比。

## 7. 局限与未来工作

- **计算资源透明度不足**：未披露 GPU 型号/数量、训练时长、总 FLOPs，也未披露闭源 VLM API 的调用成本与 token 消耗，使复现成本难以预估。
- **统计功效有限**：真机每条件 20 trials 且无置信区间；Robosuite 与 LIBERO 的成功率均为固定技能库上的点估计，**不反映独立训练运行的方差**。
- **学习曲线索引方式**：按训练迭代而非累计 rollout 成本索引，跨方法比较训练效率时需谨慎。
- **阶段归因不够干净**：Cerebellum→Brain 的比较混合了"额外训练"与"新增记忆层级"两个变量，未在匹配预算下隔离层级贡献。
- **Verifier 特权信息的贡献未被分离**：缺少"仅用公开观测的 Verifier"这一对照，无法判断特权信息本身与 Verifier 的其他职能各贡献多少。
- **迁移范围有限**：LIBERO 与 Robosuite 共用 Robosuite 物理引擎，论文明确表示这不构成跨物理引擎的迁移证据；真机仅一台 UR5e，未验证跨本体泛化。
- **未来工作**：作者把降低 VLM 推理延迟、扩展技能库规模、以及在更多本体上验证共享接口的通用性列为后续方向。

## 8. 总体评价

- **主要贡献**：把 sim-to-real 的迁移单位从"策略参数"重定义为"经公开代码接口表达的可执行任务知识"，并给出 Proposer–Verifier–Governor 这一可复用的技能获取与准入机制；两级（Cerebellum/Brain）层级设计使"学技能"与"学组合"可以顺序、解耦地训练。
- **方法上的亮点**：Verifier 使用仿真特权信息但被**约束只能输出公开可表达的反馈**，这一"特权只用于监督、不进入持久知识"的分离是全文最关键的设计，也是它区别于纯域随机化与纯代码生成方法的支点。
- **实证强度**：覆盖两个仿真基准、四个真机任务、多个 Proposer 与 PVG 角色消融，广度较好；但受限于固定技能库的点估计、外部对比的非严格可比性、以及真机样本量偏小，结论应被理解为**方向性支持**而非严格排他性证明。
- **最值得后续验证的三点**：(1) 在匹配计算预算下与域随机化/非对称 actor-critic 的正面对比；(2) 跨物理引擎与跨机器人本体的技能接口迁移；(3) 独立训练多次以给出方差估计与置信区间。
