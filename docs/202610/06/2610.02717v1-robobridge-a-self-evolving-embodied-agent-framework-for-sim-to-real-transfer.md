## 摘要

## Abstract
A key challenge in bringing embodied intelligence into the real world is transferring capabilities from simulation to reality and enabling agents to continually adapt after deployment. End-to-end vision-language-action policies provide strong manipulation capabilities, but their transfer to physical environments typically relies on calibrating simulated visual and dynamical conditions, collecting additional target-domain demonstrations, and optimizing the policy through further training. Tool-using embodied agents offer flexible task orchestration, yet existing systems primarily emphasize task execution and experience reuse within a given environment, with limited support for transferring procedural knowledge and continuously adapting it across simulation and reality. We propose RoboBridge, a framework that treats sim-to-real transfer as the continued adaptation of executable task skills. The agent represents task knowledge as procedures connecting task intent, observations, tool operations, and outcome verification. Interaction feedback is used to generate candidate skill revisions, which are evaluated before being persisted or rejected. A pretrained vision-language-action policy is exposed as a reusable action tool and enhanced with inference-time guidance, enabling fine-grained execution without retraining the underlying policy. RoboBridge grounds transferable skills in task semantics and interaction interfaces shared across simulation and reality. This representation preserves reusable task structure while allowing environment-dependent operations to be selectively revised through real-world execution feedback. We evaluate the framework on LIBERO-PRO and corresponding physical tasks, studying both skill evolution and post-transfer adaptation. Our framework provides a route from one-shot policy deployment to continual procedural learning across environments.

## 2. 论文提出的方法论

### 2.1 核心思想

- 将**任务知识表示为过程性技能**（Procedural Skill），连接任务意图、观测、工具操作与结果验证。
- 技能被组织为围绕**任务相关状态与操作可供性**的可执行假设，而非绑定特定物体身份，从而保留可复用的行为结构。
- 预训练 VLA 策略被封装为**可复用的动作工具**，由智能体决定何时调用、如何组织，并在需要时通过**推理时引导**（Inference-time Guidance）调整动作生成，而不更新策略参数。
- 仿真中演化的技能通过**对齐的任务语义与交互接口**迁移到现实环境，并继续通过真实执行反馈进行演化。

### 2.2 关键技术细节

- **智能体执行循环**：
  - 每一轮 rollout 由高层规划器 Π 与统一工具接口 P 交互组成。
  - 规划器接收观测 $o_t$（结构化场景描述、相机观测、机器人状态、新鲜度与不确定性）、指令 ℓ、上一轮反馈 $f_{t-1}$ 以及当前技能 $S_k$，决定下一次工具调用 $c_t$。
  - 每轮至多执行一个物理操作，操作完成后刷新观测与反馈，循环直到任务完成、智能体显式终止或预算耗尽。
  - 轨迹记录观测、工具调用与反馈，作为后续技能更新的证据。

- **技能演化**：
  - 技能演化过程 $U$：$S_{k+1} = U(S_k, \tau_k)$，其中 $\tau_k$ 为任务 rollout。
  - 技能修订包括**添加缺失操作、替换不可靠转换、删除不再支持的行为**，同时保留未受影响的部分。
  - 每个候选技能需在可比任务条件下与当前技能对比评估；只有验证有效且提升任务执行的候选才会被持久化，否则保留当前技能并拒绝候选。
  - 仿真到现实的技能初始化：$S^r_0 = \Phi(S^s_K)$，其中 $\Phi$ 捕捉任务语义、观测格式与工具接口的对齐。

- **推理时引导**：
  - 当冻结策略产生的动作不符合当前子任务要求时，智能体根据子任务目标、执行约束与观测反馈构造奖励函数。
  - 在去噪步骤 $j$ 对候选动作序列 $A^{(j)}_t$ 进行奖励引导修正：
    $$A^{(j)}_{t,guided} = A^{(j)}_t + \eta_{t,j} \nabla_{A^{(j)}_t} r_t(A^{(j)}_t; o_t, u_t)$$
  - 其中 $o_t$ 为当前观测，$u_t$ 为局部子任务，$r_t$ 为智能体配置的奖励函数，$\eta_{t,j} \geq 0$ 控制引导强度（$\eta_{t,j}=0$ 表示无引导）。
  - 梯度仅对候选动作序列求取，预训练模型参数保持冻结。

- **技能演化的层次与推理时引导的关系**：技能演化在**跨 episode 层面**修订过程性知识（操作选择、排序、验证），推理时引导在**单次工具调用内**调整动作执行，两者互补。

### 2.3 系统组成（附录补充）

- **观测与执行解耦**：环境适配器负责观测构建（分割、几何重建、观测打包），规划器负责任务分解、物体选择、运动偏移与结果验证。
- **动作工具库**：包括笛卡尔运动（Cartesian Move、Pose Alignment）、姿态调整（Wrist Rotation、Wrist Tilt）、夹爪控制（Open Gripper、Gripper Control）以及基于策略的操作（Policy Grasp、Policy Contact）。
- **技能存储结构**：包含技能 ID、意图、前置条件、过程步骤、验证条件与恢复行为。
- **技能版本与验证记录**：每个被接受的技能关联版本标识与证据，候选技能独立评估，拒绝的候选保留为审计记录。

- **消融结论**：
  - 无技能引导时，SPATIAL-T 与 OBJECT-T 成功率分别降至 21% 和 16%，下降 62 和 78 个百分点，说明技能引导至关重要。
  - 仅追加更新时，成功率降至 44% 和 57%，下降 39 和 37 个百分点，说明**修订与删除**对技能演化不可或缺。
  - 无验证门控时，成功率降至 69% 和 63%，下降 14 和 31 个百分点，说明候选技能需经执行验证后再持久化。
  - 无推理时引导时，成功率降至 75% 和 82%，下降 8 和 12 个百分点，说明推理时引导提供额外增益。
- **真实机器人迁移**：
  - 直接迁移仿真技能将三个任务成功率从 4/15、2/15、3/15 提升至 9/15、7/15、7/15。
  - 真实机器人演化后达到 15/15、14/15、15/15。
  - 仿真初始化演化在 12 轮达到 15/15，而从零演化需 16 轮，迭代次数减少 25%。
  - 累计 token 消耗从 52.39M 降至 13.08M，减少约 75%。
- **总体结论**：当任务语义与交互接口对齐时，仿真中形成的程序性技能为真实机器人任务提供可复用的初始知识，并能通过物理执行反馈继续适应，在任务效果与适应效率两方面均带来收益。

## 7. 优点

- **问题视角新颖**：将 sim-to-real 迁移重新表述为**可执行任务技能的持续适应**，而非策略参数适配，分离了"任务过程知识"与"底层操作能力"。
- **技能表示设计合理**：技能围绕任务相关状态与操作可供性组织，不绑定特定物体身份，保留了可复用的行为结构，支持跨环境迁移。
- **受控的技能演化机制**：引入**验证门控**，候选技能需与当前技能在可比条件下对比评估，只有验证有效的改进才被持久化，避免了错误经验的永久污染与无控制的追加累积。
- **冻结策略 + 推理时引导**：在不更新 VLA 参数的前提下，通过智能体配置的奖励函数在去噪过程中引导动作生成，兼顾了细粒度执行能力与参数稳定性。
- **观测与执行解耦**：环境适配器负责感知与观测构建，规划器负责任务决策，使感知与控制实现可跨环境变化而保持观测–动作–验证循环一致。
- **实验设计较严谨**：训练/验证/测试种子严格分离，评估协议清晰，消融实验覆盖四个关键组件，真实机器人实验不仅报告成功率还报告了适应效率与 token 消耗。
- **真实迁移效果显著**：直接迁移即可带来明显提升，继续演化后接近饱和成功率，且 token 消耗减少约 75%。

## 8. 不足与局限

- **算力信息缺失**：论文未报告 GPU 型号、数量、训练/推理时长等具体算力信息，仅提供 token 消耗统计，复现成本难以精确评估。
- **真实机器人实验规模有限**：仅三个物理任务、每个条件 15 次试验，任务类型（放置、覆盖、插入）覆盖范围较窄，未涉及更多样化的操作场景（如 deformable object、多步装配等）。
- **模型与智能体配置单一**：实验仅采用 Codex with GPT-5.5 作为编码智能体，论文自身也指出未来需探索更广泛的基础模型与智能体框架。
- **基线覆盖不完全一致**：部分基线（CaP-X、RATs、ASPIRE）未报告 LIBERO-10 结果，不同方法的任务族覆盖不完全相同，整体对比的公平性存在一定限制。
- **物理评估标签主观性**：真实机器人成功由操作员提供最终标签，未讨论标注者间一致性或自动化验证手段。
- **技能迁移依赖接口对齐**：迁移效果建立在任务语义、观测格式与工具接口对齐的前提上；若真实环境的感知或控制接口与仿真差异过大，迁移效果可能下降，论文未系统研究对齐失败的情形。
- **推理时引导的奖励设计依赖智能体能力**：奖励函数由智能体根据任务上下文构造，其质量可能受基础模型能力影响，论文未深入分析奖励设计失败时的鲁棒性。
- **长期演化风险未充分讨论**：技能版本不断迭代，虽然验证门控可拒绝无效候选，但长期运行下技能库是否会出现漂移、冗余或冲突，论文未提供长期演化实验。
- **应用限制**：当前框架主要面向语言条件操作任务，对需要高频闭环控制、动态环境或人机交互的任务适用性尚未验证。
