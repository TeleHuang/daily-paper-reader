## 摘要
视觉-语言-动作（VLA）模型为自主机器人带来了前所未有的泛化能力；然而，其在实际部署中常常受限于不可靠的执行，以及针对特定机器人形态和任务进行微调的高昂计算成本。为弥合这一差距，我们提出 WayFinder，一种端到端、闭环的分层 VLA 框架，通过将高层任务推理与底层运动学控制解耦，规避了对微调的需求。WayFinder 利用零样本、离板（offboard）的多模态大语言模型（MLLM）策略来处理语言上下文和状态地图，以生成策略性航点。异步地，一个轻量级、板载（onboard）策略基于连续传感器反馈，以高频率执行实时运动学控制。我们在 Microsoft AirSim 中评估 WayFinder，在四个复杂度不同的环境和三种 MLLM 规模上进行测试，以平衡预测效果与计算效率。结果表明，与基线底层策略相比，WayFinder 实现了更优的导航可靠性。通过仅在导航失败时查询高层 MLLM，WayFinder 无需微调，最小化了昂贵的推理，并将导航成功率显著提升最多 27.45%。

## Abstract
Visual Language Action (VLA) models offer unprecedented generalization for autonomous robots; however, their real-world deployment is frequently bottlenecked by unreliable execution and the prohibitive computational cost of fine-tuning for specific robot embodiments and tasks. To bridge this gap, we propose WayFinder, an end-to-end, closed-loop hierarchical VLA framework that circumvents the need for fine-tuning by decoupling high-level task reasoning from low-level kinematic control. WayFinder utilizes a zero-shot, offboard Multimodal Large Language Model (MLLM) policy to process linguistic context and state maps for strategic waypoint generation. Asynchronously, a lightweight, onboard policy executes real-time kinematic control at high frequency based on continuous sensor feedback. We evaluate WayFinder in Microsoft AirSim, testing on four environments of varying complexity and three MLLM scales to balance prediction efficacy with computational efficiency. Our results demonstrate that WayFinder achieves superior navigation reliability compared to baseline low-level policies. By querying the high-level MLLM only during navigation failures, WayFinder eliminates the need for fine-tuning, minimizes expensive inferences, and significantly increases navigation success rates by up to 27.45%.

## 2. 方法论

### 2.1 核心思想：分层解耦 + 稀疏触发

- 将自主栈拆分为两个**异步**层：
  - **高层策略**：零样本、离板（offboard）的 MLLM（Gemma 3），负责在遇到复杂障碍或卡死时生成策略性恢复航点；
  - **底层策略**：轻量、板载（onboard）的高频运动学控制器，默认承担常规飞行与实时避障。
- 设计原则：**默认只用底层策略**，只有当底层策略检测到“进展停滞”时才触发 MLLM 查询，从而既利用常识推理，又规避微调成本与持续推理开销。

### 2.2 底层策略（基于 DRL）

- **问题建模**：局部点到点导航建模为 POMDP，元组为 (S, A, T, R)；采用 **DQN** 处理离散动作空间。
- **状态空间**：滑动时间窗 τ 融合外感与本体感知：
  - S_t = {D_k, c_k, θ_k}（k 从 t−τ 到 t）
  - D ∈ R^{144×256} 为 2D 深度图；c ∈ R² 为相对 GPS 坐标（相对目标/航点，避免过拟合绝对坐标）；θ 为 IMU 航向。
- **动作空间**：离散的平移（米）与偏航旋转（度）命令，交由机载飞行控制器转为连续加速度。
- **转移与避障**：AirSim 负责物理与渲染；引入**确定性碰撞规避算法**——短程距离传感器检测到障碍即中止本次移动，从停止位置采样新状态。
- **奖励函数**：因碰撞被规避机制消除，奖励仅聚焦路径效率与时间约束：
  - r_t = λ_p·d_t + λ_t·r_step + r_terminal
  - d_t = ‖p_t − g_t‖₂（欧氏距离）
  - r_step 为每步常数惩罚；r_terminal 到达目标半径给大正奖励，超步数上限 L 给重罚以抑制死循环。
- **网络结构**：三段卷积（ReLU）提取深度图空间特征 → 展平为 25,088 维 → 与 τ=3 的 GPS/IMU FIFO 队列拼接 → 3 层 128 节点 MLP → 输出各离散动作的 Q 值。
- **训练加速**：预先离散化 AirSim 可导航空间并缓存所有自中心深度图与碰撞状态，训练时间从数周降至数小时。
- **离线 A\* 路径生成**：用 A\* 最优步数量化路径难度，并划分训练/验证/测试集（验证与测试来自训练未见区域）。
- **课程学习与经验回放**：由易到难渐进训练；用 100 GB 内存的高容量回放缓冲区 + 随机采样缓解灾难性遗忘；基于静态 A\* 验证集早停并冻结最优权重。

### 2.3 高层策略（基于 MLLM）

- **触发条件**：在滚动窗口 N 上计算空间进展
  - Δρ_t = d_{t−N} − min_{k∈[t−N,t]}(d_k)
  - 若 Δρ_t < ε，则 T_t = True，判定为停滞（死胡同/无限循环），暂停底层策略、重置时间窗以防误触发。
- **视觉状态地图 M_t**：不直接输入 RGB-D 原始数据，而是抽象为 2D 俯视 RGB 图，按投影自底向上包含：
  1. 黑色=自由空间；2. 白色=障碍；3. 灰色=未知；4. 紫色线与圆=历史轨迹；5. 红色三角=历史航点；6. 绿色十字=起点；7. 蓝色方块=当前位置；8. 黄色星=全局目标。
  - 该设计针对现代 MLLM（SigLIP 等视觉编码器）的分词特性，用高对比色与几何图元优化视觉特征提取。
- **为何不直接用像素索引映射坐标**：Gemma 3 等使用动态缩放与切片（Pan & Scan，受 LLaVA 启发），会破坏像素与空间坐标的映射，导致精度损失。
- **语言提示**：结构化文本模板，显式给出机器人/目标/起点坐标、历史轨迹数组、历史航点数组、颜色语义，并要求仅输出安全且未尝试过的航点，格式为 `[STRATEGY]: ... [WAYPOINT]: (x, y)`。
- **全局地图构建（射线投射）**：深度图 → 相机坐标系 3D 点（用焦距与主点归一化，考虑球面畸变沿光轴投影）→ 沿 Y 轴空间滤波（忽略地面与高空障碍如电线）与深度地平线阈值 → 投影到局部 XZ 平面 → 生成三元占据栅格（free=0 / occupied=1 / unknown=−1），判定规则为：
  - z_grid < z_obs − δ_occ → free；|z_grid − z_obs| ≤ δ_occ → occupied；z_grid > z_obs + δ_occ → unknown。
  - 栅格按航向旋转、按位置平移后更新世界地图，并用掩码保证只有新观测的自由/占据单元覆盖旧值。

### 2.4 闭环流程

- 底层策略持续执行 → 检测停滞 → 触发高层 MLLM 生成恢复航点 → 新航点替代当前目标 → 重置触发标志 → 恢复高频底层控制 → 到达航点后目标切回原全局目标。

## 6. 主要结论与发现

- **整体性能**：仅用底层策略时准确率为 **44.55%–83.71%**；引入 MLLM 高层后提升至 **72.00%–96.64%**，最高提升 **27.45%**。
- **规模效应**：导航准确率与恢复率随 Gemma 3 参数量（4B→12B→27B）**单调上升**，失败恢复率相应下降，体现计算效率与可靠性的明确权衡。
- **地图观测条件**：部分观测（射线投射）地图相对完全观测真值地图恢复率下降很小，且 27B 模型下降最小，说明局部地图对生成恢复航点已足够，机器人视野外的全局信息并非关键。
- **消融关键发现**：
  - 语言提示中的**显式坐标最为关键**（去掉后恢复率从 56.79% 暴跌至 12.26%，相对路径长度升至 1.46）；
  - 去掉航点历史会导致 MLLM 重复生成相同失败航点，陷入无限循环（降至 48.02%）；
  - 去掉视觉地图影响相对温和（55.62%），说明 MLLM 能从语言坐标数组外推全局结构；
  - **反直觉结果**：用 AirSim 真值占据栅格替代射线投射地图反而导致性能下降（53.45%），作者推测局部化、部分观测的地图更能迫使 MLLM 从机器人自中心视角推理。
- **总体论断**：仅在失败时稀疏查询 MLLM 的零样本分层框架，可绕过微调、数据稀缺与高频推理限制，且该范式可推广到 DRL 之外的多种底层控制器。

- **指标覆盖不完整**：部分观测地图仅报告恢复率（1,289 条路径），缺少完整准确率与失败恢复率；论文自述失败恢复率可通过改进触发条件缓解，但未实际验证。
- **算力信息

**算力信息透明度不足**：论文未披露 GPU 型号、数量与训练/推理的具体时长，仅给出间接线索（训练从数周压缩至数小时、100 GB 回放缓冲区、MLLM 部署于离板边缘服务器、全量评估约一天）。这使复现时难以对齐硬件预算，也无法判断 27B 模型在真实边缘设备上的推理延迟是否满足恢复时效要求。

- **MLLM 延迟与实时性未量化**：论文强调稀疏触发可规避高频推理，但未报告 4B/12B/27B 各自的单次查询延迟、触发频率分布及其对端到端任务耗时的影响，缺少延迟预算分析。
- **关键超参数敏感性未研究**：停滞判据阈值 ε、滚动窗口 N、目标半径、步数上限 L 等直接决定触发假阳性/假阴性，论文未给出敏感性分析或自适应调节方案。
- **失败恢复率的改进主张未实证**：作者自述失败恢复率可通过改进触发条件缓解，但仅停留在讨论层面，未提供对应实验。
- **跨控制器泛化缺证据**：论文声称该分层范式可推广至 DRL 之外的底层控制器，却未做任何替换底层策略的对照实验。
- **定位依赖未讨论**：状态空间含相对 GPS 坐标，在 GPS 拒止或室内环境中如何退化、是否仍可工作，论文未涉及。
- **语言与模型家族泛化未验证**：提示模板与坐标格式是否对多语言、其他 MLLM 家族（如 LLaVA、Qwen-VL）同样有效，缺少迁移测试。

## 9. 总体评价与启示

- **范式价值**：论文提出了一条与主流"后训练/微调 VLA"互补的轻量路线——**分层解耦 + 失败稀疏触发 + 零样本 MLLM 推理**，在不牺牲高频安全控制的前提下借用大模型常识，为移动平台/无人机等算力受限场景提供了可落地的工程思路。
- **方法论启示**：
  - **"何时查询"比"如何查询"更关键**：以物理进展停滞（Δρ_t < ε）作为触发信号，将 MLLM 从每步控制器降级为偶发"战略顾问"，既降本又抑制幻觉累积。
  - **提示工程需与视觉编码器对齐**：显式坐标锚定（最关键）、高对比图元、历史航点与轨迹数组，是针对现代 VLM 分词/切片特性（如 Pan & Scan）的务实设计。
  - **部分观测可能优于全局真值**：反直觉的消融结果提示，自中心局部地图能诱导模型进行更贴合机器人视角的推理，这对建图与提示设计有直接指导意义。
- **局限定位**：结论目前仅在 AirSim 仿真、单一底层 DQN、单一 MLLM 家族（Gemma 3）上成立，距离可作为通用机器人导航方案仍有明显差距。
- **后续可拓展方向**：真机与 sim-to-real 验证、自适应触发阈值、端到端延迟建模、跨控制器与跨模型家族泛化、与其他 VLA/分层导航方法的横向基准对比。
