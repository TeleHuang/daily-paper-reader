## 摘要
视觉语言模型（VLM）智能体能够通过视觉反馈和动作原语控制机器人，但重复的模型调用与冗余的观测会带来大量 token 开销。我们提出 PyRUA-Lean，一种交互式代码执行框架，将反馈驱动的原语组合与选择性观测相结合：智能体将经典机器人原语与学习到的视觉-语言-动作（VLA）策略组合为 Python 单元，在其中执行条件检查和局部重试，并且仅返回显式请求的图像与状态反馈用于重新规划。在来自 LIBERO-PRO、RoboTwin 2.0 和 RoboCasa365 的 700 个模拟任务实例上，我们将 PyRUA-Lean 与使用相同 GPT-6 Astra 规划器和底层机器人原语的工具调用基线进行比较。在相同的 LLM 调用预算下，PyRUA-Lean 将总体成功率从 63.1% 提升至 71.7%。在两者均解决的实例上，它使用的 LLM 调用次数减少 49%，输入 token 减少 65%。

## Abstract
Vision language model (VLM) agents can control robots through visual feedback and action primitives, but repeated model invocations and redundant observations incur substantial token overhead. We introduce PyRUA-Lean, an interactive code-execution framework that couples feedback-driven primitive composition with selective observation: the agent composes classical robot primitives and learned vision-language-action (VLA) policies into Python cells that perform conditional checks and local retries, returning only explicitly requested images and state feedback for replanning. Across 700 simulated task instances from LIBERO-PRO, RoboTwin 2.0, and RoboCasa365, we compare PyRUA-Lean with a tool-calling baseline using the same GPT-6 Astra planner and underlying robot primitives. Under equal LLM-call budgets, PyRUA-Lean increases overall success from 63.1% to 71.7%. On instances solved by both agents, it uses 49% fewer LLM calls and 65% fewer input tokens.

## 2. 方法论：PyRUA-Lean 的核心思想与关键技术

- **基本定位**：PyRUA-Lean 全称 Python for Lean Robot-Use Agents，是一个交互式代码执行框架，构建在 RPent 的机器人栈和原语实现之上，包括经典运动/感知原语与冻结的 VLA 策略。
- **交互模式**：
  - 机器人被暴露为 Python 对象 `robo`，其方法调用原语并返回结构化结果，如物体位置、运动结果。
  - VLM 通过 `python(code)` 工具生成 Python 代码单元。
  - 运行时执行代码单元，返回反馈，供下一个代码单元使用。
  - 每个 episode 内维护持久 Python 命名空间，变量和辅助函数跨单元保留；但评估中无跨 episode 记忆。
- **反馈驱动原语组合**：
  - 一个代码单元可组合多个原语，并根据执行结果做条件分支、局部重试、循环和状态检查。
  - 例如：接近物体，若成功则尝试抓取，否则重试或停止；这些过程在单元内完成，不需额外 LLM 调用。
  - 未捕获异常会终止当前单元并返回 traceback，但异常前已赋值变量仍保留，允许后续单元修正。
  - 任务成功后，运行时会在执行动作原语前终止单元；外部 watchdog 执行两小时 episode 上限。
- **选择性观测与上下文管理**：
  - 中间结果默认保留在运行时，不自动加入 LLM 对话。
  - 智能体通过显式 `print` 和 `robo.show` 请求状态与相机图像，请求内容在单元结束时统一返回。
  - 相机图像可以只在任务未完成时请求；成功执行可能返回零图像。
  - 上下文控制的是“新增反馈”，不是删除历史；Codex CLI 保留完整对话，接近 272K token 时压缩总结。
- **程序化计算与技能复用**：
  - 代码单元可进行任务特定计算，例如从世界坐标图计算碗底高度、拟合平面、拟合圆弧、计算抓取偏航角。
  - 可定义辅助函数，如受保护下降、检查式移动，并在后续单元复用。
- **对比基线**：工具调用式 RPent 智能体。每个依赖前序结果的工具调用通常需要新的 VLM 回合；运动调用自动返回图像和状态，容易造成冗余上下文。

  - H1：同等 LLM 调用预算下，PyRUA-Lean 成功率更高。
