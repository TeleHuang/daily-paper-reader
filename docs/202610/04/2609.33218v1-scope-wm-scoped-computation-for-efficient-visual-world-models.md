## 摘要
视觉世界模型通过预测未来观测来实现机器人规划，但稠密潜在状态传播和样本密集型轨迹优化会带来高推理延迟和峰值内存占用，限制了其在资源受限平台上的实时部署。现有稀疏世界模型加速方法要么依赖无引导的 token 稀疏化，这可能丢弃规划相关信息并限制可实现的稀疏度；要么引入沉重的辅助模块和繁琐的多阶段训练流程。在这项工作中，我们提出 Scope-WM，一种高效的视觉世界模型，它将计算范围限定在预测相关的潜在区域和有前景的动作序列上。Scope-WM 将预测相关性蒸馏到一个轻量级的动作条件选择器中，并且仅对选定 token 的紧凑子集应用完整动力学预测。它使用前景状态及其变化的紧凑摘要来更新其余 token，使背景能够在无需昂贵的 token 间交互的情况下感知前景动态。在规划过程中，Scope-WM 保留并复用初始 MPC 搜索中发现的高质量动作序列，从而在降低的 rollout 预算下聚焦后续搜索。由此得到的流程仅需一次选择器蒸馏，随后对稀疏世界模型进行单个联合训练阶段。在具有挑战性的 Push-T 任务上，Scope-WM 将峰值 GPU 内存占用和规划时间分别降至稠密 DINO-WM 的 18.1% 和 14.3%，对应 6.97 倍的规划加速，同时保持有竞争力的任务性能。在五个不同的视觉规划任务上的进一步评估证明了 Scope-WM 的普遍适用性。代码可在 https://github.com/ChunZheng2022/Scope-WM 获取。

## Abstract
Visual world models enable robotic planning by predicting future observations, but dense latent-state propagation and sample-intensive trajectory optimization incur high inference latency and peak memory usage, limiting real-time deployment on resource-constrained platforms. Existing sparse world-model acceleration methods either rely on unguided token sparsification, which may discard planning-relevant information and restrict achievable sparsity, or introduce heavy auxiliary modules and cumbersome multi-stage training pipelines. In this work, we present Scope-WM, an efficient visual world model that scopes computation to prediction-relevant latent regions and promising action sequences. Scope-WM distills prediction relevance into a lightweight action-conditioned selector and applies full dynamics prediction only to a compact subset of selected tokens. It updates the remaining tokens using a compact summary of foreground states and their changes, allowing the background to perceive foreground dynamics without costly token-to-token interactions. During planning, Scope-WM preserves and reuses high-quality action sequences discovered during the initial MPC search, focusing subsequent search under reduced rollout budgets. The resulting pipeline requires only a one-off selector distillation followed by a single joint training stage for the sparse world model. On the challenging Push-T task, Scope-WM reduces peak GPU memory usage and planning time to $18.1\%$ and $14.3\%$ of those of dense DINO-WM, respectively, corresponding to a $6.97\times$ planning speedup, while maintaining competitive task performance. Further evaluations across five diverse visual planning tasks demonstrate the general applicability of Scope-WM. Code is available at https://github.com/ChunZheng2022/Scope-WM.

# Scope-WM 论文深度总结

## 1. 核心问题与研究动机

- **背景**：视觉世界模型（visual world model）通过预测未来观测，使机器人能够在执行前评估候选动作，是视觉模型预测控制（MPC）规划的核心范式。近期以 DINO-WM 为代表的方法在冻结 DINOv2 编码器提取的 patch 级特征空间中预测未来，实现任务无关的零样本规划。
- **核心痛点**：patch 级公式计算代价高昂。每个 MPC 步中，模型需对 CEM 采样出的大量动作序列、在长预测视野上反复传播**全部视觉 token**，导致规划延迟与峰值显存随 token 数和 rollout 种群数同步增长，难以在资源受限平台上实时部署。
- **现有稀疏加速方案的不足**：
  - **无引导 token 稀疏化**（如随机丢弃 patch）：可能丢弃规划相关信息，且可安全施加的稀疏度受限。
  - **重辅助模块 + 多阶段训练**（如 DDP-WM）：引入动态定位网络与前景-背景交叉注意力，训练流程繁琐。
- **更深层的问题**：高效稀疏想象不只是"保留多少 token"，而是一个**三层耦合的计算分配问题**——哪些 token 需要准确动力学预测、剩余 token 如何在不消除计算节省的前提下演化、更便宜的潜在 rollout 如何转化为更高效的轨迹优化。任一环节失配都会抵消收益。

## 2. 方法论

### 2.1 核心思想

Scope-WM 在 DINO-WM 基础上，将计算"范围化"到**预测相关的潜在区域**和**有前景的动作序列**，在三个互补层面分配计算：

- **Token 层**：Distilled Relevance Selection（DRS），识别需要完整动力学预测的紧凑 token 子集。
- **动力学层**：Foreground-Delta Background Update（FDBU），用轻量前景条件计算更新剩余 token，替代稠密 token 间交互。
- **规划层**：Elite-Bank CEM（EB-CEM），把后续轨迹搜索集中在初始 MPC 发现的高质量动作序列附近。

整体流程仅需**一次性选择器蒸馏 + 单阶段稀疏世界模型联合训练**。

### 2.2 关键技术细节

**（1）DRS：蒸馏相关性选择**

- **教师相关性目标**：从训练好的稠密 DINO-WM 教师计算潜在预测损失 `L_T`，用**梯度×输入**评分估计每个视觉 token 对教师预测损失的贡献：`r̃_{t,i} = ||x_{t,i} ⊙ ∂L_T/∂x_{t,i}||₂`；再帧内归一化得到软相关性目标分布 `q_{t,i}`。
- **轻量相关性头**：将视觉特征、本体状态、动作嵌入分别经线性投影后相加，送入小 MLP 产生相关性 logit `s_{t,i}`；温度缩放 softmax 得预测分布 `π_{t,i}`。
- **蒸馏损失**：最小化 `q` 与 `π` 的 KL 散度 `L_DRS = DKL(q || π)`。
- **推理**：按 `s` 取 Top-K 生成二值前景掩码 `m_{t,i}`，划分前景集 `F_t` 与背景集 `B_t`。选择器设计刻意轻量——因冻结 DINOv2 patch token 已通过自注意力全局上下文化，仅需 token-wise MLP，rollout 开销可忽略，且能产生状态、动作、预测目标感知的掩码。

**（2）FDBU：前景-差分背景更新**

- 稀疏动力学预测器**仅作用于前景 token**：`Ẑ^F = f_θ(Z^F)`，Transformer 注意力成本从 `O((HN)²)` 降至 `O((HK)²)`，`K ≪ N`。
- 计算前景差分 `Δ^F_{t+1,i} = ẑ^F_{t+1,i} − z^F_{t,i}`，并分别对前景状态与前景运动做**均值池化**，融合为前景动力学上下文 `c_{t+1} = ψ_c([z̄^F, Δ̄^F])`。
- 对每个全网格 token，用轻量 MLP 独立预测残差更新 `u` 与标量门 `γ = σ(ψ_g(...))`；**仅背景 token** 接受门控残差更新：`z̃^B = z + α(1−m)γu`。
- 最终全网格预测由前景预测散布回全网格、背景经 FDBU 更新合成：`z̃ = m·ẑ^F + (1−m)·z̃^B`。
- 训练用**全网格潜在预测损失** `L_WM = MSE(Z̃, Z*)` 联合监督前景预测与背景更新，**无需单独训练阶段**。

**（3）EB-CEM：精英库 CEM**

- **观察**：增加 CEM 样本数在低样本区间显著提升成功率，但很快饱和；且后期 MPC 步恢复能力有限——早期动作一旦把状态带入不利区域，后续重规划难以挽回。
- **机制**：初始 MPC 步用大种群（`M_front=300`）强调早期探索，之后降至 `M_later=100`；把初始步最终 CEM 迭代中最好的 `M_b` 个候选存入**持久精英库 B**。
- 后续每个 CEM 迭代，`η` 比例种群在库中精英附近做高斯扰动局部精化（`A_local = B + λσ ⊙ ξ`），其余从当前 CEM 高斯全局采样；两者合并构成最终候选集。精英库初始化一次、后续不再平移或替换。
- 该机制**不改变规划目标与世界模型**，与稀疏模型互补：DRS/FDBU 降低单次 rollout 成本，EB-CEM 改善跨 MPC 步的搜索预算分配。
