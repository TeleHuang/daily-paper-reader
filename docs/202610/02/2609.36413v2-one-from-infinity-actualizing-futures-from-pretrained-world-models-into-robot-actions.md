## 摘要
预训练的视频世界模型能够为一个场景给出许多合理的未来，但机器人必须实现与任务条件精确对应的那一个。为了将世界模型转化为可执行的机器人策略，现有方法利用大规模机器人数据和计算资源对庞大的世界模型骨干进行微调。我们挑战这一现状，认为昂贵的部分已在世界模型预训练中支付，因为视频世界模型的表示空间已经铺陈出多样的潜在未来。在这种情况下，剩下的就是选择能够完成任务的未来，并读出实现该未来的动作。我们将这一任务形式化为“实现”（actualization），即在冻结世界模型提供的先验之上学习任务条件的选择与实现。这可以通过一个极小的 actualizer 模型来解决。我们在冻结的世界模型编码器之上实现了 RoboActualizer，其参数少至 60M。该 actualizer 由两个轻量级 DiT 专家组成，通过流匹配联合预测未来隐变量和动作。该模型可以完全在单张 32 GB 峰值内存的 GPU 上训练。与现有 WAM 和 VLA 相比，RoboActualizer 的可训练参数最多减少 100 倍，在 LIBERO、LIBERO-Plus、RoboTwin 2.0 等仿真基准以及两个真实平台上的五项任务上取得了出色性能，且延迟低至 39 ms，可实现实时控制。

## Abstract
A pretrained video world model admits many plausible futures for a scene, but a robot must realize the exact task-conditioned one. To turn world models into executable robot policies, existing methods fine-tune the heavy world model backbone using large-scale robot data and computational resources. Challenging this status quo, we argue that the expensive part has already been paid in the world model pretraining since the representation space of a video world model lays out the diverse potential futures. In this case, what remains is to select the future that accomplishes the task and to read out the actions that realize it. We formalize this task as actualization, which learns a task-conditioned selection and realization on top of a prior supplied by a frozen world model. This can be solved by a tiny actualizer model. We implement RoboActualizer with as few as 60M parameters on top of a frozen world model encoder. The actualizer is composed of two lightweight DiT experts that jointly predict future latents and actions by flow matching. The model can be trained entirely on a single GPU with 32 GB peak memory. With up to 100x fewer trainable parameters than existing WAMs and VLAs, RoboActualizer reaches great performance on simulation benchmarks including LIBERO, LIBERO-Plus, RoboTwin 2.0 and five tasks on two real-world platforms, with a low latency of 39 ms that allows real-time control.

## 1. 核心问题与研究动机

- **背景**：在互联网规模视频上预训练的世界模型（如 V-JEPA 2.1、Wan、Cosmos 等）已成为强大的"世界如何演化"预测器。其本质特征是**不承诺单一结局**：同一初始场景可对应多种合理未来，这是通用世界模型的必要属性。
- **矛盾**：机器人恰恰需要完成**一个特定任务**并输出精确动作。世界模型的"多未来"特性与机器人的"单一任务"需求之间存在鸿沟。
- **现有两条路线及其代价**：
  - **规划式（MPC）**：冻结世界模型，在测试时对候选动作做大量想象 rollout 搜索。代价在推理端——每次决策需多次 rollout，控制频率受限；且目标通常是目标图像或手工设计的代价函数，而非语言指令。
  - **世界-动作模型（WAM）**：用大规模机器人数据与算力微调庞大骨干，把动作预测吸收进世界模型。代价在训练端——需更新重骨干，计算开销巨大。
- **核心论点**：昂贵的部分（对场景动力学的建模）**已在世界模型预训练中支付完毕**。冻结表示空间里已经铺好了多样潜在未来，剩下要做的只是"**选择**能完成任务的未来"并"**读出**实现它的动作"。选择远比动力学建模廉价。
- **形式化任务：Actualization（现实化）**——在冻结世界模型提供的先验之上，学习任务条件的选择与实现。

## 2. 方法论

### 2.1 核心思想：先验固定，只学选择与读出

- 世界模型 `g_φ` 将短片段 RGB 观测 `x_{t-Δ:t}` 编码为隐表示 `z_t ∈ R^{N×D}`（N 个空间 token，维度 D），因其跨帧注意力，`z_t` 编码的是整段 clip 的动力学，天然指示"接下来可能发生什么"。
- 未来隐目标 `z+_{t:t+H}` 由同一 `g_φ` 编码，在未来若干离散时刻采样：`z+_{t,h} = g_φ(x_{t+h-Δ:t+h})`。
- 关键分解（贝叶斯）：给定 `z_t` 与指令 `ℓ`，未来与动作的联合分布分解为三项：
  - **先验** `p(z+ | z_t)`：由冻结世界模型给出（多任务混合分布，每个任务对应一个分量 `F_ℓ(z_t)`）；
  - **选择** `p(ℓ|z+,z_t)/p(ℓ|z_t)`：唯一必须从机器人数据学习、用于把先验重加权到任务分量的部分；
  - **实现** `p(a_{t:t+H}|z+,z_t,ℓ)`：把选中的未来映射为动作。
- 学习目标为最大似然：`min_θ E_D[−log q_θ(z+, a | z_t, ℓ)]`，其中 `z_t = g_φ(x)` 且 `φ` 固定。由于 `F` 的几何已由冻结空间给出，`q_θ` 只需定位分量，复杂度由"选择"而非"场景动力学"决定——这正是极小模型够用的原因。对比之下，先前工作把 `φ` 一并优化，必须同时塑造先验与策略，难度高得多。

### 2.2 为什么小模型可行（表示论论证）

- 宽度为 `d_model` 的 actualizer 最多只能估计秩为 `d_model` 的几何分量，其能力受 `z_t` 前 n 个主成分约束。
- 在 LIBERO 演示的 V-JEPA 2.1 latent 上，`d_model = 384`（DiT-S 宽度）即可保留 **93.8%** 方差，跨基准稳定（损失仅 6.2%）——说明该表示空间本质低维。
- 但朴素 v-prediction 目标含**满秩各向同性高斯噪声**，窄网络无法拟合，故采用 **x-prediction（clean-sample parameterization）**，直接预测 `z+` 本身，其与输入同样具有低秩结构。

### 2.3 模型架构（RoboActualizer）

- **视觉编码器**：冻结 V-JEPA 2.1 ViT-L/16-384（约 300M），float32、eval 模式，不进优化器与 checkpoint；输入 clip 为 `{t−6, t−4, t−2, t}`（clip len=4，间隔 2），取最后时间组，得 392×1024 token。
- **Actualizer**：两个轻量 DiT（DiT-S，约 60M）组成 **Mixture-of-Transformers（MoT）**：
  - **latent expert**：预测任务条件未来 latent（实现"选择"）；
  - **action expert**：预测实现该未来的动作 chunk（实现"读出"）；
  - 两专家权重独立，通过**共享自注意力**交互；图像 token 与噪声 latent 走 latent 分支，噪声动作 token 走 action 分支；指令经冻结 UMT5-XXL 文本编码器（128 token×4096）与 8 维本体感知（合并为 129 个 context token）通过**交叉注意力**条件化两分支。
- **细节**：12 层 pre-norm 块；AdaLN-single 条件化；RoPE 位置编码（图像 3D RoPE 按 frame/h/w 分 12/10/10 对，动作 1D RoPE 与图像帧共享步轴）；FFN ratio 4；输出头零初始化；latent 按通道归一化（统计量随 checkpoint 保存）。
- **损失**：两专家独立采样噪声水平 `τ_a, τ_z ~ U(0,1)` 经 shift `s=5` 映射，在**速度空间**计算带截断分母的 x-prediction 损失：
  `L_a = E‖(a−â)/max(1−τ_a,0.05)‖²`，`L_z = E‖(z+−ẑ+)/max(1−τ_z,0.05)‖²`，总损失 `L = L_a + λ_z L_z`（λ_z=1）。
- **训练效率关键**：因 `g_φ` 冻结，所有 latent 可**离线预计算并缓存**，训练全程无需前向世界模型。
- **推理**：编码器每步仅前向一次；仅小型 actualizer 迭代 K 步去噪。部署时丢弃未来 latent 预测（action-only 模式），可缓存干净帧中间特征，进一步降延迟。

## 3. 实验设计

### 3.1 数据集与场景

- **LIBERO**：4 个任务套件（Spatial / Object / Goal / Long），1,712 条演示、277,713 帧（20 Hz LeRobot 格式）。
- **LIBERO-Plus**：LIBERO 的扰动变体，7 个扰动维度（Camera / Robot / Language / Light / Background / Noise / Layout），共 10,030 个扰动任务实例；**仅在 LIBERO 演示上训练，直接零微调迁移**，不做任何数据增强。
- **RoboTwin 2.0**：50 个双臂操作任务，每任务随机抽 50 条演示（共 2,500 episodes、564,911 帧），在 Clean 与 Random（随机背景、杂乱桌面、随机光照、桌高抖动）两种设置下各评 25 episodes。
- **真实机器人**：
  - **FANUC CRX-10iA** 单臂 + 夹爪：Mug Hanging（挂杯）、Cooking Sequence（多阶段烹饪），各约 100 条遥操作演示（SpaceMouse，10 Hz）。
  - **Unitree G1** 人形 + Dex3-1 灵巧手：Box Packing、Cup Insertion、Plate Handover，各约 170 条演示（30 Hz）。

### 3.2 对比基线

- 仿真：OpenVLA（279M）、π0（3.3B）、π0.5（3.3B）、π0-Fast、UniVLA（123M）、Motus（5.9B）、WorldVLA（7.0B）、Fast-WAM（6.0B）、DC-WAM（6.0B）、LingBot-VA（5.3B）。
- 真机：π0.5（VLA 基线，从预训练权重微调）、Fast-WAM（WAM 基线，从头训练）。
- 评测协议：闭环、无测试时调优/动作集成/测试时增强；初始状态取自基准自带 init-state 文件，seed=42；不做 checkpoint 选择，统一报告最终 checkpoint。

### 3.3 主要结果

- **LIBERO**：平均成功率 **98.0%**（Spatial 98.4 / Object 100.0 / Goal 96.6 / Long 96.8），仅 60M 可训练参数，超过 100× 参数量的基线。
- **LIBERO-Plus**：**63.1%**，优于 Fast-WAM 的 51.5%、DC-WAM 的 60.9%、π0-Fast 的 61.6%，显著优于 OpenVLA 的 28.5%。
- **RoboTwin 2.0**：**58.8%**（Clean 57.8 / Random 59.9），对比 Fast-WAM 41.9%、π0.5 31.4%、LingBot-VA 17.2%。
- **真机**：FANUC Mug 95% vs Fast-WAM 10%、Cooking 60% vs 15%；G1 Box 77% vs π0.5 57%、Cup 83% vs 50%、Plate 90% vs 30%。

### 3.4 消融实验

- **latent 预测的必要性**：去掉 latent 预测目标（等价于在冻结 V-JEPA 表示上挂一个流匹配策略），成功率从 60% 骤降至 **17.9%**。
- **表示空间对比**：DINOv3 39.7%、WAN VAE 25.9%、V-JEPA 单帧 46.4%、V-JEPA 单帧×4 帧 44.8%、V-JEPA 视频分支×4 帧 **60.0%**——说明 latent 的**未来可预测性**比其表示能力更重要。
- **算力分配**：世界模型 80M + DiT-S = 50.7%；80M + DiT-B = 53.2%；300M + DiT-S = 60.0%；300M + DiT-B = 61.0%——**放大冻结世界模型比放大 actualizer 更有效**。
- **架构消融**：Single DiT 51.8% vs MoT 60.0%；v-prediction 52.7% vs x-prediction 60.0%；加宽 head 48.5% vs 不加 60.0%。

## 4. 资源与算力

- **训练**：在缓存的 V-JEPA latent 上训练，仅优化约 60M 参数，**单张 NVIDIA PRO 6000（32 GB 峰值显存）15 小时**完成 LIBERO 训练，无需任何具身预训练。
- **对比**：WAM 基线 Fast-WAM 有 6B

可训练参数、需在数十至数百张 GPU 上以大规模机器人数据联合微调世界模型与策略，训练成本高出约两个数量级。
- **训练全程无需世界模型前向**：由于 `g_φ` 冻结，LIBERO 全部演示的 latent 可一次性离线编码并缓存为固定张量，训练循环只读缓存、只反传 60M 参数的 actualizer，这是 15 小时单卡预算的根本原因。
- **推理成本**：每步仅需视觉编码器前向一次（可缓存干净帧的中间特征进一步摊薄），随后是小模型 K 步去噪；相比 MPC 路线需在测试时对候选动作做大量想象 rollout，控制频率不受世界模型规模直接约束。

## 5. 关键洞察与讨论

- **"先验已付清、只需选择"是全文的枢纽**：把昂贵的动力学建模留在预训练阶段，把机器人学习问题重新定义为在冻结表示空间中的**条件重加权与读出**问题。这解释了为什么 60M 参数足以在多个基准上超过 3B–7B 的 VLA/WAM。
- **表示空间的"未来可预测性"比"表示能力"更重要**：消融显示 DINOv3（强表示、弱未来预测）仅 39.7%，而 V-JEPA 视频分支 60.0%。世界模型的价值不在于编码当前帧，而在于其 latent 本身携带"接下来会怎样"的低维几何。
- **低秩假设被经验验证**：DiT-S 宽度 384 即保留 93.8% 方差，说明 LIBERO 演示在 V-JEPA latent 上占据低维流形；因此**选择**（定位任务分量）比**建模**（塑造整片未来分布）简单得多，小模型才够用。这同时解释了为何必须用 x-prediction：v-prediction 的满秩各向同性噪声目标超出窄网络的拟合能力。
- **算力应投在冻结世界模型一侧**：80M→300M 带来的增益（50.7%→60.0%）远大于 actualizer DiT-S→DiT-B 的增益（60.0%→61.0%），提示"更大的冻结先验 + 更小的读出器"是更优的资源配置。
- **MoT 与 x-prediction 是工程上的关键**：Single DiT（51.8%）与 v-prediction（52.7%）都显著低于 MoT + x-prediction（60.0%），说明 latent 选择与动作读出需要**共享注意力但独立权重**，以在同一潜空间内对齐"选哪个未来"与"怎么做"。
- **冻结带来的零样本迁移**：LIBERO-Plus 上不做任何微调与增强即达 63.1%，说明表示空间中的选择机制对相机、光照、背景、布局等扰动具有内在鲁棒性——扰动改变的是先验分量的相对权重，而非分量本身的几何。

## 6. 局限性

- **受限于冻结世界模型的上限**：方法无法超越 `g_φ` 所编码的动力学；若目标任务超出预训练视频分布，latent 中不存在对应分量，actualizer 无从选择。
- **latent 缓存与存储开销**：离线预计算虽省算力，但需为整个数据集存储 latent（含多帧、多 token），数据规模增长时存储与 I/O 可能成为瓶颈。
- **长时程与精细力控任务**：LIBERO-Long（96.8%）虽高，但更长的多阶段任务仍存在误差累积；真机 Cooking 60% 明显低于 Mug 95%，提示阶段转换与接触密集型操作的鲁棒性仍有空间。
- **对本体感知与动作空间的适配**：8 维本体感知、固定 chunk 长度、特定机器人构型（单臂夹爪 / 人形灵巧手）需各自微调读出器，跨具身零样本能力未充分验证。
- **评测范围**：真机实验任务数与演示量相对有限（每任务约 100–170 条），统计置信区间与更广泛任务族的泛化性有待更大规模验证。

## 7. 结论与启示

- 论文提出 **Actualization（现实化）** 范式：在冻结世界模型的多未来先验之上，只学习**任务条件的选择**与**动作读出**，把机器人控制从"重训练世界模型"或"测试时重搜索"中解放出来。
- **RoboActualizer** 以约 60M 可训练参数（冻结 300M V-JEPA 2.1 + MoT DiT-S 双专家）在 LIBERO（98.0%）、LIBERO-Plus（63.1%，零微调）、RoboTwin 2.0（58.8%）与多台真机任务上全面领先更大规模基线，训练仅需单张 32GB GPU、15 小时。
- 更广泛的启示是：随着世界模型预训练日趋成熟，机器人学习的瓶颈可能从"建模动力学"转移到"**从无穷未来中选择并实现一个**"；而后者的复杂度由选择问题而非动力学问题决定，因而可以被极小、极廉价的模块承担。这为"冻结大世界模型 + 轻量任务读出"的通用机器人策略提供了有力的实证支持。
