## 摘要
世界动作模型（WAMs）利用预训练视频模型，通过联合预测未来视觉状态与动作，提升机器人控制的泛化能力。这种能力带来显著的推理成本，因为在去噪过程中会重复处理稠密的未来帧 token。已有方法通过 token 剪枝来应对，其在视频扩散模型中优先考虑视觉保真度以降低去噪成本。然而，这些方法在 WAM 的联合去噪过程中并未利用动作相关性来决定保留哪些未来帧 token。本文提出 Sparse-WAM，一种免训练的动作引导稀疏想象框架，通过选择性处理未来帧 token 来加速 WAM 推理。我们观察到，尽管未来表示不断更新，在连续去噪步骤之间，从动作 token 到未来帧 token 的注意力（动作到未来注意力）在空间分布上存在显著重叠。受此启发，我们提出动作引导的 token 选择，在保留跨帧上下文的同时保留特定帧中与动作相关的区域。然而，朴素实现会带来注意力评分和 token 打包的开销，从而抵消剪枝带来的计算节省。因此，我们引入 Pilot，一种高效引擎，通过轻量级评分和跨步骤复用 token 选择来降低稀疏推理开销。在 LIBERO 上使用 FastWAM-Joint，以及在 RoboLab-120 上使用 Cosmos 3 Edge，Sparse-WAM 在 NVIDIA RTX 4090 上相较于稠密 eager 推理分别实现了约 2.0 倍和 1.8 倍的推理加速，同时基本保持任务性能。

## Abstract
World-action models (WAMs) leverage pretrained video models to improve generalization in robot control by jointly predicting future visual states and actions. This capability comes at a substantial inference cost, as dense future-frame tokens are repeatedly processed during denoising. Prior methods address this by token pruning that prioritizes visual fidelity to reduce denoising costs in video diffusion models. However, these methods do not use action relevance to determine which future-frame tokens to retain during joint denoising in WAMs. In this paper, we propose Sparse-WAM, a training-free framework for action-guided sparse imagination that selectively processes future-frame tokens to accelerate WAM inference. We observe substantial overlap in the spatial distribution of attention from action tokens to future-frame tokens (action-to-future attention) between consecutive denoising steps, despite continued updates to the future representations. Motivated by this, we develop Action-Guided Token Selection to retain frame-specific action-relevant regions together with cross-frame context. However, a naive implementation can incur attention-scoring and token-packing overhead that offsets the computational savings from pruning. We therefore introduce Pilot, an efficient engine that reduces sparse inference overhead through lightweight scoring and cross-step reuse of token selections. On LIBERO with FastWAM-Joint and RoboLab-120 with Cosmos 3 Edge, Sparse-WAM achieves inference speedups of approximately $2.0\times$ and $1.8\times$, respectively, over dense eager inference on an NVIDIA RTX 4090, while largely preserving task performance.

# Sparse-WAM 论文深度总结

## 1. 核心问题与研究动机

- **背景**：世界动作模型（World Action Models, WAMs）通过联合预测未来视觉状态与动作，利用时空先验提升机器人控制的泛化性与鲁棒性，代表工作如 DreamZero、Cosmos 3。
- **核心痛点**：WAM 在推理时需显式生成高分辨率未来帧，将大量视觉 token 注入每一步去噪过程。由于单步去噪成本随 token 数显著增长，反复处理未来帧 token 导致推理延迟高、控制频率受限。
- **现有方案的两条路线及其缺陷**：
  - **推理时移除想象**：训练时使用未来预测，推理时直接生成动作——丢失了未来预测带来的泛化收益。
  - **压缩未来帧 token**（低分辨率/紧凑潜变量/非对称去噪/特征复用）：仍将计算分配给与动作相关性有限的区域。
- **关键空白**：视频扩散模型中的 token 剪枝方法（如 ToCa、WorldCache）以**视觉保真度**为准则，而 VLA 中的剪枝方法（如 SpecPrune-VLA）针对**已观测输入**。在 WAM 中，未来帧 token 由噪声初始化并与动作 token 联合去噪，**哪些区域与动作相关无法预先确定**，因此不能直接沿用既有剪枝准则。
- **研究机会**：作者发现动作 token 对未来帧 token 的注意力（action-to-future attention）在相邻去噪步之间空间分布高度重叠，尽管未来表示本身持续变化——这为**跨步复用 token 选择**提供了依据。

## 2. 方法论

### 2.1 核心思想
提出 **Sparse-WAM**：一种**免训练**框架，利用动作到未来注意力作为 token 相关性的低成本代理，在线选择未来帧 token 进行稀疏计算，并跨去噪步复用选择；配合 **Pilot** 引擎降低选择与打包开销。

### 2.2 关键观察（动机支撑）
- **观察 1（动作–帧对齐 + 空间变化）**：帧级注意力图呈近似对角带，每个未来帧主要接收约 H/F 个连续动作查询的注意力，边界处查询还会关注相邻帧；同时注意力热点在不同未来帧间空间位置会移动。
- **观察 2（跨帧上下文一致性）**：排除热点区域后，跨帧注意力重叠度上升，说明存在跨帧稳定的上下文区域（如夹爪等非接触部位）。
- **观察 3（跨步注意力一致性）**：相邻去噪步的空间注意力分布高度重叠。定量结果：Cosmos 3 Edge 上平均相邻步重叠 **81.11%**，FastWAM-Joint 上达 **97.97%**；跨帧重叠较低，分别为 68.89% 与 81.85%。

### 2.3 动作引导的在线 Token 选择

- **评分**：将 H 个动作查询按时间对齐划分为 F 组（每组 H/F 个），对每帧的空间分数为该组动作查询在注意力权重上的加权和：
  - 定义 `S_ℓ(f,j) = Σ_{i∈I_f} α_{f,i} · U_ℓ(i,f,j)`，其中 `U_ℓ` 为跨头平均的动作到未来注意力；中心查询权重更大（边界查询会关注邻近帧）。
- **层质量筛选**：为每层打分 `Q_ℓ = R_ℓ(1 − E_ℓ)`，其中 `R_ℓ` 为帧对齐注意力质量，`E_ℓ` 为归一化空间熵；选出得分最高的 K_layer 层构成 `L_core`，聚合空间分数 `V(f,j)`。
- **帧特定核心 token（K_c）**：
  - 先构建公共候选池 `P = TopK_j(max_f V(f,j), N_s − K_s)`（保留容量给锚点）；
  - 再在池内按各帧自身分数选择 `C_f = TopK_{j∈P}(V(f,j), K_c)`，使保留位置可随热点漂移。
- **共享空间锚点（K_s）**：
  - 从「未被任何帧选为核心」的候选集 E 中，按 `μ_j / (1 + CV_j)` 排序选择，兼顾注意力强度与跨帧一致性（CV 为跨帧变异系数，作为惩罚项）；
  - 核心集与锚点集不相交，每帧恰好保留 K_c + K_s 个 token，序列长度固定。
  - 锚点仅在位置上共享，其表示仍是帧特定的、独立更新。

### 2.4 Pilot 高效执行引擎

- **低开销注意力剖析**：复用稠密条件前向（τ_d = 0 的全步）中已有的 query–key 点积，直接计算 `S_ℓ(f,j)`，**复用原始 log-sum-exp 归一化器**（而非仅对未来 key 归一化，以保持层质量评分中的注意力质量），不物化完整注意力矩阵、不做额外前向或 value 加权输出。
- **跨步复用与紧凑执行**：
  - 默认仅在每个 action chunk 的**初始步**做全量计算，构造选择并缓存视觉速度预测；后续稀疏步直接复用两者；
  - 复用原始位置索引与打包元数据，跨 Transformer 层和去噪步保持一致，固定每帧 token 预算保证序列长度恒定，利于编译执行。
- **被省略区域的采样更新**：被跳过的未来 token 仍参与采样。通过掩码 `M_v` 组合当前预测与缓存预测：`ṽ^(τ)_v = M_v ⊙ v^(τ)_v + (1 − M_v) ⊙ v^(τ_d)_v`，使采样器能更新全部未来潜变量；动作预测每步都重算。

## 6. 主要结论与发现

- **效率与性能**：
  - LIBERO（FastWAM-Joint）：**1.98×** 加速，FLOPs 降至 49.65%，平均成功率 **98.45%**，仅比稠密（98.75%）低 **0.30 个百分点**。

- **关键发现**：WAM 中对不断演化的想象 token 的稠密计算，对动作预测而言**部分是冗余的**；稀疏化可在基本保持任务性能的前提下实现显著加速。
- **消融结论**：核心 token 与共享锚点互补（35.5% vs 仅核心 34.5%、仅锚点 34.2%、随机 31.7%、稠密 36.8%），且组合方案加速比（1.809×）与仅核心方案相当。
- **权衡关系**：剪枝比例从 28.89% 升至 68.89%，加速从 1.45× 提升至 2.36×，但成功率从 37.5% 降至 28.3%。
- **鲁棒性**：LIBERO-Plus 上 Sparse-WAM 63.04% vs 稠密 70.89% vs 纯动作 FastWAM 51.96%——稀疏想象比「移除想象」更鲁棒，但仍不及稠密推理（损失 7.85 个百分点）。
- **FLOPs 不等于延迟**：Edge 上 Sparse-WAM FLOPs 占比更高（60.73% vs 50.35%），但延迟更低，说明固定稀疏序列长度与编译执行对实际延迟同样关键。

## 7. 优点

- **问题定位精准**：首次指出 WAM 联合去噪场景下，视觉保真度/观测相关性并非未来 token 保留的正确准则，转而使用动作到未来注意力。
- **免训练、即插即用**：无需额外训练或微调，可直接应用于现有 WAM，部署成本低。
- **动机–方法闭环严谨**：三条观察（帧对齐、跨帧上下文、跨步一致性）分别直接对应三项设计（分组评分、共享锚点、跨步复用），逻辑链条清晰。
- **工程实现考量充分**：Pilot 复用原始 LSE 归一化器、不物化完整注意力矩阵、复用打包元数据、固定序列长度以支持 CUDA Graph/torch.compile，避免「剪枝收益被选择开销吞噬」这一常见陷阱。
- **实验覆盖较广**：三个 WAM 主干、四个基准（含真实机器人）、多种扰动类别，并与 4 个强基线对比；对执行后端与匹配后端的差异做了透明披露。
- **对省略区域的处理完整**：通过掩码混合当前/缓存预测，保证采样过程对所有未来潜变量仍然有效，避免采样器失配。
