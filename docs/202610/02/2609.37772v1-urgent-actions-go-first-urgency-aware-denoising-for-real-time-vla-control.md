## 摘要
扩散与流匹配的视觉-语言-动作（VLA）策略通过迭代去噪生成动作块，带来显著的推理延迟，严重限制了实时机器人控制。现有加速方法将动作块视为单一整体计算单元，忽视了滚动时域控制的一个关键物理现实：动作是联合生成的，却按顺序被消费，从而导致执行紧迫性本质上是异质的。我们利用这一不对称性提出紧迫性感知去噪（UAD），一种新颖的推理时框架，根据每个动作在物理上何时被需要来分配去噪计算。UAD 在更少的去噪步骤后释放时间关键的紧急动作，同时将尾部动作持续进行的后台细化与物理执行重叠。然而，异质去噪引入两个关键挑战：紧急动作的提前释放误差，以及尾部动作的轨迹不一致性。UAD 通过两个核心机制优雅地同时解决这两个问题：轨迹协调（Trajectory Reconciliation），它重建统一的内部状态演化，以在不增加额外模型评估的情况下恢复联合去噪的一致性；以及幽灵动作校正（Ghost Action Correction），它利用未执行的幽灵延续来动态补偿剩余可执行动作中的提前释放误差。在多种 VLA 架构、仿真基准和真实世界操作任务上的广泛评估表明，UAD 在平均动作可用延迟上实现了最高 1.89 倍的加速，同时保持与采用最优去噪预算的原始推理相当的成功率，相比最先进的 VLA 加速基线提供了更有利的成功率-延迟权衡。

## Abstract
Diffusion and flow-matching Vision-Language-Action (VLA) policies generate action chunks through iterative denoising, incurring substantial inference latency that severely limits real-time robotic control. Existing acceleration methods treat an action chunk as a monolithic computational unit, ignoring a crucial physical reality of receding-horizon control: actions are generated jointly but consumed sequentially, resulting in inherently heterogeneous execution urgencies. We exploit this asymmetry to introduce Urgency-Aware Denoising (UAD), a novel inference-time framework that allocates denoising computation according to when each action is physically needed. UAD releases time-critical urgent actions after fewer denoising steps while overlapping the continued background refinement of tail actions with physical execution. However, heterogeneous denoising introduces two key challenges: early-release errors in urgent actions and trajectory inconsistency in tail actions. UAD elegantly resolves both through two core mechanisms: Trajectory Reconciliation, which reconstructs unified internal state evolution to restore joint denoising coherence without additional model evaluations, and Ghost Action Correction, which leverages non-executed ghost continuations to dynamically compensate for early-release errors across remaining executable actions. Extensive evaluations across multiple VLA architectures, simulation benchmarks, and real-world manipulation tasks demonstrate that UAD achieves up to a 1.89x speedup in average action availability latency while maintaining comparable success rates to vanilla inference with optimal denoising budget, offering a more favorable success-latency trade-off than state-of-the-art VLA acceleration baselines.

## 1. 核心问题与整体含义

- **研究背景**：扩散与流匹配（flow-matching）VLA 策略通过迭代去噪生成动作块（action chunk），动作质量高但推理延迟大，严重限制实时机器人控制。
- **现实瓶颈**：论文测量显示，典型场景中执行一个动作块约 500 ms，而生成下一个动作块约 300 ms；同步执行时机器人每个周期有超过 30% 时间空闲等待新动作，边缘设备更严重。
- **现有方法不足**：量化、剪枝、特征缓存、自适应步数减少、生成-执行重叠等加速方法，通常把动作块当作**单一整体计算单元**，对整个块使用统一去噪预算。
- **核心洞察**：滚动时域控制中，动作是**联合生成、顺序消费**的。块内动作的物理执行紧迫性本质异质：前部动作最紧急，其生成延迟直接决定机器人何时开始执行；尾部动作有更大时间缓冲，可与前部动作的物理执行重叠。
- **整体含义**：应按照“动作何时被物理需要”来分配去噪计算，而不是均匀分配。由此提出 **Urgency-Aware Denoising (UAD)**，一种推理时加速框架。

## 2. 方法论

### 2.1 核心思想

- 将动作块按执行紧迫性分为：
  - **紧急动作**：索引集合 \(\mathcal{U}=\{0,\dots,U-1\}\)，需立即执行；
  - **尾部动作**：索引集合 \(\mathcal{T}=\{U,\dots,H-1\}\)，有执行缓冲；
  - 每个推理周期实际只执行前 \(S\) 个动作，\(S\le H\)。
- UAD 让紧急动作用更少去噪步 \(K<N^*\) 提前释放，尾部动作保留最优步数 \(N^*\)，从而把尾部去噪与紧急动作的物理执行重叠。

### 2.2 关键技术细节

- **Urgency-Aware Early Release (UAER)**
  - 对紧急动作分配 \(N_i=K\)，对尾部动作分配 \(N_i=N^*\)。
  - 使用动作特定的 Euler 步长：
    \[
    x_i^k = x_i^{k-1} + \frac{1}{N_i}v_i^k
    \]
  - 紧急动作在 \(K\) 步后直接释放为可执行动作 \(a_i=x_i^K\)；尾部动作继续完整去噪。
  - 当紧急动作执行时间足以覆盖剩余尾部去噪时，尾部去噪延迟被完全掩盖。

- **Trajectory Reconciliation (TR)**
  - 问题：DiT 中动作 token 通过共享注意力耦合，异质步长会破坏联合去噪状态一致性，导致尾部动作也出现轨迹误差。
  - 方法：利用已计算并缓存的速度 \(v_i^k\)，按规范步长 \(1/N^*\) 重新积分，重建紧急动作的内部协调状态：
    \[
    x'^i_K = x^i_0 + \frac{1}{N^*}\sum_{k=1}^{K}v_i^k
    \]
  - **零额外 DiT 评估**，因为速度已缓存。
  - 当 \(K=1\) 时，第一次 DiT 评估与 vanilla 完全相同，因此可精确恢复 vanilla 状态；\(K>1\) 时虽不精确，但经验上仍显著降低尾部误差。
  - 重建后的紧急动作继续参与联合去噪，其未执行延续称为 **ghost states**，最终完全去噪结果为 **ghost actions** \(a'_i=x'^i_{N^*}\)。

- **Ghost Action Correction (GAC)**
  - 问题：已释放并执行的紧急动作存在提前释放误差，无法回溯修正。
  - 方法：用 ghost action 与已释放紧急动作之差估计累计误差：
    \[
    E=\sum_{i=0}^{U-1}(a'_i-a_i)=\sum_{i=0}^{U-1}(x'^i_{N^*}-x^i_K)
    \]
  - 将误差均摊到剩余可执行尾部动作 \(i=U,\dots,S-1\)：
    \[
    a_i=x^i_{N^*}+\frac{E}{S-U}
    \]
  - 物理语义处理：加性维度（如笛卡尔平移）直接相加；旋转在 \(SO(3)\) 上组合；离散维度（如夹爪开合）做 mask，避免误切换。
  - 对相对于固定或 chunk 级参考的动作表示，GAC 不适用，此时只用 UAER+TR。

- **实现细节**
  - 每动作时间条件：扩展 SmolVLA 和 π0.5，使每个动作 token 接受独立 flow time，复用预训练权重，无新增可训练参数。
  - 异步执行：紧急动作完成后同步 GPU 并释放到执行队列；尾部去噪在独立 CUDA stream 上继续。
  - 执行 \(S\) 个动作后，基于最新观测重新规划。
