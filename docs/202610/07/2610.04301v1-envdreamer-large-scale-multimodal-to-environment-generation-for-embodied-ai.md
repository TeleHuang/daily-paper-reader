## 摘要
大规模数据集和高容量模型加速了视觉与语言领域的进展。本工作引入一个平台，旨在为具身学习、世界模型和机器人学带来可比的收益。我们提出 EnvDreamer，一个利用大语言模型和视觉语言模型生成用于具身 AI 和机器人训练的 Unreal Engine 5 环境的框架。EnvDreamer 能够采样大规模、多样、可交互、可定制且通过验证器验证的虚拟环境，用于跨导航、交互和操作任务的训练与评估。我们通过大量生成场景和简单基线来展示该平台。在 EnvDreamer 生成环境中训练的策略，无需显式建图或人工任务监督，在涵盖导航、重排和操作的多个具身基准上取得有竞争力的结果。EnvDreamer 还支持面向真实到仿真研究的图像条件重建。最后，我们发布 EnvDreamer-20k，一个包含 20,000 个通过验证器验证的环境的数据集，附带任务程序、场景图、轨迹和元数据，以支持可复现的基准测试。

## Abstract
Large datasets and high capacity models have accelerated progress in vision and language. This work introduces a platform aimed at bringing comparable gains to embodied learning, world models, and robotics. We present EnvDreamer, a framework that uses large language and vision language models to generate Unreal Engine 5 environments for embodied AI and robot training. EnvDreamer enables sampling of large, diverse, interactive, customizable, and validator passed virtual environments for training and evaluation across navigation, interaction, and manipulation. We illustrate the platform with a large set of generated scenes and simple baselines. Policies trained on EnvDreamer generated environments, without explicit mapping or human task supervision, achieve competitive results on multiple embodied benchmarks spanning navigation, rearrangement, and manipulation. EnvDreamer also supports image-conditioned reconstruction for real-to-sim studies. Finally, we release EnvDreamer-20k, a dataset of 20,000 validator passed environments with task programs, scene graphs, trajectories, and metadata to support reproducible benchmarking.

## 2. 方法论：核心思想与关键技术细节

- **核心思想**：以自然语言（可选图像）为第一规范，通过"计划–编译–应用–验证"闭环，将语言描述自动转换为完全可交互、物理启用的 UE5 环境。
- **系统组成**：
  - **Home Agent**：基于 vLLM（GPT-5 级别）的智能体，接收文本/图像提示与系统信息（Remote Control API 命令、视口截图），用思维链（CoT）将请求分解为子任务，生成结构化 JSON 布局计划与任务列表。
  - **编译器**：将 JSON 计划编译为 Unreal Python 代码，仅在需要自定义规则、传感器或物理组件时回退到 C++。
  - **Evaluator Agent**：迭代式任务完成检查，验证场景布局、家具摆放与合理性，直到环境通过验证。
  - **验证器套件（Unit-style Validators）**：检查可玩性、物理一致性、目标完整性（可达性、碰撞、关节约束、任务谓词）。
- **工作流程（Plan–Compile–Apply–Validate 循环）**：
  1. 规划器提出场景程序（资产、摆放、关系）或布局描述（房间、边界、相机、材质）。
  2. 归一化器将提案对齐到轻量级场景图镜像。
  3. 编译器生成 Unreal Python 代码。
  4. 执行器通过 Remote Control 应用动作，捕获渲染结果与场景图差分。
  5. 验证器评估后决定接受或迭代修改。
  - 支持两种模式：**direct build**（实时编辑运行中的关卡）与 **layout build**（将可复用布局实例化为场景）。
- **多样性与交互性**：
  - 布局：从单间到多房间住宅及室外地块，房间数量、长宽比、连通模式可变。
  - 资产：大型资产库，含语义类别与关节部件；摆放规则反映常识性房间/位置偏好。
  - 材质与光照：每次加载可变化，模拟不同时段与外观。
  - 任务：从物体搜索、重排到工具使用与多步操作，编码为带显式前置条件与成功度量的可执行程序。
  - 物体支持抓取、放置、开关、状态切换、关节操作；电器有功能状态，容器可填充/清空。
- **图像到环境（Sim-to-Real）**：给定目标空间照片，vLLM 提出对齐图像的场景图，EnvDreamer 在 UE5 中实例化语义匹配资产，实现最小人工创作的仿真重建。
- **规模与效率**：场景表示为紧凑的 JSON 式程序，带确定性种子，支持静态数据集与训练时按需生成；可直接在 UE5 中加载，存储开销低。
- **机器人配置**：内置 Franka Emika Panda（7-DoF 操作臂）与 Unitree Go1（四足运动平台），共享统一的 RGB/深度/语义掩码/本体感知观测与动作接口，支持纹理、光照、杂乱度与物理参数的域随机化。

## 6. 主要结论与发现

- **性能优势**：EnvDreamer-20k 预训练在所有测试的导航、重排与操作基准上一致优于 ProcTHOR-10K 预训练，且零样本迁移能力强。

  - ArmPointNav：Scratch 24.6 → P-10K 37.9 → ED-20k 39.2。
  - Room Rearrangement：Scratch 3.2 → P-10K 7.4 → ED-20k 8.1。
- **规模效应**：性能随数据集规模（5k→20k）持续提升，验证了生成 20k 环境的决策。
- **质量优于规模**：通过完整验证器的 10k 环境可匹配甚至超过 20k 未验证环境，说明场景质量比单纯扩大规模更高效。

- **可扩展性**：场景由带确定性种子的紧凑程序表示，可轻松扩展到 20k 以上并按需生成。

## 7. 优点

- **语言优先、代码生成式范式**：以自然语言为第一规范，编译为 Unreal Python，降低环境创作门槛并支持快速迭代。
- **验证器驱动质量保障**：单元式验证器（可玩性、物理一致性、目标完整性）在生成时过滤失败模式，保证数据集质量，是相对其他程序化生成系统的关键差异点。
- **大规模 + 可复现**：EnvDreamer-20k 是目前最大的公共具身 AI 交互环境语料之一，附带场景程序、场景图、任务程序、验证结果与参考轨迹，支持精确再生与可复现基准。
- **多模态与真实到仿真**：支持图像条件生成，可将真实空间重建到仿真中，服务于 sim-to-real 研究。
- **多任务覆盖**：涵盖导航、重排、操作，任务程序带显式前置条件与成功谓词，支持长时程顺序交互。
- **丰富的诊断分析**：补充材料提供房间数/面积分布、物体共现 PMI、提示级多样性统计、失败模式分类等，分析细致。
- **公平对比设计**：与 ProcTHOR-10K 在相同架构、相同预算下对比，遵循统一评测协议。

## 8. 不足与局限

- **范围覆盖有限**：
  - 目前聚焦室内环境，室外场景虽被框架支持但未纳入当前数据集。
  - 缺乏复杂物理（液体、可变形物体）。
  - 仅支持单智能体任务，无多智能体验证器。
- **任务复杂度受限**：任务限于相对短时程（10–50 步）且单一解法，未覆盖长时程、开放式、多解法的真实世界复杂性。
- **生成效率瓶颈**：每个环境生成需 2–5 分钟，高并行时 CPU 瓶颈降低单实例吞吐；GPU 并行扩展效率从 100% 降至 24.2%。
- **验证器盲区**：罕见配置可能通过所有自动检查但仍显笨拙（如椅子技术上可达但视觉上嵌入角落）。
- **提示与图像歧义风险**：欠指定提示（如"让公寓更现代"）可能导致大规模材质变更并降低任务可行性；含镜面或玻璃墙的参考图像可能使规划器幻觉出额外房间或开口。
- **算力披露不足**：未明确报告总 GPU 数量、总训练时长与总 GPU 小时数，仅给出单次实验的 GPU 型号与吞吐量数据。
- **消融完整性**：部分消融（提示严格度、材质随机化）仅给出定性趋势，数值结果待补充，削弱了结论的量化支撑。
- **评测偏差风险**：所有下游评测仅用 RGB 输入，未验证其他传感模态下的表现；对比主要集中于 ProcTHOR-10K 一个预训练基线，与其他大规模环境生成系统（如 Infinigen、Holodeck）的横向对比有限。
