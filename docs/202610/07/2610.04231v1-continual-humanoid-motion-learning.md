## 摘要
人形机器人全身控制器如今能够跟踪多种动态运动，但它们通常以离线方式训练后便被冻结，因此教会这类控制器一项新技能往往会侵蚀其已掌握的技能。我们研究人形机器人全身运动的持续学习，其中单个控制器必须从顺序任务流中获取技能，且不能回访过去的数据。我们提出相似度引导的 LoRA-PNN，这是一种渐进神经网络（PNN）策略，通过轻量级低秩适应在复用跨技能知识的同时，从构造上防止灾难性遗忘。一种由动态时间规整构建、并通过最优传输聚合的两级运动相似度度量，决定基于哪个先前技能进行构建以及分配多少新容量，从而带来强前向迁移和大幅效率提升。在六个顺序学习的技能类别上，我们的相似度引导 LoRA 策略在所有方法中取得了最佳前向迁移（0.125 对 0.079）和最高平均准确率，同时最多节省 94.5% 的可训练参数和 40.8% 的训练时间。所得控制器达到 96.13% 的仿真到仿真迁移，并部署在实体 Unitree G1 上。我们的代码可在 https://anonymous.4open.science/r/continual-humanoid-learning-35D3 获取。

## Abstract
Humanoid whole-body controllers can now track a diverse set of dynamic motions, but they are typically trained offline and then frozen, so teaching such a controller a new skill tends to erode the skills it already mastered. We study continual learning for humanoid whole-body motion, where a single controller must acquire skills from a sequential task stream without revisiting past data. We introduce Similarity-guided LoRA-PNN, a progressive neural network (PNN) policy that prevents catastrophic forgetting by construction while reusing knowledge across skills through lightweight low-rank adaptation. A two-level motion-similarity measure, built from dynamic time warping aggregated by optimal transport, decides which prior skill to build on and how much new capacity to allocate, yielding strong forward transfer and large efficiency gains. Across six sequentially learned skill categories, our similarity-guided LoRA policy attains the best forward transfer (0.125 vs. 0.079) and the highest average accuracy among all methods, while saving up to 94.5% of trainable parameters and 40.8% of training time. The resulting controller reaches 96.13% sim-to-sim transfer and is deployed on a physical Unitree G1. Our code is available at https://anonymous.4open.science/r/continual-humanoid-learning-35D3.

## 1. 核心问题与研究动机

- **背景**：基于学习的人形机器人全身运动跟踪已能复现大量敏捷动作（行走、跳跃、舞蹈、格斗等），但这类控制器通常**离线训练后即被冻结**，本质上是静态控制器。
- **核心痛点**：若在新动作数据上微调以学习新技能，会触发**灾难性遗忘（catastrophic forgetting）**，导致已掌握技能严重退化——这与人类"新旧技能共存"的学习方式形成鲜明对比。
- **研究空白**：持续学习（Continual Learning, CL）在计算机视觉与自然语言处理中已有深入研究，但在机器人领域多局限于操作与导航，**人形机器人全身运动的持续学习尚未被系统研究**。
- **整体含义**：论文首次形式化并基准化"持续人形全身运动学习"问题——单一控制器需在**不回放旧数据**的前提下，从顺序任务流中不断获取新技能，同时保持旧技能不退化。这为构建"不断增长的通才控制器"提供了实用路径。

## 2. 方法论：Similarity-guided LoRA-PNN

### 2.1 核心思想
以**渐进神经网络（PNN）** 为骨架：每个任务实例化一个独立"列（column）"，旧列全部冻结，从而**从结构上保证零遗忘**。关键挑战在于如何让新增列高效复用旧知识、控制参数与计算开销。

### 2.2 关键技术细节

- **问题建模**：每个任务建模为目标条件强化学习（PPO），actor 接收本体状态 $s_t$ 与参考状态 $g_t$，输出 23 维关节动作（Unitree G1），由 PD 控制器转为力矩，最大化跟踪与正则化奖励的折扣回报。
- **PNN 横向连接**：第 $k$ 列隐层同时接收本列输入与来自旧列的横向连接 $U_i^{(k:j)}$，实现逐层知识迁移；旧列冻结 → 无遗忘。
- **父列继承（Parent Column Inheritance）**：新任务 $k$ 到来时，依据预计算相似度选择最相似的旧列 $p(k)=\arg\max_{l<k}S(l,k)$，**复制其参数作为初始化**（而非 PNN 的随机初始化），提供更强归纳偏置。
- **相似度引导的 LoRA 秩分配**：每个非首列的线性层用 LoRA 参数化 $W'=W+W_BW_A$，仅训练低秩增量。**相似度越高 → 秩越小**（迁移容易，省参数）；**相似度越低 → 秩越大**（需更多容量）。提供三种规则：
  - **Fixed**：固定秩；
  - **Binned**：按相似度分档映射到 $\{4,8,16\}$；
  - **Linear**：$r_k=\text{clip}(r_{\max}-\alpha\bar{S}_k, r_{\min}, r_{\max})$，随相似度线性变化。

### 2.3 两级运动相似度度量（DTW + 最优传输）

- **逐帧特征**：平移不变、航向归一化的局部平面速度、偏航角速度、各关节增量旋转幅度（SO(3) 测地距离）、可选接触信号。
- **窗口化**：将长序列（3–5 分钟，含停顿/转换）切分为重叠短窗，转化为局部行为集合。
- **窗口级 DTW**：带 Sakoe–Chiba 带约束的加权 DTW 对齐窗口，路径长度归一化得到窗口代价。
- **动作级 OT**：将窗口作为分布，用 Sinkhorn 求解熵正则最优传输（附加软时间顺序惩罚 $\beta|\tau_A-\tau_B|$），得到动作-动作距离。
- **集合级 OT**：在动作-动作代价矩阵上再做一次均匀质量 OT，得到集合-集合距离 $D_{\text{set}}$，对集合大小不敏感。
- **结果**：$S(l,k)=\exp(-D_{\text{set}}/\tau_s)$。距离矩阵显示 run 最具区分度（与其他任务距离最大），walk 最中心（共享周期步态）。

### 2.4 策略训练

- 每列作为独立 actor 训练，旧列冻结，无回放，共享单一 critic。
- 奖励为跟踪项（根速度、锚点/关键体位置姿态与速度）与正则项（动作速率、关节速度/加速度、足滑、限位/碰撞）的加权和。
- **教师-学生蒸馏**：特权教师（Isaac Gym，含基座速度、关键体姿态、接触、域随机化参数等）→ 仅用可部署观测的学生（DAgger，历史编码器，冻结共享编码器）。

## 6. 主要结论与发现

- **零遗忘**：FM = BWT ≈ 0，所有旧技能完整保留（PNN 结构保证）。
- **最强前向迁移**：sim-LoRA 的 FWT = **0.125**，优于最佳基线 KungfuBot2 的 **0.079**。
- **最高精度**：AA = **0.945**、AIA = **0.964**，优于 PNN 全微调（0.938/0.949）及所有基线；EWC/PackNet 显著落后（AA 仅 0.488/0.586）。
- **效率提升**：最多节省 **94.5% 可训练参数**（2.4M → 132K）与 **40.8% 训练时间**（2.94 → 1.74 h/5k）；即使最佳精度的线性秩变体仍省 **90.9% 参数**。
- **模仿质量不降**：保持 100% 成功率与最低动态误差（$E_{\text{mpjve}}$、$E_{\text{mpjae}}$）。
- **迁移与部署**：sim-to-sim 成功率 **96.13%**；持续蒸馏优于任务级教师合并（96.13% vs. 94.07%）；真机 Unitree G1 上 30 个动作达 **90.33%** 成功率。
- **顽固性权衡**：IM = 0.021 略高于基线（负值），说明冻结列以少量可塑性换取遗忘保证。

## 7. 优点

- **结构保证零遗忘**：PNN 冻结旧列使零遗忘成为架构性质，而非需要优化的目标，方法论上干净可靠。
- **相似度驱动的智能复用**：两级 DTW+OT 相似度度量同时解决时间错位、序列长度不等、停顿/转换等问题，对集合大小不敏感，理论设计扎实。
- **参数与计算效率**：LoRA + 相似度引导秩分配，使新技能成本随"新颖度"而非固定预算增长，契合持续学习的本质需求。
- **端到端闭环验证**：从 Isaac Gym 训练 → MuJoCo sim-to-sim → 实体 Unitree G1，且单控制器无逐技能微调，工程落地性强。
- **统一基准贡献**：首次为持续人形全身运动学习建立统一协议与多方法适配基线，具有领域开创性。
- **蒸馏策略有效**：持续教师 → 持续学生优于任务级教师合并，验证了渐进策略可压缩为单一紧凑控制器。

## 8. 不足与局限

- **任务标识符依赖**：采用任务增量协议，测试时需提供 task identifier，未解决类增量（class-incremental）或无任务 ID 场景。
- **可塑性代价**：IM 略高于基线，冻结列在联合训练上界面前牺牲部分可塑性，对高度冲突的任务流可能受限。
- **扩展性隐患**：PNN 横向连接数随任务数呈 $O(K^2)$ 增长，虽论文称 LoRA 与并行训练使长任务流可行，但仅验证 K=6（架构上限 16），未展示大规模任务流实测。
- **算力信息缺失**：未报告 GPU 型号、数量，复现与成本评估困难。
- **真实机器人对比不足**：真机仅报告本方法成功率（90.33%），未与基线方法做真机定量对比，公平性论证有限。
- **安全约束**：真机手腕被锁定，动作空间受限，可能影响动作覆盖度。
- **超参数敏感性**：秩分配涉及 $\gamma_1,\gamma_2,\alpha,\tau_s$ 等固定超参，跨任务/跨机器人泛化性未充分探讨。
- **数据集范围**：仅基于 LAFAN1 与 Kungfu 两个动作数据集，技能类别覆盖有限，对更多样化运动（如物体交互、地形行走）的适用性未知。
