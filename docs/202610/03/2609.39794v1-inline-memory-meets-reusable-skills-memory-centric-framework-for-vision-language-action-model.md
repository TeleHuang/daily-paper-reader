## 摘要
视觉-语言-动作（VLA）模型已在通用机器人操作中展现出巨大潜力，但将其适配到新任务和新领域仍然效率低下：现有方法通常依赖参数调优，这会带来高昂成本，并存在对先前学习任务发生灾难性遗忘的风险。为解决这一问题，我们提出 Optimus-R，一个以记忆为中心的 VLA 框架，将机器人适配形式化为显式的查询-技能记忆调优。Optimus-R 引入了：(i) 用于技能提取的内联记忆接口。它向 VLA 前缀流中插入可学习记忆 token，使主干网络能够在原生动作条件化路径中导出控制感知的查询表示和技能表示。(ii) 用于技能学习的查询-技能记忆库。它将技能外化为用于决定检索什么的查询原型，以及用于指定如何行动的技能值，从而在有限参数更新下支持技能复用与扩展。(iii) 用于技能更新的轻量级桥接与适配机制。它通过轻量级适配器和残差记忆更新，将目标域查询和技能与现有记忆空间对齐。在域内适配、跨域适配和终身学习上的实验表明，Optimus-R 能够实现数据高效的技能学习，同时缓解灾难性遗忘。

## Abstract
Vision-Language-Action (VLA) models have shown strong promise for general-purpose robotic manipulation, yet adapting them to new tasks and domains remains inefficient: existing methods often rely on parameter tuning, incurring substantial costs and risking catastrophic forgetting of previously learned tasks. To address this, we propose \textbf{Optimus-R}, a memory-centric VLA framework that formulates robotic adaptation as explicit query-skill memory tuning. Optimus-R introduces: (i) An \textbf{Inline Memory Interface for skill extraction}. It inserts learnable memory tokens into the VLA prefix stream, allowing the backbone to derive control-aware query and skill representations within the native action-conditioning pathway. (ii) A \textbf{Query-Skill Memory Bank for skill learning}. It externalizes skills into query prototypes for deciding \emph{what} to retrieve and skill values for specifying \emph{how} to act, supporting skill reuse and expansion with limited parameter updates. (iii) A lightweight \textbf{Bridge-and-Adapt mechanism for skill updating}. It aligns target-domain queries and skills with the existing memory space through a lightweight adapter and residual memory updates. Experiments on in-domain adaptation, cross-domain adaptation, and lifelong learning show that Optimus-R enables data-efficient skill learning while mitigating catastrophic forgetting.

## 1. 核心问题与研究动机

- **背景**：视觉-语言-动作（VLA）模型（π0、π0.5、OpenVLA、OpenVLA-OFT、DreamVLA 等）借助大规模机器人数据预训练，已成为通用机器人操作的重要基础模型。
- **核心痛点**：将 VLA 部署到新任务、新物体、新场景和新领域时，主流做法仍是**参数中心的微调**（全量微调、LoRA、Adapter）。这带来三重代价：
  - 每个新技能都隐式写进模型权重，**适配成本高**；
  - 新任务学习会**干扰/遗忘**已有任务（灾难性遗忘）；
  - 新学到的行为难以显式检索、扩展和复用。
- **关键问题**：能否让 VLA 通过一个**显式的记忆接口**来获取、存储和复用技能，而不是反复更新参数？
- **三个耦合子问题**（论文提出的记忆中心 VLA 必须解决）：
  1. **技能提取**：技能应从 VLA 自身派生，而非作为"分离的外部上下文"——外部检索记忆与 VLA 的动作条件化通路耦合太弱，难以编码控制相关信息；
  2. **技能组织**：技能应被显式组织，而非吸收进权重，否则难以检索/扩展/复用；
  3. **域偏移下的可检索性**：视觉或动力学变化会使目标域观测偏离源域记忆空间，造成查询与存储技能错配。
- **整体含义**：论文将机器人适配统一重述为 **技能提取（skill extraction）→ 技能学习（skill learning）→ 技能更新（skill updating）** 三阶段，提出 Optimus-R，把适配形式化为"查询-技能记忆调优"，为 VLA 持续学习提供新范式。

## 2. 方法论

### 2.1 核心思想

- 保持预训练 VLA 主干**大体可复用**，把新技能外化为记忆库中的"查询原型 + 技能值"条目；适配时只更新轻量对齐模块、原型残差和记忆条目，而非反复全局更新参数。

### 2.2 关键技术细节

**(i) 内联记忆接口（Inline Memory Interface）——技能提取**

- 在 VLA 前缀流中拼接可学习记忆 token $E_{mem}$（$m=4$），主干前向得到多模态状态 $H^{vl}_t$ 与记忆状态 $M_t$：$[H^{vl}_t; M_t] = F_\theta(O_t, L; E_{mem})$。
- 用**两个独立的注意力池化算子**从共享记忆状态 $M_t$ 中分别读出查询上下文 $\bar m^q_t$ 与技能内容 $\bar m^s_t$，再经 Query Encoder 与 Skill Encoder 得到：
  - 查询嵌入 $q_t \in \mathbb{R}^{d_q}$：**仅用于检索**；
  - 技能嵌入 $s_t \in \mathbb{R}^{d_s}$：**作为技能值**存入记忆库。
- 训练时用轻量 Skill Decoder 以 Huber 损失重建未来动作块 $\hat A^s_t = D_s(s_t)$，把技能空间"锚定"在可执行行为上。
- Token Projector $T_\psi$ 将技能嵌入映射为 VLA 兼容的 skill token $S_t$，用于条件化 Flow Policy：$\tilde A_t = \pi_\theta(H^{vl}_t, S_t)$。
- **与已有方法的区别**：不是"分离式提示/外部检索"，而是让记忆 token 走主干原生动作条件化通路，从而获得**控制感知**的表示。

**(ii) 查询-技能记忆库（Query-Skill Memory Bank）——技能学习**

- 记忆库形式：$\mathcal{B} = \{(p^q_j, p^s_j, n_j, E_j)\}_{j=1}^{K}$，即查询原型（决定"检索什么"）、技能原型（指定"如何行动"）、支持计数、以及用于回放的紧凑潜在查询-技能对集合 $E_j$。
- **建库流程**：从 Stage A 提取 $(q_t, s_t)$ 对 → **运动感知下采样**（按动作变化量 $\nu_i$ 保留动态片段，抑制静态冗余）+ **归一化进度分层采样**（保证轨迹各阶段覆盖）→ **技能聚类**：先在查询空间聚类，对技能方差 $\sigma^2_s(C)$ 过高的簇再在技能空间二次切分，得到既"状态-任务可检索"又"动作空间一致"的原型。
- **检索**：查询先经记忆坐标对齐 $q'_t = A_{mem}q_t$，取 top-$K_r$（默认 2）原型，按温度 $\tau_{mem}$ 的 softmax 权重 $\alpha_{tj}$ 加权聚合：$\hat s_t = \sum_{j \in N_t}\alpha_{tj}(p^s_j + \Delta p^s_j)$。
- **残差更新**：$\Delta p^q_j, \Delta p^s_j$ 提供局部修正而不覆盖基原型，从而在改变局部记忆坐标的同时保留可复用技能。

**(iii) Bridge-and-Adapt 机制——技能更新（三阶段训练）**

- **Stage A（接口预训练）**：训练记忆 token、两个池化器、Query/Skill Encoder、Skill Decoder、Token Projector 以及 VLA 主干最后若干层；损失
  $\mathcal{L}_{pre} = \mathcal{L}_{fm} + \lambda_q\mathcal{L}^{nce}_q + \lambda_s\mathcal{L}_{skill}$，
  其中 $\mathcal{L}_{fm}$ 为原 VLA 流匹配损失，$\mathcal{L}^{nce}_q$ 为查询对比损失（正样本 = 同任务且归一化进度接近的样本 + 同轨迹时间邻域样本），$\mathcal{L}_{skill}$ 为动作块重建。训练后冻结接口并构建初始记忆库。
- **Stage B（桥接适配，跨域如 sim-to-real）**：解冻主干，与 $A_{mem}$、$\tau_{mem}$、活跃原型残差一起更新；接口模块、Token Projector、基原型保持冻结。当技能空间错配较大时，启用**低秩残差技能适配器** $\tilde s_t = A_s(\hat s_t) = \hat s_t + U_sV_s^\top \hat s_t$（$r \ll d_s$，零初始化，初期保持恒等）。适配器激活由新颖率 $\eta_{batch}$ 与检索-技能对齐误差 $e_{align}$ 连续多批超阈触发。
- **Stage C（记忆适配，域内终身学习）**：冻结主干与内联记忆接口，仅更新 $A_{mem}$、$\tau_{mem}$、活跃原型残差与记忆库条目。样本对齐后查询接近已有原型则更新残差与统计；否则进入候选缓冲，仅当簇满足 $|C_{new}| \ge N_{min}$、$Var_q \le \epsilon_q$、$Var_s \le \epsilon_s$ 时才**追加新原型**。
- **统一适配目标**：$\mathcal{L}_{life} = \mathcal{L}_{fm} + \lambda_{align}\|\tilde s_t - \mathrm{sg}(s_t)\|_2^2 + \lambda_{reg}\sum_{j\in A_t}(\|\Delta p^q_j\|_2^2 + \|\Delta p^s_j\|_2^2)$；对齐项中混入存储的潜在查询-技能对做回放（约 3:1 新/回放比），**回放不存原始图像、动作或轨迹**，兼顾隐私与旧技能保持。
- **推理**：不需要 Skill Encoder/Decoder，只需查询分支 + 对齐 + top-$K_r$ 检索 + Token Projector 条件化 Flow Policy。
