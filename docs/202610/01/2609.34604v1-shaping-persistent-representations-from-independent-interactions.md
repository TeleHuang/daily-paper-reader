世界模型从交互经验中学习环境动力学。这些动力学依赖于当前状态和动作，也依赖于跨交互持续存在的属性。然而，标准的预测式训练仅凭局部证据就能降低误差，而无需将持久信息组织成可复用的上下文。我们提出 SPRII，一种训练原则，它利用交互之间的关系作为持久上下文的弱监督，同时保留学习器原有的目标。例如，同一系统的不同轨迹即使状态和动作不同，也共享持久属性。SPRII 利用这类关系来指导上下文学习，而无需数值属性标签。两个可组合组件分别促使相关交互的上下文相互一致（Align），并利用一个交互的上下文预测另一个交互的未来（Cross）。我们的分析区分了三个相互关联的问题：学习到的上下文中可获取哪些持久信息（Formation）、该上下文如何影响固定的预测器（Use），以及它是否降低任务误差（Value）。一个阶段的成功并不保证下一阶段的成功。受控实验表明，更可靠的关系能改善表征组织，但添加共享属性约束可能会降低对仍然共享的属性的可访问性。在固定模型权重下，上下文替换会改变预测，而来自历史的收益取决于预测时域和读出方式。评估涵盖十三种设置，包括受控物理系统、公开动力学任务、机器人与触觉数据以及伙伴交互，并跨越多个学习器家族。相对于相应的基线，SPRII 在下游任务性能上平均提升超过 10%，在持久属性读出上平均提升超过 15%。项目页面见 https://persistent-learning-review.netlify.app/interactive.html。

## Abstract
World models learn environment dynamics from interaction experience. These dynamics depend on the current state and actions, as well as on properties that persist across interactions. Yet standard predictive training can reduce error using local evidence alone, without organizing persistent information into reusable context. We introduce SPRII, a training principle that uses relations between interactions as weak supervision for persistent context while retaining the learner's native objective. For example, different trajectories of the same system share persistent properties even when their states and actions differ. SPRII uses such relations to guide context learning without numerical property labels. Two composable components encourage contexts from related interactions to agree (Align) and use one interaction's context to predict another's future (Cross). Our analysis distinguishes three linked questions: what persistent information is accessible in the learned context (Formation), how that context influences a fixed predictor (Use), and whether it reduces task error (Value). Success at one stage does not guarantee success at the next. Controlled experiments show that more reliable relations improve representation organization, but adding a shared-property constraint can reduce access to a property that remains shared. Context substitutions change predictions at fixed model weights, while the benefit from history depends on prediction horizon and readout. Evaluations span thirteen settings, including controlled physical systems, public dynamics tasks, robotic and tactile data, and partner interaction, across multiple learner families. Relative to the corresponding baselines, SPRII yields average gains of over 10% in downstream task performance and over 15% in persistent-property readout. The project page is available at https://persistent-learning-review.netlify.app/interactive.html.

# 论文总结：Shaping Persistent Representations from Independent Interactions（SPRII）

## 1. 核心问题与整体含义

- **研究动机**：世界模型从交互经验中学习环境动力学。未来演化既取决于当前状态与动作，也取决于跨交互持续存在的属性（如质量 m、阻尼 γ、刚度 k 等）。然而标准的预测式训练仅凭当前状态、动作与近期运动等局部证据即可降低误差，缺乏将持久信息组织成可复用上下文的动力。
- **核心痛点**：
  - 准确的预测并不必然意味着系统信息被组织为可复用的形式；
  - 可从观测中恢复的物理属性，未必能从预测潜变量中轻易读出；
  - 数值属性标签通常不可得，无法直接监督持久信息的组织。
- **关键洞察**：交互之间的关系（如同一系统、同一物体、同一伙伴）提供了一种弱但通常可得的监督信号。无需知道属性的数值，只需知道两条历史"共享某些持久属性"，即可引导学习关注跨交互持续的信息。
- **整体含义**：论文提出 **SPRII**（Shaping Persistent Representations from Independent Interactions）训练原则，将"关系"作为显式训练选择，并引入 **Formation（形成）→ Use（使用）→ Value（价值）** 的三阶段分析框架，强调前一阶段成功不保证后一阶段成功。

## 2. 方法论

### 2.1 核心思想

- 用交互间的关系 $R_G(A,B)$（系统/任务/伙伴身份）作为持久上下文的弱监督；
- 保留学习器原有目标（native objective），仅以可组合的正则项增强训练；
- 无需数值属性标签，仅需关系成员身份。

### 2.2 持久–当前接口

- 分离历史派生上下文与接收者当前信息：
  - $z_p^A = g_p(H_A)$，$z_p^B = g_p(H_B)$（共享历史编码器）
  - $z_s^B = g_s(C_B)$（当前输入编码器）
- 上下文来源可以是接收者自身（Self）或相关供体（Donor）。

### 2.3 两个可组合组件

- **Align（对齐）**：基于 VICReg，包含配对上下文一致性、逐维方差惩罚、跨维协方差惩罚：
  - $L_{align} = \tfrac{2}{5}I + \tfrac{2}{5}V + C$，$\epsilon = 10^{-4}$
  - 关系决定哪些配对接受该压力；无 stop-gradient。
- **Cross（交叉）**：用相关供体上下文预测接收者未来，Self 与 Cross 共享预测器 q、当前输入 $C_B$ 与条件 $u_B$：
  - $\hat{y}^{self}_B = q(z_s^B, z_p^B, u_B)$
  - $\hat{y}^{A\to B}_B = q(z_s^B, z_p^A, u_B)$
  - $L_{cross} = \mathbb{E}_{(A,B)\sim\Pi_G}[\ell_{task}(\hat{y}^{A\to B}_B, y_B)]$
- **联合训练**：$L = L_{base} + \lambda_p L_{align} + \lambda_x L_{cross}$（SpringWorld 中 $\lambda_p=1.0$，$\lambda_x=0.1$）。

### 2.4 适配多种学习器

- JEPA：观测编码器 + 因果 Transformer 生成 $z_p$；MLP 生成 $z_s$；
- CPC / RSSM：保留原生对比/变分目标；
- 有监督动力学与动作学习器：保留任务损失；
- NOD / Overcooked：原生目标已使用其他交互，仅添加 Align。

### 2.5 理论连接（附录 I）

- **Formation**：命题 1（配对结构暴露）、命题 2（关系损坏下的对齐压力，$1-\alpha$ 系数）、命题 3（联合预测与关系选择，$M_G = K^\top K - \beta D_G$，选择 top-d 特征子空间）；
- **Use**：固定权重干预下的风险变化分解（式 21），含预测敏感度与残差交叉项；
- **Value**：命题 4（任务价值与读者误差），平方损失 $\Delta^\star_{sq} = \mathbb{E}\|m_D - m_0\|^2$；对数损失 $\Delta^\star_{log} = I(Y;D|X)$；实际读者风险 = 可达价值 + 超额风险差。

## 6. 主要结论与发现

- **Formation（形成）**：
  - 更可靠的关系显著增强持久组织（α 从 0 到 1，between/within 比从 0.260 升至 4.391，drag 部分几何从 0.031 升至 0.796）；
  - 改变配对规则会重定向可访问性：G1→G2 时 mass 线性探针 R² 从 0.527 降至 0.071，drag 从 0.308 升至 0.925，**即使 mass 仍然共享**；
  - 理论解释：选择的持久子空间是 $M_G = K^\top K - \beta D_G$ 的 top-d 特征子空间，更广的共享关系可改变主导方向。
- **Use（使用）**：
  - 供体物理改变固定读者的预测，匹配供体–目标物理降低 h16 误差（mass/drag/stiffness 均成立）；
  - Align 主要贡献组织与匹配优势，Cross 额外降低误差；
  - PokeWorld 中 G1 下 mass、G2 下 drag 响应更强。
- **Value（价值）**：
  - 历史收益随预测时域增长：Cold 从 h1 的 2.0% 升至 h16 的 35.7%；Moving 从 1.2% 升至 29.7%；
  - 直接上下文在 D-Clean 中优于解码参数（h32 降 22.8%），但在 SpringWorld 中相反（直接上下文比 Decode 高 2.1%），**可解码参数不决定最佳读出接口**；
  - 残差读出 M2 相对 M1 平均降 7.9%，但 PokeWorld 中 M1 更优——**价值依赖读者与预测问题**；
  - 更强 Formation 不保证更大读者价值（PokeWorld 5,000 步下 α 增大并未带来正 M2 增益）。
- **总体**：关系设计与读出设计互补——一个塑造上下文中可用信息，另一个决定其服务任务的效率。

## 7. 优点

- **概念清晰**：将"信息形成 / 预测使用 / 任务价值"三阶段分离，避免将可访问性、依赖性与收益混为一谈；
- **方法通用**：Align 与 Cross 可组合，保留原生目标，适用于 JEPA、CPC、RSSM、NOD、AD 等多种学习器；
