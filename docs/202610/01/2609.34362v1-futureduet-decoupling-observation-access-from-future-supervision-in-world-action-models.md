## 摘要
世界动作模型（WAMs）通过未来视觉监督增强机器人动作生成。现有 WAM 通常将主视角与腕部观测融合为单一视觉流，并用相同的未来视频目标训练二者，尽管它们的视觉动态存在差异。稳定的主相机揭示场景级任务演化，而腕部相机随末端执行器移动，将局部交互变化与视角偏移和自遮挡混杂在一起。这些截然不同的预测需求表明，两种视角可能受益于不同的未来目标。我们提出 FutureDuet，它在控制中保留两种视角，同时允许每个视觉流接受不同的未来目标。对于主视角，未来 RGB 对任务演化建模，而交互掩码和机器人骨架将监督聚焦于任务物体和机器人运动。对于腕部流，未来潜在预测对短时程交互变化建模，而无需像素级重建。ActionDiT 联合读取由此得到的任务状态（Task State）和交互状态（Interaction State），将场景级进展与近距离交互证据相结合。所有辅助预测模块仅用于训练，不增加推理开销。FutureDuet 在 RoboTwin50 上实现了 94.2% 的干净成功率和 94.1% 的随机化成功率，在 LIBERO 上实现了 99.2% 的平均成功率。这些提升在六个需要精确交互的 RoboTwin50 任务上最为显著，在干净和随机化设置下相较 Fast-WAM 平均提升 9.2% 和 12.8%。控制实验进一步表明，将腕部通路分离并为两种视角分别设计未来监督可带来互补增益。

## Abstract
World Action Models (WAMs) augment robot action generation with future visual supervision. Existing WAMs commonly fuse main and wrist observations into one visual stream and train both with the same future-video objective, despite their different visual dynamics. A stable main camera reveals scene-level task evolution, whereas wrist cameras move with the end effector, mixing local interaction changes with viewpoint shifts and self-occlusion. These contrasting predictive demands suggest that the two views may benefit from different future objectives. We introduce FutureDuet, which retains both views for control, while allowing each visual stream to receive a different future objective. For the main view, future RGB models task evolution, while interaction masks and robot skeletons focus supervision on task objects and robot motion. For the wrist stream, future latent prediction models short-horizon interaction changes without requiring pixel-level reconstruction. ActionDiT jointly reads the resulting Task State and Interaction State, combining scene-level progress with close-range interaction evidence. All auxiliary prediction modules are training-only, adding no inference overhead. FutureDuet achieves 94.2% clean and 94.1% randomized success on RoboTwin50 and 99.2% average success on LIBERO. The improvements are most pronounced on six RoboTwin50 tasks that require precise interaction, averaging gains of 9.2% and 12.8% over Fast-WAM in clean and randomized settings. Controlled studies further show complementary gains from separating the wrist pathway and designing future supervision separately for the two views.

## 2. 方法论：核心思想与关键技术细节

- **核心思想**：解耦“哪些观测用于控制”与“每个视觉流预测什么样的未来”。主视角建模场景级任务演化，腕部视角建模短时程局部交互变化，最终由 ActionDiT 联合读取两类状态生成动作。
- **整体流程**：
  - 输入：语言指令 \(c\)、本体感受 \(p_t\)、主视角历史 \(o^m_{\le t}\)、腕部历史 \(o^w_{\le t}\)。
  - 输出：动作块 \(a = a_{t:t+H-1}\)。
- **主视角 Task State**：
  - VideoDiT 提取主视角特征 \(H^m_t = F_m(o^m_{\le t}, c, p_t)\)。
  - 学习查询适配器将特征汇总为 Task State：\(S^{\text{task}}_t = A_{\text{task}}(Q_{\text{task}}, H^m_t)\)。
  - 主视角未来监督包括：
    - 未来 RGB 预测：编码为 VAE 潜变量 \(z^m\)，用 flow matching 预测速度。
    - 交互掩码：离线 SAM 3 生成被操作物体及目标区域掩码，用 focal–Tversky 损失监督。
    - 机器人骨架：将记录的机器人构型投影到标定主视角，用 focal–Dice 损失监督。
  - 共享 DPT 风格解码器读取噪声条件下的中间 VideoDiT 特征，多个输出头预测未来偏移处的掩码和骨架。
- **腕部 Interaction State**：
  - 轻量在线编码器提取腕部特征 \(H^w_t = E_{w\omega}(o^w_{\le t})\)。
  - 学习查询适配器生成 Interaction State：\(S^{\text{int}}_t = A_{\text{int}}(Q_{\text{int}}, H^w_t)\)。
  - 未来监督采用潜在预测而非像素重建：
    - 冻结的 V-JEPA 2.1 编码器离线处理未来腕部片段，生成缓存目标 \(Z^{w,\text{fut}}_t\)。
    - 训练时共享预测器 \(P_\psi\) 联合预测左右腕部潜变量：\(\hat{Z}^{w,\text{fut}}_t = P_\psi(H^w_t, \text{sg}[S^{\text{task}}_t])\)。
    - 使用 stop-gradient，防止腕部目标通过条件连接更新主流程；损失为有效潜变量元素的平均绝对误差 \(L_{\text{wrist}}\)。
- **Duet Interface 与 ActionDiT**：
  - Duet Interface 将 Task State 和 Interaction State 投影、融合为共同条件空间：\(C^{\text{duet}}_t = A_{\text{duet}}([S^{\text{task}}_t; S^{\text{int}}_t])\)。
  - ActionDiT 同时读取融合状态、当前主视角 key/value 特征、指令和本体感受，通过 flow matching 从噪声积分生成动作块。
  - 组合损失：\(L = L_{\text{act}} + \lambda_{\text{rgb}}L^m_{\text{rgb}} + \lambda_{\text{mask}}L_{\text{mask}} + \lambda_{\text{ske}}L_{\text{ske}} + \lambda_{\text{wrist}}L_{\text{wrist}}\)。
- **部署效率**：VAE 解码器、DPT 解码器、预测头、V-JEPA 教师和腕部预测器在评估时全部剪枝，因此辅助未来预测不增加推理开销。

## 6. 主要结论与发现

- **整体性能领先**：
  - RoboTwin50：clean 94.2%，randomized 94.1%，较 Fast-WAM 均提升 2.3 个百分点。
  - LIBERO：平均 99.2%，在 Spatial、Object、Goal 上取得报告中的最佳结果。
- **困难交互任务提升显著**：
  - 6 个在两种设置下均低于 90% 的任务上，FutureDuet 较 Fast-WAM 平均提升 clean 9.2 个百分点、randomized 12.8 个百分点。
  - 这些任务占总净增益的 48%（clean）和 66%（randomized），典型任务包括 Open Microwave、Hanging Mug、Turn Switch。
- **腕部通路分离有效**：
  - 仅加入腕部观测到统一通路，成功率从 34.3% 升至 55.8%。
  - 轻量独立腕部通路即使无未来预测也达到 60.9%，说明分离本身有架构收益。
  - 固定独立通路后，未来 RGB 监督提升至 64.1%，未来潜变量监督进一步提升至 69.7%。
- **训练-only 潜变量监督兼顾性能与效率**：
  - 直接部署 V-JEPA 编码器可达 63.2%，但延迟从约 196.86 ms 增至 244.99 ms。
  - 将未来潜变量预测限制在训练阶段，可在接近基线延迟下达到 69.7%。
- **结构化主视角监督提供互补增益**：
  - 加入 mask 和 skeleton 后，统一腕部通路平均成功率从 71.0% 升至 73.5%，独立未来潜变量通路从 76.0% 升至 80.3%。
  - mask 更有利于物体相关任务，skeleton 更有利于机器人运动相关任务，二者结合最佳。
- **读出诊断揭示机制**：
  - mask 监督提高动作查询对任务物体区域的注意力和敏感性。
  - skeleton 监督提高对执行机器人区域的注意力和敏感性。
  - 注意力模式与 K/V 干预结果一致，说明结构化目标确实塑造了 ActionDiT 读取的证据。

## 7. 优点

- **问题洞察清晰**：明确指出多视角 WAM 中“观测访问”与“未来监督”被错误耦合，并提出可验证的替代设计。
- **方法设计简洁有效**：主视角与腕部视角分别使用适合自身动态的监督目标，避免腕部像素级重建的困难。
- **零推理开销**：所有辅助预测模块均为训练时使用，部署时剪枝，兼顾性能与效率。
- **控制实验细致**：通过腕部通路研究、主视角因子研究和读出诊断，逐步拆解各设计因素的贡献，而非仅报告最终指标。
- **诊断方法有说服力**：同时使用动作到视觉注意力和 K/V 干预，区分“读取位置”与“实际影响”，增强机制解释。
- **性能提升显著且集中**：在精确交互任务上提升尤为明显，说明方法针对了 WAM 的薄弱环节。
- **公平性较好**：主基准与 Fast-WAM 严格对齐训练与评估条件，便于归因。

## 8. 不足与局限

- **仅限仿真验证**：论文明确表示评估目前限于仿真，尚未在真实机器人上测试，真实世界的传感器噪声、标定误差和动态变化可能带来额外挑战。
- **依赖离线标注与预训练模型**：主视角 mask 依赖 SAM 3 离线生成，骨架依赖标定投影，腕部目标依赖冻结 V-JEPA 2.1，增加了数据准备和模型依赖成本。
- **任务覆盖有限**：控制实验集中在 3 个或 6 个任务上，虽然主基准有 50 个任务，但机制性结论的统计基础仍较小。
- **困难任务仍未解决**：仍有 6 个任务在两种设置下低于 90%，说明精确交互完成仍是开放问题。
- **算力与训练成本未报告**：未提供 GPU 型号、数量、训练时长等信息，不利于复现和成本评估。
- **泛化性未充分验证**：未探索更广泛的视角-目标配置，也未验证跨机器人形态、跨场景或真实环境的迁移能力。
- **潜在偏差风险**：部分基线来自不同来源，评估条件可能不完全一致；随机化设置虽增强鲁棒性，但仍受限于仿真器的分布设计。
- **辅助目标设计需人工选择**：mask、skeleton、latent 等目标及其权重需要针对任务设计，可能引入额外调参成本。
