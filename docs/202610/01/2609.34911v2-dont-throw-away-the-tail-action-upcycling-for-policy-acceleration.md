## 摘要
现代机器人策略从单次观测中预测未来动作块，仅执行其前缀，并在重新规划前丢弃其余部分。选择该前缀的长度，即执行时域，会在反应性与效率之间形成权衡。较短的执行时域使策略对环境保持反应性，但需要频繁调用策略。近期的测试时方法会为每个动作块自适应地选择执行时域，但它们要么读取模型内部信息（其中信号必须针对每种架构进行选择），要么抽取额外样本，从而增加成本。我们提出 Action Upcycling，一种无需训练的算法，它复用策略原本会丢弃的动作，且无需访问模型内部信息或抽取额外样本。我们发现，只要动作速度保持平滑，被丢弃的动作就与其重新规划后的版本保持接近。因此，Action Upcycling 将执行时域扩展到速度开始波动的点。在模拟和真实世界操作任务上的大量实验表明，在多种视觉-语言-动作模型（VLA）乃至一个世界动作模型（WAM）上，Action Upcycling 将策略调用减少 1.2-1.7 倍，且成功率没有损失。它以可忽略的成本适用于任何分块策略，并且与其他策略加速方法（如少步采样和流式动作解码）正交，为策略加速开辟了一个新维度。

## Abstract
Modern robot policies predict a chunk of future actions from a single observation, execute only a prefix, and discard the rest before replanning. Choosing the length of this prefix, the execution horizon, poses a trade-off between reactivity and efficiency. A short horizon keeps the policy reactive to the environment, but requires frequent policy calls. Recent test-time methods adaptively select the horizon for each chunk, but they either read model internals, where the signal must be chosen for each architecture, or draw extra samples, which adds cost. We propose Action Upcycling, a training-free algorithm that reuses actions the policy would otherwise discard, without accessing model internals or drawing extra samples. We find that discarded actions stay close to their replanned versions as long as the action velocity remains smooth. Action Upcycling therefore extends the execution horizon up to the point where the velocity begins to fluctuate. Extensive experiments on simulated and real-world manipulation tasks show that Action Upcycling reduces policy calls by 1.2-1.7x with no loss in success rate, across multiple Vision-Language-Action Models (VLAs) and even a World Action Model (WAM). It applies to any chunked policy at negligible cost and is orthogonal to other policy acceleration methods such as few-step sampling and streaming action decoding, opening a new axis for policy acceleration.

# 论文总结：Don't Throw Away the Tail: Action Upcycling for Policy Acceleration

## 1. 核心问题与研究动机

- **背景**：动作分块（action chunking）已成为现代机器人模仿学习与 VLA（视觉-语言-动作模型）的标准范式——策略从单次观测预测长度 `H` 的动作块（prediction horizon），但通常只执行前 `h` 个动作（execution horizon）后即重新规划，其余 `H-h` 个"尾部动作"被直接丢弃。
- **核心矛盾**：执行时域 `h` 的选取存在两难。`h` 短 → 策略反应性高、可频繁重观测纠错，但需要大量策略前向调用（大骨干网络代价高）；`h` 长 → 调用少、效率高，但对环境变化与执行误差不敏感。且最优 `h` 随任务、甚至同一任务内部而变化。
- **现有测试时自适应方法的局限**：
  - **基于注意力**（AutoHorizon、Knowing When to Stop）：需读取模型内部注意力权重/熵，信号需针对每种架构挑选（层、注意力类型、去噪步），通用性差。
  - **基于采样**（AAC、A3）：需抽取多个候选动作块（如 K=20），额外前向传播显著增加单次调用延迟。
- **本文含义**：作者观察到"被丢弃的尾部动作"其实携带可用信息——它们与重新规划后的版本高度相关（Pearson 相关 0.89–0.98），只要动作速度保持平滑，尾部就值得复用。由此提出 **Action Upcycling**：一种**免训练、免模型内部访问、免额外采样**的算法，复用原本会被丢弃的尾部动作，把加速的着力点从"降低单次调用成本"转向"减少调用次数"，开辟了策略加速的新维度。

## 2. 方法论

### 2.1 核心思想
- 若预测动作块中速度平滑，则尾部动作与重规划结果接近、可信；一旦速度开始波动，尾部就不可信，应停止复用。
- 用**累积速度波动** `c_k` 作为"尾部可信度"信号，自适应决定每个 chunk 实际执行长度 `h_exec`。

### 2.2 问题形式化
- 第 `i` 次调用：`A_i = π(o_{t_i}) = (a_1, ..., a_H)`，控制器执行 `a_1..a_h`，丢弃尾部 `a_{h+1}..a_H`。
- Action Upcycling 额外执行 `Δh_i ∈ [0, H-h]` 个尾部动作。
- 定义**平均执行长度** `h̄ = (1/n) Σ(h + Δh_i)` 与**复用比** `r = h̄/h ∈ [1, H/h]`；`r=2` 意味着策略调用次数减半，`r=1` 退化为原策略默认设置。

### 2.3 速度波动信号（关键技术细节）
- 速度定义依动作参数化而定：相对位移（如 LIBERO）取 `v_k = a_k`；绝对关节位置（如 RoboTwin 2.0、真机）取 `v_k = a_k - a_{k-1}`。
- 累积波动：`c_k = Σ_{j=h+1}^{k} ||v_j - v_{j-1}||_2`，`h < k ≤ H`，且 `c_h = 0`。由于每项非负，`c_k` 沿尾部单调不减：动作平稳时保持小值，一旦波动即抬升。
- 动机验证（Figure 1）：被丢弃动作与重规划动作的 RMSE 随速度波动增大而增长，说明 `c_k` 是尾部可信度的有效代理信号。

### 2.4 自适应执行时域选择
- 给定阈值 `τ ≥ 0`：`h_exec(A_i; τ) = max{ k : c_k ≤ τ, h ≤ k ≤ H }`。
- `τ = ∞` → 整块执行；`τ = 0` → 退化为默认设置。
- **阈值标定**：`τ` 越大，复用比 `r` 越大。将各 chunk 的信号 `c_{h+1}..c_H` 汇入池 `C`（仅依赖 chunk 本身，无需额外 rollout、无需示教或成功标签），取 `C` 中满足 `h̄(τ) ≥ r·h` 的**最小元素**作为 `τ`。
- **算法流程（Algorithm 1）**：① 用策略 rollout 构建信号池 `C` 并标定 `τ`；② 循环：策略预测 chunk → 计算 `c_k` → 取满足 `c_k ≤ τ` 的最大 `k` 作为 `h_exec` → 执行 `a_1..a_{h_exec}` 并推进时间。

## 6. 主要结论与发现

- **核心发现**：被丢弃的尾部动作与重规划版本强相关（Pearson 0.89–0.98）；两者 RMSE 随速度波动单调增长，因此速度波动可作为尾部可信度的免模型内部信号。
- **主结果**：在全部策略-基准组合上，Action Upcycling 将策略调用减少 **1.2–1.7×**，成功率**不降反略有提升**（如 π0.5：LIBERO 96.9→97.9，LIBERO-Plus 83.7→86.5，RoboTwin 59.7→60.5）；单次调用延迟基本不变，故单回合推理时间按比例下降。对 FastWAM 无需任何修改即可生效，说明方法超越 VLA 范畴。
- **对比优势**：相比 AAC 与 AutoHorizon，本文方法在 LIBERO/LIBERO-Plus 上成功率最高、调用减少最多、单回合时间最短，且无需访问模型内部；AAC 因多次采样使单次延迟从 136 ms 升至 802 ms，在 RoboTwin 上甚至反而增加调用次数；AutoHorizon 在 RoboTwin 上调用减少略多但成功率下降。

## 7. 局限性、风险与可改进方向

- **信号池标定仍需一次策略 rollout**：虽然 `τ` 的标定只依赖 chunk 本身（无需成功标签、无需额外环境交互之外的 rollout），但"先跑一遍收集信号池"这一步在部署初期不可避免。论文显示随机 2% 的 chunk 即可近似还原 `τ`，在线池也能达到相当效果，说明该成本很低，但严格意义上并非零成本、零先验的"即插即用"。
- **复用比 `r` 是预设目标而非自适应目标**：算法以"达到 `r·h` 的平均执行长度"为目标反推 `τ`，因此 `r` 的选择仍带有人工成分。论文只做了 `r` 的敏感性扫描（Figure 6），未给出"如何在未知任务上自动选择 `r`"的机制。若 `r` 设得过大，可能把不可信的尾部也纳入执行；设得过小则加速收益有限。
- **依赖"速度平滑 ⇒ 尾部可信"这一经验假设**：该假设在操作类任务上被 RMSE 实验支持（Figure 1），但在接触丰富、强动态、需快速切换模式的任务（如插拔、抛接、力控装配）中，动作速度本身可能频繁跳变，导致 `c_k` 过早超阈值、复用比退化到接近 1，加速收益消失。论文的 benchmark 以 pick-and-place 与抽屉类长时域任务为主，对这类高动态场景覆盖不足。
- **动作参数化的适配性**：速度定义在相对位移与绝对关节位置之间切换（`v_k = a_k` vs `v_k = a_k − a_{k−1}`），说明信号构造依赖对动作语义的正确判断。若动作空间混合（如同时含关节位置与夹爪二值/连续量），波动信号是否仍具可比性、夹爪维度是否应单独处理，论文未展开讨论。
- **与基于采样的方法相比放弃了"预测不确定性"信息**：本文刻意回避额外采样，换来低延迟；代价是无法像 AAC 那样直接估计动作分布的方差。在分布外（OOD）观测下，速度波动信号是否仍能可靠指示尾部不可信，缺少专门的压力测试。
- **真机验证规模有限**：8 个任务（π0.5）/ 4 个任务（GR00T N1.6）、每任务 10 回合、单臂 YAM 平台，且未与 AAC / AutoHorizon 在真机上对比，因此"优于其他自适应时域方法"这一结论目前仅在仿真中成立。
- **潜在风险：长时域误差累积**。复用尾部相当于在执行阶段引入"旧策略的意图"，若环境在复用期间发生基线原本能通过重规划纠正的扰动，本方法可能延迟一次纠错机会。论文的成功率结果（不降反升）表明在测试任务上该风险被"更少的重规划抖动"所抵消，但这属于经验结论而非理论保证。

## 8. 总体评价与贡献定位

- **核心贡献**：把"策略加速"的问题从一个被默认接受的二选一（要么减少单次调用成本，要么缩短执行时域）中解放出来，指出第三条路径——**复用本来就要被丢弃的尾部动作**。这一视角转换的巧妙之处在于：尾部动作已经由策略"免费"生成，复用它们不增加任何前向计算，却直接减少调用次数，因此在"调用次数 × 单次延迟"的加速分解中同时改善前者而不恶化后者。
- **方法简洁性**：整个算法可归结为"累积速度波动 + 单阈值截断"，不需要模型内部访问、不需要额外采样、不需要训练或微调、不需要示教或成功标签。这种"零侵入"特性使它天然适配任意 VLA/WAM 架构（论文用 π0.5、SmolVLA、GR00T N1.7、FastWAM 四种不同架构验证），也使其能与少步采样、FlashVLA 等正交加速手段直接相乘（最高 6.7× 总加速）。
- **实证说服力**：4 策略 × 3 仿真 benchmark + 真机的覆盖在同类工作中属较充分；同时报告成功率、调用次数、单次延迟、单回合时间四类指标，有效排除了"加速来自单次成本变化"的混淆；固定长度执行的消融专门回应了"只是执行更长所以变好"的替代解释，是设计上的加分项。
- **与前作的关系**：与 AAC、AutoHorizon 同属"自适应执行时域"赛道，但后者分别以采样和注意力为信号来源，本文以动作序列自身的平滑性为信号，在延迟与通用性上占优；在 RoboTwin 等任务上 AutoHorizon 调用减少更多但成功率下降，说明本文方法在"省调用"与"保成功"之间取了更保守、更稳健的平衡。
- **适用边界**：方法的价值在"单次策略调用昂贵（大骨干、多去噪步）+ 任务动作相对平滑"的场景中最大，即当前主流 VLA 部署场景。对于本身调用极廉价的小模型，或动作高度非平滑的任务，收益会显著收窄。
- **可复现性**：全部使用公开 checkpoint，仿真中不微调，基线方法与对比方法均采用官方实现与默认超参，`τ` 标定流程在 Algorithm 1 中给出，复现门槛较低。未披露的 GPU 总数与总训练时长不影响方法本身的复现，但影响对"真机微调成本"的完整评估。
- **一句话总结**：本文用一条极简的速度波动判据，把"被丢弃的尾部"从浪费变成了加速资源，在几乎不牺牲成功率的前提下将策略调用减少 1.2–1.7×，并且这一收益可与现有加速技术叠加——是一个动机清晰、实现轻量、验证扎实、边界明确的实用型贡献。
