## 摘要
视觉-语言-动作（VLA）策略通常将一个数十亿参数的模型置于反馈回路中，在每次预测新的动作块时反复重算任务上下文。然而，任务理解的变化远慢于机器人状态。我们提出 Fast-VLA，它在每个回合中仅调用一次冻结的 4B VLM，将指令和初始视图上下文化为固定的多层键值任务记忆。在执行期间，轻量级在线 actor 将学习到的时间索引和机械臂索引查询与当前视觉和本体感觉反馈融合，形成动作查询。这些查询从固定记忆中检索任务上下文，并预测动作块，而无需重新运行基础模型。Fast-VLA 在 RoboTwin 2.0 Clean 和 Randomized 上分别达到 92.46% 和 92.40% 的成功率，在 LIBERO 和 LIBERO-Plus 评估中分别达到 95.95% 和 79.11%。在相同硬件上，与三个持续条件化基线相比，它将 RoboTwin 的摊销策略推理时间降低 10.9–17.1 倍，并需要 1.22 GiB 的预填充后在线常驻内存。任务记忆交换进一步表明，actor 依赖与回合匹配的任务记忆。这些结果表明，任务上下文可以一次性建立，同时闭环控制在执行全程保持响应。项目页面：https://garfield-kh.github.io/FastVLA

## Abstract
Vision-language-action (VLA) policies commonly place a multi-billion-parameter model inside the feedback loop, repeatedly recomputing task context whenever they predict a new action chunk. Yet task understanding changes far more slowly than the robot state. We introduce Fast-VLA, which invokes a frozen 4B VLM once per episode to contextualize the instruction and initial views as fixed, multi-layer key-value task memory. During execution, a lightweight online actor fuses learned time- and arm-indexed queries with current visual and proprioceptive feedback to form action queries. These queries retrieve task context from the fixed memory and predict action chunks without re-running the foundation model. Fast-VLA achieves 92.46% and 92.40% success on RoboTwin 2.0 Clean and Randomized, and 95.95% and 79.11% on LIBERO and LIBERO-Plus evaluation. Against three continually conditioned baselines on the same hardware, it reduces RoboTwin amortized policy inference time by 10.9-17.1x and requires 1.22 GiB of post-prefill online resident memory. Task-memory swaps further show that the actor relies on episode-matched task memory. These results show that task context can be established once while closed-loop control remains responsive throughout execution. Project page: https://garfield-kh.github.io/FastVLA

# Fast-VLA: You Only Think Once for Robot Manipulation — 论文结构化总结

## 1. 核心问题与研究动机

- **背景**：VLA（Vision–Language–Action）策略把大规模预训练 VLM 的语义知识引入机器人控制，使单一策略能跟随多样指令。但主流做法（π0、π0.5、OpenVLA 等）把数十亿参数的骨干网络放进**控制闭环**：每预测一个动作块（action chunk），就重新编码当前图像与语言指令。
- **核心矛盾**：机器人必须持续观测并修正动作，但**指令与任务目标在整个回合内几乎不变**。作者据此提出"双时间尺度"直觉——任务理解变化慢，控制反馈变化快；人类也是先确定目标与目标物体，之后靠视觉/本体感觉微调动作，而非每个小动作前重新理解任务。
- **待回答的问题**：大型 VLM 骨干是否必须在每次控制决策时重跑？能否"只思考一次"（think once）却仍保持闭环响应？
- **关键难点**：固定记忆无法表示当前世界状态（物体与机械臂在动），因此真正的挑战是**如何用实时观测去查询固定任务上下文**。
- **整体含义**：论文主张把"一次性任务理解"与"重复闭环控制"解耦，用回合级（episode-level）记忆替代逐块重算，从而在不牺牲成功率的前提下大幅降低摊销推理成本与在线显存。

## 2. 方法论

### 2.1 核心思想：两阶段架构
- **阶段一（每回合一次）**：冻结的 4B VLM（DM0.5）接收指令 $L$ 与初始多相机视图 $I_0$，输出层间 KV 任务记忆 $M_0 = G_{\text{VLM}}(L, I_0)$，随后 VLM 退出控制回路。
- **阶段二（每个动作块）**：轻量在线 actor 编码当前视图 $I_t$、本体状态 $q_t$、可选短历史 $H_t$ 得 $Z_t = G_{\text{online}}(I_t, H_t, q_t)$，再由预测阶段 $\hat A_{t:t+K-1} = F_{\text{pred}}(Z_t; M_0)$ 输出动作块。

### 2.2 任务记忆的构建
- 保留 DM0.5 **全部 34 层 Transformer** 的 key/value 张量：$M_0 = \{(K^\ell_0, V^\ell_0)\}_{\ell=1}^{34}$。
- 保留全层而非仅末层，使 actor 能在不同 VLM 深度上检索任务上下文。
- 记忆在整个回合内固定不变；训练时离线预计算并缓存 KV，避免重复前向。

### 2.3 在线 actor 的技术细节
- **视觉输入**：每个相机一个独立可训练的 DINOv2（ViT-B/14）编码器，同相机不同帧共享权重；视觉 token 加学习到的 slot embedding 与时间偏移以区分"当前/历史"。
- **查询融合（Query Fusion）**：为每个未来时间步 $\tau\in\{0,\dots,49\}$ 与机械臂 $a\in\{\text{left},\text{right}\}$ 初始化学习查询 $z^{(0)}_{\tau,a} = e_{\text{time}}(\tau) + e_{\text{arm}}(a)$；将 7 维本体状态与该臂腕部视图 CLS token 投影、拼接角色嵌入后经 MLP 得臂反馈 $c^a_t$；用门控残差 MLP 把归一化查询与对应反馈融合并加回查询；同一臂反馈在**每个解码层前**通过层特定的门控残差重新注入。
- **动作解码器（4 层，每层四段）**：Self-Attention（跨未来时间步与双臂协调）→ Cross-Visual Attention（读取当前视图与历史视觉 token）→ Cross-Memory Attention（从固定记忆检索任务上下文）→ FFN。
- **KV 记忆适配器（关键设计）**：每个解码层 $m$ 学习 34 个记忆层上的打分 $s_{m,\ell}$，经 softmax 得 $\alpha_{m,\ell}$，初始化时偏向深度对齐层；先用旋转位置编码把各层 key 变换到公共空间 $R_{c\leftarrow\ell}(K^\ell_0)$，再加权混合 $(\bar K_m,\bar V_m)=\sum_\ell \alpha_{m,\ell}(R_{c\leftarrow\ell}(K^\ell_0), V^\ell_0)$；随后用一次 grouped-query cross-attention 读取 $(R_{m\leftarrow c}(\bar K_m),\bar V_m)$。key 侧另有 segment embedding 区分指令 token 与初始图像 token。
- **动作头**：线性层，单次前向直接输出 $50\times14$ 的双臂绝对关节指令，**无迭代去噪**。
- **LIBERO 单臂配置**：agent-view + wrist 两路图像，单组动作查询，$10\times7$ 动作块，不使用视觉历史。

### 2.4 训练与推理
- 损失：归一化动作上的 $\ell_1$ 损失，仅训练在线 actor（含视觉编码器），VLM 全程冻结。
- 优化：AdamW + cosine，学习率 $3\times10^{-4}$，DINOv2 学习率乘子 0.1，1000 步 warmup，BF16 autocast，梯度裁剪 1.0。
- 摊销延迟定义：$(T_{\text{prefill}} + \lceil H/K\rceil T_{\text{actor}})/H$，即把一次性 prefill 计入每环境步成本。
