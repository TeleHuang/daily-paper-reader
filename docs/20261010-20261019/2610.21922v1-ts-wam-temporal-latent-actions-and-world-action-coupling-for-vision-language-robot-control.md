## 摘要
许多视觉-语言-动作策略依赖带有动作标注的机器人演示，并且缺乏预测未来视觉状态的显式机制。这些局限妨碍了从无动作视频中学习，并可能导致对演示条件的过拟合，从而削弱泛化性和鲁棒性。我们提出 TS-WAM，一种轻量级教师-学生世界-动作模型，通过自监督时序学习和显式未来预测来应对这些挑战。其 vlm-jepa 框架利用 EMA 目标分支从异构数据中学习，包括机器人演示和无动作人类视频，而无需单独训练的外部教师。通过将 vlm-jepa 与 delta-lwm 耦合，TS-WAM 学习根据当前观测和指令预测潜在动作，并利用这些潜在动作预测未来视觉特征，以在推理时指导动作生成。统一的端到端训练架构联合优化时序表示学习、视觉动力学和机器人控制，无需单独的潜在动作或世界模型预训练阶段。推理时移除 EMA 目标分支，使部署策略保持轻量。在 LIBERO、LIBERO-Plus 和 SimplerEnv 上的实验，以及在 Franka Research 3 和 RevoTron 上的真实世界操作实验表明，TS-WAM 实现了较强的操作性能、泛化性和鲁棒性。

## Abstract
Many vision-language-action policies rely on action-labeled robot demonstrations and lack an explicit mechanism for predicting future visual states. These limitations hinder learning from action-free videos and can encourage overfitting to demonstration conditions, weakening generalization and robustness. We present TS-WAM, a lightweight Teacher-Student World-Action Model that addresses these challenges through self-supervised temporal learning and explicit future prediction. Its vlm-jepa framework learns from heterogeneous data, including robot demonstrations and action-free human videos, using an EMA target branch without requiring a separately trained external teacher. By coupling vlm-jepa with delta-lwm, TS-WAM learns to predict latent actions from the current observation and instruction and uses them to predict future visual features that guide action generation at inference. A unified end-to-end training architecture jointly optimizes temporal representation learning, visual dynamics, and robot control without a separate latent-action or world-model pretraining stage. The EMA target branch is removed at inference, keeping the deployed policy lightweight. Experiments on LIBERO, LIBERO-Plus, and SimplerEnv, together with real-world manipulation experiments on Franka Research 3 and RevoTron, demonstrate that TS-WAM achieves strong manipulation performance, generalization, and robustness.

- **研究背景**：当前视觉-语言-动作（VLA）策略通常以预训练 VLM 为语义骨干，再接扩散或流匹配动作解码器。这类方法指令跟随能力强，但动作接口主要直接从机器人轨迹学习，隐藏状态未必表示“动作将要造成的短时视觉变化”，策略缺少执行前的显式后果预测。
- **核心痛点**：
  - 依赖带动作标注的机器人示范，难以利用大量无动作人类视频。
  - 容易过拟合示范条件，泛化和鲁棒性不足。
  - 现有潜在动作模型（LAM）或潜在世界模型多采用“先预训练、再适配”的两阶段流程，引入额外检查点和优化边界，且不保证学到的潜在表示对最终动作解码器有用。
- **整体含义**：论文主张把**时序预测作为 VLA 策略的中心接口**，通过教师-学生非对称结构，从机器人示范与无动作视频中端到端学习“当前观测+指令 → 潜在动作 → 未来视觉特征 → 动作”的因果链条，在不增加推理负担的前提下提升操作性能、泛化性与鲁棒性。

## 2. 方法论

### 2.1 核心思想

- 提出 **TS-WAM（Teacher-Student World-Action Model）**，由两个耦合模块组成：
  - **vlm-jepa**：自监督学习时序潜在动作表示。
  - **delta-lwm**：以潜在动作为条件预测未来视觉特征位移，并与动作生成耦合。
- 采用**非对称双 VLM 分支**：
  - 在线 X-VLM 只接收当前观测和语言指令，保持因果性。
  - EMA Y-VLM 接收当前与未来观测，作为训练期“未来感知教师”，提供目标潜在动作。
- 推理时剪除 EMA 教师分支，仅保留在线分支、世界解码器和动作头，部署策略保持轻量。

### 2.2 vlm-jepa：时序潜在动作学习

- 在线分支向当前图像-语言序列插入可学习 `latent-X` 查询 token，得到隐藏状态 \(X_t\)。
- 轻量 transformer 预测器 \(P_\phi\) 将 \(X_t\) 与目标查询嵌入 \(Q_Y\) 映射到潜在动作空间，输出预测潜在动作 \(\hat z_t\)。
- 预测器结构为：分别投影 latent-X token 和目标查询、加入位置嵌入、拼接后过自注意力堆栈，仅保留目标位置并投影回世界模型码空间。该显式瓶颈防止潜在动作直接从单个 VLM 隐藏状态复制，迫使模型从当前观测推断时序意图。
- 教师分支使用同一 VLM 和潜在动作映射器，但输入当前与未来图像，输出目标潜在动作 \(z^Y_t\)。
- 教师参数按 EMA 更新：\(\xi \leftarrow m\xi + (1-m)\theta_Y\)，梯度不流经教师。
- 时序对齐损失为在线预测与 stop-gradient 教师目标之间的 L1 距离（可选对目标做码维度归一化）：
  \[
  \mathcal{L}_{temp}=\|\hat z_t-\bar z^Y_t\|_1
  \]
- 该目标不重建像素、不需要动作标签，只要求学生在仅有当前观测时推断教师所表示的时序变化。

### 2.3 delta-lwm：潜在世界-动作耦合

- 使用**冻结 DINOv3 编码器**提取当前与未来帧的空间特征网格 \(F_t, F_{t+1}\)。
- 可训练解码器 \(D_\psi\) 不预测绝对未来表示，而是预测**特征位移**：
  \[
  \Delta F_t=F_{t+1}-F_t,\quad \widehat{\Delta F}_t=D_\psi(F_t,\hat z_t)
  \]
- 解码器为 AdaLN 条件 transformer，条件向量为池化后的潜在动作投影，使同一视觉状态在不同意图下产生不同位移。
- 世界模型损失同时监督教师潜在路径和学生潜在路径：
  \[
  \mathcal{L}_{world}=\|D_\psi(F_t,z^Y_t)-\Delta F_t\|_2^2+\|D_\psi(F_t,\hat z_t)-\Delta F_t\|_2^2
  \]
- 为增强潜在动作与视觉动态的**可识别耦合**，引入排序约束：匹配潜在动作的预测误差应比批内错配潜在动作的误差小一个 margin：
  \[
  \mathcal{L}_{dep}=\left[\mu+\|D_\psi(F_t,\hat z_t)-\Delta F_t\|_2^2-\|D_\psi(F_t,\tilde z_t)-\Delta F_t\|_2^2\right]_+
  \]
- 预测未来特征为 \(\hat F_{t+1}=F_t+\widehat{\Delta F}_t\)，作为动作头的内部预测条件，而非额外观测。

### 2.4 流匹配动作策略

- 动作头为条件 transformer + flow matching，输入包括当前特征 \(F_t\)、预测未来特征 \(\hat F_{t+1}\)、完整 VLM 隐藏序列、本体状态和具身标识。
- 对噪声 \(\epsilon\sim\mathcal N(0,I)\)、流时间 \(\tau\in[0,1]\)，构造插值动作 \(a_\tau=(1-\tau)\epsilon+\tau a\)，目标向量场 \(u=a-\epsilon\)，损失为：
  \[
  \mathcal{L}_{flow}=\mathbb E_{\tau,\epsilon}\|v_\theta(a_\tau,c)-u(a,\epsilon,\tau)\|_2^2
  \]
  其中条件 \(c=(F_t,\hat F_{t+1},h^{vlm}_t,s_t)\)。
- 训练时未来视觉条件可混合预测特征与真实未来特征：
  \[
  F^{cond}_{t+1}=r_t\hat F_{t+1}+(1-r_t)F_{t+1}
  \]
  \(r_t\) 为伯努利掩码，训练中逐渐提高选择预测的概率；推理时 \(r_t=1\)，保证训练与部署条件一致。
- 动作损失仅在有效、非填充动作 token 及带机器人动作的样本上计算。

### 2.5 端到端联合训练

- 每个片段中，首帧观测和指令仅进入在线 X-VLM 一次，同时产生 \(\hat z_t\) 和 VLM 上下文 \(h^{vlm}_t\)。
- 预测潜在动作送入 delta-lwm，未来特征与当前特征、VLM 上下文在动作头拼接。机器人动作损失因此可微分地经过动作头、预测未来特征、世界解码器、潜在动作预测器和在线 VLM。
- 机器人样本损失：
  \[
  \mathcal{L}_{robot}=\mathcal{L}_{flow}+\lambda_T\mathcal{L}_{temp}+\lambda_W\mathcal{L}_{world}
  \]
- 无动作 ego 视频样本仅激活时序和世界模型项：
  \[
  \mathcal{L}_{ego}=\lambda_T\mathcal{L}_{temp}+\lambda_W\mathcal{L}_{world}
  \]
- 机器人样本与 ego 样本可在同一批次或连续微批次中交错，掩码损失求和后统一更新共享模块，使无动作视频持续塑造机器人控制所用表示，而非作为被丢弃的预训练阶段。
