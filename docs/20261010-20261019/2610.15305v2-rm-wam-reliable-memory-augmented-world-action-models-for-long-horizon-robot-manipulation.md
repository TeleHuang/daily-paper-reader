## 摘要
世界动作模型（World Action Models, WAMs）通过联合预测未来视觉状态与动作来提升机器人操作能力，然而现有大多数方法主要基于当前观测进行决策。这限制了其在长时程任务中的可靠性，因为视觉上相似的状态可能对应不同的交互历史与任务阶段。此外，直接引入历史观测可能带来过时、阶段不匹配或受错误污染的信息，从而导致世界预测不准确并累积闭环误差。我们提出 RM-WAM，一种可信的记忆增强世界动作模型，它将记忆视为依赖上下文的预测资源，而非普遍有用的历史上下文。RM-WAM 利用互补的短期视觉状态记忆与潜在事件记忆来表示历史，二者分别捕捉近期交互动态与较长期的状态转移。一种反事实记忆学习方案在保持当前输入与预测目标固定的同时改变可访问的历史，使模型能够学习历史记忆的上下文相关效用估计。基于该估计，一种效用感知门控机制自适应地控制记忆注入世界-动作主干网络。实验表明，RM-WAM 凸显了在长时程任务中可靠且选择性利用记忆的重要性。

## Abstract
World Action Models (WAMs) improve robotic manipulation by jointly predicting future visual states and actions, yet most existing methods make decisions primarily from the current observation. This limits their reliability in long-horizon tasks, where visually similar states may correspond to different interaction histories and task stages. Moreover, directly incorporating historical observations can introduce stale, stage-mismatched, or error-contaminated information, leading to inaccurate world prediction and accumulated closed-loop errors. We propose RM-WAM, a reliable memory-augmented World Action Model that treats memory as a context-dependent predictive resource rather than universally useful historical context. RM-WAM represents history using complementary short-term visual state memory and latent event memory, which respectively capture recent interaction dynamics and longer-term state transitions. A counterfactual memory learning scheme varies the accessible history while keeping the current inputs and prediction targets fixed, enabling the model to learn a context-dependent utility estimate for historical memory. Based on this estimate, a utility-aware gating mechanism adaptively controls memory injection into the world-action backbone. Experiments demonstrate that RM-WAM highlights the importance of reliable and selective memory utilization in long-horizon tasks.
