Introduction
VLA models bring the semantic knowledge of large pretrained VLMs into robot control, enabling
a single policy to follow diverse instructions across objects and scenes (Kim et al., 2024; Black
et al., 2025; Yuan et al., 2026). This capability, however, is commonly coupled to repeated backbone
execution: each action chunk re-encodes the current images and language instruction with a large
model. Therobotmustcontinuously observetheenvironmentand reviseitsactions, butthe instruction
and overall task remain largely unchanged. Must the large VLM backbone also be re-run at every
control decision?
When manipulating objects, people typically work out the goal and identify the relevant objects
before acting. As they reach, grasp, and place, they adjust their movements from what they see and
feel without reinterpreting the whole task before every small action. This suggests two timescales:
task understanding can remain stable, while control must respond continuously to changes in the
scene. This motivates a policy that establishes task context once and then stays responsive to live
observations throughout execution.
Prior work reduces VLA inference cost by changing action representations or generation procedures
(Pertsch et al., 2025; Yuan et al., 2026). These improvements leave a separate question: must a large
model recompute task context for every action chunk? Can a VLA think once about the task and still
manipulate effectively as the scene changes throughout an episode?
A fixed memory cannot represent the current world state: objects and arms move, and the visible
scene changes during execution. The central challenge is to use live observations to query fixed
task context at every control decision. We address this with Fast-VLA—You Only Think Once. A
frozen 4B VLM encodes the instruction and initial multi-camera views into layer-wise key–value
task memory at the start of an episode, then leaves the repeated control loop.
The online actor continually processes current camera views and proprioception, with short visual
history in the RoboTwin configuration.
Query fusion combines learned time- and arm-indexed
queries with current arm state and wrist-view features to form action queries. The action decoder
uses these queries to read visual tokens and task memory, and an action head predicts an action chunk
in one forward pass. The memory remains fixed, but the observations and predicted actions change
at every control decision. The policy therefore remains closed-loop even though its task memory is
fixed.
We evaluate Fast-VLA on RoboTwin 2.0 (Chen et al., 2025), LIBERO (Liu et al., 2023), and LIBERO-
Plus (Fei et al., 2025). On RoboTwin 2.0, it reaches 92.46% success in the Clean setting and 92.40%
under domain randomization. Fast-VLA obtains 95.95% on standard LIBERO and 79.11% on the
LIBERO-Plus protocol. On RoboTwin, same-hardware measurements against Faster-WAM (HUST),
DM0.5, and Fast-WAM show a 10.9–17.1× reduction in amortized policy inference time after
including its one-time initial call, and its post-prefill online resident memory is 1.22 GiB. Task-
memory swaps cause large performance drops, showing that the actor depends on episode-matched
memory in our evaluation.
Our contributions are threefold:
• We introduce an episode-level VLA architecture that represents one-time task understanding
as fixed, multi-layer memory, moving a frozen 4B VLM outside the repeated control loop.
• We develop an online actor that fuses learned queries with live visual and proprioceptive
feedback to form action queries. These queries retrieve task context across VLM depths,
enabling action-chunk prediction in one forward pass.
• Across RoboTwin 2.0, LIBERO, and LIBERO-Plus, we show that this separation preserves
competitive closed-loop performance while reducing RoboTwin amortized inference cost
by 10.9–17.1×; controlled memory interventions verify that the actor uses episode-matched
context.

Related Work
Efficient VLA policies.
Generalist VLA policies couple pretrained VLM representations with
action generation through autoregressive tokens, flow matching, or specialized action heads (Kim
et al., 2024; Black et al., 2025). Recent work reduces the cost of each policy invocation through
parallel continuous-action decoding and action chunking (Kim et al., 2025), or through more compact
action tokenization (Pertsch et al., 2025). These methods primarily optimize action generation while
retaining repeated processing of new observations by the VLM backbone. Our focus is instead the
frequency of backbone invocation: Fast-VLA removes the frozen VLM from the control loop after
one episode-level prefill. HyperVLA amortizes task conditioning by encoding the instruction and
initial image into the generated parameters of a compact base policy, which then maps each current
observation to an action (Xiong et al., 2025). Fast-VLA instead keeps the online actor shared across
episodes and retains task context as explicit, layer-wise key–value task memory; at every control
decision, query fusion combines learned queries with current feedback to form action queries that
retrieve from this fixed memory.
Reusing computation across control steps.
VLA-Cache reuses representations of visually stable
tokens between adjacent observations while selectively recomputing changed or task-relevant content
(Xu et al., 2025). World-action models reduce online cost by omitting test-time future generation
(Yuan et al., 2026), sparsifying video–action interaction (Zhao et al., 2026), or attaching a shallow
action module to a deep video backbone (Ma et al., 2026). These approaches reduce the work
performed at each online call, but retain a large visual or video backbone in the repeated control
path. Fast-VLA instead fixes task context at episode start and delegates changing-state estimation
entirely to a lightweight online actor.

3.3
Online actor
Live inputs.
In the RoboTwin configuration shown in Figure 2, the online actor receives current
head and two wrist images, short head-camera history, and robot state. Each camera has a separate
trainable DINOv2 (Oquab et al., 2023) encoder, with weights shared across frames from that camera.
Visual tokens carry learned slot embeddings and time offsets, distinguishing past from current
evidence. These tokens feed Cross-Visual attention; the CLS token from each current wrist view
separately feeds query fusion.

read differently as execution progresses.
Action decoding.
Each of the four action decoder layers follows the four stages shown in Figure 2.
Self attention coordinates queries across future time steps and the two arms. Cross-Visual attention
reads visual tokens from current views and available history, grounding each query in visual feedback.

feed-forward network (FFN) updates the query. Together, these stages ground each action query
in both the current visual–proprioceptive state and episode-level task context, enabling task-aware
action prediction that remains responsive throughout execution.

Experiments
Training setup.
We train separate policies on RoboTwin 2.0’s 50-task Clean+Randomized training
set and demonstrations from all 40 tasks across the four LIBERO suites. The action decoder and
head are trained from scratch, while the visual encoders are initialized from DINOv2 and fine-tuned.
Since the task-memory VLM is frozen, we precompute and store its task-memory KV caches offline
and reuse them throughout actor training, avoiding repeated VLM forward passes. Full training
details are provided in Table 1 and Appendix A.
Evaluation protocol.
We follow the established evaluation protocols of RoboTwin 2.0 (Chen et al.,
2025), standard LIBERO (Liu et al., 2023), and LIBERO-Plus (Fei et al., 2025). On RoboTwin
2.0, we evaluate 100 episodes per task in each setting (10,000 rollouts). On standard LIBERO, we
evaluate all four 10-task suites with 50 initial states per task (2,000 rollouts). We also evaluate on all
10,030 LIBERO-Plus perturbation instances. Baseline success rates come from published reports,
benchmark compilations, or our evaluations of released checkpoints, as detailed in Appendix C.
Cost measurement.
Inference costs are measured separately under a common profiling protocol
on identical hardware. Across Tables 2 and 3, Pred./exec. denotes actions predicted per call / actions
executed before replanning; ms/chunk is the wall time of one action-generation call, and amortized
ms/step follows the execution schedule and includes any once-per-episode setup. We report online
resident memory separately from the initialization peak for Fast-VLA. Appendix B provides the
measurement details.

4.1
RoboTwin 2.0: performance and inference cost
Fast-VLA achieves 92.46% Clean and 92.40% Randomized success (92.43% mean) on RoboTwin
2.0 (Table 2). Among baselines in the table with at least 90% mean success and measured inference
costs, Fast-VLA provides at least 10.9× faster amortized inference. Relative to DM0.5, its mean
success is 1.02 percentage points lower with 11.2× faster amortized inference at the same replanning
interval of 50 environment steps. Compared with Faster-WAM (HUST), Fast-VLA scores 0.09 points
lower with a 10.9× speedup; it exceeds Fast-WAM by 0.60 points with a 17.1× speedup. Faster-
WAM (Noah), at 89.17% mean success, has the lowest measured amortized latency among the WAM
baselines; Fast-VLA exceeds its mean success by 3.26 points with a 3.6× speedup.
4.2
LIBERO and LIBERO-Plus
Fast-VLA achieves 95.95% on standard LIBERO and 79.11% on LIBERO-Plus (Table 3). Compared
with Faster-WAM (Noah) and Faster-WAM (HUST), it achieves 4.11 and 5.54 percentage points
higher LIBERO-Plus success with 3.1× and 21.2× faster amortized inference, respectively, although
its standard LIBERO success is lower. All three methods replan every 10 environment steps. On
LIBERO-Plus, Fast-VLA trails π0.5 and DM0.5 by 6.59 and 6.79 percentage points, respectively.
Both baselines use pretrained action-generating weights, whereas our action decoder and head are
trained from scratch on LIBERO demonstrations.
4.3
Qualitative rollouts and live visual grounding
Figure 3 shows successful rollouts on RoboTwin 2.0 and LIBERO-10, plus the same drawer task under
LIBERO-Plus sensor noise. The noisy episode succeeds despite severe third-person corruption, with
an unperturbed wrist view available to the actor. In all three episodes, task memory is built once
from the initial observations and reused throughout execution. Appendix D shows five additional
perturbation types and further clean rollouts.
Figure 4 visualizes how the actor uses current visual feedback during a successful stack blocks two
episode. As control passes from the left arm to the right, head-camera attention shifts from the red
block to the green block, while each wrist focuses on the object relevant to its arm. The right wrist
attends to the green block before the second sub-goal begins. Together, these shifts show that the
actor updates its visual focus as the active sub-goal changes.

Memory construction.
Building on the memory-swap results, Table 5 examines how memory
construction affects task performance and robustness. Removing task memory reduces success to
69.90/53.69 on standard LIBERO/LIBERO-Plus, highlighting its importance for task execution and
robustness. Retaining only text-token KV from image-conditioned memory achieves 93.20/73.84,

improving standard LIBERO success over text-token-only memory with a similar LIBERO-Plus suc-
cess rate. Full memory achieves the highest success on both benchmarks (95.95/79.11), supporting
the use of instruction and visual KV across multiple VLM layers.
Online observations.
Table 6 shows the importance of current wrist vision: a wrist-only policy
reaches 87.10/68.72 on standard LIBERO/LIBERO-Plus, compared with 70.80/30.80 for the head-
only policy. Without wrist vision, success is 65.60/33.49; without proprioception, it is 94.30/72.41.
These results identify wrist vision as a key source of closed-loop feedback.
Memory refresh frequency.
We compare memory-refresh schedules using the last-layer memory
variant. As shown in Table 8, refreshing the memory every action chunk changes success by +1.80
percentage points on standard LIBERO and −1.23 percentage points on LIBERO-Plus relative to
once-per-episode construction, while increasing foundation-model calls by 17.37× and amortized
inference time by 3.12× (3.975 to 12.391 ms per environment step). Refreshing every two or four
chunks still costs 2.03× and 1.48× the amortized time while improving standard success by 1.25
points but reducing LIBERO-Plus success by 3.07 and 5.46 points. These results support once-per-
episode memory construction as an efficient trade-off between success rate and VLM computation.

5
Conclusion
Fast-VLA separates one-time task understanding from repeated closed-loop control. A frozen 4B
VLM builds episode-level task memory, while the online actor uses current visual and propriocep-
tive feedback to produce action chunks. The policy reaches 92.46%/92.40% success on RoboTwin
Clean/Randomized and 95.95%/79.11% on standard LIBERO/LIBERO-Plus. Same-device mea-
surements show 10.9–17.1× lower RoboTwin amortized inference time than Faster-WAM (HUST),
DM0.5, and Fast-WAM. Task-memory swap interventions show that the actor relies on memory
matched to the episode.

E
Limitations
Fast-VLA constructs task memory once at episode initialization and keeps it fixed throughout exe-
cution. While the online actor responds to current observations, handling changes in task goals or
newly introduced instructions during an episode remains unexplored. Combining Fast-VLA with
event-triggered memory updates and high-level replanning could extend it to such dynamic settings
while retaining the efficiency of memory reuse between updates.
