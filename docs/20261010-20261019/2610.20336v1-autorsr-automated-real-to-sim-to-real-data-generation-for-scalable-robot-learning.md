## 摘要
扩展具身机器人学习需要大规模且多样的操作数据集，但收集真实世界演示在人力投入和机器人时间上仍然代价高昂。仿真提供了一种可扩展的替代方案，但将真实工作空间转换为可直接用于机器人学习的环境，仍需要在物体提取、资产处理、坐标标定和轨迹指定方面投入大量人工。我们提出 AutoRSR，一个高度自动化的真实到仿真再到真实框架，可将扫描得到的真实世界工作空间转换为可复用的具身仿真资产和可扩展的操作数据。给定多视角观测、机器人状态和开放词汇语义查询，AutoRSR 重建工作空间，提取单个物体资产，并在度量尺度上将重建场景自动配准到机器人基座坐标系。从少量参考运动出发，AutoRSR 随后生成可执行的操作轨迹，并通过轨迹插值和域随机化进行扩展。在工作空间扫描和语义查询之后，剩余流程无需人工物体标注、场景到机器人的标定或机器人遥操作。在三个真实世界操作任务中，每个任务使用 1K 个自动生成回合训练的策略达到 73.3--86.7% 的真实世界成功率，与使用 150 个人类遥操作演示训练的 pi 0.5 相当，同时将数据生成所需的人工时间减少一个数量级。这些结果表明，真实世界观测可以被转换为度量对齐、可执行且可扩展的仿真数据，同时显著减少人工投入。

## Abstract
Scaling embodied robot learning requires large and diverse manipulation datasets, but collecting real-world demonstrations remains expensive in human effort and robot time. Simulation provides a scalable alternative, yet converting a real workspace into a robot-learning-ready environment still requires substantial manual effort for object extraction, asset processing, coordinate calibration, and trajectory specification. We present AutoRSR, a highly automated real-to-sim-to real framework that converts scanned real-world workspaces into reusable embodied simulation assets and scalable manipulation data. Given multi-view observations, robot states, and open-vocabulary semantic queries, AutoRSR reconstructs the workspace, extracts individual object assets, and automatically registers the reconstructed scene to the robot base frame at metric scale. Starting from a small number of reference motions, AutoRSR then generates executable manipulation trajectories and scales them through trajectory interpolation and domain randomization. After workspace scanning and semantic queries, the remaining pipeline requires no manual object annotation, scene-to-robot calibration, or robot teleoperation. Across three real-world manipulation tasks, policies trained on 1K automatically generated episodes per task achieve 73.3--86.7% real-world success rates, comparable to pi 0.5 trained from 150 human teleoperated demonstrations, while reducing the human time required for data generation by an order of magnitude. These results demonstrate that real-world observations can be converted into metrically aligned, executable, and scalable simulation data with substantially reduced human effort.

## 1. 核心问题与研究背景

- **核心瓶颈**：具身机器人学习缺乏可扩展、多样的操作数据。真实遥操作数据保真度高，但人力与机器人机时成本极高；仿真虽可低成本批量生成，但“真→仿”转换本身仍是重人工环节。
- **关键痛点**（作者归纳为两个相互耦合的挑战）：
  - **可复用仿真资产生成**：现有流程需分别扫描物体与场景、人工分割、逐物体补全处理，人力随场景复杂度增长，场景一变就要重做；且场景重建与物体准备通常是割裂的两个阶段。
  - **可执行轨迹生成**：重建结果位于自身坐标系，必须显式做场景—机器人标定或人工对齐；示教轨迹往往依赖真机遥操作或人工指定，即便仿真免去了物理执行成本，人力仍嵌在“初始可执行数据”的生产中。
- **研究定位**：现有方法分两类——生成式（灵活但几何/外观偏离目标工作区）与重建式（保真但人工介入多）。本文走重建式 Real2Sim2Real 路线，目标是让“扫描一次真实工作区”即可成为**自动化、可复用的数据引擎**。
- **整体含义**：把人力集中到“扫描 + 语义查询 + 一段示教视频”这三个一次性输入上，其余（物体提取、坐标配准、轨迹生成、数据扩增）全自动，从而把真实观测转成度量对齐、可执行、可扩展的仿真数据。

## 2. 方法论

### 2.1 核心思想
利用**扫描过程中本就存在的信息**（腕部相机位姿与机器人关节状态同步记录）来消除后续的人工对齐与标注：因为相机刚性安装在机器人上，重建场景可用记录的几何关系自动、按度量尺度配准到机器人基座系；再用一段人类示教作为“运动种子”，在已对齐环境中恢复可执行轨迹并批量扩增。

### 2.2 流程与关键技术细节

**（1）初始化与混合扫描**
- 双臂按预定顺序绕场景扫描（左臂先、右臂后，各自回到 home 位附近视为采集完成），同时记录机器人状态；用手机内置相机 + 两个腕部 D405 做混合扫描，固定 D435 提供俯视视角并录制人类示教视频。
- 建立“图像文件名 ↔ 机器人位姿”映射；用 COLMAP / PostShot 得到稀疏点云与相机位姿（位于重建坐标系而非机器人坐标系）。

**（2）语义锚点初始化**
- 在参考帧用 SAM2 分割并沿视频传播物体 ID，得到跨视图一致的语义掩码；再把 2D 标签迁移到稀疏点云：每个点投影到所有可见视图，按可见性与遮挡关系做**多数投票**确定语义标签（式 1）。
- 标签化点云体素化（`q = round(a/h)`）合并为锚点；因点云稀疏，进一步做**语义约束的锚点生长**：仅在语义一致的 KNN 锚点对之间生成中点锚点，继承标签并重新体素化去重，抑制跨语义边界的错误传播。

**（3）物体感知高斯重建（基于 ObjectGS / Scaffold-GS）**
- 每个锚点含位置、可学习特征、实例标签、局部尺度与 M 个可学习偏移；神经高斯中心为 `μ = x_a + s_a ⊙ o_{a,m}`，颜色/不透明度/协方差由 MLP 依视角预测。
- 损失：`L_rec = (1−λ_ssim)L1 + λ_ssim(1−SSIM) + λ_obj L_CE + L_base`，其中 `L_CE` 用 2D 物体 ID 掩码监督语义分数（忽略背景标签 0），`L_base` 汇集尺度、深度、法线、畸变、不透明度、背景语义等正则。
- 稠密化时新锚点继承梯度贡献最强父锚点的标签，使**物体身份与局部几何生成耦合**，支持直接按实例选择。

**（4）物体提取与资产导出**
- 用户给出开放词汇查询（如 “bowl”, “kettle”），用 GroundingDINO + SAM 在渲染视图上得目标掩码，与渲染语义 ID 图做重叠打分关联实例 ID，再抽取对应锚点；通过空间邻域扩张抑制残留高斯，同时得到“纯物体”与“去物体场景”两种表示。
- 因锚点属性视角相关，从多个训练相机求值并聚合为标准显式 3DGS：物体用不透明度跨视图一致性 + 中值聚合，场景用均值保留覆盖；必要时对原锚点模型的多视图渲染做蒸馏以减伪影。
- 用 SuGaR 从显式高斯提网格；孤立物体用各向异性高斯支撑剔除无支撑面，再体素化 + 表面重建得到**水密碰撞网格**；需要关节资产时接 Articulate-Anymesh。

**（5）度量坐标自动对齐**
- 每张图的度量相机位姿由同步机器人构型、基座外参、手眼标定算出：`T_RC^i = T_RB · T_BE(q_i) · T_EC`。
- 重建位姿与机器人推算位姿之间用 RANSAC 求相似变换并做鲁棒精化（位置 + 朝向）；随后物体位姿映射 `p_R = s·R_RW·p_W + t_RW`，`R_RO = R_RW·R_WO`，同一尺度施加于高斯资产与碰撞网格。原 COLMAP 模型不改动；示教用标定后的头相机位姿解释，而非随意指派某张扫描图。

**（6）示教对齐与抓取重定向**
- 用已有语义查询 + GroundingDINO + SAM2 在示教首帧定位目标并全程传播（全自动）。
- 通过**可微高斯渲染**恢复物体 3D 运动：固定外观与局部几何，仅优化物体位姿，损失含前景/背景平衡轮廓损失、Dice 损失、鲁棒前景光度误差，加时间正则与有界像素质心先验；初始化限制在重建位姿邻域，后续帧以上一帧估计为初值。
- 从碰撞网格生成多方向/多闭合方向/多位置的抓取候选（考虑夹爪开合范围与几何）；用 HaMeR 的手部线索（拇指—食指中点投影）对候选排序，但**不把单目手部深度当作度量真值**。
- 由跟踪的物体运动与物体局部系下选定抓取位姿推导期望末端运动；带关节限位约束的 IK 用沿轨迹序列热启动求解，按整段位置/朝向残差验收。夹爪闭合搬运期把物体位姿绑定到实际末端位姿（保留局部抓取变换），释放时保留实际到达的放置位姿而非“吸附回”名义轨迹；受约束的关节/推动运动则保留规定物体运动学并检查接触。

**（7）轨迹与视觉扩增**
- **运动扩增**：独立随机化所有被查询物体的桌面摆放（有界平面平移 + 绕自身初始位置的偏航旋转），保持高度、尺度与已验证的抓取关系；对被操作物体做**任务相对轨迹适配**——保留采样初始位姿，调整终止位姿以维持与“独立摆放的接收物”的示教关系，用平滑时变修正混合世界坐标位置并插值相对朝向，避免绕坐标原点“公转”；可显式指定交互区间以在整段维持关系。
- 每个候选扩展为“接近—闭合—任务运动”同步序列；放置任务用物体相对表面探针做几何支撑检验，未确认支撑则保持夹持并拒收候选；批量求解 IK，筛查关节限位、位姿残差、闭合期指接触、机器人—物体网格过度穿透（作者明确这是**几何可行性筛查，不保证力闭合或动力学成功**）。
- **视觉扩增**：几何、动作、时序不变，随机化物体与场景纹理、对高斯做曝光/白平衡一致调整、对机器人网格渲染加光照变化；渲染时复用 Genesis 运行时与缓存高斯资产，按兼容回合批处理高斯数据与相机请求；机器人与高斯前景/背景层用同一相机位姿渲染并按深度合成；腕相机位姿由关节构型 + 手眼变换重算。所有输出共享同一时间轴（观测、本体状态、动作、夹爪开度帧索引对齐）。
