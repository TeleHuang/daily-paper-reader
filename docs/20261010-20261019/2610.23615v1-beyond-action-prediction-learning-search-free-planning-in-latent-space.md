## 摘要
潜世界模型在紧凑的表示空间中学习以动作为条件的状态转移，为视觉规划与控制提供了预测模型。然而，使用这些模型进行规划通常需要在测试时对动作序列进行代价高昂的优化。我们提出用一种目标条件逆模型替代这种在线搜索，该模型直接从当前观测和目标观测预测动作。一个关键挑战在于，仅进行动作预测既不能保证目标表示编码了与动作相关的信息，也不能保证预测动作与学习到的潜预测模型一致。我们提出后见逆JEPA规划（HIJP），这是一个在训练期间同时解决上述两方面的免搜索框架。HIJP将离线轨迹上的未来观测重新标记为目标，从而在多个时间跨度上提供动作监督。通过在目标表示上保留梯度，该监督直接塑造视觉表示。HIJP进一步将预测动作输入潜预测模型，并将得到的下一状态表示与编码的后续观测对齐，从而强制动作—转移一致性。在推理时，逆动力学模型和潜预测模型交替应用，以生成多步动作序列，而无需在线搜索。在四个视觉控制任务上，HIJP取得86.8%的总体成功率，相较于基于搜索的规划实现1.9–16.5倍的规划加速。

## Abstract
Latent world models learn action-conditioned state transitions in a compact representation space, providing a predictive model for visual planning and control. However, planning with these models typically requires costly test-time optimization over action sequences. We propose to replace this online search with a goal-conditioned inverse model that directly predicts actions from current and goal observations. A key challenge is that action prediction alone neither ensures that goal representations encode action-relevant information nor that predicted actions are consistent with the learned latent prediction model. We introduce Hindsight Inverse JEPA Planning (HIJP), a search-free framework that addresses both aspects during training. HIJP relabels future observations along offline trajectories as goals, providing action supervision across multiple temporal horizons. By retaining gradients through the goal representations, this supervision directly shapes the visual representation. HIJP further feeds predicted actions into the latent predictor model and aligns the resulting next-state representations with encoded successor observations, enforcing action-transition consistency. At inference time, the inverse dynamics model and latent predictor models are applied alternately to generate multi-step action sequences without online search. Across four visual control tasks, HIJP achieves 86.8% overall success and a 1.9-16.5x planning speedup over search-based planning.

## 1. 核心问题与研究动机

- **背景**：潜世界模型（latent world model）把高维视觉观测压缩为紧凑潜表示，并学习“以动作为条件的潜转移”，从而为视觉规划与控制提供预测模型（如 DINO-WM、PLDM、LeWM 等）。
- **痛点**：这类模型在测试时必须依赖 CEM / MPPI 等优化器，在每个重规划点反复采样并评估大量候选动作序列，测试时计算开销巨大。
- **自然思路**：学习一个“目标条件逆模型”，直接从当前观测与目标观测预测动作，用摊销（amortized）推理替代在线搜索。
- **作者指出的两个关键不足**：仅靠动作预测监督并不充分：
  1. **目标侧表示未被充分塑造**：目标表示通常只作为条件输入，梯度不回传，动作监督无法塑造目标侧视觉特征；且已有方法（如 INTACT 等）多只用轨迹窗口的固定终点作为目标，浪费了离线轨迹中天然存在的“多时间跨度”状态–目标关系。
  2. **逆模型与潜预测模型缺乏耦合**：二者通常分别监督（预测器只用示范动作训练），但实际规划时是“逆模型预测动作 → 预测器推进潜状态”的串联组合，该组合从未被显式约束，预测动作未必能在学到的动力学下产生正确转移。
- **整体含义**：论文主张把动作监督“扩展到动作预测之外”——既用于塑造目标条件表示，也用于约束预测动作所诱导的潜转移，从而真正实现可替代在线搜索的免搜索规划。

## 2. 方法论：HIJP（Hindsight Inverse JEPA Planning）

### 2.1 核心思想
端到端联合训练四个模块：视觉编码器 \(f_\theta\)、动作编码器 \(\psi_\omega\)、潜预测器 \(g_\phi\)、目标条件逆动力学头 \(h_\xi\)；用“后见目标重标注 + 梯度贯通目标表示 + 动作–转移一致性”三条设计，使训练时的“逆模型→预测器”组合与推理时的组合完全一致。

### 2.2 关键组件与公式（文字说明）
- **潜世界模型**：\(z_t=f_\theta(o_t)\)，\(\hat z_{t+1}=g_\phi(z_{t-m+1:t}, a_{t-m+1:t})\)，预测损失 \(L_{pred}=\text{MSE}(\hat z_{t+1}, z_{t+1})\)；另加 SIGReg 各向同性高斯正则 \(L_{sigreg}\) 防止表示坍缩（作用于窗口内全部帧）。
- **后见条件逆动力学**：在长度 \(W\) 的轨迹窗口内采样锚点 \(i\sim U\{0,\dots,W-2\}\)、未来偏移 \(\kappa\sim U\{1,\dots,W-1-i\}\)，把 \(o_{i+\kappa}\) 作为后见目标，预测的是**锚点处的即时动作** \(a_i\)（而非中间动作序列）：\(L_{inv}=\text{MAE}(h_\xi(z_i,z_{i+\kappa}), a_i)\)。
  - 关键：梯度同时流经 \(z_i\) 与 \(z_{i+\kappa}\)，因此逆监督直接塑造当前侧与目标侧的视觉特征（“目标表示不只是条件变量”）。
- **动作–转移一致性**：把预测动作送回预测器 \(\tilde z_{i+1}=g_\phi(z_i,\hat a_i)\)，与真实一步后继编码对齐：\(L_{cyc}=\text{MSE}(\tilde z_{i+1}, \text{sg}[z_{i+1}])\)，其中 sg 为 stop-gradient。
  - 该损失同时更新逆头、动作编码器、潜预测器和锚点侧表示，直接监督规划时反复使用的“逆→预测”复合映射。
- **联合目标**：\(L=L_{pred}+\lambda_{reg}L_{sigreg}+\lambda_{inv}L_{inv}+\lambda_{cyc}L_{cyc}\)，其中 \(\lambda_{reg}=0.09\)、\(\lambda_{inv}=1.0\)、\(\lambda_{cyc}=0.05\)（TwoRoom）/ 0.10（其余任务）。
- **免搜索规划流程**：编码当前与目标观测 → 从 \(\hat z_0=z_t\) 起，交替执行 \(\hat a_j=h_\xi(\hat z_j,z_g)\) 与 \(\hat z_{j+1}=g_\phi(\hat z_{j},\hat a_j)\) 共 \(H=5\) 个模型步 → 执行动作块并闭环重规划（receding horizon）。
  - 每个重规划点仅需 **1 次** 逆模型+预测器自回归 rollout，无采样、无迭代精化；由于动作块 \(k=5\) 原始步，一个计划覆盖 25 个环境步。

### 2.3 实现细节
- 编码器：ViT-Tiny（12 层、3 头、宽 192、patch 14），**从零训练**，无预训练骨干；潜维度 192。
- 预测器：6 层因果 Transformer，16 头，AdaLN-Zero 注入动作条件，上下文 \(m=3\)。
- 逆头：3 层隐层（宽 512，LayerNorm+GELU）的 MLP，输入为潜向量拼接。
- 训练：AdamW（weight decay \(10^{-3}\)）、bf16 混合精度、梯度裁剪 1.0、线性 warmup + cosine 衰减、10 个 epoch、batch 48（OGCube 32）。

## 6. 主要结论与发现

- **性能**：HIJP 总体平均成功率 **86.8%**，比最强基线（INTACT，81.9%）高 **4.9 个百分点**；TwoRoom 99.5%、Reacher 81.5%（略低于 INTACT 的 85.0%）、PushT 69.5%、OGCube 96.5%。
- **增益集中在长时程操作任务**：PushT hard/extreme 比该档最佳基线高 8 / 14 个百分点；OGCube hard/extreme 保持 96%，分别高 26 / 10 个百分点。
- **效率**：相同重规划次数下相对 LeWM 提速 **1.9–16.5×**（平均 6.2× / 7.1× / 15.0× / 2.8×，分别对应 TwoRoom / Reacher / PushT / OGCube）。
- **潜空间进展**：在 extreme 档，HIJP 的最终归一化潜距离低于“同表示 + CEM”消融（PushT 上 CEM 后期基本停滞而 HIJP 继续逼近），Reacher 上波动更小。
- **动作平滑性**：extreme 档 jerk 比同表示 CEM 消融低 **14.7–26.4×**，比 LeWM 低 **15.2–24.5×**，说明平滑性主要来自摊销逆引导规划而非表示差异。
- **消融结论**：
  - 去掉 \(L_{inv}\) 影响最大（82.5% → 45.7%）；去掉 SIGReg 降至 47.0%（Reacher 近乎崩溃）→ 动作监督与表示正则都关键。
  - 只用窗口终点作目标 → 71.7%；阻断目标侧梯度 sg[\(z_g\)] → 78.5% → 支持“多跨度后见目标 + 梯度贯通目标表示”。
  - 去掉 \(L_{cyc}\) → 76.0%；冻结预测器（\(L_{cyc}\) 不更新 \(g_\phi\)）→ 78.3% → 支持一致性目标且需同时更新预测器。
  - 用 CEM 替换摊销 rollout → 69.3% → 学到的规划机制本身有效。
  - 默认损失权重（\(\lambda_{inv}=1.0,\lambda_{cyc}=0.1\)）取得最佳总体 82.5%。

- **基线与协议仍有边界**：CEM 基线共享统一超参，虽有利于公平，但未必是每个基线的最优配置；INTACT 等端到端方法的实现细节与调参预算若不同，可能影响比较。成功判定使用模拟器原生条件值得肯定，但未报告失败模式分类（如碰撞、超时、目标漂移）。
- **可复现性报告不完整**：缺少 GPU 数量、总训练时长 / GPU-hours、模型参数量、随机种子设置与完整超参表；效率实验仅在单块 RTX 4090 上报告，未给出不同硬件或批处理规模下的延迟分解。
- **应用层面约束未讨论**：方法假设目标可由观测指定且潜空间目标编码可靠；在安全关键场景中，缺少显式约束满足、碰撞避免与不确定性估计机制。逆模型直接输出动作，若预测置信度低，系统没有拒绝或回退到搜索的机制。

## 9. 研究启示与可拓展方向

- **把“规划器”作为训练对象**：HIJP 的核心启示是，不应只监督世界模型的单步预测精度，而应监督推理时实际执行的“逆模型→前向模型”复合算子。这一思路可推广到扩散策略、分层规划、模型预测控制中的学习型终端代价等。
- **目标侧表示学习值得系统研究**：让目标编码接收动作监督梯度、使用多跨度后见目标，均是低成本但有效的设计；未来可探索目标表示的不确定性建模、多目标可达性集合学习，以及目标编码与价值函数的联合训练。
- **可与搜索式规划互补**：免搜索规划适合作为快速先验或默认策略；在分布外或高不确定性情形下，可用少量 CEM / MPPI 精化或进行安全回退，从而兼顾延迟与鲁棒性。论文尚未评估这种混合策略。
- **需要更严格的闭环理论分析**：可借鉴基于模型强化学习中的 rollout 误差累积分析，给出逆模型误差、前向模型误差与任务时程之间的关系，并据此设计自适应规划步长或动作块长度。
- **评测可进一步标准化**：建议报告多随机种子、失败模式分布、规划延迟分位数（而非仅平均墙钟时间）、分布外初始状态与目标扰动测试，以及不同硬件下的效率曲线，以增强结论的可迁移性。

## 10. 总体评价

HIJP 针对“潜世界模型规划依赖在线搜索”这一实际瓶颈，提出了一个动机清晰、结构简洁、推理极轻的免搜索规划框架。其关键贡献不在于单一模块的新颖性，而在于把动作监督从“预测动作”扩展为“塑造目标表示 + 约束逆–预测复合映射”，并通过后见多跨度目标重标注与循环一致性损失，使训练目标与推理流程对齐。实验覆盖四类动力学任务，主结果与消融总体支持其设计选择；效率与动作平滑性分析也提供了有价值的补充证据。

同时，论文在统计严谨性、结构超参敏感性、分布外泛化、理论保证与算力报告方面仍有明显提升空间。总体而言，这是一篇问题定位准确、工程可落地、经验证据较扎实的工作，适合作为“学习型规划器替代在线搜索”方向的重要参考；其结论宜理解为在给定离线数据与基准范围内的有效经验验证，而非普适的理论保证。
