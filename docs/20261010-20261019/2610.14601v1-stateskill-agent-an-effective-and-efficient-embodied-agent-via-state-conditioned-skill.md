## 摘要
在本工作中，我们旨在开发一种具身 MLLM 智能体，它能够通过学习、抽象和复用可迁移且可泛化的行为模式来理解和解决具身任务。为此，我们提出 StateSkill，一种面向具身智能体的新技能表示，它将“有限状态机”概念引入技能建模，以实现有效且高效的技能构建与学习。StateSkill 的核心思想是将具身交互经验建模为有限状态机，其中技能围绕一组任务进展状态、状态转移和状态条件化引导进行组织，使具身智能体能够在任务推进过程中动态调整技能，同时保持技能上下文紧凑且与阶段相关。我们进一步开发了 StateSkill-Evolve，一种经验驱动的演化机制，它通过对新的成功和失败的状态引导轨迹进行回溯分析，迭代地精炼 StateSkill。在此基础上，我们引入 StateGRPO，它通过状态条件化 GRPO 将 StateSkill 演化与模型优化集成到一个统一的迭代学习循环中，使状态条件化技能与模型能力能够共同演化并相互增强。大量实验表明，我们提出的方法和训练得到的模型（即 StateSkill-Agent）在多种具身任务上均具有有效性。

## Abstract
In this work, we aim to develop an embodied MLLM agent that understands and solves embodied tasks by learning, abstracting, and reusing transferrable and generalizable behavioral patterns. To this end, we propose StateSkill, a new skill representation for embodied agents, which introduces the concept of "finite-state machines" into skill modeling for effective and efficient skill construction and learning. The core idea of StateSkill is to model embodied interaction experiences as a finite-state machine, where a skill is organized around a set of task-progress states, state transitions, and state-conditioned guidance, enabling embodied agents to dynamically adjust their skills as the task progresses while keeping skill contexts compact and stage-relevant. We further develop StateSkill-Evolve, an experience-driven evolution mechanism that iteratively refines StateSkill through retrospective analysis of new successful and failed state-guided trajectories. Upon this, we introduce StateGRPO, which integrates StateSkill evolution and model optimization via state-conditioned GRPO into a unified iterative learning loop, enabling state-conditioned skills and model capabilities to co-evolve and reinforce each other. Extensive experiments demonstrate the effectiveness of our proposed methods and trained model (i.e., StateSkill-Agent) across various embodied tasks.
