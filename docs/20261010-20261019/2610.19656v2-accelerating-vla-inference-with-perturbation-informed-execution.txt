ABSTRACT
Action-chunking vision-language-action (VLA) models predict sequences of fu-
ture robot actions. Under fixed-horizon execution, the robot executes a fixed-
length prefix of each predicted chunk before invoking the policy again, leaving
the remaining predictions unused. For a given number of executed actions, short
execution horizons require more policy calls. Extending the execution horizon
amortizes policy inference cost over more actions. However, uniformly applying
long horizons across episodes can limit opportunities for precise corrections. To
address this limitation, we propose PICES (Perturbation-Informed Chunk and Ex-
ecution Horizon Selection), a training-free method that jointly selects an action
chunk and the number of actions executed before the next policy call. Within
a single policy call, the action expert generates a batch of action chunks from
multiple initial noise samples and their locally perturbed counterparts, using the
same conditioning features across all samples. PICES exploits differences be-
tween corresponding actions in each nominal chunk and its counterpart to deter-
mine candidate-specific execution horizons and select a nominal chunk for execu-
tion. Experiments on simulation benchmarks and real-world manipulation tasks
demonstrate that PICES achieves speedup by up to 2.3× in wall-clock policy in-
ference time on Jetson Orin and Thor relative to fixed-horizon baselines while
improving the success rate.

INTRODUCTION
Vision-language-action (VLA) models generate robot actions conditioned on visual observations,
proprioceptive states, and language instructions (Brohan et al., 2022; Kim et al., 2024; 2025). Re-
cent VLA architectures pair a vision-language backbone with a flow-matching action expert that
transforms initial noise into an action chunk, a sequence of future actions (Bjorck et al., 2025; Black
et al., 2024; Intelligence et al., 2025; Shukor et al., 2025). In conventional action chunking, the robot
executes fixed-length actions of each predicted chunk before replanning as illustrated in Figure 1(a).
The number of actions executed before update observations defines the execution horizon (Black
et al., 2026). The cumulative policy invocations across policy rollout makes task-completion time
dependent on both per-call latency and the number of policy calls (Zhou et al., 2026; Jing et al.,
2025).
At comparable success rates, shorter task-completion times enable a robot to complete more tasks
within a fixed time budget (Shukor et al., 2025; Huang et al., 2025). This makes cumulative inference
latency as an important consideration for onboard VLA deployment, where edge platforms such as
NVIDIA Jetson Orin and Thor operate under compute and memory-bandwidth constraints (Yang
et al., 2026; Jiang et al., 2026). For example, GR00T N1.7 requires 80.4ms per policy call on Jetson
Orin and 150.9 ms on Jetson Thor (Li et al., 2026; Bjorck et al., 2025), whereas observation acqui-
sition and actuation can operate up to 60Hz and 1kHz, respectively (Jiang et al., 2026; Ma et al.,
2025; Zhang et al., 2020). In observation-inference-execution pipeline, reducing the number of pol-
icy calls lowers cumulative inference latency and shorten task-completion time (Jing et al., 2025).
For action chunking policies, executing only fraction of each predicted action chunk incurs ineffi-
ciency. However, applying long horizons uniformly across task phases delays the incorporation of

Prior works have explored diverse action-chunk execution strategies to balance temporal consis-
tency and reactivity, including temporal ensembling, adaptive chunk updates, and guided candidate
selection (Zhao et al., 2023; So et al., 2026; Liu et al., 2025a). AAC estimates action entropy of
action candidates to decide a shared exceuction horizon (Liang et al., 2026). AutoHorizon derives
the execution horizon from self-attention within a predicted chunk (Wang et al., 2026). A3 selects a
representative trajectory from multiple candidates and then performs additional flow-matching ver-
ification to determine execution horizon (Zhao et al., 2026). Our objective is to reduce wall-clock
inference time while achieving comparable success rate by jointly selecting an action chunk and its
execution horizon. This raises our key question: Given a bounded set of candidate action chunks
generated in a single policy call, how can we select the action chunk and execution horizon to
reduce the wall-clock inference time?
We propose PICES (Perturbation-Informed Chunk and Execution Horizon Selection), a training-
free inference time method that jointly selects an action chunk and its execution horizon. For each
initial-noise sample, PICES constructs a locally perturbed counterpart by adding a small Gaussian
perturbation. A single batched policy call generates the corresponding nominal and auxiliary action
chunks using shared conditioning features encoded by the vision-language-model (VLM). Based on
the arithmetic intensity analysis of action expert and hardware ridge-point in our motivational analy-
sis, we restrict total batch size to a range with negligible incremental latency. For each candidate, the
stepwise differences between nominal and auxiliary action chunks yield a local sensitivity value. We
exploit these values to retain candidates with low initial sensitivity and estimate execution horizon
for each candidate. From the candidate pool, PICES selects and executes the nominal chunk with
the longest execution horizon. Figure 1(b) illustrates the reduction in policy calls: two calls execute
eight actions, compared with four calls with fixed horizon execution. Savings from fewer policy
calls outweigh the additional cost of candidate generation, reducing cumulative inference time as
shown in Figure 1(c).
Our key contributions are as follows:
• Through an open-loop study, we show that oracle selection from multiple action chunks can
yield lower reference-action error over a longer execution horizon than a single-candidate,
short-horizon baseline. We also characterize the cost of generating candidates in a batch.
• We propose PICES, a training-free method to reduce cumulative wall-clock inference time.
PICES uses sensitivity to initial-noise perturbations to guide the joint selection of an action
chunk and its execution horizon.
• We evaluate PICES across multiple VLA models in simulation and on real-world robot
tasks. Compared with fixed-horizon baselines, PICES reduces policy calls by 25.4–60.3%

RELATED WORK
Action Chunking in VLA Models.
Recent VLAs such as CogACT, π, and GR00T series execute
only a fixed-length horizon of each predicted chunk (Li et al., 2024a; Black et al., 2024; Bjorck
et al., 2025). Executing a long fixed-length actions reduces policy calls but limits the incorporation
of new observations, motivating adaptive execution horizons (Liang et al., 2026; Wang et al., 2026;
Chen et al., 2026) (see Appendix G for full discussion). In contrast, our method instead estimates
a horizon for each candidate and uses the estimated execution length to choose the reliable action
chunk to shorten cumulative inference time without training.
Acceleration for VLA Models.
Efficient VLA inference seeks to reduce task completion time
using various methods. To reduce inference overhead, previous work exploits redundancy in visual
inputs and model computation through token pruning, channel pruning, and model scheduling (Chen
et al., 2024; Shukor et al., 2025; Xu et al., 2026; Feng et al., 2026) (see Appendix G for full discus-
sion). Our method is orthogonal to token pruning, which reduces computation within individual pol-
icy calls. PICES examines how candidate-specific horizon selection can reduce policy calls, while
explicitly accounting for the additional cost of generating and assessing multiple action candidates.

3.2
MOTIVATIONAL STUDY
We analyze whether sampling multiple action chunks under identical conditioning inputs can pro-
vide suitable candidates for longer execution horizon than fixed-length execution. To limit the la-
tency overhead of this additional sampling, we explore affordable batch size during chunk gener-
ation. This motivates two questions: (1) Can multiple sampled chunks provide a lower reference-
action error at a longer fixed execution horizon candidate than a single sampled chunk? (2) Under
consideration of action expert’s arithmetic intensity, how many candidate chunks can we expect to
be generated in a batch with modest additional latency?
Selection by minimum reference-action RMSE.
We first compare reference action root-mean-
square-error (RMSE) across fixed execution horizons and candidate counts. We conduct the analysis
with the RT-1 Fractal dataset and GR00T N1.7 (Bjorck et al., 2025; Brohan et al., 2022). For each
condition c, we generate N ∈1, . . . , 10 candidate action chunks using independent initial noise and
evaluate horizons h ∈{1, . . . , 8}. For each input and (N, h) pair, an oracle selects the candidate
with the lowest RMSE over its first h actions relative to the corresponding reference actions. The
RMSE metric is explained in Appendix C. Figure 2 shows that selection from four candidates at

Operation Characteristics of Action Expert.
Cumulative inference-time saving for the longer
execution horizons requires generating action chunks with limited additional latency. Prior studies
identify low arithmetic intensity (AI) of action generation in action expert (Jiang et al., 2026; Zhou
et al., 2026). The roofline in Figure 3 shows the AI of the π0.5, GR00T N1.5, and GR00T N1.7
action experts at batch sizes B ∈{1, 2, 5, 10, 15, 20}. At single batch, the AI of all three action
experts lies below the ridge points of both Jetson Orin and Thor, indicating memory-bound operation
under the roofline model. When AI remains below the device’s ridge point, the operation latency
depends primarily on memory transfer latency. In such a case, the additional computation can be
accommodated without a proportional increase in latency. On Orin, all three models approach the
ridge point at a batch size of 6. On Thor, the action experts remain memory-bound even at a batch
size of 20; however, beyond a batch size of 10, growing activation traffic incurs latency overhead. We
therefore set the total generation batch-size limits to 6 on Orin and 10 on Thor to balance candidate
diversity against per-call latency. Appendix B provides the further analysis of arithmetic intensity
and measured latency on GPUs.
Together, these analyses suggest that a bounded set of action chunks can contain candidates suitable
for longer execution horizons with modest cost for the batched generation of candidates. This raises
the central question: how can we assess the reliability of each candidate’s future action steps and
jointly select a chunk and its execution horizon?
3.3
PERTURBATION-INFORMED CANDIDATE ASSESSMENT
For each nominal action chunk, we measure changes in the action expert output under local per-
turbations of the corresponding initial noise. Local sensitivity quantifies output variation under
small input changes, and exploiting this sensitivity has been used to encourage invariant represen-
tations (Rifai, 2011). In image generation, per-image perceptual path length quantifies how much
the generated image changes perceptually under small perturbations of its latent code (Karras et al.,
2020). Motivated by these observations, we use local stability under initial-noise perturbations as a
proxy for reliability of each nominal action. We estimate sensitivity at each action timestep within a
chunk and use these estimates to favor nominal candidates with lower sensitivity.

EXPERIMENTAL SETUPS
Models and benchmarks.

5
CONCLUSION
We presented PICES, a training-free inference method for flow-matching VLA policies that jointly
selects an action chunk and execution horizon. PICES estimates stepwise action sensitivity by com-
paring outputs generated from each initial noise and locally perturbed counterpart. PICES exploits
these scores to filter candidates, determine execution horizon, and select the nominal chunk with the
longest execution horizon. Experiments across multiple VLA backbones, simulation benchmarks,
and real-world robot tasks show that PICES achieves higher task success rates while reducing cu-
mulative inference time relative to the fixed-horizon baselines.

Distribution of execution horizons.
To examine how PICES selects action chunks and execution
horizons, we analyze the policy call records collected during closed-loop evaluation of GR00T N1.7
on SimplerEnv–Fractal with three N = 3 nominal candidates. We group tasks by manipulation
objective into three categories: Pick Coke/Object (Pick Coke Can and Pick Object), Open/Close
(Open Drawer and Close Drawer), and Move/Place (Move Near and Place in Closed Drawer).
Figure 8 compares the execution horizons assigned to all nominal candidates with those of the
chunks selected by PICES at the same recorded policy calls. For this analysis, we apply the horizon-
estimation rule to all three nominal candidates, including those excluded by the initial-sensitivity
filter. Each call contributes three candidate horizons (left) and one selected horizon (right). Across
all groups, the selected distribution exhibits a lower proportion of one-step horizons and a higher
proportion of intermediate horizons, particularly two to four steps. The proportion of one-step hori-
zons decreases from 59.07% among nominal candidates to 34.93% among PICES selections. The
corresponding average horizon increases from 2.49 to 3.01 actions. The consistent shift across the
three groups shows that candidate selection increases the execution length on average across dif-
ferent manipulation objectives. The resulting distribution includes both short and long horizons,
reflecting that PICES makes candidate-specific decisions during rollout.
Effect of the perturbation scale.
We examine the sensitivity of PICES’s task performance to the
perturbation scale σ on LIBERO. With N = 3, we evaluate σ ∈{0.05, 0.10, 0.25, 0.50} across the
four task suites. As shown in Figure 9, the average success rate across suites ranges from 97.15%
to 97.55%, a difference of 0.40 percentage points. Although individual suites exhibit variation, the
average success rate changes little across the sigmas.

GPU INFERENCE COST ANALYSIS
Operation Characteristics of Action Expert.
Realizing benefits of multi-action chunks requires
generating multiple candidate chunks without a proportional increase in inference latency in GPUs.
At the single batch, the arithmetic intensities (AI) of the π0.5, GR00T N1.5, and GR00T N1.7 action
experts are 59, 63, and 43 FLOP/byte, respectively. When AI remains smaller than ridge-point of
each GPU, inference remains on the memory-bound condition. The single-batch AI of VLA models
lies in the memory-bound region of the roofline models for Jetson Orin and Thor, indicating that
single-candidate generation does not fully utilize their compute throughput.
However, for the mulit-action chunk generation, B initial-noise tensors are stacked along the batch
dimension and processed by the action expert at each flow-matching step, avoiding repeated exe-
cution of the full VLA inference pipeline. At a batch size of 6, the AI of π0.5, GR00T N1.5, and
GR00T N1.7 increases to 205.6, 190.6, and 182.4 FLOP/byte, respectively. Increasing the batch
size to 8 further raises these values to 239.9, 222.1, and 223.0 FLOP/byte, exceeding the ridge point
207.5 FLOP/byte of Jetson Orin. Once the AI exceeds the ridge point, the operation turns into a
compute-bound characteristic, where additional computation increases latency.
Accordingly, for Jetson Orin, all three models approach the ridge point at a batch size of 6, without
increasing latency due to additional computation. For Jetson Thor, the operations remain memory-
bound even at a batch size of 20, indicating that the available compute throughput is still not fully
utilized. However, beyond a batch size of 10, the growing cost of loading activations, in addition to
the cost of loading action expert weights, leads to a smooth increase in latency. Considering both
hardware constraints and operation AI, these observations support setting the maximum batch size
to 6 for Jetson Orin and 10 for Jetson Thor.

ADDITIONAL RELATED WORK
Action Chunking in VLA Models.
Action chunking policy predicts a sequence of future actions
conditioned on current observation, improving temporal consistency. Recent VLAs such as Co-
gACT, π, and GR00T series use transformer-based action experts, implemented as Diffusion Trans-
formers (DiTs), to model multimodal distributions over continuous action chunks (Li et al., 2024a;
Black et al., 2024; Bjorck et al., 2025). At inference time, such policies execute only a fixed-length
horizon of each predicted chunk. Executing a long fixed-length actions reduces policy calls but
limits the incorporation of new observations, motivating adaptive execution horizons (Liang et al.,
2026; Wang et al., 2026; Chen et al., 2026; Zhang et al., 2026). MoH requires auxiliary module for
multiple horizons and uses cross-horizon agreement to determine an executable actions (Jing et al.,
2025). DEHP uses a lightweight predictor trained with online reinforcement learning to adapt the
execution horizon of a frozen pretrained action-chunking policy (Zhao et al., 2026). AAC estimates
a single execution horizon from cross-sample action entropy (Liang et al., 2026). AutoHorizon es-
timates an execution horizon for each predicted chunk using the self-attention patterns (Wang et al.,
2026). A3 selects a representative draft from sampled trajectories and determines execution horizon
through an additional batched verification pass (Chen et al., 2026). In contrast, our method instead
estimates a horizon for each candidate and uses the estimated execution length to jointly choose the
trajectory and its execution extent in inferece time without training.
Acceleration for vision-language-action models
Recent works on efficient VLA inference seek
to reduce cumulative inference time using various methods. SmolVLA overlaps action prediction
with execution and evaluates efficiency using task-completion time and the number of successful
pick-and-place operations within a fixed time budget (Shukor et al., 2025). To reduce inference
overhead, prior work exploits redundancy in visual inputs and model computation through token
pruning, channel pruning, and model scheduling (Wang et al., 2025; Li et al., 2025; Liu et al., 2025b;
Huang et al., 2025; 2026; Feng et al., 2026). FastV, originally developed for vision-language models,
prunes visual tokens using attention scores from early layers to reduce computation in subsequent
layers (Chen et al., 2024). VLA-Cache exploits temporal redundancy by reusing cached key-value
representations of minimally changed visual tokens across adjacent observations (Xu et al., 2026).
GridS reduces the computational cost of vision-language-action models by learning task-aware sam-
pling coordinates and extracting pruned visual tokens via differentiable bilinear interpolation (Feng
et al., 2026). Our method is orthogonal to token pruning, which reduces computation within in-
dividual policy calls. DaDu-Corki predicts future trajectories to reduce expensive model invoca-
tions (Huang et al., 2025). PICES examines how candidate-specific horizon selection can reduce
policy calls, while explicitly accounting for the additional cost of generating and assessing multiple
action candidates.
