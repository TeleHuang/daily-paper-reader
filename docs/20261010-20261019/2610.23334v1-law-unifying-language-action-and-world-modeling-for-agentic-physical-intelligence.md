## 摘要
世界-动作模型联合预测动作和未来世界状态，但长时程操作还需要语言推理来规划子任务目标、评估执行进度并指导动作选择。我们提出 LAW，一个闭环 VLM--WAM 框架，通过语义子任务进度统一语言推理、动作生成和世界建模。在 LAW 智能体中，混合专家视觉语言模型规划剩余子任务，估计世界-动作模型所提议动作的价值并融合这些动作，同时异步评估执行状态，以支持持续执行和子任务切换。在世界-动作模型中，Mixture-of-Transformer Experts 集成模态特定计算和共享计算，用于联合视频--动作建模。双流分层视觉记忆为两个模型维护时间上下文，而子任务局部价值学习使动作评估与语义目标对齐，并保留失败轨迹中成功前缀的监督信号。LAW 在 50 个 RoboTwin 任务上取得 94.21% 的平均成功率。将 WAM 主干替换为 OpenWAM-$alpha$ 后，平均成功率进一步提升至 95.56%，在 RoboTwin 上确立了新的开源最先进水平。尽管我们的 VLM 仅有 2B 参数，其性能仍优于使用 Embodied-R1.5 和 GPT-5.5 High 的变体。在三个长时程真实机器人任务上，LAW 取得 65% 的平均成功率，而 $pi_{0.5}$ 为 28.33%，Fast-WAM 为 25%。

## Abstract
World-action models jointly predict actions and future world states, but long-horizon manipulation further requires language reasoning to plan subtask objectives, assess execution progress, and guide action selection. We present LAW, a closed-loop VLM--WAM framework that unifies language reasoning, action generation, and world modeling through semantic subtask progress. Within the LAW agent, a hybrid-expert vision-language model plans the remaining subtasks, estimates the values of and fuses actions proposed by a world-action model, and asynchronously assesses execution status to support continued execution and subtask transitions. Within the world-action model, Mixture-of-Transformer Experts integrates modality-specific and shared computation for joint video--action modeling. Dual-stream hierarchical visual memory maintains temporal context for both models, while subtask-local value learning aligns action evaluation with semantic objectives and preserves supervision from successful prefixes of failed trajectories. LAW achieves 94.21% average success across 50 RoboTwin tasks. Replacing the WAM backbone with OpenWAM-$alpha$ further raises the average success rate to 95.56%, establishing a new open-source state of the art on RoboTwin. Despite having only 2B parameters, our VLM also outperforms variants using Embodied-R1.5 and GPT-5.5 High. On three long-horizon real-robot tasks, LAW achieves 65% average success, compared with 28.33% for $pi_{0.5}$ and 25% for Fast-WAM.

- **统一原则**：以**语义子任务进度（semantic subtask progress）**作为语言推理与世界-动作建模之间的**时间接口**——它同时定义了“何时推进计划”“候选动作应优化哪个结果”“哪些观测应在记忆中被保持显著”。

## 2. 方法论

### 2.1 总体框架：闭环 VLM–WAM

将长时程控制分解为**进度感知的语义控制环**（低频）与**短时程动作环**（高频），由当前子任务 $c_t$ 连接两者。

- 记观测 $o_t=(I_t,p_t)$（多视角 RGB + 本体状态）；VLM 记忆 $M^V_t$、WAM 记忆 $M^W_t$ 为两条独立记忆流。
- **规划器**（仅在回合初始化与语义决策事件调用）：
  $S_t=\mathrm{VLM}_{plan}(g,o_t,M^V_t)=(s_{t,1},\dots,s_{t,L_t})$，取 $c_t=s_{t,1}$；每次新计划**局部重新从 1 编号**，并用单调递增的子任务实例标识 $u_t$ 关联异步预测与当前执行实例。
- **WAM 采样 N 个候选动作块**：$\{A^{(n)}_t\}=\mathrm{WAM}_{act}(o_t,c_t,M^W_t;\epsilon_n)$，每块含 $H=32$ 步、16 维末端执行器动作（0.06 s/步），$\epsilon_n$ 提供多样性。
- **价值专家打分并融合 top-K**：$q^{(n)}_t=Q_\theta(x_t,A^{(n)}_t)$，$\hat A_t=\mathrm{Fuse}_{K,T}(\cdot)$，默认 $K=8$；机器人执行融合块的前缀后重采样。
- **状态专家异步判断子任务完成**：$\hat d_t=\mathrm{VLM}_{state}(g,o_t,c_t,M^V_t)$，以 0.5 二值化，产生 `ADVANCE` / `CONTINUE` 事件。`ADVANCE` 时把控制环切换时刻的观测存为**子任务边界状态**，重规划剩余子任务、$u_{t+1}=u_t+1$；若仅剩一个子任务则回合成功终止。
- **异步一致性机制**（Algorithm 1 的关键工程细节）：每个预测携带**输入观测时间戳**与子任务 id；结果仅在 id 匹配 $u_t$ 且时间戳新于上次已消费结果时有效，被更新预测取代的结果直接丢弃；无有效结果时按当前子任务继续执行，**不阻塞动作执行**。

### 2.2 混合专家 VLM（进度感知控制）

- 共享**冻结**的 Qwen3-VL-2B-Instruct 主干 + 三组任务特定 LoRA 适配器与专属 head：planner（r=64）、state（r=64）、value（r=128），合计约 **+100M 参数**；LoRA scale 128、dropout 0.05。
- **专家按控制功能选择，而非 token 级路由**——既复用视觉-语言表示，又避免维护三套全模型，并隔离参数更新以减少功能间干扰。
- **规划器损失**：对剩余子任务序列做自回归负对数似然 $\mathcal{L}_{plan}=-\sum_i \log p_\theta(s_i\mid g,o_t,M^V_t,s_{<i})$。
- **状态专家损失**：主任务完成二分类 + **辅助失败预测头** $\mathcal{L}_{state}=\lambda_d \mathrm{BCE}(\hat d_t,d_t)+\lambda_f \mathrm{BCE}(\hat f_t,f_t)$，促使共享表示区分“未完成”与“执行出错”。
- **价值头**：候选动作块编码为 token，与上下文 $x_t=(g,o_t,c_t,M^V_t)$ 联合处理，学习到的 query token 聚合特征后接 **101-bin 类别分布价值头**，$Q_\theta=\sum_{b=1}^{101} z_b p_\theta(b\mid x_t,A_t)$；仅训练该适配器、动作编码器、query 嵌入与价值头，其余全部冻结。

### 2.3 MoTE：视频–动作联合建模

- 原始 MoT 通过混合注意力交换信息，但后续变换仍是模态私有，**共享建模受限**。
- MoTE 在**混合注意力表示之后**插入残差 MoE 层：$\mathbf{w}=\mathrm{TopKSoftmax}(W_r \mathrm{LN}(H))$，$\tilde H=H+\alpha\sum_{e} w_e E_e(\mathrm{LN}(H))$；每个模态有独立 router。
- 默认配置：**每模态 2 个私有专家 + 1 个跨模态共享专家**，top-1 路由（同一 token 不会同时激活私有与共享），残差尺度 $\alpha=0.1$。
- 训练目标：$\mathcal{L}_{WAM}=\lambda_v\mathcal{L}_{video}+\lambda_a\mathcal{L}_{action}+\lambda_b\mathcal{L}_{balance}+\lambda_z\mathcal{L}_{z}$，默认 $\lambda_v=\lambda_a=1$、$\lambda_{bal}=\lambda_z=10^{-4}$。
- 设计要点：专家作用于**已含跨模态信息**的表示上，因此共享专家学习到的是跨“预测场景动态”与“机器人动作”的共同时序/物理结构。

### 2.4 双流分层视觉记忆

- 保留最近 5 帧（步长 4）：$\{o_{t-20},o_{t-16},o_{t-12},o_{t-8},o_{t-4}\}$；另单独保留初始观测与**子任务切换时刻的边界观测**；更早帧在当前子任务内每 4 步采样、已完成子任务内每 16 步采样；所有时间戳共享相位 $t \bmod 4$，边界帧只存一次。
- 统一形式：$M^X_t=[\{\bar x^X_{c_i}\}_{i=1}^{m};\{x^X_{\beta_i}\}_{i=1}^{p};\{x^X_{t-4j}\}_{j=1}^{5}]$，$X\in\{V,W\}$——三组分别为**空间池化压缩的长期历史**、**全分辨率子任务边界**、**全分辨率近期观测**。
- 两流在各自原生 token 空间编码（VLM 视觉 token $v_\tau$ / WAM VAE token $w_\tau$），共享同一组时间戳。

### 2.5 子任务局部价值学习

- **动机**：回合级回报会丢弃“完成若干子任务后才失败”的轨迹中的有效监督。
- **奖励设计**：每个**成功完成的子任务终止动作**给 reward 1，其余为 0；已完成的成功前缀保留正监督，最终失败子任务无正奖励，未观测子任务被排除。
- **TD 目标**：$y_t=\sum_{i=0}^{h_t-1}\gamma^i r_{t+i}+b_t\gamma^{h_t}\bar Q_{\bar\theta}(x_{t+h_t},A^{data}_{t+h_t})$；每个块在**首个语义子任务边界处截断**，$h_t$ 只计有效动作，越界动作在目标中被 mask；仅当同子任务内存在下一条记录块且不含终止动作时 $b_t=1$。
- **类别价值学习**：$y_t$ 裁剪到价值支撑域，用归一化高斯核在 bin 中心构造软标签，交叉熵训练 $\mathcal{L}_{value}=-\mathbb{E}[\sum_b \rho_{t,b}\log p_\theta(b\mid x_t,A_t)]$；101 bins 覆盖 $[-0.01,1.01]$，$\gamma=0.99$，HL-Gauss 宽度 $\sigma=0.0075$，EMA 目标 $\tau=0.005$。
- **动作融合**：温度加权 $w_n\propto \exp(Q_\theta(\cdot)/T)$；位置与夹爪指令线性加权平均，四元数用**加权 Markley 均值**（$M=\sum w_n q_n q_n^\top$ 的最大特征值单位特征向量），对 $q_n\mapsto -q_n$ 符号翻转不变。

### 2.6 训练流程

- **两阶段**：阶段一顺序训练 planner → state 专家（并独立训练 WAM）；阶段二冻结上述组件，用子任务局部目标训练价值专家。**防止价值学习破坏生成器/规划器/状态专家**。
- 失败
