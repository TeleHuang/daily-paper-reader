## 摘要
动作分块视觉-语言-动作（VLA）模型预测未来机器人动作序列。在固定视界执行下，机器人在再次调用策略之前执行每个预测块中固定长度的前缀，剩余预测未被使用。对于给定数量的已执行动作，较短的执行视界需要更多策略调用。延长执行视界可将策略推理成本分摊到更多动作上。然而，在所有回合中统一采用长视界会限制精确修正的机会。为解决这一局限，我们提出PICES（扰动信息引导的动作块与执行视界选择），一种无需训练的方法，联合选择动作块以及在下次策略调用前执行的动作数量。在单次策略调用中，动作专家从多个初始噪声样本及其局部扰动对应样本生成一批动作块，所有样本使用相同的条件特征。PICES利用每个名义动作块与其对应扰动块中对应动作之间的差异，确定各候选特定的执行视界，并选择一个名义动作块执行。在仿真基准和真实世界操作任务上的实验表明，相对于固定视界基线，PICES在Jetson Orin和Thor上的实际策略推理时间最高加速2.3倍，同时提高了成功率。

## Abstract
Action-chunking vision-language-action (VLA) models predict sequences of future robot actions. Under fixed-horizon execution, the robot executes a fixedlength prefix of each predicted chunk before invoking the policy again, leaving the remaining predictions unused. For a given number of executed actions, short execution horizons require more policy calls. Extending the execution horizon amortizes policy inference cost over more actions. However, uniformly applying long horizons across episodes can limit opportunities for precise corrections. To address this limitation, we propose PICES (Perturbation-Informed Chunk and Execution Horizon Selection), a training-free method that jointly selects an action chunk and the number of actions executed before the next policy call. Within a single policy call, the action expert generates a batch of action chunks from multiple initial noise samples and their locally perturbed counterparts, using the same conditioning features across all samples. PICES exploits differences between corresponding actions in each nominal chunk and its counterpart to determine candidate-specific execution horizons and select a nominal chunk for execution. Experiments on simulation benchmarks and real-world manipulation tasks demonstrate that PICES achieves speedup by up to 2.3x in wall-clock policy inference time on Jetson Orin and Thor relative to fixed horizon baselines while improving the success rate.

## 一、论文的核心问题与整体含义

- **研究背景**：动作分块（action-chunking）VLA 模型（如 π0.5、GR00T N1.5/N1.7）通过视觉-语言主干 + 流匹配动作专家，一次预测一段未来动作序列（chunk）。传统做法是每次策略调用后只执行固定长度的前缀（固定执行视域 h），剩余预测被丢弃。
- **核心矛盾**：
  - 执行视域短 → 每执行固定数量动作需要更多次策略调用 → 累积推理延迟高，任务完成时间长；在 Jetson Orin/Thor 等边缘平台上单次调用可达 80–150 ms，推理成为瓶颈。
  - 执行视域长 → 策略调用减少，但削弱了及时利用新观测进行精细修正的能力，容易在接触密集/精细操作阶段失败。
- **现有方法不足**：AAC 用动作熵估计共享执行视域、AutoHorizon 用自注意力模式推断视域、A3 需额外流匹配验证，均未同时兼顾"选哪个动作块"与"执行多长"两个决策，且部分方法引入显著额外延迟。
- **核心问题**：在一次策略调用内有限数量的候选动作块中，如何联合选择动作块及其执行视域，以降低累积实际推理时间并保持成功率？
- **整体含义**：提出一种**免训练（training-free）**、可与 token 剪枝等加速方法正交的推理时方法，在边缘硬件上实现"少调用、高成功率"的部署权衡。

## 二、方法论

### 2.1 核心思想
- 利用**动作专家对初始噪声局部扰动的敏感性**作为动作可靠性的代理指标：敏感度低 → 输出局部稳定 → 可信度高 → 可执行更长视域。
- 在**单次批量策略调用**中，用共享条件特征同时生成 N 个名义动作块及其 N 个扰动辅助块，据此为每个候选估计执行视域，并选出可执行最长视域的候选。

### 2.2 关键技术细节与流程（Algorithm 1）

1. **候选与扰动构造（Step 1）**：
   - 采样 N 个独立初始噪声 $Z^{(n)} \in \mathbb{R}^{d\times H}$，并构造扰动版本 $\tilde{Z}^{(n)} = Z^{(n)} + \sigma\epsilon^{(n)}$，其中 $\epsilon^{(n)}$ 为 i.i.d. 标准高斯，扰动仅施加于初始噪声、不改变条件输入 $c=(o,q,\ell)$。

2. **单次批量生成（Step 2）**：
   - 将 N 个名义噪声与 N 个扰动噪声堆叠成一个批次，动作专家在共享条件特征下一次性生成 $A^{(n)}$ 与 $\tilde{A}^{(n)}$；仅名义块用于执行。

3. **逐步敏感度计算（Step 3）**：
   - 对每个时间步 $k$ 定义归一化敏感度
     $$G_k^{(n)} = \frac{\|\tilde{a}_k^{(n)} - a_k^{(n)}\|^2}{\sigma^2\|\epsilon^{(n)}\|_F^2}$$
   - 论文在附录 D 说明：当 $\sigma\to 0$ 时，该量近似为动作对初始噪声的**方向导数的平方范数**（有限扰动下含非线性余项）。

4. **候选过滤与视域选择（Step 4）**：
   - 初始窗口敏感度 $S_n = \frac{1}{W}\sum_{k=0}^{W-1} G_k^{(n)}$（W 为参考窗口，通常取官方默认执行视域）。
   - 保留 $S_n \le \text{median}(S_1,\dots,S_N)$ 的候选集合 $\mathcal{K}$。
   - 对每个保留候选，找到首个敏感度超过自身 $S_n$ 的时间步作为视域：
     $$h_n = \min\big(\{k\in\{W,\dots,H-1\}: G_k^{(n)} > S_n\}\cup\{H\}\big)$$
   - 选择 $h_n$ 最长的候选 $n^\star$，执行其前 $h^\star = h_{n^\star}$ 个动作后重新规划。

### 2.3 动机性分析支撑
- **开环 Oracle 研究**（RT-1 Fractal + GR00T N1.7）：4 候选、8 步视域的 oracle 选择 RMSE 为 0.1795，优于单候选单步的 0.1900，说明多候选可支撑更长视域。
- **Roofline 分析**：三个动作专家单批次算术强度（43–63 FLOP/byte）均低于 Orin/Thor 的 ridge point（内存受限）；Orin 在 batch≈6 接近 ridge point，Thor 在 batch=10 后激活流量导致延迟上升，故设定批量上限为 **Orin 6、Thor 10**，以"几乎无额外延迟"的批量生成候选。
