## 摘要
强化学习已使腿式机器人实现稳健运动，但学习到的策略通常绑定于特定机器人形态，当腿数、执行器或机械属性发生变化时需要额外工程。我们提出 PolyMorph，一个以形态为条件的框架，可为异构腿式机器人学习单一运动策略。PolyMorph 将每个机器人的 URDF 转换为关节-连杆模块，并结合循环编码器、基于图的 Transformer 和逐关节解码器，以在可变腿数和关节配置下生成动作。为提高训练稳定性，PolyMorph 使用形态归一化奖励、自适应机器人采样以及由 URDF 导出的 PD 增益初始化。我们在仿真中评估 PolyMorph，涵盖双足、三足和四足机器人，包括未见过的形态变体和平台，并将该策略部署到以多种配置运行的真实四足平台上。结果表明，单一 PolyMorph 策略无需针对每个机器人重新训练即可泛化到多样机器人形态。

## Abstract
Reinforcement learning has enabled robust locomotion for legged robots, but learned policies are typically tied to a specific robot morphology and require additional engineering when the number of legs, actuators, or mechanical properties change. We present PolyMorph, a morphology-conditioned framework that learns a single locomotion policy for heterogeneous legged robots. PolyMorph converts each robot's URDF into joint-link modules and combines a recurrent encoder, graph-based Transformer, and per-joint decoder to generate actions across variable leg counts and joint configurations. To improve training stability, PolyMorph uses morphology-normalized rewards, adaptive robot sampling, and URDF-derived PD-gain initialization. We evaluate PolyMorph in simulation across bipedal, tripedal, and quadrupedal robots, including unseen morphology variants and platforms, and deploy the policy on real quadruped platforms operated in multiple configurations. The results show that a single PolyMorph policy generalizes across diverse robot morphologies without per-robot policy retraining.

## 1. 核心问题与研究动机

- **背景**：无模型强化学习（RL）已成为腿式机器人控制的主流工具，能在崎岖坡面、台阶、可变形地形上实现稳健运动；但绝大多数工作聚焦于**单一平台、单一任务**。
- **核心痛点**：策略与机器人形态强绑定。一旦自由度、连杆质量/惯量、运动学构型、腿数或执行器数量变化，策略往往失效；适配新机器人需重新设计环境、观测、动作空间与奖励函数，工程成本高昂。
- **研究问题**：能否训练**一个**运动策略，跨腿数与执行器数量各异的腿式机器人工作，并直接部署到真实硬件而**无需逐机器人重训**？
- **核心论点**：
  - 通用控制器不仅要观测当前状态，还必须**显式推理自身形态**；
  - 仅改网络架构不够，还必须解决**训练层面的不平衡**：不同机器人的奖励量级随关节/腿数缩放、易学机器人（四足）会主导均匀采样而挤压难学机器人（双足）的学习信号、手工 PD 增益会重新引入逐平台工程。
- **整体含义**：统一策略可缩短"设计—测试"迭代周期，支持快速机器人设计流程与异构平台间的策略复用，并让策略暴露于更广的形态与动力学变化。

## 2. 方法论

### 2.1 核心思想

- 将每个机器人视为**由其 URDF 解析出的关节-连杆模块序列**（一个关节 + 其子连杆 = 一个 Transformer token），用**填充 + 有效动作掩码**统一处理变长结构，从而在**共享同一套策略参数**的前提下适配不同腿数、执行器数与关节构型。
- 形式化为多 MDP 联合优化：对 K 个机器人各自的 MDP，学习单一策略 π_θ(a|s) 最大化**平均期望回报**，用 PPO 优化。
- 仅**形态相关输入**由各机器人 URDF 导出，策略参数全机器人共享。

### 2.2 网络架构（三组件）

- **状态上下文编码器（GRU）**
  - 输入本体感知序列：躯干 roll-pitch、角速度、关节位置与速度、上一步目标关节位置。
  - 关节相关观测按可配置上限 N_max = 15 零填充，以兼容不同自由度。
  - **非对称 actor-critic**：critic 额外获得仿真特权信息（体高、体线速度、地形高度扫描），actor 部署时仅用机载本体感知。
- **形态感知 Transformer**
  - Token 观测 = 连杆特征（质量、惯量、质心位置）+ 关节特征（关节位置、标称角、近期状态、近期目标动作、PD 增益），均来自 URDF 或仿真/传感器。
  - Token 序列按**从根体出发遍历运动学树**排序；每个 token 经**独立线性投影**并叠加**绝对位置嵌入**以编码模块顺序。
  - **图掩码注意力**（沿用 Body Transformer 思路）：以 URDF 导出的邻接矩阵构造注意力偏置——相连模块偏置为 0，不相连为 −∞，从而注入物理结构先验、禁止无效连接上的注意力；与固定形态设定不同，此处掩码随机器人变化。
- **逐关节解码器**
  - 每个模块的解码输入 = 该模块 Transformer 输出 + GRU 隐向量 + 速度指令。
  - 每个模块有**独立解码器参数**，输出高斯动作分布的均值（对角协方差）；动作仅施加于该机器人**有效驱动关节**，排除索引 0 的根模块。
  - Critic 侧同结构输出逐模块价值，对根模块与有效驱动模块**取平均**得到状态价值，用于 PPO 优势估计。

### 2.3 训练层面的三项关键技术

- **自适应机器人采样**：采样概率按 exp(r̄ − r_i) 归一化（奖励越低概率越高），但**保留一半环境均匀采样**以防过拟难例。用于解决双足等难学形态在均匀采样下更新不足的问题。
- **形态归一化奖励**：关节相关惩罚（力矩、位置、速度、加速度、动作平滑）除以驱动关节数；腿/足相关项（腾空时间、抬脚高度）除以腿数，使奖励量级跨形态一致，避免优化偏向特定构型并稳定 PPO。
- **URDF 导出的自动 PD 增益**：
  - 由标称姿态 q0 处的质量矩阵取机器人级惯量尺度 λ = Σ_{i=1..3} M_ii(q0)；
  - 比例增益 Kp = α²λ（α = 0.8，全机器人统一），以标量形式作用于所有执行器；
  - 微分增益按二阶阻尼关系逐关节计算 Kd,i = 2ζ√(M_ii(q0)·Kp)（ζ = 0.8，略欠阻尼），再取**中位数**作为共享 Kd，避免近端重关节与远端轻关节阻尼差异过大。
  - 以单一共享系数 + URDF 惯量尺度替代逐平台手工调参。

### 2.4 其他训练流程

- **课程学习**：难度因子按幂次衰减更新，环境参数（指令范围、地形粗糙度、外部扰动、奖励权重、形态扰动）在易/难设置间插值；配合带 warmup restart 的余弦退火学习率。
- **域随机化**：观测噪声、连杆/关节参数、PD 增益、控制延迟、摩擦、外部扰动，按参数类型在每回合开始或每步施加。

## 6. 主要发现与结论

- **单一策略可跨形态工作**：同一组参数在双足、三足、四足及 11–135 kg 质量范围内均能实现指令跟踪，并在真实 Raibo1/Raibo2 的四足、三足、双足配置上完成 50 m 户外路线，说明"形态感知 + 共享参数"的路线在工程上可行。
- **形态显式推理是必要的**：PolyMorph-MLP 在多数机器人上性能下降，尤其在自由度差异大的形态上更明显，表明简单的特征拼接不足以让网络区分"哪个关节属于哪个模块"，结构化 token + 图掩码提供了有效的结构先验。
- **训练层面的不平衡是通用策略的关键瓶颈**：移除奖励归一化后，奖励量级与关节数呈明显相关，早期回报的变异系数上升、终止率升高且不同形态间终止率差距扩大；自适应采样显著改善难学形态（如 Atlas）的收敛，说明"算法层面公平"比"网络层面通用"更易被忽视。
- **自动 PD 增益可替代手工调参**：基于 URDF 质量矩阵的惯量尺度导出 Kp/Kd，在 8 个机器人上与手工参考增益性能相当，消除了逐平台工程环节，是"零重训部署"链条上的必要一环。
- **形态嵌入具有结构意义**：t-SNE 显示嵌入按腿数与形态类别聚集，说明网络确实学到了与运动学结构相关的表示，而非仅记忆平台身份。
- **相对基线的优势**：在相同训练条件与预算下，PolyMorph 在多数机器人上的跟踪误差与终止率优于 Metamorph 与 URMA，尤其在训练集中占比较小的形态（双足、三足）上优势更明显。

## 7. 局限与批判性评估

- **形态空间仍属"同构族"**：所有机器人共享"躯干 + 若干同构腿"的模板，token 定义依赖"关节 + 子连杆"这一固定粒度；对带臂、轮腿、可变拓扑（如可重构机器人）的适用性未验证。
- **依赖 URDF 与标称参数质量**：自动 PD 增益与形态 token 均来自 URDF，真实机器人的质量/惯量辨识误差、关节摩擦与背隙未被显式建模，可能限制在低成本硬件上的迁移。
- **奖励归一化的手工性**：按关节数/腿数除以惩罚项是一种"经验性"平衡手段，仍隐含"每关节惩罚应等权"的假设；对异构执行器（如液压 + 电机混合）或不同关节重要性（髋 vs 踝）未必最优。
- **采样策略的超参敏感**：exp(r̄ − r_i) 的温度、均匀采样保留比例 0.5 等未做敏感性分析，难例过采样可能加剧对简单形态的欠拟合。
- **特权 critic 的不对称性**：训练依赖地形扫描、体速等仿真特权信息，真实部署仅用本体感知，存在表征错配风险；文中未量化该错配的影响。
- **评价以"能走"为主**：缺少对步态质量、能效、鲁棒性边界（如最大扰动、最大坡度）的系统刻画，难以判断策略是否只是"勉强通过"。
- **可复现性**：核心超参（奖励权重表、课程曲线、域随机化范围）多在附录/代码中，正文可读性受限；基线复现依赖官方实现版本，跨实现比较仍有残余偏差。

## 8. 启示与展望

- **方法论启示**：通用机器人策略的设计应同时处理三个层面——**表示**（如何编码形态）、**优化**（如何让不同形态公平地贡献梯度）、**执行**（如何自动配置低层控制器）。只解决其中一层往往不足以实现跨形态迁移。
- **工程启示**：以 URDF 为唯一"形态接口"，把 PD 增益、token 化、掩码都从同一源头导出，可显著降低新平台接入成本，这对快速迭代的机器人设计流程具有直接价值。
- **可能的后续方向**：
  - 将形态 token 扩展到轮、臂、柔性关节与可变拓扑；
  - 用学习到的形态嵌入做零样本形态搜索/协同设计（co-design）；
  - 引入在线系统辨识，缓解 URDF 误差与 sim-to-real 差距；
  - 研究奖励归一化的理论依据（如多任务梯度平衡视角），替代经验性缩放；
  - 在真实硬件上开展基线对照与更大样本的统计评估。

## 9. 总体评价

- **贡献定位**：论文的核心贡献不在于新 RL 算法，而在于把"形态感知表示 + 训练公平性 + 自动控制配置"整合为一条可落地的通用运动控制流水线，并用仿真与真实硬件共同验证。其价值在于**系统性与工程完整性**，而非单点理论突破。
- **证据强度**：仿真侧证据较充分（多形态、多基线、多消融、3 种子），真实侧证据偏弱（样本小、无基线、仅自家平台）。因此"跨形态通用"在仿真中已较可信，在真实世界中属于"可行性演示"而非"统计性证明"。
- **写作与呈现**：问题动机清晰，方法模块划分明确，消融与基线选择有针对性；不足在于部分关键超参与真实实验细节需依赖附录，效率与鲁棒性维度的分析偏少。
- **适用读者**：腿式机器人控制、多形态/多任务 RL、sim-to-real 迁移方向的研究者与工程实践者；对做机器人协同设计、快速原型验证的团队亦有参考价值。
