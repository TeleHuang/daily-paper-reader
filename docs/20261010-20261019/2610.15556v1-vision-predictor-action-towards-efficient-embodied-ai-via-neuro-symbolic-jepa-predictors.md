## 摘要
视觉-语言-动作（VLA）模型通常通过大语言模型（LLM）解码器逐 token 生成机器人动作，导致推理延迟随动作序列长度增长，并限制闭环控制频率。我们提出目标条件 Vision-Predictor-Action（VPA），用轻量级潜在控制回路替代自回归解码器。共享视觉编码器和冻结文本编码器对观测、目标图像和指令进行嵌入；神经符号选择器选择离散技能；联合嵌入预测架构（JEPA）预测器预测下一潜在状态；流匹配求解器在少量积分步骤中生成整个动作块，从而使每个决策步骤的串行网络评估不依赖于动作时域。我们分析推理复杂度、防止表征坍缩的正则化，以及潜在子目标阈值化在何种条件下限制跨任务阶段的误差累积。作为初步概念验证，我们在 LIBERO-10 套件上评估了 VPA。可训练模型参数少于 2000 万（检查点小于 75 MB，不包括冻结的 6340 万参数 CLIP 文本编码器）；单相机参考配置的一个决策步骤在 Apple M4 上耗时 10–14 ms；仅使用 LIBERO-10 演示数据在单块 GPU 上训练不到三小时，双相机策略在 200 个评估回合中成功率为 40.0%。这些来自单次训练运行的初步结果表明该方法可行。代码与权重可在 https://github.com/ylee-sling/Vision-Predictor-Action 和 https://huggingface.co/ylee-sling/vpa-libero10 获取，并归档于 https://doi.org/10.5281/zenodo.22960920。

## Abstract
Vision-Language-Action (VLA) models commonly generate robot actions token by token through Large Language Model (LLM) decoders, causing inference latency to grow with action sequence length and limiting closed-loop control frequency. We present Goal-Conditioned Vision-Predictor-Action (VPA), which replaces autoregressive decoders with a lightweight latent control loop. A shared vision encoder and a frozen text encoder embed observations, goal images, and instructions; a neuro-symbolic selector chooses a discrete skill; a Joint-Embedding Predictive Architecture (JEPA) predictor forecasts the next latent state; and a flow-matching solver generates an entire action chunk in a few integration steps, so that sequential network evaluations per decision step do not depend on the action horizon. We analyze inference complexity, regularization against representation collapse, and conditions under which latent sub-goal thresholding limits error accumulation across task phases. As an initial proof of concept, we evaluated VPA on the LIBERO-10 suite. The trainable model has under 20M parameters (checkpoint under 75 MB, excluding a frozen 63.4M-parameter CLIP text encoder); a decision step of a single-camera reference configuration takes 10-14 ms on an Apple M4; and trained only on LIBERO-10 demonstrations in under three hours on a single GPU, a two-camera policy succeeded in 40.0% of 200 evaluation episodes. These preliminary results from a single training run suggest the approach is workable. Code and weights are available at https://github.com/ylee-sling/Vision-Predictor-Action and https://huggingface.co/ylee-sling/vpa-libero10, and archived at https://doi.org/10.5281/zenodo.22960920.

# Vision-Predictor-Action（VPA）论文结构化总结

## 一、核心问题与研究动机

- **背景**：具身智能的主流范式是视觉-语言-动作（VLA）模型（RT-2、OpenVLA、Instruct2Act 等），它们把连续动作离散化为 token，再由数十亿参数的大语言模型（LLM）解码器**逐 token 自回归**输出。
- **核心痛点**：生成一个长度为 \(H\)、维度为 \(d_a\) 的动作块需要 \(N=q\cdot H\cdot d_a\) 个 token，而每个 token 都依赖前一个 token，因此必须串行执行 \(\Theta(N)\) 次前向传播；延迟至少随 \(N\)（进而随 \(H\)）线性增长。RT-2 报告的实时推理频率仅约 1–5 Hz，难以支撑反应式、动态的操作或扰动补偿。
- **已有折中方案的不足**：
  - 神经符号 VLA（如 NS-VLA）引入离散技能指针，但仍依赖因果 VLM/自回归文本解析器；
  - VLA-JEPA 引入潜在世界模型，但仍绑定在大型视觉-语言主干（如 Qwen3-VL-2B）上；
  - ACT / Diffusion Policy / 条件流匹配（π0）虽能实现 30–100 Hz 高频执行，但多为无预测动力学的反应式策略，或仍需数十亿参数 VLM 主干做语言条件。
- **论文定位**：提出 **Goal-Conditioned Vision-Predictor-Action（VPA）**，用一个轻量级“潜在控制回路”替代自回归解码器，在保留语义任务指定的同时，使**每个决策步的串行网络评估次数与动作时域 H 无关**。作者明确将其定位为“概念验证（proof of concept）”，而非追求 SOTA 性能。

## 二、方法论

### 2.1 核心思想

- 把机器人操作建模为**目标条件 MDP**（G-MDP）：状态 \(s_t=(I_t,S_t)\)，目标 \(g=(x,I_g)\) 由语言指令与（可多阶段的）目标图像组成，动作为连续动作块 \(A_t\in\mathbb{R}^{H\times d_a}\)。
- 用**四阶段非自回归流水线**解耦“高层任务逻辑”与“低层连续运动控制”：编码 → 离散技能选择 → 潜在状态预测 → 流匹配动作块生成。
- 稀疏目标奖励被替换为**潜在度量代理奖励** \(R=-\lVert z_t-z_g^{(m_t)}\rVert_2\)，仅作分析与监控信号，不参与优化（各模块均由自监督潜在预测或示范模仿训练）。

### 2.2 四个关键模块

- **① 潜在多模态目标编码**：共享 ViT 编码器 \(E_\psi\) 以孪生方式编码当前帧与各里程碑目标帧 \(z_t=E_\psi(I_t)\)、\(z_g^{(m)}=E_\psi(I_g^{(m)})\)；冻结的轻量文本编码器（CLIP ViT-B/32，512 维）把指令编码为 \(c_{\text{text}}\)，**每回合只计算一次**，不在每步依赖链上。
- **② 神经符号技能选择器 \(\pi_{h\phi}\)**：以 \((z_t,z_g^{(m_t)},c_{\text{text}})\) 为输入的两层 MLP 分类器，在固定技能字典 \(\mathcal{U}\)（如 reach/grasp/carry/release）上取 argmax，输出离散技能 \(u_t\)；单次分类开销与里程碑数 \(M\) 无关。里程碑推进由**符号转移规则**（潜在 \(\ell_2\) 阈值测试 \(\lVert z_t-z_g^{(m_t)}\rVert_2<\tau\)）控制，且 \(\tau\) 不是固定常数，而是用 VICReg 运行方差裕度校准：
  - \(\bar\gamma_n=(1-\alpha_\gamma)\bar\gamma_{n-1}+\alpha_\gamma\sqrt{\frac1d\sum_j \mathrm{Var}(Z^{(n)}_{\cdot,j})+\epsilon}\)
  - \(\tau_n=\kappa\sqrt{2d}\,\bar\gamma_n\)（\(\kappa\in(0,1)\)），其含义是“完成容差 = 独立采样潜变量 RMS 距离的一个比例”；编码器冻结后固定为 \(\tau^\star\)。
- **③ JEPA 潜在预测器 \(P_\omega\)**：\((\hat z_{t+1},\sigma_{t+1})=P_\omega(z_t,u_t)\)，以**离散技能**而非具体动作块为条件，预测 ν 步后的潜在状态；不确定性由 \(N_e=5\) 个独立初始化预测头的**集成分歧**给出，并用 \(\bar\gamma^\star\) 归一化为无量纲量。
  - 训练目标：\(L_{\text{JEPA}}=\mathbb{E}\lVert \hat z_{t+1}-\mathrm{sg}(E_{\bar\psi}(I_{t+1}))\rVert_2^2+\lambda_v v(Z)+\lambda_c c(Z)\)，目标分支为 EMA 动量编码器 + stop-gradient。
  - 反坍缩：VICReg 的**方差铰链** \(v(Z)\)（每维标准差低于裕度 γ 时受罚）与**协方差去相关** \(c(Z)\)（惩罚非对角协方差）。
  - 训练后 \(E_\psi\)、\(P_\omega\) **冻结**，为下游求解器提供平稳的条件分布。
- **④ 流匹配动作求解器 \(\pi_{l\theta}\)**：条件向量场 \(v_\theta\)，线性插值路径 \(A_t^{(\rho)}=\rho A_t+(1-\rho)\xi\)，回归目标速度 \(A_t-\xi\)（式 14）；用 Euler 法以 \(K\in\{1,2,3\}\) 步积分即可一次性生成整块 \(A_t\in\mathbb{R}^{H\times d_a}\)。
  - 统一条件向量 \(e_t=\mathrm{Concat}(\mathrm{Embed}(u_t),z_t,\hat z_{t+1},S_t,c_{\text{text}})\)，潜变量用固定统计量标准化 \((\tilde z=(z-\bar\mu_Z)/\bar\gamma^\star)\)，使阈值、不确定性、求解器输入处于同一尺度。
  - **不确定性自适应执行时域**：\(H_t=\max(H_{\min},\lfloor H_{\max}\cdot e^{-\beta\bar\sigma_{t+1}}\rfloor)\)，其中 \(\bar\sigma\) 经**快升慢降的非对称滤波**（抑制时域抖动），低不确定性时执行长前缀，高不确定性时缩短以更快回到闭环反馈。

### 2.3 两阶段训练流程

- **阶段一（表征学习，50k 步）**：随机初始化下联合训练 \(E_\psi\) 与 \(P_\omega\)（式 11），技能条件用示范数据中由夹爪指令启发式导出的标签；结束后冻结二者，固定 \(\bar\gamma^\star\)、\(\tau^\star\)。
- **阶段二（行为克隆式对齐 + 求解器训练，50k 步）**：用冻结编码器一次性编码所有帧（缓存潜变量），标准化条件输入，再分别以交叉熵训练选择器、以式 14 训练流匹配求解器（warm-start 对齐，避免早期梯度爆炸）。

### 2.4 理论分析（三类结论，强度不同）

- **命题 5.1（串行深度与计算量）**：单决策步的串行深度 \(D_{\text{VPA}}=K+3\)，**与 \(H\)、\(d_a\) 无关**；而自回归解码 \(D_{\text{VLA}}=N=\Theta(H d_a)\)。但总计算量 \(W_{\text{VPA}}(H)=C_E+C_h+C_P+K\cdot C_l(H)\)，其中 \(C_l(H)=\Omega(H d_a)\)，故**每周期成本并非关于 H 的 O(1)**；只有单次求解器评估能落在硬件并行度内时，墙钟延迟才近似与 H 无关。
- **命题 5.2（反坍缩）**：常数编码器（配最优预测器）取得目标值 \(\lambda_v(\gamma-\sqrt\epsilon)\)；**仅 λ_v>0 并不足以排除坍缩**，只有当存在非退化表征使目标值更低时，常数解才被排除出全局最优；当 \(v(Z)=c(Z)=0\) 时协方差阵正定、潜变量张满 d 维，但这要求批大小 \(B>d\)（实验 B=64、d=256，故两项惩罚不可能同时为零）。
- **命题 5.3（条件性相位转移界）**：在编码器对任务相关物理状态满足**上 Lipschitz（\(L_E\)）**与**下 co-Lipschitz（\(\mu_E\)）**假设下：
  - 可靠性：阈值满足 ⇒ 物理偏差 \(<\frac{\tau+\delta_\eta}{\mu_E}\)；
  - 完备性：物理足够接近 ⇒ 触发转移（要求 \(\tau>\delta_\eta\)）；
  - **相位起点重置**：每次里程碑切换时的物理残差 \(r_k<(\tau+\delta_\eta)/\mu_E\)，**与里程碑序列长度 M 无关**，即误差不跨阶段传播。
  - 作者明确指出：ViT 非全局 Lipschitz，下界更无法由架构约束保证，因此这只是**可检验的经验期望**，本文实验**未估计** \(L_E,\mu_E,\delta_\eta\)。

## 三、实验设计

- **Benchmark**：LIBERO-10（LIBERO 的长时域子集），10 个桌面操作任务（厨房/客厅/书房），多数含两个子任务；训练用官方示范，每任务留 2 条（共 20 条）做验证。
- **输入/动作设置**：128×128 RGB（旋转 180°），本体感知 15 维，动作 7 维（6 维末端位移 + 夹爪）；\(H=16\)，\(H_{\min}=4\)，\(K=2\)，\(d=256\)，\(N_u=4\) 个启发式技能，**\(M=1\)**（仅最终帧作为目标图像）。
- **评估协议**：每个配置 200 回合（每任务 20 次），固定初始状态、评估种子 0，600 控制步内由 LIBERO 判定成功，报告 95% Wilson 区间。
- **实验组**：
  1. **单相机 vs 双相机**（第三人称 vs 第三人称+腕部）主结果；
  2. **遮挡对照**：把第三人称视角替换为黑图（分布外）→ 成功率 0%；
  3. **训练长度检查**：第二阶段 40k / 45k / 50k 步的中间检查点；
  4. **执行时域消融**：固定 \(H_t=2/4/8\) vs 自适应（β=40.4）vs 近全块执行（β=1，\(H_t=15\)），同一检查点、同一 200 初始状态；
  5. **延迟基准**：Apple M4 上按 \(K\in\{1,2,3\}\times H\in\{8,16,32,64,128\}\) 扫描，前向 hook 计时、每次读时钟前同步，10 次预热后取 100 次运行中位数（含一次重复扫描评估波动）。
- **对比方法**：**没有在同一协议下运行任何基线**；仅与文献中 RT-2 的 1–5 Hz 及 LIBERO-10 上已报告的成功率做**非受控的间接对照**，作者多次强调不可直接比较。
