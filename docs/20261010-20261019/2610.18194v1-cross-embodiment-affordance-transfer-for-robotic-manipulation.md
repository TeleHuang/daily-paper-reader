## 摘要
机器人操作系统通常从人工标注数据集中学习物体可供性，这些数据集反映的是人手的交互可能性，而非特定机器人的物理约束。例如，人工标注者识别为可抓取的物体表面区域，对机器人而言可能在几何上不可达或机械上不可行，但这种不匹配很少被显式处理。为应对这一挑战，我们提出了一个框架，将人类可供性标注转换为以机器人物理属性为条件的机器人可执行可供性预测。该网络在给定物体的三维点云以及编码机器人几何与约束的描述符的条件下，预测物体哪些表面区域可由机器人物理执行。模型使用人类标注的可供性以及仿真中多次采样接近试验的机器人执行结果进行训练，其中执行结果决定了哪些区域对机器人是可执行的。评估在家庭物品数据集上进行，使用 UR5e 机械臂上的两种平行夹爪配置。该框架优于不接收机器人信息的模型。实验结果表明，可供性预测必须以机器人为条件，仅靠人类标注不足以学习机器人可执行的可供性表示。

## Abstract
Robotic manipulation systems commonly learn object affordances from human-annotated datasets, which reflect interaction possibilities for a human hand rather than the physical constraints of a specific robot. For example, a surface region of an object identified as graspable by a human annotator may be geometrically unreachable or mechanically infeasible for a robot, yet this mismatch is rarely addressed explicitly. To tackle this challenge, we proposed a framework that translates human affordance annotations into robot-executable affordance predictions conditioned on the physical properties of the robot. The network predicts which surface regions of an object are physically executable by the robot, given a 3D point cloud of an object and a descriptor encoding the robot's geometry and constraints. The model was trained using human-annotated affordances together with robotic execution outcomes from multiple sampled approach trials in simulation, where execution outcomes determined which regions are executable for the robot. The evaluation was performed on a household objects dataset using two parallel-jaw gripper configurations on a UR5e robot arm. The framework outperformed a model that does not receive information about the robot. The experimental results demonstrated that affordance prediction must be conditioned on the robot and that human annotations alone are insufficient for learning robot-executable affordance representations.

## 1. 核心问题与研究背景

- **核心问题**：现有机器人可供性（affordance）学习普遍依赖人类标注数据集（如 UMD Part Affordance Dataset），而这些标注描述的是"人手可以如何与物体交互"，并非"某个具体机器人本体能否执行该交互"。论文将这一错配命名为 **human-to-robot affordance gap（人—机器人可供性鸿沟）**。
- **理论依据**：可供性是**关系性**的（Gibson 式生态心理学视角），产生于物体与特定行动主体之间的交互。灵巧人手可从多位置、多姿态接近与抓取，而开口有限、运动受限的平行夹爪只能覆盖其中一部分区域。
- **问题严重性**：作者援引多篇文献指出该局限已被广泛承认（Myers 等的区域级标注受夹爪/机器人规格限制；Cavalli 等质疑非人手主体的标注有效性；Kemmeren 等指出数据集未刻画具身对交互可行性的影响），但**鲜有工作显式建模并量化这一鸿沟**。
- **研究空白**：3D 可供性分割方法（3D AffordanceNet、OpenAD、AffordMatcher 等）均把可供性当作**固定具身下的物体固有属性**；已有的具身条件化研究（硬件描述符嵌入策略网络、多具身抓取的几何匹配、agent-aware affordance）多停留在**策略/控制层**，尚未用于**逐点可供性分割**。
- **整体含义**：论文主张可供性预测必须**以机器人为条件**，人类标注只能作为"物体—交互知识"的公共先验，需用少量机器人执行数据（含**失败**案例）适配到具体本体。

## 2. 方法论

### 2.1 核心思想

将"人类可供性标注 → 机器人可执行可供性"的转换建模为**具身条件化的逐点三分类分割**问题：输入物体点云与机器人描述符，输出每个表面点属于 grasp / wrap-grasp / background；其中 background 同时包含"未被标注的区域"与"被人标注但该机器人物理上不可执行的区域"，从而**把鸿沟直接编码进标签空间**。

### 2.2 问题形式化

- 点云 \(P \in \mathbb{R}^{N\times 3}\)（机器人基座坐标系）；人类标注 \(a^H_i \in \{0,1,2\}\)（0=grasp，1=wrap-grasp，2=background）。
- 具身描述符 \(e \in \mathbb{R}^D\)；预测函数 \(G_\theta:(P,e)\rightarrow \hat{y}\)，\(\hat{y}_i\in\{0,1,2\}\)。
- **关键设定**：人类标注 \(a^H\) **仅用于训练监督**，推理时不可见。

### 2.3 多具身数据生成流程

1. **人类标注来源**：UMD 数据集逐点标注，仅保留 grasp 与 wrap-grasp 两类，其余类别映射为 background，得到 \(a^H\)。
2. **仿真执行数据**（PyBullet + UR5e + Robotiq 2F-85 / 2F-140）：
   - 每个物体在桌面工作空间采样 **200 个位姿**，作为受重力与接触动力学约束的自由刚体；
   - 用 **ICP 配准**将 UMD 源点云对齐到目标物体点云，重投影得到候选接触点集合 \(A^H\)；
   - 每个候选点采样 **5 个接近位姿**，执行抓取/包裹抓取原语，逐路点做逆运动学求解与碰撞检测；
   - 四种执行判决：**PASS**（接触 + 无碰撞闭合 + 稳定抬起）、**PARTIAL**（到达但闭合失败）、**MISMATCH**（无有效 IK 解）、**MISS**（无可行接近轨迹）；
   - **标注规则**：5 次试验中至少 1 次 PASS → 保留原类别 \(k\in\{0,1\}\)；否则 → 标为 background(2)。集合差 \(A^H \setminus A^R(e)\) 即为鸿沟的显式编码。

### 2.4 具身描述符（21 维，UR5e 实例化）

- **\(w\in\mathbb{R}^4\)**：水平外可达半径、内部死区半径、末端最低/最高高度；
- **\(g\in\mathbb{R}^5\)**：最大/最小夹爪开口、指长、指垫接触宽度、侧向掌部偏移；
- **\(q\in\mathbb{R}^{12}\)**：6 个关节的下/上限，按关节交错排列。
- 该描述符**不含可学习参数**、按机器人固定；跨具身迁移只需替换 \(e\)，**无需改动网络结构**；不同关节数的机器人对应不同维度 \(D\)。

### 2.5 网络架构（FiLM 条件化的 PointNet++）

- **编码器**：PointNet++ + 多尺度分组（MSG），三级 Set Abstraction：
  - SA1：N→512 质心，半径 {0.1, 0.2, 0.4} m，320 通道；
  - SA2：512→128 质心，半径 {0.2, 0.4, 0.8} m，640 通道；
  - SA3：全局聚合，1024 通道；
  - 三级 Feature Propagation 用距离加权插值 + 跳跃连接上采样回 N 点，保留细粒度几何。
- **FiLM 条件化**：每个 SA 层级 \(l\) 配一个独立（不共享参数）的两层 MLP \(g^{(l)}_\theta:\mathbb{R}^D\rightarrow\mathbb{R}^{C_l}\times\mathbb{R}^{C_l}\)，由 \(e\) 生成逐通道缩放 \(\gamma^{(l)}\) 与偏置 \(\beta^{(l)}\)，对 SA 输出做仿射调制 \(\tilde{h}_i=\gamma\odot h_i+\beta\)，再经跳跃连接注入 FP 层，使具身信号贯穿整个特征金字塔。
- **分类头**：两层共享 1D 卷积（256、128 通道）+ BN + ReLU + Dropout，线性投影到 3 类 logits，推理时 softmax。

### 2.6 训练目标

- **加权交叉熵**，类别权重 \(w_k=(\max_j N_j / N_k)^{1/3}\)，用于缓解 background 与可供性点的类别不平衡；不可执行的候选点被标为 background，从而把**失败执行转化为负监督信号**。

## 3. 实验设计

- **数据集/场景**：
  - 人类标注：**UMD RGB-D Part Affordance Dataset**（仅用 grasp、wrap-grasp 两类）；
  - 物体：**YCB** 家庭物品集（Fig. 5 展示的代表性物体，含勺子、叉、刀、锤、多个马克杯、汤罐、糖盒、水壶底座等）；
  - 平台：**PyBullet 仿真**中的 UR5e + 可更换 Robotiq 2F-85 / 2F-140 夹爪，末端搭载 RGB-D 相机的桌面场景；输入为 2048 点点云。
- **Benchmark / 评价方式**：逐点三分类，按类计算 Precision、Recall、F1、IoU，主指标为两类平均 **mIoU**，并报告 \(\Delta\)mIoU。
- **对比方法**：
  1. **主消融**：Embodiment-conditioned 模型 vs. **No-embodiment baseline**（同架构但不输入描述符）——检验"仅靠物体几何是否足够"。
  2. **跨夹爪迁移**：分别在 2F-85 与 2F-140 数据上训练，交叉在另一夹爪的 ground-truth 标签上评估（双向对照，\(\Delta\) 定义为 2F-140 − 2F-85）。
  3. **辅助分析**：Table III 的物理几何可行性分析（按物体尺寸与夹爪最大跨度判定 grasp / wrap-grasp 是否可行）；Fig. 4 在**已见与未见类别**上的定性预测可视化。
- **训练超参**：Adam（β₁=0.9, β₂=0.999），初始学习率 5×10⁻⁴，权重衰减 1×10⁻⁴，10 epoch 线性 warmup + cosine 退火至 1×10⁻⁶，最多 150 epoch，early stopping patience 40，batch size 8。
