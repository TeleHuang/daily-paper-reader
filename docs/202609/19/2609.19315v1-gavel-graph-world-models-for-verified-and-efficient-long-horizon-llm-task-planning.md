## 摘要
大型语言模型（LLM）为长时程机器人规划提供了灵活的接口，但生成的规划往往无法遵守具身约束、从规划错误中恢复，或在部分可观测性下进行有效推理。我们提出 GAVEL，一个围绕显式图世界模型构建、用于验证与修复长时程LLM规划的框架。该图表示相关的物体关系、动作前置条件与效果，以及关于未观测物体位置的概率信念。该模型可以在执行前预测LLM生成动作的后果，检测违规，并修复那些其修正可直接由世界模型推出的动作。该方法还将LLM重新规划仅保留给需要语义推理的错误。对于多任务指令，GAVEL 对可能物体位置的分布进行推理，以重排剩余子任务并最小化预期搜索成本。我们在 BEHAVIOR-1K 上跨100个单一长时程任务和500个多任务指令评估 GAVEL。使用 Qwen3-8B 时，GAVEL 将单任务成功率从41.2%提升至91.8%，将多任务成功率从19.9%提升至92.6%。与静态变体相比，分布式信念推理还将移动距离减少约5.4%。这些改进表明，显式图世界模型支架可以显著提升长时程具身规划在紧凑型与前沿托管式LLM能力上的可靠性和效率。

## Abstract
Large language models (LLMs) provide a flexible interface for long-horizon robot planning, but generated plans often fail to respect embodiment constraints, recover from planning errors, or reason effectively under partial observability. We present GAVEL, a framework for verifying and repairing long-horizon LLM planning built around an explicit graph world model. The graph represents relevant object-relations, action pre-conditions and effects, and probabilistic beliefs over unobserved object locations. This model can predict the consequences of LLM-generated actions before execution, detect violations, and repair those whose corrections follow directly from the world model. This method also reserves LLM replanning solely for errors requiring semantic reasoning. For multi-task instructions, GAVEL reasons over distributions of possible object locations to reorder remaining subtasks and minimize expected search cost. We evaluate GAVEL on BEHAVIOR-1K across 100 single long-horizon tasks and 500 multi-task instructions. With Qwen3-8B, GAVEL improves single-task success from 41.2% to 91.8% and multi-task success from 19.9% to 92.6%. Distributional belief reasoning also reduces travel distance by approximately 5.4% compared with a static variant. These improvements show that an explicit graph world model harness can substantially improve the reliability and efficiency of long-horizon embodied planning across compact and frontier hosted LLM capabilities.

- **研究动机**：LLM 可作为长时程机器人规划的自然语言接口，但生成的计划常违反具身约束、遗漏前置动作、无法从错误中恢复，并在部分可观测环境中搜索效率低。

- **整体含义**：论文主张不要只把场景图当作被动验证器，而应将其提升为**显式图世界模型**：由 LLM 负责语义程序生成，图模型负责动作后果预测、违规检测、模型可推导修复，以及基于信念的在线任务重排。LLM 重规划仅保留给真正需要语义推理的失败。

## 2. 方法论
- **核心思想**：构建统一图世界模型 \(G=(V,E,\Phi)\)，表示房间、物体、机器人、空间关系、物体状态标志，以及未观测物体位置的概率信念。LLM 生成候选计划后，图模型在图上前向执行动作，验证并修复，再进入物理/符号执行。
- **图与动作模型**：
  - 节点包括房间 \(R\)、物体 \(O\)、机器人 \(\rho\)；关系包括 near、under、room connect、object inside、on top、next to、holding 等；一元状态包括 open、toggled、cooked、washed、dried。
  - 动作原语共 9 个：NAVIGATE TO、GRASP、RELEASE、PLACE ONTOP、PLACE INSIDE、OPEN、CLOSE、TOGGLE ON、TOGGLE OFF。
  - 每个动作有前置条件与效果 \(\langle pre_a, eff_a\rangle\)，转移模型为：若前置成立则 \(f(G,a)=eff_a(G)\)，否则为无效 \(\perp\)。
- **部分可观测与信念**：
  - 维护未观测物体房间位置分布 \(b_t^o(r)=P(room(o)=r|H_t)\)。
  - 观测更新信念：观测到物体则定位，未观测到则从候选房间中剪除。
  - 用 RSN 初始化物体位置信念，将房间类型分数按可达同类型房间实例均匀分配并归一化。
- **LLM 规划与图修复**：
  - 指令先分解为 \(N\) 个任务，抽取对象、关系与部分图目标 \(g_i\)。
  - LLM 一次性生成各任务动作计划 \(\{π_i\}\)。
  - 图世界模型逐动作 roll-forward，检查适用性、目标完成与安全约束。
  - 若失败可由动作语义直接推出，则递归修复，例如抓取距离不足触发 NAVIGATE TO，容器关闭触发导航并 OPEN，安全违规触发恢复动作。
  - 无法模型修复的语义失败以结构化反馈返回 LLM，最多 \(T\) 次；保留历史最佳候选，防止修复循环。
- **信念感知多任务排序**：
  - 对未定位物体按候选房间信念排序，估计期望搜索成本 \(C_{srch}\)；已定位物体用几何导航成本 \(C_{loc}\)。
  - 对剩余任务构建首任务成本 \(h\) 与任务间转移成本 \(A\)，排序代价 \(J(ς)=h[ς_1]+\sum_{p=2}^N A[ς_{p-1},ς_p]\)。
  - 枚举排列，执行当前最优排序的第一个任务；执行后更新信念并在线重排剩余任务。
- **整体流程**：任务分解 → 对象/目标抽取 → RSN 初始化信念 → LLM 生成计划 → 图世界模型验证/修复 → 必要时 LLM 重规划 → 基于信念排序 → 执行首任务 → 更新信念 → 重排。
