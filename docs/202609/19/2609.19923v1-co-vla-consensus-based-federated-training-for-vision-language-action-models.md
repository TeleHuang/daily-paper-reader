## 摘要
视觉-语言-动作模型（VLA）已成为通用机器人学习的一种有前景的范式，随着模型和数据集的扩展，其性能不断提高。然而，扩展机器人数据收集仍然具有挑战性，因为数据天然分布在不同的机器人、任务和地点上，使得集中化成本高昂或不可行。联邦学习提供了一种在去中心化机器人数据上进行训练的方法，但将其应用于 VLA 需要考虑异构的机器人客户端数据分布。我们提出 Co-VLA，它将使用交替方向乘子法（ADMM）的共识优化应用于联邦 VLA 训练。我们表明，同一算法既支持全模型训练，也支持使用固定秩和秩自适应适配器的参数高效微调。Co-VLA 这一名称体现了共识与协作：拥有不同本地机器人数据集的客户端在不共享数据的情况下协作训练一个共享模型。我们的实验表明，在全模型训练和参数高效微调设置中，Co-VLA 均能达到与集中式训练相当的性能。

## Abstract
Vision-language-action models (VLAs) have emerged as a promising paradigm for general-purpose robot learning, with performance improving as models and datasets scale. Scaling robot data collection, however, remains challenging because data are naturally distributed across robots, tasks, and locations, making centralization costly or impractical. Federated learning offers a way to train on decentralized robot data, but applying it to VLAs requires accounting for heterogeneous robot client data distributions. We present Co-VLA, which applies consensus optimization using the Alternating Direction Method of Multipliers~(ADMM) to federated VLA training. We show that the same algorithm supports both full-model training and parameter-efficient fine-tuning with both fixed-rank and rank-adaptive adapters. The name Co-VLA reflects both consensus and collaboration: clients with different local robot datasets collaboratively train a shared model without sharing their data. Our experiments demonstrate that Co-VLA achieves performance comparable to centralized training in both full-model training and parameter-efficient fine-tuning settings.

## 2. 方法论

### 2.1 核心思想：全局共识优化

- 设有 N 个机器人客户端，客户端 i 持有本地数据集 D_i，本地损失为 f_i。集中式训练为 min Σ f_i(x)。
- 联邦设定下为每个客户端引入本地模型副本 x_i，服务器维护全局共识变量 z，构建共识约束优化问题：

  **min_{x1,...,xN,z} Σ_{i=1}^N f_i(x_i)　s.t.　x_i = z, i=1,...,N　(1)**

- 约束 x_i = z 强制本地与全局模型一致，从而应对异构客户端数据导致的本地漂移。

### 2.2 算法：过松弛 ADMM（Algorithm 1）

- 每轮通信 k 中，客户端与服务器交替更新：
  - **客户端（对偶更新 + 本地原始更新）**：
    - 对偶变量累积共识差距：`u_i^k = u_i^{k-1} + (x̂_i^k − z^k)`
    - 本地原始更新（实际用固定步数的本地梯度下降近似求解）：`x_i^{k+1} = argmin_{x_i} f_i(x_i) + (ρ/2)‖x_i − z^k + u_i^k‖²₂`
    - 过松弛：`x̂_i^{k+1} = α x_i^{k+1} + (1−α) z^k`
  - **服务器（全局平均）**：`z^{k+1} = (1/N) Σ_i (x̂_i^{k+1} + u_i^k)`
- **关键超参数**：
  - ρ > 0：控制二次邻近项耦合强度；
  - α ∈ (0,2)：过松弛系数，可加速收敛（α=1 即标准 ADMM）；
  - u_i：拉格朗日乘子（对偶变量），跨轮累积共识差距。
- **开销**：相较 FedAvg，客户端每轮仅增加一次对偶变量更新与一个二次正则项；服务器对 `x̂_i + u_i` 求平均并广播 z，通信带宽与 FedAvg 同量级。

### 2.3 联邦 LoRA 的共识构造

- LoRA 形式：`W_s = (W_0 + ΔW)s`，`ΔW = BA`，A∈R^{r×k}、B∈R^{d×r} 为可训练低秩因子。
- **聚合失配问题**：对客户端因子分别求平均无法还原平均更新，即 `E[ΔW_i] = E[B_i A_i] ≠ E[B_i]E[A_i]`，这是 FedAvg 聚合 LoRA 在非 i.i.d. 数据下不可靠的根源。
- **现有补救方案对比**：FLoRA 在服务器端堆叠因子再分发，通信量随客户端数量增加；FlexLoRA 在服务器端重建完整更新并用 SVD 重分解，计算重且引入近似误差。
- **Co-VLA 做法**：直接在低秩因子上施加共识约束 `A_i ≈ A`、`B_i ≈ B`，避免对独立漂移的适配器做简单平均，从而直接缓解双线性聚合失配，同时保留低秩适配器的通信效率。

### 2.4 联邦稀疏 LoRA（SoRA）

- SoRA 在 LoRA 上引入可训练门控 g∈R^r：`ΔWs = B(g ⊙ (As))`，通过 ℓ1 惩罚自动选择有效秩，训练后剪去零门控对应行列得到紧凑适配器。
- 将门控纳入联邦变量：`x_i = {A_i, B_i, g_i}`，`z = {A, B, g}`，目标为：

  **min Σ f_i(x_i) + λ‖g‖₁　s.t.　x_i = z　(2)**

- ℓ1 范数仅施加于全局门控，客户端本地更新形式不变；服务器对 A、B 仍为平均，对门控采用软阈值更新：

  **g^{k+1} = S_{λ/(Nρ)}( (1/N) Σ_i (ĝ_i^{k+1} + u_{g,i}^k) )　(3)**

  其中软阈值算子 `S_ξ(v_j) = sign(v_j)·max(|v_j|−ξ, 0)`（式 4），将阈值内的门控值精确置零以诱导稀疏。
- **特点**：联邦稀疏 LoRA 仅在服务器端增加软阈值操作，客户端训练流程保持不变。
