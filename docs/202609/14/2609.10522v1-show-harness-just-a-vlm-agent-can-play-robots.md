## 摘要
基础视觉语言模型（VLM）展现出关于世界的广泛智能，但将这种智能转化为机器人控制仍然具有挑战性。我们提出 Show-Harness，一种具身 Harness，使 VLM 能够通过连接意图与动作的紧凑语义接口来“操控”机器人。Show-Harness 暴露离散的语义动作单元，VLM 可以自然地对其进行推理，而具身特定的解释器则确定性地将其落地为本地机器人动作，从而使 VLM 直接负责细粒度的物理决策。通过同一接口，Show-Harness 证明了以下可行性：（1）直接解锁闭源前沿 VLM 用于零样本机器人控制；（2）仅需数 GPU 小时的微调即可适配小规模开源 VLM，以实现低成本部署。我们进一步开发了 GUMI（GUI 操控接口），它将相同的语义动作空间扩展到基于 GUI 的示教采集，使人类和智能体无需专用遥操作硬件即可跨具身“操控”机器人。大量实验表明，配备 Show-Harness 的 VLM 智能体在任务、具身和环境之间具有稳健的泛化能力，优于代表性的智能体范式和 VLA 范式。这些结果表明，正确的接口可以从基础 VLM 中解锁可观的具身能力，而无需额外模型容量或昂贵的具身特定预训练。

## Abstract
Foundation vision-language models (VLMs) exhibit broad intelligence about the world, yet translating this intelligence into robot control remains challenging. We present Show-Harness, an Embodied Harness that enables VLMs to "play" robots through a compact semantic interface linking intent to action. Show-Harness exposes discrete semantic action units that VLMs can naturally reason over, while embodiment-specific interpreters deterministically ground them into local robot actions, keeping the VLM directly responsible for fine-grained physical decisions. Through the same interface, Show-Harness demonstrates the feasibility of (1) directly unlocking closed-source frontier VLMs for zero-shot robot control, and (2) adapting small-scale open-source VLMs for low-cost deployment with just a few GPU-hours of fine-tuning. We further develop GUMI (GUI Manipulation Interface), which extends the same semantic action space to GUI-based demonstration collection, allowing humans and agents to "play" robots across embodiments without specialized teleoperation hardware. Extensive experiments show that Show-Harness-equipped VLM agents generalize robustly across tasks, embodiments, and environments, outperforming representative agentic and VLA paradigms. These results suggest that the right interface can unlock substantial embodied capability from foundation VLMs, without requiring additional model capacity or costly embodiment-specific pretraining.

## 1. 核心问题与整体含义

- **研究动机**：基础视觉语言模型（VLM）已编码大量机器人操作所需的世界知识（物体识别、空间关系、长程目标分解），但将这些知识转化为机器人行为仍十分困难。
- **现有路线的两难**：
  - **VLA 路线**：将 VLM 微调为直接回归具身特定的连续动作，把广泛的语义知识压缩为不透明的"像素到驱动"映射，需要针对新任务/环境/具身反复适配。
  - **分层/程序化路线**：VLM 只输出子任务调用或控制 API 程序，物理控制由下游控制器或系统特定机制中介，削弱了语义意图与物理执行之间的直接联系。
- **核心论点**：将基础模型智能带入物理世界需要一个合适的**接口**——一个对 VLM 语义上有意义、又足够细粒度以直接进行物理控制的动作空间。
- **整体含义**：Show-Harness 是一个模型无关的具身 Harness，让 VLM 通过紧凑语义动作接口"操控"机器人，无需额外模型容量或昂贵的具身特定预训练，即可解锁基础 VLM 中已有的具身能力。

## 2. 方法论

### 2.1 核心思想
- 将机器人控制重新表述为一组**离散语义动作单元**，每个单元对应一个方向上的单步运动或夹爪动作，VLM 可直接理解。
- 具身特定解释器将每个单元**确定性地**落地为小幅、有界的机器人运动，使每个语义决策都能作用于物理世界。
- Harness 闭合感知—推理—动作—反馈回路，将数字 VLM 转变为在自身原生语义空间中推理与行动的具身智能体。

### 2.2 关键公式与流程
- **感知上下文**：$c_t = \Phi_P(\ell, o_t, h_t)$，其中 $\ell$ 为语言指令，$o_t=(I_t,p_t)$ 为多视角视觉观测与本体状态，$h_t$ 为交互历史，$\Phi_P$ 为可配置推理插件。
- **语义动作选择**：$a_t = \pi(c_t) \in \mathcal{A}$，$\mathcal{A}$ 为紧凑的语义动作单元集合。
- **具身落地**：$u_t = g_E(a_t; s_t)$，$E$ 为具身，$s_t$ 为解释器内部设定点状态。
- **位姿更新**：$s_{t+1} = \Pi_E(x_t + \sigma_t R_E d_a,\ \exp(\theta_t [R_E r_a]_\times) Q_t)$，其中 $\sigma_t$、$\theta_t$ 为标定平移/旋转增量，$R_E$ 将语义方向映射到具身运动坐标系，$\Pi_E$ 施加工作空间与步长限制。

### 2.3 语义动作空间
- **动作单元**：`MV_FWD/BACK`、`MV_LEFT/RIGHT`、`MV_UP/DOWN`（相对参考视图的单步平移）；`ROTATE_CW/CCW`（绕指定轴增量旋转）；`GRASP`/`RELEASE`（夹爪开合）；`DONE`（任务完成）。
- **三大特性**：增量性（小范围局部物理变化，支持逐步修正）、可解释且具身无关（语义符号而非数值目标）、视觉接地（方向相对可观测视图定义）。

### 2.4 Harness 三阶段与插件
- **感知**：Multi-View Guidance（多视角角色与优先级指导）、Proprioception（将机器人状态、接触、夹爪状态转为文本反馈）。
- **推理**：Subtask Planning（带可视化完成判据的有序子任务计划）、Situated Planning（延迟不确定决策、按需重规划）、Action Chunking（自适应动作分块）、Adaptive Step（自适应步长）、Visual Prompt（高亮任务相关视觉目标）。
- **动作**：Action History（近期动作摘要、抑制振荡）、Failure Recovery（检测抓取失败并回滚恢复）。

### 2.5 两种控制模式
- **ZS 模式**：闭源前沿 VLM 零样本直接控制，无需微调。
- **FT 模式**：小开源 VLM 通过 LoRA（rank-64，仅更新约 3% 参数）微调，损失为语义动作 token 级交叉熵：$\mathcal{L}(\theta) = -\sum_{(\ell,o,h,a)\in D} \log \pi_\theta(a \mid \Phi_{P_{min}}(\ell,o,h))$，动作直接通过 VLM 原生词表预测，无需专用动作头或特殊 token。

### 2.6 GUMI
- 基于 GUI 的操控接口，将同一离散语义动作空间暴露给人类键盘、computer-use 智能体和 VLM 智能体。
- 每步记录执行前观测与所选语义动作，生成策略可用的 $(o_t, a_t)$ 对，同时保留底层命令与轨迹，支持跨具身复用与人—智能体协同采集。

## 3. 实验设计

### 3.1 硬件平台
- **Franka Research 3**（7-DoF 单臂）：外置 RealSense D435 + 腕部 RealSense D405。
- **AgileX 双臂**（两个 6-DoF 臂）：三个 Orbbec Dabai DC1（共享自我中心视图 + 每腕一个视图）。

### 3.2 任务与 Benchmark
- **10 个真实机器人操作任务**：5 种物体（积木、香蕉、网球、泰迪熊、棋子）× 2 种目标容器（盘子、碗）。
- 物体覆盖刚性几何、不规则形状、滚动动力学、可变形、精密操作；泰迪熊与棋子在 FT 训练中为 OOD 保留。
- 每任务 10 次随机摆放试验，50 步上限，超时计失败。
- 指标：成功率与平均步数。

### 3.3 对比方法
- **VLA 基线**：$\pi_{0.5}$、GR00T（在相同示教转换的连续末端轨迹上微调）。
- **以 VLA 为中心的智能体**：Harness VLA（H-VLA）、Goal-VLA（G-VLA）。
- **Code-as-policy 智能体**：CaP-X、RATS。

### 3.4 数据采集
- **真实机器人**：164 个 episode（7.8K 决策步），含 101 个 Franka（5.0K 步）、63 个 AgileX（2.8K 步）；统一 2 cm 平移步长。
- **仿真**：230 个 episode（13.5K 步），ManiSkill 100 个 + RoboLab 130 个（12 个任务）。

### 3.5 泛化评估维度
- **跨任务**：全部 10 个物体—容器组合。
- **跨环境**：背景、光照、视角、干扰物、仿真到现实迁移。
- **跨具身**：Franka 与 AgileX 间迁移。

## 4. 资源与算力

- **本地模型服务**：单张 RTX 5090 GPU。
- **前沿模型**：通过 API 访问（默认 Gemini-3.1 Pro）。
- **微调算力**：Qwen3.5-2B 在单张 H200 上微调**不到 2 小时**；可在 24 GB 级 GPU 上完成。
- **微调超参**：40 epoch，学习率 $1\times10^{-4}$，余弦调度 + 0.1 warmup，bf16，256×256 视图，有效 batch size 32。
- **参数效率**：LoRA rank-64 应用于所有语言模型线性层，冻结视觉编码器与多模态投影器，仅更新约 3% 参数。
- 论文未明确说明前沿 VLM API 调用的总 token 成本或总墙钟时间。

## 5. 实验数量与充分性

- **主实验**：3 个泛化维度（跨任务 10 任务、跨环境 4 条件 + sim-to-real、跨具身 5 任务 × 2 臂），每组 10–20 次试验。
- **能力分析**：细粒度控制、动作组合、旋转外推、工作空间偏移、多臂协调、推理密集任务、视频上下文学习，共 7 类物理/语义适应性实验。
- **消融研究**：
  - 前沿 VLM 选择 × 思维预算（5 个模型 × 3 档预算）。
  - 能力分解（规划 vs 细粒度抓取/放置，含坐标提示）。
  - 微调骨干缩放（Qwen/InternVL，0.8B–9B，精度/响应性/延迟权衡）。
  - Harness 插件逐一消融（9 个插件，留一法或专门场景）。
  - 动作空间表示 2×2 设计（语义名称 vs 任意符号 × 有无约定）。
- **充分性评估**：实验覆盖较全面，涵盖多种具身、任务族、环境偏移与 OOD 物体；对比基线在同一数据与硬件条件下进行控制实验，FT 与 VLA 基线共享相同示教转换轨迹，公平性较好。但真实机器人每任务仅 10 次试验，统计显著性未报告；sim-to-real 仅 20 次试验且仅 1 个任务设置。

## 6. 主要结论与发现

- **ZS 模式**在跨任务平均达 **89%**，跨环境 **100%**，跨具身 **93%**；**FT 模式**分别为 **86%**、**88%**、**87%**，全面优于 $\pi_{0.5}$（39%/40%/41%）、GR00T、H-VLA、G-VLA、CaP-X、RATS。
- **仿真到现实**：FT 仅用仿真示教即在真实 Franka 上达 13/20，而可训练 VLA 基线为 0/20。
- **物理适应性**：仅调整解释器步长（2 cm→1 cm）即可提升细粒度任务成功率（ZS 60%→82%，FT 40%→65%），无需重训；动作组合、旋转外推、工作空间偏移均表现稳健；联合双臂策略可消除碰撞。
- **语义适应性**：ZS + Situated Planning 在推理密集任务达 85%，FT 与 $\pi_{0.5}$ 仅 10%/0%；视频上下文学习 ZS 达 20/20，FT 达 95%。
- **接口设计关键**：显式动作约定（conventions）是主要接地来源，语义名称仅作为有用先验；无约定且任意符号时仅 1/20 成功，推断映射正确率 23.3%。
- **模型选择**：零样本性能大致随前沿 VLM 能力提升；增加思维预算主要减少冗余交互步而非提升成功率（GPT-5.6-sol 墙钟成本增 3.4×）；规划不是主要瓶颈，错误集中在细粒度抓取与放置。
- **微调骨干**：2B 已足够强，更大骨干主要帮助细粒度任务；1B 级模型易在目标附近过度调整导致回合过长；网球任务上小模型可优于大模型（及时纠偏比精度更重要）。

## 7. 优点

- **接口设计新颖**：语义动作单元同时满足"VLM 可自然推理"与"可直接物理落地"两个要求，避免 VLA 的语义坍缩和分层系统的物理中介问题。
- **零样本能力解锁**：前沿 VLM 无需微调即可直接控制机器人，可随前沿模型进步持续受益。
- **低成本部署路径**：小开源 VLM 仅需数 GPU 小时 LoRA 微调，在 24 GB 级 GPU 可完成，实用性强。
- **确定性接地与安全**：解释器确定性映射 + 工作空间/步长限制 + 执行前阻断违规动作，安全性可配置。
- **跨具身复用**：仅需新解释器即可适配新机器人，语义模型接口保持不变。
- **GUMI 统一人类与智能体**：无需专用遥操作硬件，支持远程采集、人—智能体协同、跨具身复用，同一示教可同时训练语义动作与连续控制策略。
- **实验设计系统**：三层泛化 + 物理/语义适应性 + 多组消融，控制变量较严谨（FT 与 VLA 基线共享相同示教轨迹）。

## 8. 不足与局限

- **具身覆盖有限**：仅在单臂/双臂平行夹爪上评估，未扩展到人形机器人或灵巧手。
- **感知模态单一**：缺乏触觉与力反馈，难以支持接触丰富、高精度物理交互。
- **sim-to-real 覆盖薄弱**：仅 1 个任务设置、20 次试验，且基线在 sim-to-real 上全部为 0，可能低估了 VLA 在更大规模仿真训练下的潜力。
- **统计充分性**：真实机器人每任务仅 10 次试验，未报告置信区间或显著性检验；OOD 物体仅 2 种。
- **对前沿 VLM API 的依赖**：ZS 模式依赖闭源模型 API，存在成本、延迟、可复现性与数据隐私问题。
- **动作空间表达力**：旋转仅支持增量式绕轴旋转，未覆盖复杂灵巧操作所需的连续位姿控制。
- **长程任务验证有限**：虽提及长程规划与恢复机制，但主实验仍以 pick-and-place 为主，复杂多阶段任务的系统性评估不足。
- **数据规模**：真实示教仅 164 个 episode（7.8K 步），相比大规模 VLA 训练数据偏小，泛化边界的结论需谨慎推广。
