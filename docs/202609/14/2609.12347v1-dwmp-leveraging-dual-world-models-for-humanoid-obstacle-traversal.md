## 摘要
人形机器人必须利用机载本体感觉和视觉观测穿越杂乱的障碍场，然而现有方法通常处理多模态观测时未明确考虑其不同特性：本体感觉观测维度低，但受高度非线性机器人动力学支配；而自我中心视觉观测维度高、噪声大且冗余。我们提出 DWMP（Dual World Model Policy，双世界模型策略），一个为人形机器人障碍物穿越的 actor 提供分离但互补的世界模型表示的框架。基于 Koopman 的动力学世界模型将本体感觉观测提升到潜在空间，使其时间演化近似线性，从而使动力学特征更易于 actor 学习。基于 RSSM 的视觉世界模型将自我中心深度观测压缩为紧凑的随机状态，同时保留与障碍物相关的几何信息。学生策略接收融合后的潜在表示以生成动作，将线性化的本体感觉动力学与压缩的视觉感知相结合。仿真和 Unitree G1 人形机器人上的实验表明，DWMP 在障碍物穿越性能上优于基线，并支持在随机障碍布局下的真实世界部署。

## Abstract
Humanoid robots must traverse cluttered obstacle fields using onboard proprioceptive and visual observations, yet existing methods usually process multimodal observations without explicitly considering their different characteristics: proprioceptive observations are low-dimensional but governed by highly nonlinear robot dynamics, while egocentric visual observations are high-dimensional, noisy, and redundant. We propose DWMP (Dual World Model Policy), a framework that provides the actor with separate but complementary world-model representations for humanoid obstacle traversal. A Koopman-based dynamics world model lifts proprioceptive observations into a latent space where their temporal evolution is approximately linear, making the dynamics features easier for the actor to learn from. An RSSM-based visual world model compresses egocentric depth observations into compact stochastic states while preserving obstacle-related geometry. The student policy receives the fused latent representation for action generation, combining linearized proprioceptive dynamics with compressed visual perception. Experiments in simulation and on a Unitree G1 humanoid robot show that DWMP improves obstacle traversal performance over baselines and supports real-world deployment under randomized obstacle layouts.

## 1. 核心问题与整体含义

- **任务背景**：人形机器人需仅依靠机载本体感觉（proprioception）与第一视角（egocentric）视觉观测，穿越杂乱障碍场并抵达目标点，同时尽量减少碰撞。
- **核心痛点**：现有多模态方法通常**未区分两类观测的本质差异**：
  - 本体感觉观测维度低，但由高度非线性的机器人动力学支配，标准 actor 网络难以直接从原始输入中学习；
  - 第一视角深度观测维度高、噪声大、冗余度高，需要压缩以剔除任务无关信息并保留障碍几何。
- **现有范式局限**：主流路线是 teacher-student 蒸馏（特权教师 + 学生模仿）。但多数工作要么只压缩视觉、把原始本体感觉直接喂给 actor，要么简单拼接多模态特征而不做预测性表征学习，导致学生策略沦为**反应式动作模仿器**，学不到描述"机器人状态与障碍布局如何演化"的结构化特征。
- **整体含义**：论文主张按模态特性**分别建模**——用 Koopman 线性化本体动力学、用 RSSM 压缩视觉——并将二者融合为学生策略的输入，从而提升障碍穿越性能与真机可部署性。

## 2. 方法论

### 2.1 问题建模
- 形式化为 POMDP 元组 $(O, A, T, R, \gamma)$。
- **观测**：$o_t = \{o^{prop}_t, o^{vis}_t\}$，其中本体感觉含关节位置/速度、机身坐标系重力向量、机身线/角速度、目标相对位置；视觉为头戴相机的第一视角深度图。
- **动作**：目标关节位置 $a_t = q^{target}_t$，由 PD 控制器以更高频率转换为力矩 $\tau_t = K_p(q^{target}_t - q_t) - K_d \dot{q}_t$。

### 2.2 Koopman 动力学世界模型
- **核心思想**：借助 Koopman 算子理论，将非线性动力学系统提升到高维可观测函数空间，在该空间中时间演化近似线性，便于网络学习与长时程预测。
- **Auto-Koopman 网络**：编码器 $\phi: S \rightarrow \mathbb{R}^{d_k}$ + 线性转移矩阵 $K \in \mathbb{R}^{d_k \times d_k}$，满足 $\phi(o^{prop}_{t+1}) \approx K\phi(o^{prop}_t)$。
- **OFTL 层**：编码器首层为观测函数转移层，对每个输入维度 $x_i$ 输出如 $[\cos(x_i), \sin(x_i), e^{x_i}]$ 的观测函数值。
- **损失**：重构损失 + 潜空间线性预测损失，即 $\mathcal{L}_{koopman} = \mathbb{E}[\|o^{prop}_t - \psi(\phi(o^{prop}_t))\|^2 + \|\phi(o^{prop}_{t+1}) - K\phi(o^{prop}_t)\|^2]$。

### 2.3 RSSM 视觉世界模型（DepthDreamer）
- **结构**：VAE 编码器（卷积层 + 双分支输出后验均值/对数方差）→ GRU 更新确定性循环状态 $z^{vis}_t$ → 先验网络（两层 MLP）→ 随机状态 $s_t$（对角高斯）→ 转置卷积解码器重构深度图 + 小 MLP 预测奖励。
- **关键公式**：循环状态更新、先验 $p(s_t|z^{vis}_t)$、后验 $q(s_t|z^{vis}_t, o^{vis}_t)$、解码 $\hat{o}^{vis}_t$、奖励预测 $\hat{r}_t$。
- **损失**：$\mathcal{L}_{rssm} = \mathbb{E}[-\ln f_{dec} - \ln f_{rew} + \beta D_{KL}(q \| p)]$，$\beta$ 控制潜信息通道容量。
- **条件化设计**：视觉模型的循环更新以 Koopman 潜状态作为动作信号，即 $z^{vis}_t = f_{rec}(z^{vis}_{t-1}, VAE(o^{vis}_t), z^{prop}_{t-1})$，实现两模型耦合。

### 2.4 策略输入与联合训练
- **融合表征**：$x^{policy}_t = [z^{prop}_t, z^{vis}_t]$，策略 $\pi_\theta$ 为 MLP，输出目标关节位置上的高斯分布参数，动作按 $a_t \sim \mathcal{N}(\mu_\theta, \sigma_\theta)$ 采样。
- **两阶段协同训练流程**（Algorithm 1）：
  - **Phase 1（教师训练 + 世界模型预训练）**：用特权信息（真值障碍位置/高度）训练教师策略，同时收集探索数据 $D_{explore}$，以 $\mathcal{L}_{world} = \mathcal{L}_{koopman} + \alpha_{vis}\mathcal{L}_{rssm}$ 联合预训练双世界模型。
  - **Phase 2（学生训练 + 世界模型微调）**：学生仅用非特权观测，经世界模型编码器得到融合表征后输出动作；交互数据存入 $D_{student}$，世界模型在该缓冲上在线更新（编码器可训练、前向传播层冻结），以适应学生自身的观测分布。
  - **学生目标**：$\mathcal{L}_{student}(\theta) = -\mathbb{E}_{\pi_\theta}[\sum \gamma^t r_t] - \lambda_{bc}\mathbb{E}_{D_{teacher}}[\log \pi_\theta(a^{teacher}_t | x^{policy}_t)]$，即奖励最大化 + 教师行为克隆。

## 9. 总体评价（补充）

总体而言，论文的核心价值在于提出了一种与多模态异质性相匹配的表征学习框架：不是把本体感觉与深度视觉简单拼接，而是分别用 Koopman 世界模型和 RSSM 世界模型建模，再以潜状态耦合形成学生策略输入。这一思路对 teacher-student 范式下“学生只模仿动作、不学习预测性表征”的问题有较强针对性，且两阶段训练流程具备较好的工程可操作性。

但当前证据更偏向“方法可行且有效”的展示，尚不足以支撑对泛化性、鲁棒性和统计显著性的强结论。若后续补充多随机种子统计与显著性检验、更全面的强基线、动态或长时程障碍场景、传感器退化实验，以及 Koopman 潜空间的物理解释与消融，论文结论会更具说服力，也更接近可复现、可推广的系统性研究。
