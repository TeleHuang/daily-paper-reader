## 摘要
近期的视频世界模型能够生成越来越逼真且可交互的视觉体验，但缺乏可靠机制来在长时间交互中维持持久的世界状态并执行可编程规则。我们提出可编程世界模型，一个将世界状态演化与视觉观测生成解耦的框架。一个智能体将自然语言指令转换为可执行程序，这些程序指定实体状态和状态转移规则，从而能够直接控制单个实体及其交互。一个轻量级引擎执行这些程序，以更新并维护显式、持久的全局世界状态，包括屏幕外实体和非视觉属性。为将世界状态与视觉生成连接起来，我们引入状态增强的3D有向包围盒（OBB）作为中间表示。该表示与目标相机轨迹一起被确定性地编译为像素对齐的时空条件信号，用于作为生成式渲染器的预训练视频模型。这种设计允许用户创建具有预定义机制、可直接控制单个实体、并在整个游戏过程中保持持久世界状态的可玩游戏。我们进一步引入CombatStateBench，一个用于评估可编程世界模型的基准。在CombatStateBench上，我们的方法达到了94%的计数准确率和98%的状态准确率，大幅优于现有交互式视频世界模型，同时支持连贯的长时程生成。这些结果证明了将显式状态演化与生成式渲染分离，对于构建持久、可编程世界的有效性。

## Abstract
Recent video world models generate increasingly realistic and interactive visual experiences, yet lack reliable mechanisms for maintaining persistent world state and enforcing programmable rules over extended interactions. We introduce Programmable World Model, a framework that decouples world-state evolution from visual observation generation. An agent translates natural-language instructions into executable programs that specify entity states and state-transition rules, enabling direct control over individual entities and their interactions. A lightweight engine executes these programs to update and maintain an explicit, persistent global world state, including off-screen entities and non-visual attributes. To connect world state with visual generation, we introduce state-augmented 3D oriented bounding boxes (OBBs) as an intermediate representation. This representation, together with the target camera trajectory, is deterministically compiled into pixel-aligned spatiotemporal conditioning signals for a pretrained video model serving as the generative renderer. This design allows users to create playable games with predefined mechanics, direct control over individual entities, and persistent world state throughout gameplay. We further introduce CombatStateBench, a benchmark for evaluating programmable world models. On CombatStateBench, our method achieves 94% Count Accuracy and 98% State Accuracy, substantially outperforming existing interactive video world models while supporting coherent long-horizon generation. These results demonstrate the effectiveness of separating explicit state evolution from generative rendering for building persistent, programmable worlds.

## 1. 核心问题与整体含义

- **研究背景**：近期视频世界模型（video world models）能生成越来越逼真、可交互的视觉体验，试图在生成式视频模型之上构建交互式世界引擎。
- **核心问题**：将视频世界模型转化为真正的交互式世界引擎，需要超出"生成合理画面"之外的能力，现有方法存在三大缺陷：
  - **实体级控制缺失**：现有控制接口主要针对相机、动作或高层提示词，难以直接寻址和操控单个实体。
  - **缺乏持久全局状态**：模型通常没有独立于当前视图、可访问与更新的显式全局状态，无法维护屏幕外实体及非视觉信息（库存、任务进度、交互历史等，对多人世界引擎尤为重要）。
  - **规则不可编程**：用户无法便捷地编程世界演化规则（如门开启条件、交互对他者的影响），提示词无法建立可一致执行的规则。
- **整体含义**：作者提出 **Programmable World Model**，将"世界状态演化"与"视觉观测生成"解耦——智能体把自然语言翻译为可执行程序，轻量引擎维护显式持久状态，生成式视频模型仅作为渲染器。核心研究问题是：**何种表示既能支持可编程世界状态演化，又能保持视觉生成所需的空间与语义结构？**

## 2. 方法论

### 2.1 核心思想

- 分离两类职责：**轻量引擎显式维护并推进权威世界状态**；**视频模型作为生成式渲染器**，在状态条件信号下合成画面。
- 采用 **状态增强的 3D 有向包围盒（OBB）** 作为中间表示，兼具显式可控性与训练–推理对齐性。

### 2.2 表示选择论证

- 作者在"表示权衡"（图 2）中分析：文本描述易写但无几何约束；2D 框/掩码受视角限制；完整 3D 场景/G-buffer 控制精细但标注成本高、推理时需解析更多自由度。
- 关键观察是 **训练–推理不对称性**：
  - 训练：已实现动态 → 结构表示（式 1）
  - 推理：状态转移 → 结构表示 → 生成动态（式 2）
- 因此选择中间粒度 OBB：只显式表示实体持久性、世界空间一致性与状态相关变化，将精细几何、铰接、形变、光照等交由生成先验完成。

### 2.3 方法流程（三阶段）

**（1）智能体编排的盒子世界（Agent-Orchestrated Box World）**

- 世界状态形式化：$s_t = (E_t, A_t, Q_t; R_t)$，其中 $E_t$ 为实体与 3D 位姿，$A_t$ 为语义/功能属性，$Q_t$ 为实体间关系，$R_t$ 为可执行世界规则。
- 初始化：用现成 3D 检测器从初始观测 $I_0$ 恢复可见实体与几何布局。
- 智能体编排器结合 3D 布局与自然语言描述 $q$，生成引擎可读的**世界程序**，指定实体初始状态、关系、支持动作、事件触发与任务目标（如战斗场景中的阵营、血量、伤害与死亡规则）。
- 引擎执行状态转移：$s_{t+1} = F(s_t, a_t)$，评估动作合法性、应用效果、解析触发事件，维护血量、库存、阵营等非视觉隐状态。

**（2）控制编译（Control Compilation）**

- 状态编译器在目标相机 $C_{t+1}$ 下投影 OBB，生成像素对齐控制：$M^{ctrl}_{t+1} = P(s_{t+1}, C_{t+1})$。
- 构造三张空间对齐控制图并通道拼接：
  - **身份图 $M^{id}$**：维护 $K$ 个可学习身份嵌入 $\{q^{id}_j\}$，按实体持久 ID 栅格化，保证跨帧实例对应，训练时每样本随机分配槽位但序列内固定。
  - **语义图 $M^{sem}$**：用预训练文本编码器生成语义嵌入 $q^{sem}_i = E_{text}(y_i)$，背景置零，深度感知栅格化处理遮挡。
  - **方向图 $M^{dir}$**：将世界空间速度旋转到目标相机坐标系，量化为 7 个状态（前/后/左/右/静止/上/下），使用可学习嵌入 $\{q^{dir}_\ell\}$，关键在于**由世界速度而非图像位移计算**，从而区分物体自身运动与相机引起的表观运动。
- 最终控制：$M^{ctrl}_{t+1} = \text{Concat}(M^{id}, M^{sem}, M^{dir})$。

**（3）生成式渲染器（Generative Renderer）**

- 基于 **LingBot-World-v1** 预训练相机控制视频生成骨干，保留其相机条件通路。
- 附加可训练的 **Structured Spatial ControlNet**，编码控制序列并将逐层特征注入主分支：$h^{(\ell)}_{main} \leftarrow h^{(\ell)}_{main} + r^{(\ell)}$。
- 训练时冻结预训练主分支与相机通路，仅优化空间控制分支。
- 渲染过程：$I_{1:T} = G_{\theta,\phi}(I_0, C, M^{ctrl}_{1:T})$。

**（4）分块自回归长时程渲染**

- 块内双向去噪，块间因果传播：$I^{(n)} = G_{\theta,\phi,\psi}(C^{(n)}, M^{ctrl,(n)}, H^{(n)}_{temp}, H^{(n)}_{spa})$。
- **时间历史**：多尺度（近期/中期/远期）潜在历史，近期更精细、远期更粗糙，训练时对历史做噪声扰动、特征损坏与部分丢弃以增强鲁棒性。
- **几何对齐空间记忆**：借鉴 AlayaWorld，将已完成 RGB 帧用深度与相机参数提升到世界空间，重投影到目标视角编码为空间 token，仅从已完成块更新以保持因果性。

### 2.4 自动训练数据流水线

- **相机参数估计**：ViPE 估计内参、位姿与度量深度。
- **语义类别发现**：Qwen3-VL 生成全局描述并识别可数类别集合。
- **实例分割与跟踪**：SAM3 产出时序关联掩码、2D 框、语义标签与持久轨迹 ID；过滤可见面积过小的掩码。
- **物体轨迹恢复**：Wild-Det3D 估计逐帧 3D OBB $b^t_i = (p^t_i, d^t_i, R^t_i, \ell_i, k_i)$，变换到共享世界坐标系形成轨迹，并在世界系中计算位移以去除相机运动影响。
- **条件图生成**：将 OBB 投影栅格化为身份/语义/方向图，z-buffer 处理遮挡。

## 6. 主要结论与发现

- **状态一致性大幅领先**：Count Accuracy 达 **94.00%**，超 LingBot-World-V2 **53.25** 个百分点、超 YUME **62.00** 个百分点；State Accuracy 达 **98.00%**，超 LingBot-World-V2 **90.00** 个百分点、超 YUME **40.00** 个百分点。
- **视频质量全面最优**：四项 VBench 指标均为最佳（Imaging 67.62、Subject 94.74、Background 96.98、Temporal 99.00）。
- **长时程与泛化能力**：支持 897 帧自回归生成；能在大角度相机旋转后正确渲染初始视野外的实体；泛化到新角色外观、赛车场景、人车混合类别。
- **核心论点验证**：将显式状态演化与生成式渲染分离，比依赖生成模型隐式状态表示更可靠；世界状态可执行、可验证，外观保持生成式。

## 7. 优点

- **问题分解清晰**：将"世界状态"与"视觉渲染"解耦，把权威状态交给可验证的轻量引擎，避免了状态预测误差随长时程累积的问题。
- **表示设计巧妙**：状态增强 3D OBB 在可控性、标注成本与训练–推理对齐之间取得平衡；方向图由世界速度而非图像位移计算，有效解决相机–物体运动歧义。
- **确定性接口**：状态编译器通过显式投影与栅格化建立实体到像素的确定对应，而非依赖学习的场景 token 映射。
- **长时程机制完整**：多尺度时间历史 + 几何对齐空间记忆，兼顾近期细节与全局持久性。
- **数据流水线实用**：自动从无标注视频恢复相机、语义、实例轨迹与 3D OBB，为规模化训练提供路径。
- **基准贡献**：CombatStateBench 带同步状态与控制标注及自动一致性验证，填补可编程世界模型评估空白。
- **公平评估设计**：VLM 评判不接触特权信息，指标宽松但客观。
