## 摘要
可泛化的机器人操作需要预测场景将如何演化、识别在何处交互可行，并确定如何行动。带动作标注的机器人视频可直接监督控制，但成本高昂且多样性有限；而第一人称人类视频能捕获多样交互，却缺乏机器人动作，并存在具身与外观差异。我们提出 AffordanceWAM，一种可供性感知的生成式世界动作模型，在生成的未来世界中通过标量可供性和可供性热图表示以物体为中心的时空可供性。该表示将视觉预测锚定于任务相关物体和交互区域以用于动作生成，并为人类视频与机器人视频提供共享的交互目标。AffordanceWAM 基于预训练视频扩散 Transformer，使用分别参数化的世界专家和动作专家，并通过掩码联合自注意力耦合，在统一的流匹配目标下联合预测未来 RGB 观测、标量可供性场、可供性热图和连续机器人动作。人类视频监督所有三个未来世界流，而机器人轨迹额外提供动作监督，从而无需人类动作标签或重定向即可实现迁移。在 RoboCasa、CALVIN ABC→D 以及真实世界操作上的实验表明，相较于仅 RGB 和仅机器人数据的基线，性能持续提升。在固定机器人监督下，随着带可供性标注的人类视频规模增大，RoboCasa 性能单调提升。这些结果支持将可供性作为视觉-语言-动作学习和人类到机器人迁移的有效接口。

## Abstract
Generalizable robot manipulation requires predicting how a scene will evolve, identifying where interactions are feasible, and determining how to act. Action-labeled robot videos directly supervise control but are costly and limited in diversity, whereas egocentric human videos capture diverse interactions but lack robot actions and differ in embodiment and appearance. We introduce AffordanceWAM, an affordance-aware generative World Action Model that represents object-centric spatiotemporal affordance through Scalar Affordance and Affordance Heatmap, within the generated future World. This representation grounds visual prediction in task-relevant objects and interaction regions for action generation, and provides shared interaction targets across human and robot videos. Built on a pretrained video diffusion Transformer, AffordanceWAM uses separately parameterized World and Action Experts, coupled through Masked Joint Self-Attention, to jointly predict future RGB observations, Scalar Affordance fields, Affordance Heatmaps, and continuous robot actions under a unified flow-matching objective. Human videos supervise all three future-World streams, whereas robot trajectories additionally provide action supervision, enabling transfer without human action labels or retargeting. Experiments on RoboCasa, CALVIN ABC$\rightarrow$D, and real-world manipulation demonstrate consistent gains over RGB-only and robot-data-only baselines. Under fixed robot supervision, RoboCasa performance improves monotonically as affordance-annotated human video scales. These results support affordance as an effective interface for both vision-language-action learning and human-to-robot transfer.

  - 现有 World Action Models 多预测 RGB 或视觉 latent，偏重外观、背景和视角变化，交互结构仍隐式，难以作为跨具身迁移接口。
- **核心问题**：在 WAM 联合训练中，什么样的“未来世界表示”能有效连接人类视频与机器人控制，并让无动作标签的人类视频真正提升机器人策略？
- **整体含义**：论文提出以“可供性”作为跨具身共享交互接口：语言指定任务意图，可供性将意图锚定到物体和可交互区域，动作专家再基于该表示生成控制。其目标是减少对人类动作标签、动作重定向和跨具身动作对齐的依赖。

## 2. 方法论
- **核心思想**：构建 AffordanceWAM，一个可供性感知的生成式 World Action Model。未来世界不只包含 RGB，还包含两类可供性：
  - **Scalar Affordance**：逐帧标量场 \(F_t \in [0,1]^{H\times W}\)，表示任务相关物体和可交互区域。
  - **Affordance Heatmap**：将标量场渲染回 RGB 空间，关联交互区域与视觉上下文。
- **未来世界与动作联合建模**：
  - 输入：RGB 历史 \(I^-\)、语言指令 \(\ell\)、本体状态 \(s\)。
  - 输出：未来 RGB \(I^+\)、标量可供性 \(F^+\)、可供性热图 \(M^+\)、连续动作块 \(U_0\)。
  - 目标建模为 \(p_\theta(W^+, U_0 \mid I^-, \ell, s)\)，其中 \(W^+=(I^+,F^+,M^+)\)。
- **双专家架构**：
  - **World Expert**：基于预训练视频扩散 Transformer，联合预测未来 RGB、Scalar Affordance、Affordance Heatmap。
  - **Action Expert**：独立参数，从 World 各层的 RGB 和 Scalar Affordance 隐藏特征中读取信息，生成连续动作。
  - 两者层数相同但隐藏维度不同，通过 **Masked Joint Self-Attention** 在对应层耦合。
- **Masked Joint Self-Attention 的关键设计**：
  - RGB 与 Scalar Affordance token 可相互注意。
  - Affordance Heatmap token 可注意 RGB、Scalar Affordance 和自身。
  - Action token 可注意 RGB、Scalar Affordance 和自身。
  - **阻断 Action → World 的信息流**，避免动作影响世界预测。
  - **阻断 Affordance Heatmap → Action 的注意力路径**，减少额外 RGB 捷径，鼓励动作专家更多使用 Scalar Affordance。
- **流匹配目标**：
  - 对干净目标 \(y_0\) 与噪声 \(\epsilon\) 做线性插值 \(y_\tau=(1-\tau)y_0+\tau\epsilon\)，目标速度为 \(u=\epsilon-y_0\)。
  - 对 RGB、Scalar Affordance、Heatmap、动作分别建立速度预测损失，统一为流匹配 MSE。
  - Scalar Affordance 编解码器还受帧级重构 MSE 监督，以保留空间可供性信息。
- **训练策略**：
  - **Stage I 异构联合预训练**：
    - 人类视频只更新 World Expert，监督三个未来世界流，不构造伪动作。
    - 机器人轨迹同时更新 World 和 Action Expert，额外监督动作。
    - 先 World-only warmup，再逐步引入动作监督；混合“噪声 World 联合训练”和“固定 World 训练”。
  - **Stage II 任务特定后训练**：
    - 冻结完整 World 模型，只优化 Action Expert。
    - 使用无可供性标注的机器人 VLA 演示适配目标任务。
    - 保留噪声 World 与完成预测 World 两类条件，但梯度在 World 接口处停止。
- **推理流程**：
  - 从独立高斯噪声初始化未来 RGB、Scalar Affordance、Heatmap 和动作 latent。
  - 两个专家联合生成，逐层交换特征；历史 RGB latent 每步重新 clamp。
  - 联合生成后固定预测 World，进行短程 Action-only 去噪细化。
  - 主要设置：35 步 World + 35 步 Action 联合生成，再做 8 步 Action refinement，强度 0.25。

## 3. 实验设计
- **仿真数据集/场景**：
  - **RoboCasa**：多样化家庭操作任务；下游适配每任务 300 条演示。
  - **CALVIN ABC → D**：在 A、B、C 环境训练，在未见 D 环境测试，评估长时程跨环境泛化。
- **真实世界场景**：
  - 5 个基础语言条件任务：水果放盘子、杯子套入、物体选择、工具/物体放置等，涉及类别、颜色、形状选择。
  - 3 个复杂任务：Close the Drawer、Pick All the Fruit、Arrange the Flower。
  - 每个任务 50 条微调轨迹，15 次试验。
- **对比方法**：
  - RoboCasa：GR00T-N1、UVA、UWM、π0、GR00T-N1.5、Cosmos Policy。
  - CALVIN：SuSIE、GR-1、OpenVLA、CLOVER、UniVLA、π0、Seer、VPP。
  - 真实世界：主要与 Cosmos Policy 在同等 50 条轨迹微调预算下比较。
- **评估指标**：
  - RoboCasa：平均任务成功率。
  - CALVIN：完成 1–5 个连续任务的成功率及平均序列长度。
  - 真实世界：各任务成功率、宏平均成功率、复杂任务阶段成功率。
- **消融实验**：
  - 可供性作为 V-L-A 接口：有无可供性、有无人类视频。
  - 2×2 factorial：人类视频 × 可供性监督，检验人类视频收益是否依赖可供性表示。
  - Scalar Affordance 与 Heatmap 的互补作用。
  - 人类数据规模 scaling：0%、20%、40%、60%、80%、100%。
  - 架构消融：Masked Joint Self-Attention、Late fusion、Independent World→Action、Open Heatmap→Action、无预测 World 后训练、无 Heatmap 流。
  - 定性失败模式分析：空间漂移、RGB-copy collapse、错误物体定位、长时程退化等。
