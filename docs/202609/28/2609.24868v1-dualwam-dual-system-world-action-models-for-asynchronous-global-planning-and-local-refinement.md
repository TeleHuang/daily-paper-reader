## 摘要
世界动作模型（World Action Models, WAMs）能够联合生成机器人动作并预测未来世界状态，从而将视频预训练中的先验迁移到机器人控制中。然而，未来视觉预测的计算开销很高，因此现有 WAM 往往依赖长动作块来摊薄跨控制步的推理成本，代价是闭环响应能力下降。我们提出 DualWAM，一种双系统 WAM，通过解耦全局规划与局部细化，在保留更广时域的世界-动作生成的同时，实现高频闭环动作更新。System 2 周期性地在更广的世界-动作块上进行高噪声双向去噪，以建立全局规划；而仅使用腕部观测的 System 1 从中间去噪状态中提取时间对齐的短窗口，并利用最新的腕部观测完成低噪声细化，这些观测在交互过程中提供与动作对齐的局部几何、运动和接触线索。两个系统沿着共享的去噪轨迹异步运行：每个全局规划被多个局部更新复用，而 System 1 则反复融入新的交互反馈。在 Franka 和 Galbot 上的零样本操作任务中，DualWAM 相比最强的评估基线平均成功率提升 4.5 个百分点，同时实现 16.6 倍的关键路径加速。进一步研究表明，角色匹配的自我中心数据和 UMI 数据可将成功率提升 14 个百分点，并且这种解耦设计天然支持边缘-云部署，其通信开销显著低于基线。

## Abstract
World Action Models (WAMs) jointly generate robot actions and predict future world states, transferring priors from video pretraining to robot control. However, future visual prediction is computationally expensive, so existing WAMs often rely on long action chunks to amortize inference cost across control steps, at the cost of closed-loop responsiveness. We present \method, a dual-system WAM that preserves broader-horizon world-action generation while enabling high-frequency closed-loop action updates by decoupling global planning and local refinement. \systwo periodically performs high-noise bidirectional denoising over a broader world-action chunk to establish a global plan, while wrist-only \sysone extracts a temporally aligned short window from the intermediate denoising state and completes low-noise refinement using the latest wrist observations, which provide action-aligned cues about local geometry, motion, and contact during interaction. The two systems operate asynchronously along a shared denoising trajectory: each global plan is reused across multiple local updates, while \sysone repeatedly incorporates fresh interaction feedback. Across zero-shot manipulation tasks on Franka and Galbot, \method improves success over the strongest evaluated baseline by 4.5 percentage points on average, while achieving a 16.6$\times$ critical-path speedup. Further studies show that role-matched egocentric and UMI data improve success by 14 percentage points, and that the decoupled design naturally supports edge--cloud deployment with substantially lower communication overhead than the baseline.

## 1. 核心问题与整体含义

- **研究背景**：世界动作模型（World Action Models, WAMs）联合生成机器人动作并预测未来世界状态，可将视频预训练中的语义与物理先验迁移到机器人控制中，并展现出一定的零样本泛化能力。
- **核心矛盾**：未来视觉预测计算开销极高，现有 WAM 往往依赖**长动作块**来摊薄跨控制步的推理成本，但这会降低闭环响应能力——模型更新之间执行的动作越长，新的交互反馈越难影响后续动作。
- **缩短动作块的代价**：需要更频繁的世界-动作生成，并鼓励短视的下一块预测，容易偏向局部外观捷径而非更广时域的动态结构。
- **现有缓解手段的不足**：减少、压缩或异步解码未来预测等方法，未能在一个共享的世界-动作生成过程中，联合特化**去噪阶段、视觉上下文与更新频率**。
- **整体含义**：DualWAM 提出将世界-动作生成分解为**全局规划**与**局部细化**两个互补阶段，在保留广时域世界-动作生成的同时，实现高频闭环动作更新，缓解“高效全局预测”与“响应式闭环控制”之间的张力。

## 2. 方法论

### 2.1 核心思想

- 将**一条共享的世界-动作去噪轨迹**按噪声区间和语义角色切分给两个 WAM：
  - **System 2（全局规划）**：低频率、高噪声、双向去噪、多视角观测，负责建立全局轨迹结构。
  - **System 1（局部细化）**：高频率、低噪声、因果去噪、仅腕部观测，负责短窗口局部修正。
- 两个系统**异步运行**：每个 System 2 更新被多个局部控制更新复用；System 1 每次更新都融入最新腕部交互反馈。
- 关键区别：不是简单级联或独立双去噪链，而是沿**统一 rectified-flow 噪声坐标**对同一条轨迹分区。

### 2.2 问题形式化与公式

- 干净全局世界-动作目标：`X0 = [Zg0, Zw0, A0]`，其中 `Zg0`、`Zw0` 为未来全局视角与腕部视角视频潜变量，`A0` 为时间对齐动作序列。
- 加噪状态：`Xσ = (1 − σ)X0 + σϵ`，`ϵ ∼ N(0, I)`，`σ ∈ [0,1]`。
- 目标 rectified-flow 速度：`V = ϵ − X0`。
- 推理时选定交接噪声水平 `τ`：System 2 从 `σ=1` 去噪到 `τ`，System 1 从 `τ` 继续到 `0`。
- 第 `k` 个执行窗口的交接：`U_kτ = C_sk(Xτ; H1) = [Zw,k_τ, A k_τ]`，`C_sk` 按执行进度选择时间对齐的腕部潜变量与动作窗口。
- 训练目标：
  - `Li = E[ Σ_{m∈Mi} λ_m^(i) || V_m^(i) − V̂_m^(i)(S_σ^(i), σ, c_i) ||² ]`
  - System 2：`I2 = [τ_train, 1]`，`M2 = {g, w, a}`。
  - System 1：`I1 = (0, τ_train]`，`M1 = {w, a}`。
  - `τ_train = 0.7`，System 1 学习整个低噪声区间，推理交接 `τ` 可在该范围内选择。

### 2.3 关键技术细节

- **System 2（全局规划）**：
  - 处理完整多视角世界-动作状态，视频帧视野 `H2 = 32`。
  - 高噪声下变量尚未确定，双向注意力允许全预测时域变量互相约束，形成整体运动计划。
  - 输出部分去噪轨迹 `Xτ`，是粗略但连贯的联合假设，不直接解码为最终可执行动作。
- **System 1（短时域局部细化）**：
  - 紧凑、腕部中心的 WAM，局部视野 `H1 = 8` 帧。
  - 每个局部更新结合时间对齐窗口、最新腕部观测与机器人状态，完成低噪声细化。
  - 腕部相机刚性附着于末端执行器，其视频运动提供**动作对齐的视觉轨迹**，并揭示近距离几何、遮挡与接触线索。
  - 窗口内使用**因果时间注意力**（每个位置只关注当前及之前位置），同时保留窗口内并行去噪。
- **训练增强**：随机平移 System 1 的腕部-动作输入，偏移概率随执行进度增加，模拟 System 2 预测与真实执行状态错位，提升异步执行鲁棒性。
- **异步闭环执行**：
  - System 2 在后台更新部分去噪全局轨迹，System 1 立即用最新有效状态细化局部动作。
  - 跳过执行窗口已过期的动作块的低噪声细化，保证去噪动作与实际执行时间戳对应。
- **实时优化**：
  - 三 GPU CFG 并行（条件/无条件分支分置两卡）。
  - cuDNN 矩阵乘、注意力与激活融合、CUDA Graph 编译、W8A8 量化（Edge decoder 数值稳定投影层，精度敏感层保留 BF16）。
  - 共享轨迹去噪与 Edge 时间步采样：在线 System 1 去噪前向从 4 次降到 1 次，端到端 2.27× 加速。
- **部署设置**：全局视野 `H2=32`，局部视野 `H1=8`，System 2 刷新间隔 32 控制帧，训练低噪声上界 `τ_train=0.7`。
