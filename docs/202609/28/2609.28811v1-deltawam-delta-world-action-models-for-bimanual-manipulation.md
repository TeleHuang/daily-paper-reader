## 摘要
世界动作模型（WAM）通过联合建模视觉动态与动作，将预训练视频生成器中的视觉与运动先验迁移到机器人控制中。然而，现有 WAM 在训练期间预测密集未来帧，反复建模基本不变的内容，并将动作条件动态与无关的外观变化耦合。在推理时，使用沉重的视频专家处理每个完整观测，会成为少步动作生成的瓶颈。因此，我们提出 DeltaWAM，使用密集锚点、稀疏增量和动作流联合预测视觉增量与动作，并包含三种在表示与计算共享方面不同的架构。我们进一步提出流式 Delta 记忆（SDM），用紧凑的观测增量更新缓存的锚点上下文，从而减少繁重的视频专家处理。在 RoboTwin 上，配备 SDM 的 DeltaWAM 将平均成功率较 Fast-WAM 在干净设置下从 81.3% 提升至 85.4%，在视觉随机化下从 75.8% 提升至 83.9%。三种架构将训练 FLOPs 降低 17.78–23.77%，而 SDM 将单步推理延迟和 FLOPs 分别降低 36.57% 和 31.55%；真实世界评估进一步表明，在所评估的策略中，其总体成功率和归一化进度最高。代码：https://github.com/AIGeeksGroup/DeltaWAM。网站：https://aigeeksgroup.github.io/DeltaWAM。

## Abstract
World-action models (WAMs) transfer visual and motion priors from pretrained video generators to robot control by jointly modeling visual dynamics and actions. Existing WAMs, however, predict dense future frames during training, repeatedly modeling largely unchanged content and coupling action-conditioned dynamics to nuisance appearance variations. At inference, processing each complete observation with the heavy video expert bottlenecks few-step action generation. Accordingly, we propose DeltaWAM, which jointly predicts visual deltas and actions using dense-anchor, sparse-delta, and action streams, with three architectures that differ in representation and computation sharing. We further develop Streaming Delta Memory (SDM), which updates cached anchor context with compact observed deltas, reducing heavy video-expert processing. On RoboTwin, DeltaWAM with SDM improves average success over Fast-WAM from 81.3% to 85.4% in the clean setting and from 75.8% to 83.9% under visual randomization. The three architectures reduce training FLOPs by 17.78-23.77%, while SDM reduces one-step inference latency and FLOPs by 36.57% and 31.55%, respectively; real-world evaluations further show the highest overall success rate and normalized progress among the evaluated policies. Code: https://github.com/AIGeeksGroup/DeltaWAM. Website: https://aigeeksgroup.github.io/DeltaWAM.

## 一、核心问题与整体含义（研究动机与背景）

- **背景**：世界动作模型（World-Action Models, WAMs）通过联合建模视觉动态与机器人动作，把预训练视频生成模型中的视觉与运动先验迁移到机器人控制中。此类方法对涉及复杂物体交互、接触状态变化的操作任务尤其有价值。
- **核心问题一：训练阶段稠密未来帧建模冗余且易受干扰**。现有 WAM 通常预测完整未来帧，但相邻操作观测高度冗余：背景、工作空间几何和大部分物体内容基本不变，真正与动作相关的改变往往是稀疏、局部、围绕夹爪和被操作物体的。稠密预测会重复建模静态内容，并把动作条件动态与光照、纹理、背景等“ nuisance appearance variation”耦合，损害视觉随机化下的鲁棒性。
- **核心问题二：推理阶段重型视频专家成为瓶颈**。以 Fast-WAM 为代表的 action-only WAM 虽不在推理时显式生成未来视频，但每个控制周期仍需把完整当前观测送入重型视频 DiT，构造逐层 KV 上下文供动作去噪。随着动作去噪步数减少，Action DiT 变便宜，但固定视觉上下文计算仍占主导，成为少步动作生成的推理瓶颈。
- **整体含义**：论文主张对视觉信息进行“选择性处理”：用**稠密锚点**保留场景语义，用**稀疏视觉增量**描述场景变化，并让同一增量表示在推理时作为视觉上下文的增量更新。由此提出 **DeltaWAM**，一种 delta-native 的世界动作模型，在保持操作性能的同时提升视觉鲁棒性并降低训练与推理开销。

## 二、方法论：核心思想、关键技术与算法流程

### 1. 核心思想：三流分解

- DeltaWAM 将世界动作建模分解为三个 token 流：
  - **稠密锚点流（dense anchor stream）**：编码参考观测，保留完整场景语义、物体身份、空间关系。
  - **稀疏增量流（sparse delta stream）**：表示相邻观测之间的视觉转变，每个 transition 仅用一个 delta token 表示。
  - **动作流（action stream）**：预测可执行的动作 chunk。
- 关键点：不再反复重建静态内容，而是把世界建模容量集中在“场景如何变化”上；同一 delta 表示既用于未来视觉转变监督，也用于推理时对观测历史的流式记忆更新。

### 2. Delta 表示

- 使用 delta encoder 将相邻观测压缩为增量 token：
  - \(d_t = E_\Delta(o_t, o_{t+1}) \in \mathbb{R}^{N_\Delta \times d_\Delta}\)
  - 论文中 \(N_\Delta = 1\)，即每次帧间转变仅一个 token，远少于锚点观测的稠密空间 token 网格。
- 一条视觉轨迹由锚点观测和成对 delta 序列表示：
  - \(D_{t:t+H-1} = [d_t, d_{t+1}, \ldots, d_{t+H-1}]\)

### 3. 模型架构与三种变体

- **初始化**：
  - Anchor Network 从预训练视频生成 backbone 初始化，具体为 Wan2.2-TI2V-5B。
  - Delta DiT、Action DiT、共享 DA-DiT 由预训练视频 DiT 权重插值初始化，参考 Fast-WAM。
  - 冻结 delta encoder、视频 VAE 和文本编码器；Anchor backbone 通过 LoRA 适配。
  - 语言指令与当前本体感知状态构成三流共享条件上下文。
- **信息流控制**：使用结构化 attention mask，强制从 anchor 到预测流的单向条件，避免预测流信息回漏。
- **三种架构变体**：
  - **Anchor-Shared**：anchor 与 delta 流共享视觉 backbone，Action DiT 通过逐层联合注意力与之交互。delta 预测可直接继承预训练视频 backbone 的视觉表示与运动先验。
  - **Separated**：独立的 Delta DiT 和 Action DiT，均以同一 anchor 为条件。
  - **Action-Shared**：delta 与 action token 映射到共同 backbone，保留模态特定输入/输出头；引入 **Dual-Stream Residual Experts (DRE)** 保留流私有结构。
- **DRE 公式**：
  - 对每个流 \(m \in \{\Delta, a\}\)，共享块输出 \(\bar{H}^\ell_m\)，再经流特定轻量更新：
    \[
    H^{\ell+1}_m = \bar{H}^\ell_m + U^\ell_m \phi(D^\ell_m \bar{H}^\ell_m)
    \]
    其中 \(\phi\) 为 GELU，\(D^\ell_m\) 降维投影，\(U^\ell_m\) 升维投影。
  - 作用：共享 DA-DiT backbone 促进视觉转变与动作之间的跨任务知识迁移，残差专家提供流私有容量，减少两个预测目标间的干扰。

### 4. 联合 Delta-Action 训练目标

- 使用联合 delta–action flow matching。独立采样高斯噪声 \(\epsilon_\Delta, \epsilon_a\) 和 flow times \(\tau_\Delta, \tau_a \in [0,1]\)，构造噪声插值：
  - \(D_{\tau_\Delta} = (1-\tau_\Delta)D_t + \tau_\Delta \epsilon_\Delta\)
  - \(A_{\tau_a} = (1-\tau_a)A_t + \tau_a \epsilon_a\)
- 在共享多模态上下文 \(C_t\) 下，delta 分支和 action 分支分别优化速度预测目标：
  - \(L_\Delta = \mathbb{E}[\|v^\Delta_\theta(D_{\tau_\Delta}, \tau_\Delta; C_t) - (\epsilon_\Delta - D_t)\|_2^2]\)
  - \(L_a =

\[
L_a = \mathbb{E}\Big[\big\|v^a_\theta(A_{\tau_a}, \tau_a; C_t) - (\epsilon_a - A_t)\big\|_2^2\Big]
\]
- 总目标为两项加权和：
  \[
  L = L_\Delta + \lambda_a L_a
  \]
  其中 \(\lambda_a\) 平衡视觉转变预测与动作预测的梯度尺度，避免稠密视觉目标压过动作学习信号。
- 关键设计：两个分支共享同一多模态上下文 \(C_t\)（由语言指令、本体感知状态与锚点视觉特征构成），但在噪声采样与流时间上相互独立，从而允许 delta 分支在更“干净”或更“嘈杂”的插值点上提供稳定的视觉转变表征，供 action 分支去噪时作为条件。

### 5. 推理机制：delta 作为流式记忆更新

- **训练-推理解耦**：训练时显式监督 \(d_t\) 逼近 \(o_{t+1}-o_t\) 的视觉转变；推理时不要求生成未来帧，而是复用 delta 分支的输出作为“视觉上下文的增量更新”。
- **增量上下文维护**：维护一个锚点视觉上下文缓存（来自当前参考观测的稠密 token），每个新观测到来时，仅需计算一个新的 delta token 并写入缓存，替代对整个观测重新做重型编码。
  - 该过程将原本“每周期一次完整视频 DiT 前向”的开销，替换为“一次轻量 delta 编码 + 上下文更新”。
- **对少步动作生成的意义**：当 Action DiT 的去噪步数被压缩到很少时，固定视觉上下文计算成为主要瓶颈；增量更新使视觉侧成本随控制周期近似常数且远低于完整前向，从而释放少步动作生成的实时潜力。
- **与 Fast-WAM 类方法的对比**：Fast-WAM 仍需在每个控制周期把完整当前观测送入重型视频 DiT 构造逐层 KV；DeltaWAM 则以 delta 增量刷新缓存，避免重复编码静态场景内容。

### 6. 算法流程（概念性）

1. 采集轨迹 \(\{(o_t, a_t)\}\)，构造锚点观测与相邻帧对 \((o_t, o_{t+1})\)。
2. 用冻结 delta encoder 抽取增量 token \(d_t\)；用视频 VAE 编码锚点观测得到稠密锚点 token。
3. 拼接语言指令与本体感知状态为共享条件 \(C_t\)。
4. 在结构化 attention mask 下，分别对 delta 流与动作流施加 flow matching 噪声，前向三流网络，计算 \(L_\Delta\) 与 \(L_a\)。
5. 反向传播更新 Anchor（LoRA）、Delta/Action DiT（或共享 DA-DiT）参数。
6. 推理时按控制周期增量更新视觉上下文，仅对动作分支做少步去噪，输出动作 chunk。

## 三、实验设计与主要发现（基于论文论述）

### 1. 实验维度

- **操作性能**：在典型机器人操作基准上评估动作成功率，验证 delta 建模不损失控制能力。
- **视觉鲁棒性**：引入视觉随机化（光照、纹理、背景、干扰物等），考察模型对 nuisance appearance variation 的抵抗能力，检验“解耦动作相关变化与外观扰动”的假设。
- **效率**：比较训练与推理开销，重点关注推理时每控制周期的视觉侧成本与端到端延迟。
- **消融**：
  - 三种架构变体（Anchor-Shared / Separated / Action-Shared）对比；
  - DRE 组件的增益；
  - delta token 数量 \(N_\Delta\) 的影响（论文设 \(N_\Delta=1\)）；
  - 是否使用 delta 增量更新 vs. 完整观测重编码。

### 2. 主要结论（论文主张）

- **稀疏增量足以支撑控制**：单个 delta token 即可承载动作相关的视觉转变信息，稠密未来帧重建并非必要。
- **鲁棒性提升**：将动作条件动态与静态外观解耦后，模型在视觉随机化下表现更稳定。
- **效率提升**：增量式视觉上下文更新显著降低推理瓶颈，配合少步动作生成更接近实时控制需求。
- **架构选择权衡**：共享 backbone 有利于视觉-动作跨任务迁移，但需 DRE 之类的流私有容量来抑制目标干扰；分离式架构则更简单但迁移性可能较弱。

## 四、方法贡献与创新点

- **问题重构**：把世界动作模型从“稠密未来帧预测”重构为“锚点 + 稀疏增量”的选择性视觉建模，直指冗余与鲁棒性两大痛点。
- **统一表示**：同一 delta 表示在训练中作为视觉转变监督目标，在推理中作为视觉上下文的增量更新载体，实现训练-推理一致性。
- **架构与训练**：提出三流分解、结构化 attention mask、DRE 残差专家与联合 delta–action flow matching 目标，兼顾跨任务迁移与流间解耦。
- **效率导向**：明确针对 action-only WAM 的推理瓶颈，给出增量上下文更新的解决路径。

## 五、局限与可讨论点

- **单 token 表达力边界**：\(N_\Delta=1\) 在快速、大幅场景变化或强交互场景下是否足够，需进一步验证；过强压缩可能损失细粒度转变信息。
- **增量误差累积**：推理时上下文依赖连续 delta 更新，若某步 delta 不准确，误差可能在长时程任务中累积。
- **对 delta encoder 的依赖**：encoder 冻结，其表征质量直接决定增量 token 的信息保真度，可能限制上限。
- **泛化与基准覆盖**：鲁棒性与效率优势在不同机器人平台、不同任务分布上的普适性仍需更广泛验证。
- **与生成式世界模型的取舍**：放弃显式未来帧生成可能牺牲可解释性与部分下游用途（如可视化规划），换取效率与鲁棒性。

## 六、整体评价

DeltaWAM 的核心洞见在于：机器人操作中真正与动作相关的视觉变化是稀疏且局部的，因此世界动作模型不必承担稠密视频生成的全部负担。通过“稠密锚点 + 稀疏增量 + 动作流”的三流分解，以及 delta 表示在训练与推理间的统一复用，论文同时回应了训练冗余、视觉鲁棒性与推理效率三个问题。其价值不仅在于具体架构，更在于为 WAM 提供了一种“选择性视觉处理”的设计范式：以最小必要的视觉信息维持场景记忆，把建模容量集中于动作相关的转变。若后续工作能在更长时程、更强动态场景与真实机器人上验证增量误差可控性与泛化性，该范式有望成为高效世界动作模型的重要方向。
