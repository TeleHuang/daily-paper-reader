## 摘要
机器人操作基础模型需要在多样场景中进行可扩展的评估和数据生成，而仿真为两者提供了环境。自动化场景生成提供了一条有前景的路径，然而先前的工作主要强调粗粒度的场景布局，而非细粒度的功能性物体组合。受这一差距的启发，我们提出了GIF，一个用于交互式与功能性物体组合的智能体生成框架。在该框架中，我们将这一问题重新定义为解耦重建后接相对位姿恢复。CoGen利用2D和3D生成模型的互补优势，生成具有粗初始位姿的实例解耦网格。GPRM在联合几何与物理指导下优化相对位姿，并由VLM验证器选择最符合结构化规范的最佳候选。我们进一步构建了一个涵盖八类代表性接触几何类别的基准，并与最先进的生成器进行比较；GIF在提升资产质量和关系匹配的同时，将碰撞率降至1%以下。最后，我们合成了用于策略学习的数据，揭示了在仿真和真实世界部署中的多样性扩展效应。

## Abstract
Robot manipulation foundation models require scalable evaluation and data generation across diverse scenarios, with simulation providing an environment for both. Automated scene generation offers a promising path, yet prior work has largely emphasized coarse-grained scene layouts rather than fine-grained functional object compositions. Motivated by this gap, we present GIF, an agentic Generation framework for Interactive and Functional object compositions. In this framework, we recast this problem as disentangled reconstruction followed by relative pose recovery. CoGen produces instance-disentangled meshes with coarse initial poses leveraging complementary strengths of 2D and 3D generative models. GPRM refines the relative pose under joint geometric and physical guidance, and a VLM verifier selects the candidate that best matches the structured specification. We further construct a benchmark spanning eight representative contact-geometry classes and compare with state-of-the-art generators; GIF improves both asset quality and relation matching, while reducing collision rate to below 1%. Finally, we synthesize data for policy learning, revealing diversity scaling in both simulation and real-world deployment.

## 1. 核心问题与整体含义

- **研究动机**：机器人操作基础模型（如 VLA）需要大规模、多样化的仿真场景来支撑训练与评估。虽然已有不少自动化场景生成工作，但它们大多停留在**粗粒度的场景布局**（如房间、桌面物体摆放），无法生成机器人操作真正需要的**细粒度功能性物体组合**。
- **核心问题**：如何从语言或图像指令出发，生成“可独立交互的物体对 + 精确的相对位姿”，满足功能接触（如“盖子盖在锅上”“杯子挂在杯架上”）的同时，保证无穿透、在仿真中稳定，并能直接用于下游机器人策略学习。
- **整体含义**：将场景生成问题重新定义为“**解耦重建 + 相对位姿恢复**”，并通过智能体式流程整合 2D/3D 生成模型、几何与物理优化、VLM 验证，使自动生成的物体组合达到**接触级精度**，从而为机器人操作学习提供可扩展的数据来源。

## 2. 方法论

### 2.1 总体框架

GIF 是一个多模块智能体流水线，输入为语言指令或参考图，输出为仿真就绪的刚性物体网格与位姿：

- 多模态输入规范化；  
- CoGen：互补式 2D-3D 资产生成；  
- GPRM：几何与物理引导的位姿精化；  
- VLM 验证与候选筛选；  
- 最终场景用于策略数据合成和 VLA 训练。

### 2.2 多模态输入规范化

- 多模态 agent 将任意输入（纯文本、参考图、物体资产图）化为统一规范：(I_ref , J_scene)。
- I_ref 是仅包含前景物体对的参考图，J_scene 是结构化 JSON，描述物体身份、属性、关系。
- 采用“分析—行动—验证”循环：需要时先调用图像生成/编辑工具产出 I_ref，再由 VLM 验证是否满足要求，不通过则编辑或重绘。

### 2.3 CoGen：互补式 2D-3D 资产构建

- **直接重建分支**：基于 I_ref 和每个物体的实例 mask，用图像到 3D 模型（SAM3D）直接重建，得到 m_ref、p_ref。
- **擦除—再生成分支**：用 2D 图像编辑模型把遮挡的“伙伴物体”擦除，再补全目标物体，得到无遮挡的 I_erase，再经 SAM3D 得到 m_erase、p_erase。
- 该分支解决接触处互相遮挡造成的“实例融合”“几何泄漏”和“隐藏面幻觉”问题。
- 两个分支会给出两组候选“网格+位姿”，后续 GPRM 在四种交叉组合上精化。

### 2.4 GPRM：几何与物理引导的位姿精化

对每对候选，依次使用多级优化：

1. **粗到细 ICP**：用单目深度估计和实例 mask 得到目标点云，与候选网格逐步配准。
2. **RenderOpt（可微渲染优化）**：用 nvdiffrast 渲染网格，比较渲染轮廓/深度与参考图，优化位姿和尺度；包含 recall/precision、自深度、遮挡顺序等损失。
3. **ColliOpt（碰撞避免优化）**：基于凸分解碰撞体，求解“离当前位姿最近的无碰撞位姿”，并加地面间隙约束；用 Drake 建模、SNOPT 求解。
4. **EvoOpt（仿真感知进化优化）**：若上述结果仍不满足物理稳定性，将 MuJoCo 当作黑盒，用 CMA-ES 搜索位姿邻域，最小化漂移、残留穿透、速度和输入位姿偏差。

该方法不依赖任务专属先验，也不需要估计器输出精确 6-DoF，而是通过几何一致性与物理仿真反馈逐步逼近接触级位姿。

### 2.5 VLM 验证与场景选择

- 将候选场景加载到 MuJoCo，运行到收敛或步数上限；  
- 渲染多视角、多时刻图块，交 VLM 检查关系是否成立且稳定；  
- 通过验证的候选再交由 VLM 横向比较，选出最符合 J_scene 的场景；  
- 若不通过则触发进一步精化。

### 2.6 策略数据合成与 VLA 训练

- 把验证通过场景视为任务终态，随机化初始桌面位姿，用运动规划器合成“到达验证相对位姿”的轨迹。
- VLM 标注物体对称性，用“位姿等价类”避免给模型提供冗余但等价的监督。
- 使用高保真光线追踪渲染 + 光照/纹理/相机/位姿域随机化。
- 策略采用 π0.5 结构（换用 Qwen3-VL-2B 作为 VLM 主干），动作头为 flow-matching expert，输入为第三视角 + 腕部相机，可直接部署到真实机器人。

## 6. 主要结论与发现

- GIF 在语言和图像两种输入设置下，**8 类关系匹配（R.M.）均为最高**；平均 R.M. 明显超过最强基线 SceneSmith。
- **物体匹配质量（O.M.）**也有提升，且没有牺牲资产保真度。
- **物理碰撞率极低**（接近 0），唯一的残余碰撞出现在“勺子挂墙钩”这种凸分解会减小环形半径的任务中，需在“钩挂稳定性”和“碰撞惩罚”间做权衡。
- 用户研究显示，人类更偏好 GIF 场景，尤其在关系匹配上优势显著（对 SceneSmith 胜率 95.9%，对 GenieSim 100%）。
- CoGen 的“擦除—再生成”互补分支对关系匹配很关键；GPRM 的每个阶段均带来一致增益，EvoOpt 对 Hook 类任务提升最大，说明物理仿真反馈不可替代。
- 策略学习显示，GIF 生成的功能组合可作为可执行的 VLA 训练任务；增加资产变体数量能同时提升仿真与真实世界成功率，表明**资产多样性有助于 sim-to-real 泛化**。

## 7. 优点

- **问题定义清晰且有价值**：聚焦“接触精确、功能正确、仿真就绪”的物体对，而不只是粗布局。
- **模块化设计有解释性**：解耦重建与位姿恢复，将困难问题拆成可独立消融的步骤。
- **多模态生成与重建互补**：巧妙结合 2D 生成大模型的先验与 3D 重建模型，缓解遮挡和实例纠缠。
- **几何与物理量联合引导**：既有图像空间优化，也有碰撞约束和 MuJoCo 黑盒搜索，考虑了“重力后关系是否保持”这一关键问题。
- **VLM 作为智能体验证者**：整合高层语义判断与底层仿真，形成“生成—验证—再优化”闭环。
- **基准构建有来源依据**：从 Ego4D 真实操作数据归纳接触几何类别，非纯手工臆造。
- **实验链完整**：从资产生成到仿真评估、消融、用户研究、真实机器人策略部署全链路打通。

## 8. 不足与局限

- **刚性物体限定**：不处理关节物体与可变形物体；凸分解和 MuJoCo 仿真假设也会限制柔性/铰接资产。
- **尺度偏小**：多物体场景目前只是“初步扩展”，论文承认需要人工调参、重试并可能产生较高成本；房间级布局尚未纳入。
- **基准以两物体为主**：虽然两物体组合是接触位姿问题的基本单元，但对真实操作场景的覆盖仍有限。
- **可能的选择偏倚**：基准任务来源于 LLM 聚类 Ego4D，且任务选择由 LLM 完成，可能存在类别代表性偏差。
- **自动评估依赖 VLM**：O.M./R.M. 本质上由 VLM 打分，语言输入时无法与“隐藏参照”做像素级核对，存在评分类别的主观性/系统性偏移；虽然用户研究部分缓解，但成本较高、难以扩展。
- **基线适配公平性存疑**：不同基线接受不同输入/场景适配，可能未能反映其原生最佳能力；图像类基线依赖人为合成的“白桌面”参考图，工作流不够自然。
- **策略学习实验范围很小**：仅两个任务、有限资产预算，且初始布局固定为 10 种 × 3 次重复，泛化结论仍有限。
- **可复现性信息不足**：未完整提供总训练 GPU 时数、各模块全部配置与完整运行日志；策略训练借助专有渲染引擎和仿真器，复现门槛较高。
- **潜在放大风险**：作者也明确指出，多物体顺序生成尽管单次成本近似线性，但计入重试后系统级成本可能显著上升，需更合理框架加以控制。
