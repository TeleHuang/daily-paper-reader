## 摘要
世界-动作模型利用预测的未来观测来指导动作生成，但以视觉为中心的预测会遗漏决定接触丰富操作的关键局部接触线索。然而，在我们的实验中，简单地将未来触觉观测作为附加视图进行预测，仅能恢复可实现收益的三分之一。这一差距反映了时序不匹配：预测先于执行，而触觉反馈在执行过程中才到达。我们提出了TacPAC，它将触觉预测转化为实时动作修正。一旦基础模型规划了一个动作块，TacPAC会缓存该规划所依赖的预测接触信息以及规划自身的表示，然后一个触觉专家将每个新观测到的触觉图像与该缓存进行对照读取，以修正尚未执行的动作。因此，反馈是依据规划所预期的内容而非孤立地进行解读，且一次修正仅需对缓存进行单次遍历，其成本比重新生成该动作块低20.7倍。在涵盖精密插入、易碎物体操作、物体重新定向和长时程操作的五项真实机器人任务中，TacPAC在每项任务中均领先，并将其仅基于视觉的基础模型的平均成功率从22%提升至64%。代码可在 https://github.com/LogosRoboticsGroup/TacPAC 获取。

## Abstract
World-action models guide action generation with predicted future observations, but vision-centric predictions miss the local contact cues that decide contact-rich manipulation. However, naively predicting future tactile observations as additional views recovers only a third of the achievable gain in our experiments. This gap reflects a timing mismatch: predictions precede execution, while tactile feedback arrives during it. We introduce TacPAC, which turns tactile prediction into real-time action correction. Once the base model has planned an action chunk, TacPAC caches the predicted contact that plan was conditioned on together with the plan's own representation, and a tactile expert reads each newly observed tactile image against that cache to correct the actions not yet executed. Feedback is thus interpreted against what the plan anticipated rather than in isolation, and one correction is a single pass over that cache, $20.7\times$ cheaper than regenerating the chunk. On five real-robot tasks spanning precision insertion, fragile-object handling, object reorientation, and long-horizon manipulation, TacPAC leads every task and raises the average from 22% for its vision-only base model to 64%. Code is available at https://github.com/LogosRoboticsGroup/TacPAC.

## 1. 论文的核心问题与整体含义（研究动机和背景）

接触丰富的机器人操作（如插充电器、捏取薯片）强依赖于局部接触状态的变化——如微小错位、滑移、形变。这些信息通常难以从视觉图像中准确感知。现有的 World-Action Models（WAMs，世界-动作模型）通过预测未来视觉观测来引导动作生成，但以视觉为主的预测会忽视关键接触线索。

论文提出一个自然但被证明不够充分的改进方向：让 WAM 同时预测未来触觉观测（将触觉图像作为额外的“视频视图”）。作者在实验中发现，这种“触觉预测”仅能恢复理论上可行增益的三分之一，原因是**时序不匹配**：预测发生在动作执行之前，而真正有价值的触觉反馈是在执行过程中才逐渐到达的，它无法修正已经计划但尚未执行的动作。

基于此，论文提出 **TacPAC**：将“触觉预测”转化为“实时动作修正”。其核心洞察是：触觉反馈只有在**对照模型原本预期会感知到的接触状态**去解读时，才有意义；孤立的触觉观测无法回答“当前接触是否偏离了计划预期”这一问题。

## 2. 论文提出的方法论

### 核心思想
TacPAC 采用三专家架构（Mixture-of-Transformers, MoT）：
- **视频专家**：预测未来的视觉与触觉观测；
- **动作专家**：在预测的未来观测基础上生成动作块（action chunk）；
- **触觉专家**：在执行过程中，利用实时触觉图像去修正尚未执行的动作。

关键设计是 **“缓存”（cache）+“触觉专家”** 的联合机制：

1. **规划阶段**：基础模型（视频专家+动作专家）完成去噪后生成动作块 $\hat{a}$，同时以“未来触觉预测 + 动作计划”作为条件。
2. **预填充（prefill）**：基础模型完成后，对已经去噪的视频向量和动作块做一次“干净前向”（τ=0），并缓存每层的 attention keys 与 values。缓存中包含**预测的触觉视图**（代表模型预期的接触状态）和**动作块表示**（代表计划本身），视觉键值不缓存。
3. **修正阶段**：每当新的触觉图像 $I_m$ 到达时，触觉专家以当前触觉图像、已执行前缀的更新后动作块、以及缓存的触觉-动作 KV 为输入，单次前向输出一个“增量动作”（delta action）$\Delta a$，仅叠加到尚未执行的后续动作步上（即从偏移 $m+d$ 开始，$d$ 为最近观察到的执行延迟，以动作步计量）。

### 关键技术细节

- **触觉观测作为图像输入**：与视觉图像拼接到同一个视频编码空间，通过共享 tokenizer 处理，使触觉预测成为现成视频预测的一部分。
- **动作块宽度与长度**：动作块长度 $H = 48$，每个动作包含 7 维关节指令 + 1 维夹爪指令，控制频率 30 Hz，单个动作块对应约 1.6 秒运动；VAE 时域 stride 为 4，未来帧 stride 为 4，因此一个潜在帧覆盖 16 个动作步。
- **触觉专家的训练**：Stage 1 训练视频与动作专家；Stage 2 冻结两者，仅训练触觉专家，且用动作专家权重初始化触觉专家。训练时使用**基础模型自身生成的动作块**（而非真实动作块）来计算修正残差，使训练与推理路径一致。每个冻结的计划和缓存配合 $K=4$ 个随机采样的偏移 $m$，并只监督偏移之后尚未执行部分的动作残差：
  
  $L_{\text{tac}} = \frac{1}{H - m} \sum_{i \ge m} \|\hat{a}_i + \Delta a_i - a_i\|^2$

- **推理流程**：机器人立即执行计划的动作块；预填充与执行并行；每个新的触觉帧触发一次触觉专家的单次前向。修正只覆盖该帧之后尚未执行的部分，且每次修正叠加到**原始计划**上（而非上一次的修正版本），从而避免错误修正的累积传播。
- **没有显式的“预测 vs. 观测”比较器**：触觉专家通过注意力自动从缓存和当前触觉图像中获取差异信息，是一种隐式学习。

## 3. 实验设计

### 真实机器人任务（共 5 类）：
1. **充电器插头插入**（charger-plug insertion）— 紧配合、精准对齐。
2. **多目标水果转移**（multi-object fruit transfer）— 连续转移三个水果至托盘，损伤即失败。
3. **易碎薯片转移**（fragile potato-chip transfer）— 夹持力控制，不可捏碎。
4. **空瓶直立**（empty-bottle uprighting）— 轻量易变形物体，需要温和夹持并稳定释放。
5. **扩展卡插入**（expansion-card insertion）— 类似插头，紧配合插入主板插槽。

### 实验设置
- 机器人：Flexiv Rizon 4；夹爪集成两个 InTac S1 触觉传感器；手腕 D405 + 第三视角 D435i 相机。
- 所有方法执行相同的任务定义、重置流程、二元成功标准与试验预算，每个方法在每个任务上运行 **20 次真实世界试验**，报告按任务的平均成功率。

### 对比方法（baselines）：
- **π0.5**（通用 VLA），**ACT**（动作分块模仿学习），**VITaL**（触觉-视觉预训练策略），**LingBot-VA**（纯视觉 WAM），**Dream-Tac**（触觉预测类 WAM），**T-Rex**（触觉反馈修正类 WAM）。所有方法均适配到同一机器人/动作接口；纯视觉方法不额外加触觉信息，Dream-Tac/T-Rex 保留其触觉感知方式。

### 消融实验（第 4.3 节，回答 Q2/Q3）
通过组建 5 个变体并切断触觉通路中不同环节来定位各因素贡献：
1. **Vision only**：去除触觉输入和触觉专家 → 纯视觉 WAM。
2. **w/o tactile expert**：仅保留触觉预测、无实时修正。
3. **w/o tactile prediction**：触觉专家保留，但触觉视图不从视频和预测目标中去掉，即无触觉预测但有实时修正 —— 变为“反应式触觉修正”。
4. **w/o tactile cache**：有触觉预测、有触觉专家，但屏蔽专家对缓存中触觉键的读取。
5. **TacPAC（完整）**：保留全部触觉通路。

## 6. 论文的主要结论与发现

1. **触觉预测不足以发挥触觉的全部价值**：加入触觉预测仅使纯视觉 WAM 的平均成功率从 22% 提升至 37%，而完整 TacPAC 可达 64%，说明“预测之后再修正”这一机制贡献了主要增益。
2. **触觉预测与触觉修正是互补的、不可相互替代的**：去掉触觉修正（w/o tactile expert）与去掉触觉预测（w/o tactile prediction）分别使成功率降至 37% 和 33%，均显著低于完整系统。
3. **缓存的预测触觉信息至关重要**：在保持“触觉预测 + 触觉专家 + 当前触觉图”不变的前提下，仅禁止触觉专家读取缓存的预测触觉键值，就使成功率从 64% 降至 47%（−17 个百分点），直接验证了“以预期接触作为修正参照”的价值。
4. **反应式修正“没有预期”甚至可能产生负效应**：在损伤敏感型任务（薯片、水果）上，未接触预测、仅反应式触觉修正的成功率（45%、25%）低于纯视觉 WAM（60%、30%），说明没有预期时，触觉反馈会干扰原本已经正确的计划。
5. **触觉修正能够满足实时性**：单次修正 30.4 ms（32.9 Hz），较重新生成整个动作块快约 20.7×；执行轨迹统计中，仅 1.6% 的触觉专家调用中机器人前进了一个或更多控制步，几乎无由修正造成的运动抖动或突变现象。

## 7. 优点

- **问题切入清晰且具有洞察力**：从“预测-执行时序失配”的角度解释了为什么单纯预测触觉不够，直指世界模型与闭环控制之间的空隙。
- **方法新颖且工程实现高质量**：以层内键值缓存的方式将“执行前的预期”与“执行中的观测”结合起来、用单次前向完成修正，在概念上简洁，在工程上易于复用原模型的注意力机制。
- **实验设计严谨且自洽**：围绕四个研究问题展开，并借助层层递进的消融变体来验证系统性主张；“切断缓存访问”实验直接证明了方法核心假设，而非仅仅是整体指标对比。
- **真实世界评估**：使用真实机器人而非仿真，且任务覆盖插入、易碎物、轻质物、多阶段任务，具有一定的多样性和纵向难度。
- **效率显著且可量化**：TacPAC 明确给出延迟对比和实时性证据，证明了这一方案不只是一个“离线效果提升”，而是能在实际控制频率内运行。

## 8. 不足与局限

### 实验覆盖方面
- 评估仅基于单一机械臂（Flexiv Rizon 4）和单一型号触觉传感器（InTac S1），未做跨本体或跨传感器迁移。
- 5 个任务虽多样，但都属于桌面夹爪操作，不包含在手操作、双臂协调、长时间序列任务或野外环境。
- 触觉专家只在“触觉图像-修正偏移”的既定语义下训练，难以直接迁移到任务分布急剧变化的新环境。

### 偏差与统计风险
- 每任务每方法仅 20 次试验，无置信区间或显著性检验，随机性带来的总体误差可能使部分性能差距变大或变小无法评估。
- 诊断实验通过夹爪宽度等推断执行阶段，存在将“静置接触”与“自由空间暂停”误分的可能，虽作者声称偏置方向保守，但不能完全排除系统性分类错误。
- 深度消融与数据统计的抽样和帧处理（如去除关键帧帧差、按任务归一化比较）均可能引入轻微偏差。

### 方法层面的局限
- 修正本身受限于基础模型的表达能力：若基础模型完全没有生成利用触觉预测的动作块，触觉专家的修正空间会变小（这也从“无触觉预测”变体的较低成功率侧面可见）。
- 触觉专家只修正当前动作块；长时程任务中如果规划总是基于错误的接触预期，仍然只能利用“事后修正”的范围，无法提前规避或改变全局策略。
- 显式的“预期 vs. 观测”比较是通过注意力隐式完成的，缺乏可解释性；若缓存中的预期触觉与动作块之间存在未建模的耦合或噪声，可能被错误地吸收为无意义修正。

### 资源与可重复性
- 训练时长与数据规模未在正文明确，需依赖附录和开源代码复现；给定真实机器人环境，跨实验室复现难度较大——因为任务成功标准涉及的物理细节（如“可见损伤”“稳定直立”）需要人工判定，存在主观性，不同实验结果分散度的可复制风险尚待消除。
