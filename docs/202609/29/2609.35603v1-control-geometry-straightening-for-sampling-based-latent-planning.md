## 摘要
联合嵌入预测架构使得利用潜在世界模型进行规划成为可能，但仅凭准确的转移预测并不能保证规划目标易于优化。我们提出控制几何拉直（Control-Geometry Straightening, CGS），这是一种单一的辅助损失，通过直接拉直控制几何来学习对规划器友好的表示，从而实现采样高效的规划。CGS 仅使用来自像素-动作对的局部转移，使动作之间的成对余弦相似度与对应潜在差异之间的成对余弦相似度相匹配。该损失可应用于使用端到端学习或预训练表示的世界模型架构。在线性动力学下，我们的理论分析将该目标与时序拉直以及整个规划时域上更均衡的终端代价曲率联系起来，从而为 MPPI 提供有限预算保证，为 CEM 提供局部收缩结果，并为梯度下降提供收敛界。在四个控制环境和多种规划器上，CGS 以更少的采样候选和细化步骤改进规划，分别相较 LeWorldModel (LeWM) 及其时序拉直变体 (LeWM+TS) 取得最高 20 和 12.6 个百分点的成功率提升，其中基于采样的规划器每次更新使用 128 个候选。探针、与 DINO-WM 架构的比较以及规划器侧消融，阐明了潜在运动组织、状态依赖性和动态上下文如何塑造规划行为。因此，拉直控制几何使良好动作序列在有限规划预算下更容易被找到。

## Abstract
Joint-embedding predictive architectures enable planning with latent world models, but accurate transition prediction alone does not ensure that the planning objective is easy to optimize. We introduce Control-Geometry Straightening (CGS), a single auxiliary loss that learns planner-friendly representations by directly straightening control geometry for sampling-efficient planning. CGS matches pairwise cosine similarities among actions to those among corresponding latent differences only using local transitions from pixel-action pairs. The loss can be applied across world-model architectures using end-to-end learned or pretrained representations. Under linear-dynamics, our theoretical analysis connects this objective to temporal straightening and more balanced terminal-cost curvature across the full planning horizon, yielding finite-budget guarantees for MPPI, local contraction results for CEM, and convergence bounds for gradient descent. Across four control environments and multiple planners, CGS improves planning with fewer sampled candidates and refinement steps, achieving success-rate gains up to 20 and 12.6 percentage points over LeWorldModel (LeWM) and its temporal-straightening variant (LeWM+TS), respectively, with sampling-based planners using 128 candidates per update. Probes, comparisons with DINO-WM architecture, and planner-side ablations clarify how latent motion organization, state dependence, and dynamical context shape planning behavior. Straightening control geometry thus makes good action sequences easier to find under limited planning budgets.

## 2. 方法论

### 2.1 核心思想

- 提出 **Control-Geometry Straightening（CGS）**：一种单一辅助损失，通过匹配**动作之间的成对余弦相似度**与**对应潜在差分之间的成对余弦相似度**，从局部像素-动作转移中学习对规划器友好的表示。
- 核心直觉：对齐、正交、反向的动作应对应诱导出角度关系一致的潜在转移，从而"拉直"控制几何。

### 2.2 关键技术细节

- **模型结构**（以 LeWM 为基座）：编码器 $f_\theta$（tiny ViT，输出 [CLS] 投影至 $d$ 维潜在 $z_t$）＋ Transformer 预测器 $g_\phi$（带时序因果掩码，输入 $N$ 帧历史与动作，预测 $N$ 步下一帧），历史长度 $N=3$。
- **CGS 损失构造**：
  - 对每个转移 $t$，令 $\Delta z_t = f_\theta(o_{t+1}) - f_\theta(o_t)$；
  - 单位化动作 $u_t = a_t/\|a_t\|_2$、潜在差分 $v_t = \Delta z_t/\|\Delta z_t\|_2$；
  - 构造余弦 Gram 矩阵 $K_A = UU^\top$、$K_Z = VV^\top$；
  - 损失为 $L_{CGS} = \|K_Z - K_A\|_F^2 / (N(N-1))$，即对 $N(N-1)$ 个非对角元素求均方余弦差异。
- **训练目标**：$L = L_{LeWM} + \lambda_{CGS} L_{CGS}$，其中 $L_{LeWM} = L_{pred} + \lambda_{SIGReg} L_{SIGReg}$；CGS 权重在前 5% 训练更新中从 0 线性 ramp 到最终值。
- **与 TS 的关系**：当相邻动作方向一致（$u_t^\top u_{t+1}=1$）时，CGS 的相邻项退化为 TS 的平方角损失 $(1 - v_t^\top v_{t+1})^2$。

### 2.3 理论分析（线性动力学下）

- 在线性动力学 $z_{t+1} = Az_t + Ba_t$、$B$ 可逆、$d_a = d$ 的设定下：
  - **命题 4.2**：CGS 损失在总体意义上等价于 $R(A,B) = \|D^\top D\|_F^2 + 2\|D^\top B\|_F^2 + \|B^\top B - cI\|_F^2$（$D = A - I$）；零损失当且仅当 $A = I$ 且 $B^\top B = cI$。即 CGS 同时促进**时序拉直、减少漂移-控制耦合、动作效应均衡**。
  - **推论 4.3（ε-CGS 界）**：由 $L_G(c) \le \ell$ 导出 $\|D\|_{op}$、$\|D^\top B\|_{op}$、$\|B^\top B - cI\|_{op}$ 的谱范数界。
  - **定理 4.4**：CGS 控制规划 Hessian，$\|G_H/(cH) - P_H\|_{op} \le \xi_H(\varepsilon) = (2H^2-3H+2)\varepsilon + O_H(\varepsilon^{3/2})$；有效条件数 $\kappa_{eff}(G_H) \le (1+\xi_H)/(1-\xi_H)$。相比仅用 TS + 控制各向同性只能得到 $O(\sqrt{\varepsilon})$ 的 Hessian 扰动，CGS 的显式混合缺陷界将其锐化到 $O(\varepsilon)$。

## 6. 主要结论与发现

- **CGS 显著提升规划成功率与采样效率**：在 K=128 时，CGS 对 LeWM 的 MPPI 增益在 PushT 与 Cube 上分别达 13.3 与 20.0 个百分点；最高较 LeWM 和 LeWM+TS 分别提升 20 与 12.6 个百分点。
- **少样本更高效**：在 PushT 上即便候选极少 CGS 也领先；Cube 上差距随 K 增大而扩大（K=128–256 时约 80% vs LeWM 60%）。
- **理论-实验一致**：Cube 的 XYZ 子空间探针显示 CGS 降低总体收缩因子 $q_\infty$（0.685 vs LeWM 0.841、TS 0.835），提高一步进展概率（K=32 时 91.3% vs 75.1%、80.3%）。
- **表示几何改善**：CGS 使潜在转移路径更贴合动作参考的转向结构，动作扰动响应热图更接近理想圆环参考（规划各向同性）。
- **跨架构适用**：CGS 可应用于端到端 LeWM 与预训练 DINO-WM（CLS 与 Patch），其中对紧凑 CLS 表示的增益尤为明显。
- **环境依赖性**：Reacher 上效果更依赖规划器（GD 提升明显，CEM 略降），因为指尖运动强烈依赖当前状态而非仅动作；TwoRooms 因任务简单趋于饱和。
- **先验质量提升**：CGS 改善匹配的 BC 先验（Cube 上相对目标距离比从 0.262 降至 0.116），使搜索前初始化更好。

## 7. 优点

- **方法极简且通用**：单一辅助损失，无需未来目标、逆动力学解码器或额外标签，仅用局部像素-动作转移，可直接叠加到端到端或预训练世界模型上。
- **理论扎实**：在线性动力学下建立了从局部表示几何到全时域规划 Hessian 曲率的完整链条，并为 MPPI/CEM/GD 三类规划器分别给出有限预算保证，且明确指出 CGS 相比 TS 将 Hessian 扰动从 $O(\sqrt{\varepsilon})$ 锐化到 $O(\varepsilon)$。
- **实验全面且协议严谨**：跨 4 环境、5 规划器、9 档采样预算、多种消融与探针，统一超参与共享温度，使用 nAUC 与多种子统计。
- **机制可解释**：通过探针、动作扰动热图、MDPI 收缩因子等多种手段刻画"控制几何"如何影响规划，而不仅是报告成功率。
- **跨架构验证**：同时验证了端到端学习表示与冻结预训练表示，增强了结论的普适性。

## 8. 不足与局限

- **理论假设较强**：核心分析基于线性动力学、固定半径理想化、$d \ge d_a$、$B$ 列满秩及联合覆盖假设；非线性 rollout 下的 Hessian 含非半正定残差项，论文未覆盖。
- **状态依赖性限制**：CGS 仅以动作为参考几何，在 Reacher 等状态强依赖任务上效果有限；论文用 transition-CGS 作为诊断，但该变体需要关节状态标签，属于特权信息，无法用于纯像素-动作设定。
- **收益不一致**：DINO-WM Patch 表示因起点已很强，CGS 增益参差；Reacher 上 CEM 甚至略低于 LeWM，说明方法并非在所有表示-规划器组合上普遍有效。
- **超参敏感**：CGS 权重需按环境调节（PushT 用 0.01，其余默认 0.5），过大权重会与其他损失冲突。
- **算力信息缺失**：未报告 GPU 型号/数量/训练时长，复现成本不透明。
- **定性可视化选择性**：部分轨迹

部分轨迹（如 Figure 9）为精选示例，未说明抽样标准、失败案例比例或与定量指标的对应关系，因此只能作为机制示意，不能单独支撑方法有效性的结论。

## 9. 总体评价（补充）

总体而言，该论文的核心贡献在于把“控制几何”显式引入潜在世界模型的表示学习目标，并通过线性动力学下的规划 Hessian 与采样规划器收缩分析，将局部动作-潜在差分余弦对齐与有限预算规划效率联系起来。其方法极简、理论叙事完整、实验覆盖面较广，且对 MPPI/CEM/GD 等规划器给出了较统一的分析框架。

但该工作的局限也较明显：理论依赖线性动力学、可逆控制矩阵与理想化覆盖假设；经验上在 Reacher 等状态强依赖任务中收益不稳定，在 DINO-WM Patch 等较强表示上增益参差；同时算力披露不足、部分定性证据选择性较强。更准确的定位是：CGS 为“规划友好表示”提供了一个有理论动机、在若干基准上有效的辅助正则化方向，而非在所有控制任务和规划器上稳定优于 TS 的普适解。
