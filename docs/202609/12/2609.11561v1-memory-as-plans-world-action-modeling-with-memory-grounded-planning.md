## 摘要
主流的机器人策略通常采用马尔可夫形式，但许多复杂的真实世界操作任务本质上是非马尔可夫的，需要超出当前观测的长时程记忆。现有的记忆机制通常依赖语言摘要、不断增长的视觉窗口或二者的组合，因此可能会丢失细粒度的视觉证据，或面临历史覆盖范围与执行效率之间的权衡。我们提出 MaP-WAM，一种“记忆即规划”（Memory-as-Plans）框架，它将依赖记忆的世界-动作建模分解为基于记忆锚定的规划和以规划为条件的执行，并将长期多模态情节上下文用作规划阶段的证据，而不是反复让执行器以完整历史为条件。MaP-WAM 将记忆表示为已完成的片段记录，其中包含语言指令和稀疏视觉上下文，并将这种情节记忆转换为由下一片段级语言计划及相应视觉引导组成的紧凑计划。世界-动作-进度（WAP）模型在未知时长内执行每个计划，在推理时联合预测动作块和相应的执行进度，并通过计划-观测对齐校准预测进度，以实现自适应片段转换和闭环上下文更新。MaP-WAM 保持执行器上下文长度固定，而结构化注意力进一步在规划和执行中支持键值缓存。MaP-WAM 在 RMBench 上以 83.3% 的成功率取得了最先进的性能，并在真实机器人任务上达到 78.0% 的成功率，同时随着任务历史增长，执行器推理延迟保持大致恒定。

## Abstract
Mainstream robotic policies often adopt a Markovian formulation, but many complex real-world manipulation tasks are inherently non-Markovian, requiring long-horizon memory beyond the current observation. Existing memory mechanisms often rely on language summaries, growing visual windows, or their combinations, and may therefore lose fine-grained visual evidence or face a trade-off between history coverage and execution efficiency. We introduce MaP-WAM, a Memory-as-Plans framework that decomposes memory-dependent world-action modeling into memory-grounded planning and plan-conditioned execution, and uses long-term multimodal episodic context as planning-time evidence rather than repeatedly conditioning the executor on the full history. MaP-WAM represents memory as completed segment records containing language instructions and sparse visual context, and converts this episodic memory into compact plans comprising the next segment-level language plan and corresponding visual guidance. A World-Action-Progress (WAP) model executes each plan over an unknown duration by jointly predicting action chunks and corresponding execution progress at inference time, calibrating predicted progress through plan-observation alignment for adaptive segment transitions and closed-loop context updates. MaP-WAM keeps the executor context length fixed, while structured attention further enables key-value caching in both planning and execution. MaP-WAM achieves state-of-the-art performance on RMBench with an 83.3% success rate and attains 78.0% success on real-robot tasks, while maintaining approximately constant executor inference latency as task history grows.

## 1. 核心问题与整体含义（研究动机与背景）

- **核心问题**：主流机器人策略（VLA、世界-动作模型 WAM）普遍采用马尔可夫假设，仅以当前观测或固定短窗口作为条件。然而许多复杂真实操作任务本质上是**非马尔可夫**的——决策所需信息可能已从当前视野中消失，必须依赖长时程记忆。
- **现有记忆机制的不足**：
  - **语言记忆**（如 MemER、Mem-0、MEM）：将历史压缩为语言摘要或中间指令，紧凑可解释，但可能丢失细粒度视觉/空间证据。
  - **持续更新记忆**（如 latent state、memory bank）：早期证据易被压缩或覆盖，长时程下难以保留任务相关信息。
  - **增长视觉窗口**（如 LingBot-VA 等因果 WAM）：保留丰富感知证据，但逐帧条件化导致推理延迟与 GPU 显存随历史快速增长，形成"历史覆盖 vs 执行效率"的权衡。
- **论文主张**：长时程视觉历史不必在每个控制步直接输入执行器；它主要用于确定**下一片段级计划**与期望的视觉演化，而执行可遵循一个"基于记忆锚定的计划"完成。
- **整体含义**：提出 **MaP-WAM（Memory-as-Plans）**，将记忆表示为"计划"，把依赖记忆的世界-动作建模解耦为**记忆锚定规划（memory-grounded planning）**与**计划条件执行（plan-conditioned execution）**，在保持执行器上下文固定、推理延迟近似恒定的同时，保留对长期细粒度视觉证据的访问能力。

## 2. 方法论

### 2.1 核心思想：Memory-as-Plans 分解

- 将一般记忆依赖策略 $\pi(a_{t+1:t+h} \mid f_{\le t}, s_t, l)$ 分解为两个阶段：
  - **规划阶段**：$\pi_P(C_k \mid C_{<k}, l)$，由情节上下文与全局指令推断下一片段计划。
  - **执行阶段**：$\pi_E(a_{t+1:t+h} \mid C_k, f_t, s_t, l)$，条件于计划、当前观测与本体状态生成动作块。
- 执行器输入与历史长度无关，故上下文长度固定。

### 2.2 结构化多模态情节上下文

- 每个已完成片段 $i$ 贡献记录 $C_i = \{l_i, G_i\}$：
  - $l_i$：该片段的语言指令；
  - $G_i$：从该片段真实执行轨迹中按 8 个等长时间箱、每箱取最后一帧得到的 **N=8 帧稀疏视觉上下文**；
  - 初始观测单独记为 $G_0 = f_0$。
- 规划片段 $k$ 前的情节上下文记为 $C_{<k}$，提供规划阶段的历史证据。

### 2.3 记忆锚定的语言-视觉规划

- **语言规划**：微调 VLM（Qwen3.5-4B），输入全局指令 $l$、已完成片段指令 $l_{<k}$ 和关键帧集合 $f^\star$（初始帧 + 各完成片段末帧），预测下一子目标语言计划 $l_k$。
- **视觉规划**：用**因果世界模型（CWM）**（由 WAN-2.2-5B 初始化）以 flow-matching 目标生成视觉计划 $G_k$，条件为 $(G_{<k}, l_k, l)$。
- **因果注意力与 KV 缓存**：采用块因果掩码，使已完成片段证据成为静态可缓存前缀，防止未来信息泄漏，并支持规划阶段的键值复用。

### 2.4 World-Action-Progress（WAP）模型

- **进度定义**：对训练片段 $f_{i:j}$，归一化进度 $p_t = \frac{t-i}{j-i}$，$t \in [i,j]$，为执行状态与视觉计划提供连续时间坐标。
- **架构**：以预训练视频 DiT 为基础，通过 **Mixture-of-Transformers（MoT）** 扩展出动作专家（1.02B 参数，隐藏维 1024）与进度专家（207M 参数，隐藏维 256）。
- **联合预测**：给定计划 $C_k=\{l_k,G_k\}$、当前观测 $f_t$、本体状态 $s_t$ 与当前进度 $p_t$，联合预测未来视觉潜变量、动作块与进度序列。
- **注意力设计**：
  - 视觉计划作为静态干净前缀，当前观测为干净状态 token，噪声目标为动态 token；
  - 计划前缀独立于动态 token，可在片段执行期间缓存复用；
  - 动作/进度 token 与未来视觉 token 相互不可见（未来视觉仅作训练辅助目标，推理时可省略）；
  - 交叉注意力中所有 token 关注语言计划 $l_k$，动态 token 额外条件于 $s_t$ 与 $p_t$。
- **训练目标**：对视觉、动作、进度三分支分别施加条件 flow-matching 损失，加权求和 $L_E = \lambda_v L_E^v + \lambda_a L_E^a + \lambda_p L_E^p$。

### 2.5 闭环规划与执行

- **计划-观测对齐的进度校准**：部署时无真值进度，递归使用预测进度会累积误差。利用视觉计划的时间索引，按当前进度估计检索邻近计划帧，用 RGB 空间平均绝对像素差选出与执行后观测最相似的帧，将进度条件向该帧的进度值靠拢。
- **进度门控片段转换**：对最近动作的预测进度取平均，超过阈值 $\tau=0.95$ 即判定当前片段完成，终止当前计划、更新情节上下文并触发下一轮规划。
- **上下文更新**：将真实执行观测均匀重采样为稀疏视觉上下文 $G_k$，替换生成计划写入记录 $\{l_k, G_k\}$，保证上下文锚定于真实观测而非生成预测。

## 6. 主要结论与发现

- **仿真性能**：MaP-WAM 在 RMBench 取得 **83.3% 总体平均成功率**，超越所有代表性基线（次优 LingBot-VA 为 77.1%）。在 Swap T 与 Press Button 上均达 **96%**；在极具挑战的 Observe and Pick Up 上，将最强基线从 9% 提升至 19%。
- **真实机器人性能**：Find Button 达 **88%**，Press Buttons 达 **68%**，平均 **78.0%**；基线在 Press Buttons 上完全失败（0%）。
- **推理效率**：执行器保持约 **827 ms** 的动作块延迟，随历史帧数增长近似恒定；而全上下文执行器在 1500 帧时延迟约为零历史的 4 倍，1700 帧时显存超过 80GB 导致 OOM。
- **消融结论**：
  - 视觉计划与视觉记忆均对 Observe and Pick Up、Swap T 有显著贡献；用当前观测替代情节视觉证据会导致物体身份或空间位置错误。
  - 进度建模各组件均有效：去掉进度条件显著损害 Press Button；进度校准在最长任务 Blocks Ranking Try（平均 423.10 步 vs 其他 116.32 步）上收益最大，可缓解自回归进度预测的漂移。

## 7. 优点（方法与实验设计亮点）

- **问题定位清晰**：明确指出非马尔可夫长时程操作中"历史覆盖 vs 执行效率"的核心矛盾，并给出结构性解法。
- **架构解耦优雅**：将记忆处理从每步执行中剥离，转化为片段级规划，使执行器上下文长度固定，从根本上避免上下文随历史膨胀。
- **多模态情节记忆设计**：以"语言指令 + 稀疏视觉关键帧"的片段记录组织记忆，兼顾语义抽象与细粒度视觉证据，且稀疏采样控制了成本。
- **进度作为一阶模态**：不同于将进度用作事后验证器或奖励信号，WAP 将进度与动作、视觉动力学联合生成并反馈为条件，为执行提供显式时间坐标，可区分视觉相似但语义阶段不同的状态。
- **计划-观测对齐机制**：训练-free 的轻量匹配即可校准递归进度漂移，实用性强。
- **工程效率考虑周全**：块因果掩码与结构化注意力支持规划与执行两阶段的 KV 缓存；未来视觉分支可训练时辅助、推理时省略。
- **实验较为全面**：仿真 + 真实机器人 + 视觉规划消融 + 进度建模消融 + 延迟/显存分析，验证了性能与效率两个维度。

## 8. 不足与局限

- **依赖预定义片段结构**：MaP-WAM 的规划与进度建模建立在现有 benchmark 提供的片段边界与片段指令之上；对无分段演示需依赖自动片段发现，论文将其列为未来工作，当前方法在真实非结构化场景中的适用性受限。
- **对齐度量较简单**：计划-观测对齐采用 RGB 空间平均绝对像素差的训练

无关（training-free）匹配策略，虽轻量且无需额外训练，但对光照变化、视角偏移、纹理重复或低纹理表面较为敏感，可能出现帧检索错配，从而把进度条件拉向错误锚点；论文未给出该度量在干扰条件下的鲁棒性分析。

- **进度阈值为固定超参数**：片段终止采用固定阈值 $\tau=0.95$，缺乏自适应机制；当任务节奏差异较大或进度预测存在系统性偏差时，可能需要逐任务调参，论文未讨论阈值敏感性。
- **规划粒度受片段长度制约**：方法以"片段"为规划单位，若演示中单个片段过长（如 Blocks Ranking Try 平均 423.10 步），则一次规划需覆盖很长的执行跨度，规划误差与进度漂移的累积风险相应增大；论文虽用进度校准缓解，但未从根本上解决长片段内的重规划问题。
- **视觉计划为生成式预测**：$G_k$ 由因果世界模型采样生成，可能存在与真实物理不符的"幻觉帧"；虽然执行阶段以真实观测重采样写入上下文，但规划阶段仍可能被不准确的生成计划误导，论文未量化生成质量对下游成功率的影响。
- **模型与算力成本较高**：整体系统包含微调 VLM（Qwen3.5-4B）、CWM（WAN-2.2-5B）与 WAP（视觉 DiT + 1.02B 动作专家 + 207M 进度专家），需 8×A800 80GB 训练，部署时也需同时承载规划器与执行器，对实际机器人平台（尤其边缘算力）的落地成本较高；论文未报告端到端部署的显存占用与整机功耗。
- **评估统计稳健性有限**：仿真使用全局种子 0、真实机器人仅 2 个任务，未报告多种子方差、置信区间或显著性检验；部分基线（如 π0.5 在 Press Buttons 上为 0%）的失败原因未深入剖析，可能低估其真实能力或高估本方法优势。
- **训练协议不完全一致**：规划器多任务训练、WAP 单任务训练，而部分基线采用不同训练范式，跨方法比较的公平性存在一定不确定性。
- **真实场景泛化性待验证**：真实实验任务（Find Button、Press Buttons）结构相对规整、指令与片段边界清晰，尚未在开放动态环境、多物体长时程装配或人机协作等更复杂场景中验证。
- **缺乏对失败模式的系统分类**：论文报告了成功率但未系统统计失败类型（如规划错误、进度误判、抓取失败、视觉对齐失败），不利于后续针对性改进。

## 9. 总体评价

MaP-WAM 针对长时程非马尔可夫操作中"记忆保真度"与"执行效率"难以兼得的根本矛盾，提出了一个结构清晰、工程可行的解耦框架：以"记忆即计划"为核心隐喻，将历史证据的消费集中在片段级规划阶段，而让执行器在固定长度上下文中条件于计划运行。这一设计在概念上简洁——执行器无需感知完整历史，规划器则通过块因果 KV 缓存高效复用情节证据——并在 RMBench 与真实机器人任务上同时取得了性能提升与延迟稳定性的验证。

其方法学亮点在于：（1）多模态稀疏情节上下文（语言指令 + 关键帧）兼顾语义与视觉细节；（2）将进度建模提升为一阶联合预测模态，而非事后奖励或分类标签；（3）训练-free 的计划-观测对齐机制为递归进度漂移提供了实用的在线校正手段。

主要局限在于对预定义片段结构的依赖、生成式视觉计划的可靠性、以及对大规模算力的需求。总体而言，该工作为记忆依赖型世界-动作建模提供了一个有说服力的范式参考，但其向无分段、开放域真实场景的迁移，以及更鲁棒的对齐与自适应片段机制，仍是后续研究的关键方向。
