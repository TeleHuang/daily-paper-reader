## 摘要
长时程目标条件强化学习将控制交由提出子目标的高层模块，但现有子目标只是价值函数或潜在动作的隐式副产物，与生成它们的执行器绑定。我们研究一种不同的对象：由路径条件决定的、每个成功执行器都必须经过的不可回避阶段的顺序；它可从离线轨迹中恢复，却不属于其中任何一条轨迹。其定义性性质是拓扑的：不可跳过的阶段是每条可行路径都必须穿越的分离集，而自由空间中的环路则迫使做出路径选择。我们在由成功轨迹构建的传输加权载体上，通过0维与1维同调来读取这两者，得到一个可枚举的、带壳层证书的闸门集合；这些经过认证的闸门即我们所称的拓扑必然性。经认证的闸门以递归拓扑闸门层级的形式进入决策回路。在固定且同构的自由空间下，该对象在执行器替换后依然成立：在PointMaze数据上冻结的闸门无需重新训练即可迁移至Ant和Humanoid，在统一接口下取得最高的Humanoid综合成绩（96.1），并在多路径任务上比拥有地图特权的参考方法高+36.0（p=1.4e-5）；该规划器在PointMaze上达到饱和（100±0），在AntMaze（giant +22.9）和Kitchen（+15.8/+12.6）上达到或超过最强基线。

## Abstract
Long-horizon goal-conditioned reinforcement learning delegates control to a high-level module that proposes subgoals, but existing subgoals are implicit byproducts of value functions or latent actions, tied to the executor that produced them. We study a different object: a route-conditioned order of unavoidable stages that every successful executor must traverse, recoverable from offline trajectories and belonging to none of them. Its defining properties are topological: an unskippable stage is a separating set that every admissible path must cross, and a loop in free space forces a route choice. We read the two by homology in dimensions 0 and 1 over a transport-weighted carrier built from successful trajectories, yielding an enumerable gate set with shell-level certificates; the certified gates are what we call topological necessities. Certified gates enter the decision loop as a recursive topological gate hierarchy. Under a fixed, isomorphic free space, the object survives executor replacement: gates frozen on PointMaze data transfer without retraining to Ant and Humanoid, attaining the highest Humanoid aggregate under a unified interface (96.1), with +36.0 over a map-privileged reference on the multi-route task (p=1.4e-5); the planner saturates PointMaze (100+/-0) and matches or exceeds the strongest baselines on AntMaze (giant +22.9) and Kitchen (+15.8/+12.6).

## 1. 核心问题与整体含义

- **研究背景**：离线目标条件强化学习（offline GCRL）中，长时域任务通常采用时间抽象——高层模块提出子目标，低层策略执行子目标。
- **核心痛点**：现有子目标大多是**拟合管线的隐式副产物**（价值函数、潜在动作或策略输出的副产品），其定义绑定于产生它的执行器。当执行器或具身（embodiment）改变时，这些子目标会吸收执行器特有的变化（对任务而言是噪声），导致迁移退化——"任务知识绑定于谁执行它"。
- **核心问题**：是否存在与执行器无关的任务结构？它能否仅从他人的离线经验中恢复？
- **论文提出的对象**：去除执行器后剩下的唯一东西是**不可回避阶段的顺序**（route-conditioned order of unavoidable stages）——每个成功行为都必须选择自由空间中每个环路的一侧，然后按固定顺序穿越相应区域。该顺序由任何成功执行器的轨迹传递，却**不属于其中任何一个**。
- **整体含义**：这是一种"任务级"而非"执行器级"的子目标定义。其性质是拓扑的：不可跳过的阶段是**分离集**（每条可行路径必须穿越），自由空间中的环路强制**路线选择**（winding 性质）。论文称这些经认证的闸门为**拓扑必然性（topological necessities）**，是可证伪的结构性子目标。

## 2. 方法论

### 2.1 核心思想

- 将离线数据视为诱导出**观测策略空间的几何–拓扑表示**，直接分析该对象（"载体"carrier），而非拟合某个策略。
- 机制不变的结构存在于所有成功轨迹**共享的支撑集**中；任何拟合策略只是该结构的一种实现。
- 用**同调维度匹配**分解任务结构：不可跳过阶段的顺序是 **H0 问题**，路线分叉是 **H1 问题**——每个子问题用表达它的最低维不变量。

### 2.2 关键技术细节

**（a）载体构建与目标相对几何**

- 从成功轨迹集 D+（在首次到达目标处截断）构建 **传输加权 kNN 图**：
  - 每个维度计算**直线度分数** ηd = 净位移 / 总变差（∈[0,1]，含 ε 保护的零变差维度）；
  - 软化传输权重 η̃d = ηd^σ（σ = 1/2），度量 dη(x,y) = ‖A(x−y)‖，A = diag(η̃)。
  - 该度量是常系数平坦黎曼度量，其测地线恰为直线段（Lemma 1），便于把欧氏图测地一致性结论迁移过来。
- **双重边过滤**：密度测试删除跨越无支撑区域的边；三点探测（t = 0.25, 0.5, 0.75）删除不合理捷径（阈值 ratio 2.5）。
- **径向坐标**：以目标节点集 Vg 为虚拟超级源做多源 Dijkstra，r(u) = dG(u, Vg)，直接由图计算而非回归。
- **校正嵌入 ψθ: R^D → R^m（m=16）**：损失 = 径向损失（‖ψθ(xi)‖ 拟合 r(xi)）+ 等距损失（‖ψθ(xi)−ψθ(xj)‖ 拟合边权 wij），λ=1 且从不按任务调参。嵌入**仅用于壳层测量**，规划与监控保留图级结构参考，执行器只接收分布内路径点。

**（b）持久瓶颈读取（H0）**

- 将载体状态按径向坐标分箱为**壳层** S(ρ)，用校正空间中的**最小体积包围椭球（MVEE）体积**或**香农熵**定义截面测度 μ(ρ)。
- 对一维剖面 μ(ρ) 做**子水平集过滤**：每个谷 v 的持久性 pers(v) = d_v − b_v（出生=谷底，死亡=合并鞍点）。
- 用**数据自适应拐点（kneedle elbow）τ** 位于持久性谱隙上缘，区分幸存谷与边缘谷；无注册正间隙的分段不给门（而非强行截断）。
- 幸存谷定位到**门区域**（窄分离颈区，非单点），按 r 排序形成**路径条件门链** Γc = (g1, …, gK)。

**（c）H1：路线分叉**

- 成功轨迹覆盖走廊但不覆盖路线间的障碍块，因此轨迹诱导的覆盖复形带有真实的高维同调结构；平面情形下有界补分量由平面对偶表示 H1 类。
- 用**多尺度立方持久 H1 读取**（GUDHI 3.13.0，占据掩码膨胀一格，过滤值 = 到覆盖的欧氏距离）检测有界孔洞，为每条路线分配**绕数（winding number）签名**。
- 签名同时作为决策工具：累积绕数选择部署路线链，在判别性案例中实现零路线切换；签名重合时按构造回退到几何规则。

**（d）递归拓扑闸门层级**

- 对每对相邻闸门，把成功轨迹限制在对应路线段，在该子载体上**重新应用同一壳层读取**；持久子颈细分长段，直到无分段含超拐点的持久子颈（观测深度 ≤ 2）。
- 层级固定路线的拓扑；使其可执行是"致密化"问题，任何保持路径点落在执行器训练分布内的规则都可作为部署接口（如 support-flow 接口）。
- 同一颈壳兼作**运行时监控器**：漂移、停滞、完成不一致触发全局重锚（有收敛保证）。

**（e）理论保证（T1–T6 + Lemma 8）**

- **T1（离散 Eikonal 三元组）**：dG 是度量；r 关于 dG 是 1-Lipschitz（|r(u)−r(v)| ≤ dG(u,v)）；沿最短路径等号成立。Eikonal 约束由回归目标转为恒等式。
- **T2（传输加权流形图的测地一致性）**：在 BdSL 2000 框架下证明 (1−ε)dM ≤ dGP ≤ (1+ε)dM；推论给出径向标签的一致性与无偏性。
- **T3（瓶颈的持久同调刻画）**：真实门是深谷（pers ≥ ∆true），伪谷浅（≤ ∆false），拐点落入间隙 ⇒ 幸存集 = 真门集；给出分离证书（任何从 {r > ρ⋆+ε} 到目标的可行路径必须穿越 Sρ⋆）、Cheeger 见证、检测正确性、JS 相变通道互补性。
- **Lemma 8（机制不变性）**：在同一任务流形上，各机制（行为策略/执行模态）各自的检测正确性指向同一几何定义的目标，故**承重幸存门集跨机制一致**；肘部并列的边缘实例注册但不计数。
- **T4**：Jacobian 活动谱的谱隙 ⇔ 有效维度 meff，误差界含有效样本量 Peff 重标定。
- **T5**：级联收敛与成功率分解 SR ≥ (1−εplan)(1−2α)(1−εterm)，含锚定失败概率 panchor 与路径级鞅集中。
- **T6**：接口分布匹配界 E[δ] ≤ επ + Lδ·W1(νr, μpath)，解释五种帧选择规则的成败排序。

- **未明确说明**：论文**未报告 GPU 型号、数量、总训练时长或总计算预算**。仅在附录提到"CPU 确定性重跑"、以及执行器类别的检查点文件与训练日志。
- **结论**：算力细节披露不足，只能推断执行器训练是主要开销，规划/发现侧为轻量 CPU 计算。

## 5. 实验数量与充分性

- **实验规模（大致）**：
