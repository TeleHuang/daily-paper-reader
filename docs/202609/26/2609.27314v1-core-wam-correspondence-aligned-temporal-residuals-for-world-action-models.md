## 摘要
比较当前与过去的观测有助于机器人在操作过程中理解场景变化并选择后续动作。然而，当物体或相机移动时，在相同图像位置比较视觉特征可能会混入不同的场景内容。我们提出 CoRe-WAM，一种通过参数高效的时间接口引入对应关系对齐的视觉变化的世界-动作模型。其 TraceDelta 模块利用来自冻结跟踪模型的对应关系，将历史视觉特征迁移到当前位置，然后在共享的预训练特征空间中计算带符号差异。因此，对应关系决定哪些历史内容与当前内容进行比较，而不是作为单独轨迹表示进入策略。一个轻量级适配器将这些差异转换为有效性门控的残差，用以补充当前的视觉条件，使策略能够在利用当前场景信息的同时使用近期变化。CoRe-WAM 构建于 Motus 之上，保持预训练主干权重冻结，并优化 159 万个参数。在 5,000 次更新的适配预算下，CoRe-WAM 在 50 个 RoboTwin 2.0 任务上取得 92.22% 的干净成功率，比 Motus 高 3.56 个百分点；在随机化评估中，其成功率为 89.60%，提升 2.58 个百分点。将 TraceDelta 集成到基于 StarVLA 的策略中，可将干净成功率从 58.10% 提升至 67.62%，表明该时间接口可迁移至 Motus 之外。

## Abstract
Comparing current and past observations helps robots understand scene changes and select subsequent actions during manipulation. However, comparing visual features at the same image location can mix different scene content when objects or the camera move. We introduce CoRe-WAM, a world-action model that incorporates correspondence-aligned visual changes through a parameter-efficient temporal interface. Its TraceDelta module uses correspondences from a frozen tracking model to transport historical visual features to current locations before computing signed differences in a shared pretrained feature space. Correspondence thus determines which historical content is compared with the present, rather than entering the policy as a separate trajectory representation. A lightweight adapter converts these differences into validity-gated residuals that supplement current visual conditioning, allowing the policy to use recent changes alongside current-scene information. Built on Motus, CoRe-WAM keeps the pretrained backbone weights frozen and optimizes 1.59 million parameters. With a 5,000-update adaptation budget, CoRe-WAM achieves 92.22% clean success across 50 RoboTwin 2.0 tasks, 3.56 percentage points above Motus; on randomized evaluation, it achieves 89.60% success, a 2.58-point gain. Integrating TraceDelta into a StarVLA-based policy improves clean success from 58.10% to 67.62%, supporting transfer of the temporal interface beyond Motus.

## 1. 核心问题与整体含义（研究动机与背景）

- **背景定位**：机器人操作中，当前观测描述"现在是什么"，而近期历史观测揭示"场景如何演化"。工具使用、物体交接、铰接物体交互、多阶段放置等任务都依赖这种演化信息来选择后续动作。
- **技术脉络**：视觉-语言-动作（VLA）模型将预训练视觉/语言表示连接到机器人控制；世界-动作模型（WAM）进一步把控制与视觉预测相连（如 Motus 联合理解、视频生成与动作专家；Fast-WAM 研究视频协同训练与未来想象的作用）。
- **核心痛点**：直接对两帧预训练特征做"同一图像网格位置相减"时，一旦物体或相机移动，该位置对应的场景内容已经不同。所得差异混合了"区域特征自身变化"与"该区域被不同内容占据"两种效应，历史信息本身并不自动构成有意义的时间比较。
- **核心主张**：**先建立对应关系，再计算变化**。对每个当前区域，先找到其历史对应区域，再在共享预训练特征空间中比较二者表示。对应关系在此充当"历史特征的搬运算子"，而非作为独立轨迹表示输入策略。
- **整体含义**：论文把变化检测中的"先配准后比较"原则引入机器人策略条件化，构造出一种参数高效、可跨架构迁移的时间接口，回答"策略应如何关联当前观测与历史证据"这一基础问题。

## 2. 方法论：核心思想、关键技术与算法流程

### 2.1 总体框架

- 在时刻 \(t\)，策略接收当前观测 \(O_t\)、机器人状态 \(s_t\)、指令 \(\ell\)，输出动作块 \(A_t\)；另引入历史观测 \(O_h\)（\(h=t-s\)，\(s\) 为观测步长）。
- 同一冻结视觉-语言编码器处理两个观测：\(Z_\tau = E_\phi(O_\tau,\ell)\)，\(\tau\in\{h,t\}\)，提取空间特征网格 \(F_\tau\in\mathbb{R}^{H\times W\times D}\)。
- 原始理解输入为 \(U_t=P(Z_t)\)（\(P\) 为冻结投影器）。TraceDelta 在编码器特征空间比较当前与对齐后的历史特征，把差异映射为投影接口上的残差，仅注入头相机 token 位置 \(\Omega\)，**保持当前观测通路完整**。

### 2.2 TraceDelta 三步流程

- **第一步：轨迹引导的特征搬运（Align history）**
  - 使用冻结的 Trace Anything 模型在共享 3D 坐标系中估计稠密像素轨迹。
  - 对当前 token 中心 \(p_i\)，在其轨迹上取历史时刻 \(h\) 的点，经最近邻匹配到历史稠密 3D 场，再换算为考虑缩放、裁剪与相机布局的特征采样坐标。
  - 定义反向映射 \(C_{t\to h}\)：\(q_i=C_{t\to h}(p_i)\)，\(\bar f_{h,i}=W(F_h,q_i)\)，\(W\) 为双线性采样。
  - 二元掩码 \(m_i\) 记录对应是否可用（有限且落在指定相机区域内），无效位置不参与残差注入；掩码是采样可用性而非学习语义分数。

- **第二步：带符号时间差分（Compare features）**
  - 固定网格残差（Raw Delta）：\(\Delta_i^{raw}=F_t(p_i)-F_h(p_i)\)。
  - TraceDelta 残差：\(\Delta_i^{trace}=F_t(p_i)-\bar f_{h,i}=F_t(p_i)-W(F_h,C_{t\to h}(p_i))\)。
  - 两个操作数位于同一冻结特征空间；保留符号以表达变化方向而非坍缩为幅度。对应关系决定"与哪块历史内容比较"，差异度量的是配准后的特征变化，而非位移本身。恒等对应下该式退化为 Raw Delta。

- **第三步：有效性门控的视觉条件注入（Inject change）**
  - 轻量适配器把差异映射到 Motus 理解维度：\(g_\psi(\Delta)=W_2\,\text{GELU}(W_1\,\text{LN}(\Delta)+b_1)+b_2\)，实现维度为 2048→256→512。
  - 学习标量 \(\alpha\) 缩放残差，采样有效性在适配后进行门控：\(r_i=\alpha\,m_i\,g_\psi(\Delta_i^{trace})\)，保证无效位置即便适配器偏置非零也贡献为零。
  - 残差散布到原生头相机位置：\(U'_t=P(Z_t)+\text{Scatter}_\Omega(\{r_i\}_{i\in\Omega})\)。评测配置中 \(\Omega\) 为 6×10 网格共 60 个 token，位于打包视觉 token 序列索引 10–69，其余位置无直接残差。

### 2.3 训练与因果推理

- 适配阶段冻结预训练主干，仅优化时间适配器、动作侧 LoRA 低秩更新与现有动作解码器，共约 1.59M 可训练参数（约占策略 0.02%）。
- 推理时冻结 Trace Anything 仅用当前与过去观测在线估计对应关系；训练与推理共享同一 VLM 预处理与头相机 token 映射。
- 历史不可用时时间分支旁路，策略仅用 \(P(Z_t)\) 做视觉条件。

## 6. 主要结论与发现

- **主结果**：CoRe-WAM 在 50 个 RoboTwin 2.0 任务上干净成功率 92.22%（比 Motus 高 3.56 pp），随机化成功率 89.60%（提升 2.58 pp）；相比 Raw Delta 分别高 2.06 与 1.94 pp，相比 Current-only 高 0.88 与 1.78 pp。
- **任务级表现**：Move Can Pot（+50 pp）、Scan Object（+19 pp）、Handover Mic（+16 pp）增益最大；放置与打包类任务同样改善（Put Bottles Dustbin +13 pp，Place A2B Left 与 Place Bread Skillet 各 +10 pp）。
- **迁移性**：TraceDelta 集成到 StarVLA 后，干净成功率从 58.10% 提升到 67.62%（+9.52 pp）；随机化条件下仅从 10.60% 到 10.81%（+0.21 pp），表明接口在干净分布下迁移有效，在分布偏移下增益有限。
- **组件贡献**：Current-only 相对 LoRA-only 提升 0.44/0.52 pp，说明轻量视觉接口本身有贡献；Raw Delta 相对 Current-only 在干净上 −1.18 pp、随机化上 −0.16 pp，说明"有历史输入"与"有意义的时间比较"是两个不同的设计选择。
- **真实机器人**：Astribot S1 上分布内任务 28/30（93.3%），OOD 任务 25/30（83.3%）。
- **参数效率**：仅优化约 1.59M 参数（约 0.02%），冻结主干与对应关系估计器，不增加策略输入 token 数。

## 7. 优点

- **问题切入精准**：明确指出"同位置特征相减"在运动场景下的语义混淆，并用图示直观说明为何必须先配准再比较，动机清晰且具有普遍性。
- **方法设计简洁且解耦**：TraceDelta 把对应关系定位为"历史特征的搬运算子"而非额外 token 或轨迹表示，避免引入独立的轨迹-动作融合模块；当前观测通路保持完整，时间证据仅作补充。
- **参数高效与模块化**：冻结主干与对应估计器，仅训练适配器 + LoRA + 动作解码器；适配器维度在 Current-only、Raw Delta、TraceDelta 之间保持一致，使对比聚焦于输入差异而非容量差异。
- **有效性门控设计严谨**：掩码在适配器之后施加，保证无效采样位置即使适配器偏置非零也贡献零，边界行为明确。
- **可迁移性验证**：在 Motus 与 StarVLA 两种不同视觉/动作接口上验证，且迁移实验采用匹配适配预算与检查点准则，比直接复用检查点更有说服力。
- **消融层次清晰**：四个变体逐一分离动作适配、视觉容量、时间信息与对应关系对齐的贡献，并附有任务级随机化控制与参数预算分解。
- **真实机器人部署**：在 Astribot S1 上完成分布内与 OOD 序列任务，并给出推理延迟与执行频率等工程细节。

- **分布偏移下迁移增益微弱**：StarVLA 在随机化条件下仅提升 0.21 pp，说明该接口在干净分布上的收益未必能推广到分布偏移场景。
- **真实世界实验覆盖有限**：仅 2 个任务、每任务 30 次试验，且 OOD 任务为顺序放置，任务多样性与统计效力不足以支撑广泛结论。
- **对应关系依赖冻结跟踪器**：Trace Anything 冻结且未针对机器人操作场景适配，其估计误差会直接传播到残差；论文未报告对应关系质量或其失败模式的影响分析。
- **残差注入范围受限**：仅注入头相机 60 个 token（6×10 网格，索引 10–69），未讨论其他相机视角或其他 token 位置是否也需时间条件。
-

- **任务级方差与置信区间缺失**：主实验与消融均未报告每任务成功率的方差、标准误或置信区间，无法判断任务级增益（如 +50 pp、+19 pp）是否由少数 episode 的随机波动主导；跨方法百分点差的可信度因此受限。
- **超参数与设计选择缺乏敏感性分析**：适配器维度（2048→256→512）、残差缩放 \(\alpha\) 的初始化、注入 token 数量（60 个）与网格尺寸（6×10）、观测步长 \(s\) 等关键设计均未给出敏感性实验，读者难以判断这些选择是性能必要还是恰好可用。
- **训练预算匹配的边界不清晰**：论文以"全局 batch × 更新次数"论证适配预算仅为 FastWAM-Joint 的约 1/192，但同时声明该比例仅针对额外适配预算而非端到端成本；这一限定使"参数高效"的主张在端到端算力意义上仍待澄清，且未给出与 4D-WAM 在同等总计算量下的对照。
- **对应关系质量未量化**：未报告 Trace Anything 在 RoboTwin 场景下的跟踪精度、对应可用率（掩码 \(m_i\) 的激活比例）或失败模式，也未做"用真值对应替换估计对应"的上界实验，因此无法界定性能瓶颈来自对应估计还是来自残差注入机制本身。
- **残差注入范围的合理性未讨论**：仅注入头相机 60 个 token，论文未说明为何选择该范围、是否评估过全 token 注入或跨相机注入，也未讨论在头相机被遮挡或视角失效时该接口的行为。
- **历史窗口与步长未做系统扫描**：\(O_h\) 的观测步长 \(s\) 只给定固定设置，缺少对更长/更短历史、多帧历史或非等距历史的比较，因而无法说明该接口对时间跨度的鲁棒性。
- **真实机器人 OOD 定义偏窄**：OOD 任务为顺序放置，与分布内任务在技能构成上较为接近，"OOD"的挑战强度有限；且未报告失败案例的类型分布（如抓取失败、对应失效、规划错误），难以定位真实场景中的主要失效来源。
- **与同期工作的比较完整性**：对比方法均沿用各自原始协议而非在同一管线内复现，跨方法差异可能混入实现、数据与评测细节；论文虽已声明这一点，但未提供任何同管线复现的对照点以校准差距。
- **统计与协议透明度**：TraceDelta 干净结果取两次评测较高分，而组件控制为单次运行，作者已声明为"描述性分数差"，但这一非对称评测使组件间增益（如 +0.88 pp、+2.06 pp）的统计解释力被削弱。

## 9. 可复现性与开放性

- **可复现要素较完整**：论文给出了冻结主干、投影器、跟踪器与可训练模块的划分，参数预算逐项分解（适配器 660,225、LoRA 917,504、动作解码器 16,398），并明确了数据划分（按轨迹不相交留出）、样本量（2,386 条轨迹 / 19,088 样本）、GPU 配置（8×H100，全局 batch 32）与更新步数（5,000）。
- **复现障碍**：关键组件依赖外部冻结模型（Motus、StarVLA、Trace Anything），其权重与版本未在总结范围内给出；随机化评测的聚合口径、TraceDelta 两次评测取高分的具体规则、以及 \(\alpha\) 与适配器的初始化细节，均需要原文补充才能完全复现。
- **开放问题**：该接口是否可推广到非双臂、非头相机主导的形态（如移动操作、灵巧手）；对应关系是否可在训练中端到端微调而非冻结；残差注入是否可扩展为多历史帧的加权组合——这些均未在论文中给出结论。

## 10. 总体评价

- **贡献定位**：论文的核心贡献不在于新的策略骨干或新的世界模型，而在于对"策略应如何消费历史观测"这一接口级问题的重新表述——把历史条件化从"同位置相减"改为"先配准再比较"。这一视角转换具有跨架构的普适性，是本文最具迁移价值的论点。
- **证据强度**：主实验覆盖 50 个任务、干净与随机化两种设置，并配有四层消融、跨架构迁移与真实机器人验证，实验规模在同类工作中属充分；但组件级比较的统计严谨性、对应关系质量分析与超参数敏感性仍是明显短板。
- **适用边界**：方法在干净分布与结构化操作任务上收益稳定（尤其工具使用、交接、放置类），但在分布偏移下的迁移增益微弱（StarVLA 随机化仅 +0.21 pp），提示该接口的价值高度依赖对应估计在目标域内的可靠性。
- **工程代价**：约 510 ms 推理延迟与在线对应估计是部署于高频率闭环控制的现实约束；参数高效（约 0.02%）是其优势，但端到端算力优势仍需更清晰的对照才能成立。
- **一句话判断**：这是一篇问题定义清晰、方法解耦、参数高效且跨架构可迁移的工作，其最大价值在于把变化检测的"配准—比较"原则引入机器人策略条件化；其结论的可信度受限于组件级统计严谨性、对应质量透明度与分布偏移下的增益边界。
