## 摘要
跨具身学习已表明，单个模型（例如视觉-语言-动作（VLA）模型）可以学习能够应用于异构机器人以完成各种任务的状态表示和操作技能。我们假设安全约束的实施同样如此。满足安全约束所需的推理，例如检测障碍物、识别其应被避开，并选择安全的抽象动作，在很大程度上是跨机器人共享的。不同具身之间的差异在于抽象安全动作如何实现：形态、运动学和动力学决定了哪些动作安全且可行。因此，同一动作对一个机器人可能安全，对另一个机器人则可能不安全。这对于在共同的末端执行器动作空间中运行、而没有显式捕捉安全性如何依赖于机器人形态和运动学的通用操作策略尤为重要。我们提出具身条件化安全滤波，其中基于 Hamilton-Jacobi 可达性的价值函数及其对应的安全最大化策略在机器人之间共享。利用机器人及其环境的形态感知潜表示，我们直接在潜空间中执行 Hamilton-Jacobi 可达性分析，从而使学习到的安全概念能够跨具身泛化，同时仍显式地以每个机器人的形态和运动学为条件。我们在五种双臂机器人具身和五项带有全身避碰约束的操作任务上评估我们的方法。我们的结果表明，一个在五项操作任务和四种具身上联合训练的单一策略，能够对留出具身展现出零样本泛化，并降低标称策略的碰撞率。结果还表明，使用更多具身进行训练可以提升泛化能力。

## Abstract
Cross-embodiment learning has shown that a single model, such as a vision-language-action (VLA) model, can learn state representations and manipulation skills that can be applied across heterogeneous robots to accomplish various tasks. We hypothesize that the same holds for safety enforcement. The reasoning required to satisfy a safety constraint, such as detecting an obstacle, recognizing that it should be avoided, and selecting a safe abstract action, is largely shared across robots. What differs across embodiments is how the abstract safe action is realized: morphology, kinematics, and dynamics determine which actions are safe and feasible. Consequently, the same action can be safe for one robot and unsafe for another. This is especially important for generalist manipulation policies that operate in a common end-effector action space without explicitly capturing how safety depends on the robot's morphology and kinematics. We propose embodiment-conditioned safety filtering, in which a Hamilton-Jacobi reachability-based value function and its corresponding safety-maximizing policy are shared across robots. Using a morphology-aware latent representation of the robot and its environment, we perform Hamilton-Jacobi reachability analysis directly in latent space so that the learned safety concepts can generalize across embodiments while remaining explicitly conditioned on each robot's morphology and kinematics. We evaluate our approach across five bimanual robot embodiments and five manipulation tasks with whole-body collision-avoidance constraints. Our results show that a single policy, jointly trained across five manipulation tasks and four embodiments, exhibits zero-shot generalization to a held-out embodiment, reducing the nominal policy's collision rate. They also show that training using more embodiments improves generalization.

## 1. 论文的核心问题与整体含义

- **研究动机**：跨具身学习已证明单个 VLA 模型可跨异构机器人共享状态表示与操作技能，但安全约束的执行是否也能跨具身共享尚不明确。
- **核心矛盾**：避障等安全推理（检测障碍、识别风险、选择抽象安全动作）在很大程度上跨机器人共享；然而抽象安全动作的具体实现受形态、运动学与动力学制约，同一动作对某机器人安全，对另一机器人可能不安全。
- **关键背景**：通用操作策略常在共同末端执行器动作空间中输出动作，再映射到各机器人关节运动，但同一末端轨迹在不同连杆长度、关节轴、关节限位下可能产生不同全身运动，导致安全性差异。
- **研究问题**：能否用多具身数据学习一个安全滤波器，并零样本泛化到新具身？现有方法（如 EmbodiSteer、Any-Body Guard）依赖具身特定运动学或配置空间采样，未学习可跨异构具身联合训练的安全表示。
- **整体含义**：提出“具身条件化安全滤波”，在形态感知潜空间中共享 Hamilton–Jacobi 价值函数与安全最大化策略，同时显式条件化于每个机器人的形态与运动学。

## 2. 论文提出的方法论

### 核心思想
- 在潜空间中执行 Hamilton–Jacobi（HJ）可达性分析，学习一个共享的安全 critic \(Q_\theta\) 与安全策略 \(\pi^{\text{safe}}_\phi\)，二者以形态感知潜状态为输入，可跨不同自由度、不同连杆数的双臂机器人泛化。
- 安全推理共享，但安全动作实现具身相关：actor 输出关节角度位移而非末端位姿增量，直接指定关节配置变化。

### 关键技术细节

- **冻结的 HoloBrain-0 编码器**：
  - 输入多视角 RGB-D、关节角、夹爪开度、相机内外参。
  - 输出场景 token \(c\)（含 3D 世界坐标）与每连杆机器人 token \(\hat{z}\)。
  - 关节角被排除，因不同具身零位、旋转方向、URDF 不一致；使用连杆位姿作为统一几何参考。

- **安全相关特征增强**：
  - 为每个连杆 token 拼接安全特征向量 \(b_i \in \mathbb{R}^{16}\)，包括：归一化位置、方向四元数、线/角速度雅可比与关节速度乘积、运动树归一化深度、手臂身份、归一化夹爪开度。
  - 融合方式：\(z^{(0)}_i = \text{Norm}(\text{MLP}(\text{Norm}(\hat{z}_i) \parallel b_i)) \in \mathbb{R}^{256}\)，融合权重跨所有连杆与具身共享。

- **几何感知机械臂–场景交叉注意力**：
  - 每个连杆 token 作为 query，场景 token 作为 key/value。
  - 注意力偏置加入连杆到场景 patch 的 3D 距离与方向：\(\beta^{(m)}_{ij} = \text{softmax}_j [ \frac{q^{(m)\top}_i k^{(m)}_j}{\sqrt{C_{\text{head}}}} + f^{(m)}_\psi(\log d_{ij}, \hat{r}_{ij}) ]\)。
  - 输出拼接注意力加权方向 \(\sum_j \beta^{(m)}_{ij} \hat{r}_{ij}\)，显式保留方向信息。
  - 经过 3 个 transformer block（交叉注意力 + 自注意力 + FFN），得到潜状态 \(z = (z^{(3)}_1,\dots,z^{(3)}_{N_{\text{link}}})\)。

- **安全 actor**：
  - 线性头（共享于所有关节）将每个关节关联的连杆 token 映射为高斯分布均值与 log 标准差。
  - 采样后 tanh 压缩至 \([-1,1]\)，再按各关节动作上限 \(a^{\max}_i = \dot{q}^{\lim}_i \Delta t\) 缩放。
  - 夹爪 token 不产生动作，由名义策略控制。

- **HJ 安全 critic**：
  - 动作 \(a\) 为关节角度位移。利用连杆雅可比计算线性/角位移：\(dp_i = J^{\text{lin}}_i a\)，\(dw_i = J^{\text{ang}}_i a\)。
  - 将 \(dq_i, dp_i, dw_i\) 及指示符 \(1_i\) 投影后加到连杆 token：\(\bar{z}^{(0)}_i = z_i + W_a [dq_i, dp_i^\top, dw_i^\top, 1_i]^\top + b_a\)。
  - critic 再经 2 个 transformer block，交叉注意力使用动作后估计的连杆位置计算几何偏置。
  - 每个 token 经共享 FFN 输出安全分数 \(Q_i\)，用软最小值聚合：\(Q_\theta(z,a) = -T \log \sum_i \exp(-Q_i/T)\)。

- **HJ 可达性训练**：
  - 价值函数 \(V(s) = \sup_\pi \inf_{t\ge0} h(\xi^\pi_s(t))\)，Bellman 方程 \(V(s) = \min\{h(s), \max_a V(f(s,a))\}\)。
  - 使用 SAC 适配 HJ 可达性，critic 损失：\(L(\theta) = \mathbb{E}[(Q_\theta(s_t,a_t)-y_t)^2]\)，目标 \(y_t = (1-\gamma)h(s_t) + \gamma \min\{h(s_t), \max_a Q_\theta(s_{t+1},a)\}\)。
  - 在线安全过滤：若 \(Q_\theta(z,a_{\text{nom}}) \ge 0\) 执行名义动作，否则执行 \(\pi^{\text{safe}}_\phi(z)\)。

## 3. 实验设计

- **仿真平台**：RoboTwin 2.0（基于 SAPIEN），物理频率 250 Hz，控制频率 25 Hz，控制周期 \(\Delta t = 0.04\) s。
- **机器人具身**：五种双臂机器人：Piper、Franka-Panda、ARX-X5、UR5-WSG、Aloha-AgileX。Franka-Panda 每臂 7 DoF，其余 6 DoF。
- **任务**：五项双臂操作任务：Place Bread in Basket、Place Container on Plate、Stack Two Blocks、Place Burger & Fries、Stack Two Bowls。
- **障碍设置**：每个场景加入同一静态障碍物（RoboTwin-OD 068 boxdrink），训练时 70% 概率在名义路径上，30% 偏离；评估时始终在路径上。
- **失败函数**：\(h(s)\) 为机器人（含抓取物体）与障碍物之间的最小符号距离，机器人用包围球近似，障碍物用有向包围盒。
- **Benchmark 与对比方法**：
  - Nominal：未过滤的 cuRobo 规划器。
  - X-VLA-Safe：用 X-VLA 编码器替换 HoloBrain-0 的变体。
  - CrossSafe w/o Geo, Aug：去掉几何感知注意力与安全特征增强。
  - CrossSafe w/o Geo：去掉几何感知注意力。
  - CrossSafe w/o Aug：去掉安全特征增强。
  - CrossSafe：完整方法。
  - 另对比 CrossSafe specialists（单具身训练）与 generalists（四具身联合训练）。
- **评估协议**：留一具身交叉验证（leave-one-embodiment-out），5 折。每折在 4 个具身上训练，在 4 个 InD 具身和 1 个 OOD 具身上评估。每任务-具身对评估 50 episodes。指标：碰撞率 CR、成功率 SR、干预率 IR、接触力 Force。

## 4. 资源与算力

- 每个模型训练 **2 天**，使用 **1 张 NVIDIA A40 GPU（48 GB 显存）**、**8 CPU 核心**、**48 GB RAM**。
- 未提及多 GPU 或分布式训练；共训练 5 个留一具身模型（generalists），另有 specialists 和消融模型，总算力未明确汇总，但可推断为多次单卡两日训练。
- 推理延迟：HoloBrain-0 视觉与机器人状态编码器 \(59.8 \pm 1.4\) ms，新增可训练模块 \(13.1 \pm 0.3\) ms，完整流水线 \(73.0 \pm 1.9\) ms。

- **实验组数**：
  - 5 种具身 × 5 任务 = 25 个任务-具身对。
  - 每个 learned 方法有 5 个留一具身模型，每个模型评估 20 个 InD 对（1000 episodes）和 5 个 OOD 对（250 episodes）。

  - 额外比较 generalists vs specialists：specialists 评估 1250 InD + 5000 OOD episodes；generalists 评估 5000 InD + 1250 OOD episodes。
  - 消融：w/o Aug、w/o Geo、w/o Geo+Aug 三种。
  - 基线：Nominal、X-VLA-Safe。

  - 覆盖多种具身（含不同 DoF）、多任务、留一具身验证、消融、与基线对比，实验设计较充分。
  - 所有方法使用相同超参数、相同在线数据收集率、相同 warmup 缓冲区，公平性较好。
  - 场景确定性：所有方法在相同场景上评估，可复现。

  - 仅在仿真中验证，无真实机器人实验。

## 6. 主要结论与发现

- **单滤波器跨任务与具身提升安全性**：CrossSafe 将 InD 碰撞率从 64.1% 降至 39.8%，OOD 从 64.1% 降至 49.8%；接触力从 179.6 N 降至 InD 113.6 N、OOD 102.9 N。
- **零样本泛化到未见具身**：在留出 Franka-Panda（7 DoF，训练具身均为 6 DoF）时，CrossSafe 仍将平均 CR 从 66.0% 降至 60.4%，SR 从 40.4% 升至 45.2%，为五种方法中最低 CR。
- **几何感知注意力与安全特征增强有助于泛化**：去掉任一或两者均导致 OOD CR 上升；完整 CrossSafe 在 OOD 上表现最佳。
- **优于 X-VLA-Safe**：CrossSafe 在 InD 和 OOD 上均实现更低 CR、更低 Force、更高 SR；X-VLA-Safe 虽降 CR 但任务成功率减半且力上升。
- **更多具身训练提升泛化**：generalists 相比 specialists，OOD CR 49.8% vs 54.4%，SR 29.4% vs 27.0%，Force 102.9 N vs 144.8 N；InD 成功率也更高。
- **安全过滤牺牲部分任务成功率**：CrossSafe 相对 Nominal 降低 CR 37.9%（InD）和 22.3%（OOD），但损失 26.4% 和 8.7% 任务成功。

## 7. 优点

- **首次实现跨具身潜空间安全滤波器**：单一 HJ critic 与安全策略可跨不同连杆数、不同 DoF 的双臂机器人联合训练，并零样本泛化到留出具身。
- **形态感知潜表示设计精巧**：
  - 安全特征增强补充了 HoloBrain-0 未编码的连杆速度、归一化位置、运动树深度等安全关键信息。
  - 几何感知交叉注意力显式利用 3D 距离与方向，增强机器人–场景空间关系建模。
- **动作空间选择合理**：actor 输出关节角度位移，避免末端位姿增量在不同具身下产生不同全身运动的安全歧义。
- **可变长度序列处理**：actor/critic 基于每连杆 token 操作，天然支持不同连杆数、关节数与自由度。
- **软最小值聚合**：critic 用软最小值聚合每连杆安全分数，平滑且可微，适合全局安全评估。
- **实验设计严谨**：留一具身交叉验证、多任务、多具身、消融、基线对比、相同超参数与数据收集率，公平性较好。
- **与现有方法对比清晰**：X-VLA-Safe 作为替代 VLA 编码器基线，消融验证各组件贡献。

## 8. 不足与局限

- **无形式化安全保证**：作为学习型滤波器，CrossSafe 不提供形式化保证，过滤后碰撞率
