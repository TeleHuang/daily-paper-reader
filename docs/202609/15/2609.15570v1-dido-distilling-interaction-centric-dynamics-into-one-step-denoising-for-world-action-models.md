## 摘要
世界动作模型（WAM）利用视频生成模型预测机器人操作中的未来视觉动力学，但迭代去噪会给闭环控制带来额外的延迟。我们通过实验发现，视觉内容在去噪过程中以不同的速率收敛。静态背景结构在早期即已形成，而夹爪与被操作物体在第一步之后仍然模糊，其交互动力学只有通过后续去噪才会显现。因此，将多步视频模型简单地截断为一步虽能保留场景结构，却会丢失对操作最为关键的交互中心动力学。为解决这一问题，我们提出 DIDO，将多步视频模型的收敛动力学蒸馏到单步去噪中。DIDO 将分布匹配蒸馏与交互中心表征引导相结合。除了将多步生成压缩为一次前向传播外，DIDO 还利用有监督的边界框视觉推理 token 显式建模夹爪、被操作物体及其交互。此外，DIDO 将目标物体在多个模型层中的表征与预训练 DINOv3 编码器的特征对齐。这种交互中心引导有助于蒸馏模型在单步中同时保留相关实体及其未来动力学，同时大幅降低推理延迟。DIDO 在 LIBERO 上取得 99.0% 的平均成功率，在 LIBERO-Plus 上为 76.6%，在 RoboTwin 上为 92.0%，并展现出向真实机器人操作中的长时程与泛化任务的有效迁移能力。

## Abstract
World Action Models (WAMs) use video generation models to predict future visual dynamics for robotic manipulation, but iterative denoising introduces additional latency for closed-loop control. We empirically find that visual content converges at different rates during denoising. Static background structure forms early, whereas the gripper and manipulated object remain blurry after the first step, with their interaction dynamics emerging only through subsequent denoising. Consequently, naively truncating a multi-step video model to one step preserves scene structure but loses the interaction-centric dynamics most critical for manipulation. To address this issue, we propose DIDO, which distills the converged dynamics of a multi-step video model into a single denoising step. DIDO combines distribution matching distillation with interaction-centric representation guidance. Beyond compressing multi-step generation into one forward pass, DIDO explicitly models the gripper, manipulated object, and their interaction using supervised bounding-box visual reasoning tokens. Additionally, DIDO aligns the target object's representations across multiple model layers with features from a pretrained DINOv3 encoder. This interaction-centric guidance helps the distilled model preserve both the relevant entities and their future dynamics in a single step, while substantially reducing inference latency. DIDO achieves an average success rate of 99.0\% on LIBERO, 76.6\% on LIBERO-Plus, and 92.0\% on RoboTwin, while also demonstrating effective transfer to long-horizon and generalization tasks in real-world robotic manipulation.

# DIDO 论文中文总结

## 1. 核心问题与整体含义

- **背景**：视觉-语言-动作模型（VLA）直接由当前观测与语言指令预测动作，不显式建模环境演化。世界动作模型（WAM）则借助视频生成模型预测未来视觉动态，为策略提供"预见性"。
- **核心矛盾**：视频生成依赖迭代去噪，推理开销大，拖慢闭环控制；直接截断为单步虽能提速，却会丢失关键信息。
- **关键经验发现**：去噪过程中视觉内容以不同速率收敛——
  - 静态背景结构在第一步即已成形；
  - 夹爪与被操作物体在第一步后仍模糊，其**交互动力学**要到后续去噪步骤才逐步显现（潜空间中交互区域帧间变化早期微弱、后期增强且空间局部化）。
- **问题本质**：朴素单步截断保留了"场景结构"，却丢掉了对操作最关键的"交互中心动力学"，因此需要一个能在单步内恢复交互动态的蒸馏方案。

## 2. 方法论

### 2.1 核心思想
将多步视频模型（教师）已收敛的动态分布蒸馏进单步生成器（学生），并用交互中心表征引导，使单步前向传播同时保留场景结构与夹爪-物体交互动态，随后耦合动作专家做闭环控制。

### 2.2 关键技术细节

- **基础模型**：以 Wan2.2-TI2V-5B 为骨干，从公开四步蒸馏 checkpoint 初始化，先适配机器人操作演示得到"机器人域四步教师"。

- **Stage I：单步世界动力学蒸馏**
  - 采用分布匹配蒸馏（DMD），目标为匹配教师收敛后的输出分布而非复现其采样轨迹：
    - `L_DMD = E_t [ D_KL( p_θ,t ‖ p_T,t ) ]`
  - 梯度通过"假分数网络"与"冻结真分数网络"的分数差估计；用归一化梯度代理 `g_DMD = (x̂_F0 − x̂_T0) / mean|x_g − x̂_T0|`，假分数网络更新频率高于生成器（每 5 步更新一次生成器）。

- **交互中心视觉推理（四组 token）**
  - 引入 `T_inter = [T_obj ; T_int ; T_grip ; T_align]`，共 64 个 token（每组 16 个），嵌入视频 Transformer 并与视频表征共同演化。
  - **轨迹监督**：`[T_grip ; T_int]` 预测夹爪未来 `H_a=32` 步边界框序列，`[T_obj ; T_int]` 预测物体未来边界框；共享 `T_int` 以捕获二者相对时空演化。损失为平滑 L1 + GIoU：
    - `L_box = (1/H_a) Σ [ smoothL1(b̂_h, b_h) + λ_giou L_giou ]`
    - `L_inter = λ_obj L_box(obj) + λ_grip L_box(grip)`
  - **多层视觉对齐**：用冻结 DINOv3 对目标物体裁剪区域编码，在多个视频 Transformer 层将 `T_align` 投影后对齐：
    - `L_align = (1/|S|) Σ_l ‖ P_l(T_align^l) − F_DINO ‖_1`

- **动力学 token 精炼**
  - 将空间特征图划分为 4×5=20 个区域（每区 2×2 单元），以当前帧与未来帧 value 特征差 `s_tk(r)=‖V_tk(r)−V_t0(r)‖_2` 构建动态图；按区域聚合动态得分排序，保留 top-3 高动态区域的全分辨率 token，其余 17 个区域做 2×2 平均池化。上下文由 323 降至 191 个 token。

- **Stage II：交互感知动作预测**
  - 通过 mixture-of-transformers 将单步世界模型与动作专家耦合，动作专家直接访问世界模型中间表征，**无需解码再编码未来视频**。
  - **共享注意力（非对称）**：动作 token 可关注全部世界模型表征，但世界模型 token 对动作流遮蔽，保留 Stage I 学到的预测通路。
  - 动作生成采用**流匹配**：`a_τ=(1−τ)ϵ+τa`，`L_act = E‖v_θ(a_τ,τ)−u‖²`，每次前向预测 32 步动作块，推理用 10 步 Euler 积分。
  - 总损失：`L_stage2 = λ_video L_video + λ_act L_act + L_inter + λ_align L_align`；DMD 仅用于 Stage I。

- **自动标注**：物体框由语言解析 + 开放词汇检测 + 视频跟踪得到；夹爪框在仿真中由状态投影、真实场景用 Grounding DINO + SAM 3 跟踪；缺失框线性插值。DINOv3 仅用于构造训练目标，推理时移除。

## 8. 不足与局限

- **监督粒度较粗**：交互中心推理依赖夹爪与目标物体的边界框监督，对多物体交互、可变形物体、精细接触几何可能不足。
- **标注噪声风险**：自动标注在严重遮挡或指代歧义时仍可能出现检测/跟踪失败，引入噪声监督。
- **训练流程复杂**：包含教师准备、单步蒸馏、联合策略学习三个阶段，比直接训练动作策略更繁琐，工程成本高。

- **鲁棒性并非全面领先**：LIBERO-Plus 上相机扰动项（45.3%）明显低于部分 VLA 基线，说明在特定分布偏移下仍有短板。
