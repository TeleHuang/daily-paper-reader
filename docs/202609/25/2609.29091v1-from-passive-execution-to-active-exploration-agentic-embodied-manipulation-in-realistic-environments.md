## 摘要
近年来，智能体系统的发展显著提升了具身操作的长时程能力。然而，许多现有框架仍遵循被动执行范式，这限制了它们在涉及文本语义线索、干扰物以及初始不可见目标的真实场景中的适用性。为弥补这一差距，我们提出了一种基于智能体的主动探索框架，使机器人能够与环境动态交互，而不仅仅是执行预定义指令。具体而言，我们的框架由三个协同模块组成：用于高层任务推理的规划模块、用于视觉场景理解的感知模块，以及用于低层操作的执行模块。该设计使机器人能够主动获取任务相关信息，根据环境反馈调整行为，并在部分可观测条件下完成操作任务。此外，我们引入了一种细粒度的感知-执行交错策略，将视觉反馈与技能执行紧密耦合，以提高探索鲁棒性。我们在一个真实的 Find-and-Place 任务上评估了我们的方法，证明了其在目标物体必须在操作前被主动发现的挑战性环境中的有效性。

## Abstract
Recent advances in agentic systems have substantially enhanced the long-horizon capability of embodied manipulation. However, many existing frameworks still follow a passive execution paradigm, which limits their applicability to real-world scenarios involving textual semantic cues, distractors, and initially invisible targets. To bridge this gap, we propose an agent-based active exploration framework that enables robots to dynamically interact with the environment rather than merely execute predefined instructions. Specifically, our framework consists of three collaborative modules: a planning module for high-level task reasoning, a perception module for visual scene understanding, and an execution module for low-level manipulation. This design allows the robot to actively acquire task-relevant information, adapt its behavior based on environmental feedback, and complete manipulation tasks under partial observability. Furthermore, we introduce a fine-grained perception-execution interleaving strategy, which tightly couples visual feedback with skill execution to improve exploration robustness. We evaluate our method on a realistic Find-and-Place task, demonstrating its effectiveness in challenging environments where target objects must be actively discovered before manipulation.

## 1. 核心问题与研究背景

- **研究动机**：智能体系统与 Vision-Language-Action（VLA）模型的发展已显著增强具身操作的长时程推理与决策能力，机器人可将高层目标分解为可执行子任务并跨长程交互维持任务进度。
- **核心问题**：多数现有具身操作框架仍遵循**被动执行范式**（passive execution paradigm），即依据用户指令执行预定义的规划、策略或技能序列，隐含假设包括：
  - 任务相关物体可见；
  - 场景布局无杂乱；
  - 视觉信息足以直接执行。
- **现实差距**：真实场景中目标物体常被遮挡、初始不可见、被干扰物包围，或仅能通过间接语义线索（如文本标签）识别。部分规划类方法虽考虑了此类情形，但依赖精心设计的工程模块、范式泛化性有限。
- **整体含义**：论文主张将操作从"被动指令执行"重构为"感知–规划–行动"的闭环过程，以弥合实验室式设定与真实部署之间的鸿沟。

## 2. 方法论

### 核心思想
- 提出**基于智能体的主动探索框架**（agent-based active exploration framework），使机器人能够主动获取任务相关信息、依据环境反馈调整行为，并在**部分可观测**条件下完成操作。

### 三模块协同架构
- **规划模块（Planning）**：高层决策者，输入为用户指令、当前视觉观测与交互历史，输出下一个子任务。可决定搜索特定区域、检查语义线索、打开容器、取物或放置物体，将欠明确的长时程指令转化为可执行的探索与操作步骤序列。
- **感知模块（Perception）**：提供结构化场景理解，充当视觉 grounding 组件，功能包括物体识别、目标定位、光学字符识别（OCR）与场景级语义理解；据此判断当前场景是否包含足够信息供任务执行。
- **执行模块（Execution）**：将规划出的子任务转换为可执行的机器人动作并驱动与环境交互。该模块不要求智能体直接输出连续控制指令，而是桥接任务级推理与物理执行，提升长时程任务的执行稳定性，使规划模块可专注于语义推理与任务进度。

### 细粒度感知–执行交错策略（Fine-grained Interleaving）
- 将长时程操作任务分解为**细粒度操作单元**（如打开抽屉、关闭抽屉、抓取物体），每个单元对应一个不可再分的执行步骤，会产生潜在的新环境状态。
- 流程：执行一个原子操作 → 调用感知模块更新环境理解 → 规划模块判断当前子目标是否达成、是否需要进一步探索、是否进入下一操作，形成"**观察–行动–验证–重规划**"循环。
- 关键价值：
  - 目标不在当前观测中时，主动选择可能揭示新信息的操作单元（如打开抽屉后立即重新感知）；
  - 逐步感知更新可渐进式降低不确定性；
  - 每次原子操作后验证场景，可纠正早期假设、防止长时程误差累积，提升对干扰物与语义歧义的鲁棒性。

## 3. 实验设计

### 场景 / Benchmark
- 在**真实世界 Find-and-Place 任务**上评估，模拟部分可观测、语义线索与干扰物共存的实用场景。
- 环境配置：桌面上放置**两个多抽屉柜**，每个柜子关联不同物体类别，顶面标注类别标签；目标物体置于未知抽屉中，初始不可见；每个抽屉可能含干扰物。
- 指令形式："Could you help me find the {target object} and place it into the box?"

### 实施细节
- 平台：**Franka 机械臂**（真实世界部署）。

- 判定标准：需正确识别相关柜子、逐层搜索抽屉直至找到目标、抓取目标并放入盒子，才算成功。
- 失败情形：选错柜子、未找到目标即停止、抓取到干扰物、最终放置失败。
