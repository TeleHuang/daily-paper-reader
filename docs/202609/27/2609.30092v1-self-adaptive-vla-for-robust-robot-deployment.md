## 摘要
尽管视觉-语言-动作（VLA）模型在机器人操作中展现出令人印象深刻的能力，但其无记忆特性使其在测试时环境变化下变得脆弱，尤其是由磨损或不完美校准引起的硬件偏移。使这些模型能够在部署期间自适应，而无需持续进行现场重新校准，仍是实现真实世界可扩展性的关键瓶颈。在这项工作中，我们提出 Self-Adaptive VLA，一种新颖的后训练方案，使策略能够利用自身的 rollout 作为上下文，迭代地适应部署时的硬件偏移。为此，我们首先在刻意注入的硬件偏移下收集策略 rollout。然后，我们通过为这些已知偏移预补偿专家动作，将基础策略的训练数据转化为偏移条件化的专家演示。接着，我们引入一个轻量级、即插即用的上下文编码器，将偏移环境中的上下文（包括视觉观测、本体感觉和动作）压缩为潜在上下文 token。该 token 通过自适应层归一化（AdaLN）调制策略。此外，我们发现上下文 token 可以被集成，从而使策略能够逐步迭代地自我校正并缓解失败。在四个精度关键的双臂和灵巧操作任务上的大量实验表明，Self-Adaptive VLA 在硬件偏移（如执行偏差和关节编码器偏移）下恢复了基础策略超过 80% 的性能。此外，与基础策略相比，Self-Adaptive VLA 能够更稳健地部署到新的工作站。我们的方法为稳健的大规模真实世界机器人部署和更轻松的维护提供了一条路径。视频见 https://icefoxzhx.github.io/self-adaptive-vla。

## Abstract
While Vision-Language-Action (VLA) models demonstrate impressive capabilities in robotic manipulation, their memoryless nature renders them brittle to test-time environment shifts, particularly hardware shifts caused by wear or imperfect calibration. Enabling these models to self-adapt during deployment without requiring continuous on-site recalibration remains a critical bottleneck for real-world scalability. In this work, we introduce Self-Adaptive VLA, a novel post-training recipe that enables the policy to iteratively adapt to deployment-time hardware shifts leveraging its own rollouts as context. To do so, we first collect policy rollouts under deliberately injected hardware shifts. We then transform the base policy's training data into shift-conditioned expert demonstrations by pre-compensating the expert actions for these known shifts. Next, we introduce a lightweight, plug-in context encoder that compresses the context, including visual observation, proprioception, and actions in the shifted environment, into a latent context token. This token modulates the policy through adaptive layer normalization (AdaLN). Furthermore, we find that context tokens can be ensembled, allowing the policy to iteratively self-correct and mitigate failures step by step. Extensive experiments across four precision-critical bi-manual and dexterous manipulation tasks show that Self-Adaptive VLA recovers over 80% of the base policy's performance under hardware shifts, such as actuation bias and joint encoder offsets. Moreover, Self-Adaptive VLA enables more robust deployment to new workstations compared to the base policy. Our approach provides a pathway for robust large-scale real-world robot deployments and easier maintenance. See videos at https://icefoxzhx.github.io/self-adaptive-vla.

## 1. 核心问题与整体含义

- **研究动机**：Vision-Language-Action（VLA）模型在机器人操作中表现优异，但其本质是“无记忆”的，只依赖当前观测或极短上下文，因此对测试时环境变化非常脆弱。
- **关键瓶颈**：真实部署中，制造公差、硬件磨损、标定误差等会导致**部署时硬件偏移**，使策略性能急剧下降。为每台机器人持续进行现场重新标定耗时且不现实，成为大规模真实部署与维护的核心障碍。
- **问题设定**：论文研究两类常见硬件偏移：
  - **执行偏差（actuation bias）**：底层控制器或力矩传感器偏置导致实际执行动作偏移，但状态感知仍准确。
  - **关节编码器偏移（joint encoder offset）**：编码器零位错误导致执行动作和状态感知同时偏移，且本体感觉与训练环境不可区分，只能从视觉中推断。
- **整体含义**：作者提出一种后训练方案，使基础 VLA 策略能够利用自身失败 rollout 作为上下文，在部署时迭代适应未知硬件偏移，而无需持续人工校准，也几乎不增加推理开销。

## 2. 方法论

### 2.1 核心思想

- 不改变基础 VLA 的无记忆主策略结构，而是训练一个**轻量级即插即用上下文编码器**。
- 将策略在硬件偏移下产生的失败轨迹压缩为**上下文 token**，再通过 AdaLN 调制基础策略，使其输出经过硬件偏移补偿的动作。
- 多个 trial 的上下文 token 可线性相加集成，使策略逐步定位并补偿残余偏移。

### 2.2 关键技术细节

- **基础策略**：采用 flow matching VLA，包含 VLM backbone 和 DiT 动作去噪器。
  - 输入：语言指令 \(l\)、图像观测 \(o_t\)、本体感觉 \(q_t\)。
  - 输出：未来动作块 \(A_t\)。
  - 去噪器通过 AdaLN-Zero 注入扩散时间步条件。
  - 训练损失为条件 flow matching 损失：
    \[
    L(\theta)=\mathbb{E}\left\|v_\theta(A_t^\tau,\tau \mid c_{o_t})-(A_t-\epsilon)\right\|_2^2
    \]
- **上下文数据构造**：
  1. 从基础策略训练数据 \(D_{base}\) 出发；
  2. 随机采样硬件偏移 \(\delta\)；
  3. 在注入偏移下运行冻结的基础策略，收集次优 rollout \(D_{shift}\)；
  4. 将专家轨迹中的动作按已知偏移进行**预补偿**，得到偏移条件化专家数据 \(D_{contextualized}\)。
  - 关键点：补偿目标来自高质量人类专家数据，而非次优 rollout，保证监督质量。
- **上下文编码器**：
  - 输入：多视角视频、本体感觉、动作序列，时间窗口 \(T=15\)，30 Hz。
  - 视频下采样后由 ViT/DINOv3 提取 token；状态与动作经共享 MLP 映射为 token。
  - 加入可学习类型嵌入区分不同模态。
  - 使用两个自注意力块，带时序 1D RoPE。
  - 最后通过可学习 query 的注意力池化，压缩为单个上下文 token \(c \in \mathbb{R}^d\)。
- **策略调制**：
  - 上下文 token 与扩散时间步条件相加，再输入 DiT 的 AdaLN 层。
  - 训练时冻结 VLM backbone，仅优化上下文编码器，使用与基础策略相同的 flow matching 损失。
  - 推理时上下文编码器只需在失败 trial 后执行一次，生成静态 token；闭环控制阶段零额外计算开销。
- **迭代集成**：
  - 多个 trial 的上下文 token 直接相加：
    \[
    \text{ensemble}(c_1,c_2,\dots,c_m)=c_1+c_2+\dots+c_m
    \]
  - 论文发现上下文 token 在潜空间中呈结构化线性分布，硬件偏移自由度对应主要正交轴，因此简单求和稳定有效。

## 3. 实验设计

- **任务与场景**：四个双臂/灵巧操作任务，均要求精确抓取与插入：
  - **Transport Corn**：6-DoF Piper/Piper-X 臂 + 平行夹爪。
  - **Insert Tube**：6-DoF Piper/Piper-X 臂 + 平行夹爪。
  - **Cap Marker**：6-DoF Piper/Piper-X 臂 + 平行夹爪。
  - **Assemble Ring**：两个 7-DoF Marvin 臂 + 20-DoF Wuji Hand。
- **传感器配置**：每个机器人配备 1 个 ego 相机和 2 个腕部相机。
- **评估协议**：
  - 每个方法测试 20 个 episode，每个 episode 使用一个未见过的硬件偏移，代表 20 个未校准部署环境。
  - 每个 episode 最多允许 6 个 trial，任一 trial 成功即视为成功。
  - trial 之间完全重置场景。
- **指标**：
  - 成功率 \(s\)；
  - 性能恢复比：
    \[
    \rho=\frac{s-s_{base,misaligned}}{s_{base,nominal}-s_{base,misaligned}}
    \]
- **对比方法**：
  1. 基础策略（Base，无记忆）；
  2. Base + Shift Data：仅用新收集的偏移 rollout 微调，无上下文编码器；
  3. Gated Memory Policy（GMP）：通过交叉注意力集成跨 trial 记忆；
  4. Self-Adaptive VLA（单 trial）；
  5. Self-Adaptive VLA + Ensemble（最多 6 trial）。
- **消融实验**：
  - 去除本体感觉（-Proprios）；
  - 使用全部 patch token 替代压缩 CLS token（All Patch Tokens）。
- **其他分析**：
  - 上下文 token 潜空间结构分析：余弦相似度、PCA、子空间维度；
  - 新工作站部署实验：训练工作站 + 两个未校准新工作站；
  - 成功率随 trial 数量变化曲线。

## 6. 主要结论与发现

- **基础策略对硬件偏移极度脆弱**：
  - 标称条件下成功率接近 100%；
  - 在硬件偏移下成功率降至接近 0%，且无法通过多 trial 自我恢复。
- **仅用偏移数据微调不足**：
  - Base + Shift Data 在多数任务上提升有限，说明单纯暴露于偏移 rollout 不足以实现鲁棒适应。
- **Self-Adaptive VLA 有效恢复性能**：
  - 单 trial 后恢复约 46%–49% 的性能；
  - 集成最多 6 个 trial 后恢复约 80%–84%；
  - Transport Corn 任务从 0%–20% 恢复到 100%。
- **迭代集成优于固定记忆窗口**：
  - GMP 在超过两个 trial 后难以继续提升，固定注意力窗口可能覆盖旧上下文并陷入重复错误；
  - Self-Adaptive VLA 随 trial 增加持续改进。
- **上下文 token 潜空间高度结构化**：
  - 同一硬件偏移轴的正负号上下文 token 余弦相似度约 -0.987 至 -0.991，不同轴之间接近 0；
  - 主成分分析显示 token 按偏移类型聚集；
  - 子空间维度与偏移轴数量一致，六个主成分解释 99.8% 方差。
- **本体感觉对执行偏差尤为重要**：
  - 去除本体感觉后性能下降，执行偏差下下降更严重；
  - 更密集的 patch token 没有显著收益，压缩 CLS token 已足够。
- **新工作站部署更鲁棒**：
  - 基础策略从训练工作站 95% 降至新工作站 70% 和 10%；
  - Self-Adaptive VLA 用最多 2 个 trial 恢复至 90% 和 50%。

## 7. 优点

- **问题定义清晰且实际**：聚焦部署时硬件偏移这一真实痛点，而非仅仿真泛化。
