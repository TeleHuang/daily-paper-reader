## 摘要
世界动作模型（World Action Models, WAMs）通过联合建模动作与环境动态，实现面向未来的控制。然而，迭代扩散或流推理会带来显著的去噪延迟。先前的推理状态为加速提供了天然机会，但不断变化的规划上下文、观测和中间表示会迅速使保留状态过时。因此，要保留有用的计算，就需要自适应调整推理状态，而非按原样复用。为此，我们提出 WAMACHINE，一个无需训练的框架，通过随控制回路演进而保留并自适应调整推理状态，实现高效且准确的续算，从而加速 WAM 推理。在闭环重规划之间，Trajectory Remapping 将前一重规划的规划状态重映射，以初始化下一次重规划，减少冗余轨迹生成。在去噪步骤之间，Observation Rebinding 在动作执行期间进行前瞻推理，并在一致性检查通过时将保留的去噪状态重新绑定到真实观测以继续计算，减少暴露给控制回路的延迟。在 Transformer 层之间，Residual Rescaling 在探针检查失败时选择性地重新缩放保留的层状态，并通过中间层的完整计算进行刷新，减少重复的 Transformer 计算。在 LIBERO 和 RoboTwin 2.0 上对三种代表性 WAM 架构的评估表明，WAMACHINE 在观测到动作延迟上实现了 1.47–3.05× 加速，在每次重规划的 GPU 推理时间上实现了 2.23–3.27× 加速，同时保留了原生 WAM 任务成功率的 96.69–99.54%。

## Abstract
World Action Models (WAMs) enable future-aware control by jointly modeling actions and environment dynamics. However, iterative diffusion or flow inference incurs substantial denoising latency. Prior inference state offers a natural opportunity for acceleration, yet changing planning contexts, observations, and intermediate representations can quickly render retained state stale. Preserving useful computation therefore requires adapting inference state rather than reusing it as-is. To this end, we present $\mathrm{WAM}{\scriptstyle\mathrm{ACHINE}}$, a training-free framework that accelerates WAM inference by preserving and adapting inference state for efficient and accurate continuation as the control loop evolves. Across closed-loop replans, Trajectory Remapping remaps replan state from the preceding replan to initialize the next replan, reducing redundant trajectory generation. Across denoising steps, Observation Rebinding performs anticipatory inference during action execution and rebinds retained denoising state to the real observation for continuation when consistency checks pass, reducing latency exposed to the control loop. Across Transformer layers, Residual Rescaling selectively rescales retained layer state and refreshes it through full computation of the middle layers when probe checks fail, reducing repeated Transformer computation. Evaluations of three representative WAM architectures on LIBERO and RoboTwin 2.0 show that $\mathrm{WAM}{\scriptstyle\mathrm{ACHINE}}$ achieves 1.47-3.05$\times$ speedups in observation-to-action latency and 2.23-3.27$\times$ speedups in GPU inference time per replan, while preserving 96.69-99.54% of native WAM task success.

# 论文总结：Efficient World Action Model Inference with Adaptive Intermediate States（WAMACHINE）

## 1. 核心问题与研究动机

- **背景**：世界动作模型（World Action Models, WAMs）联合建模机器人动作与环境未来演化，实现"面向未来"的闭环控制与规划，但推理代价高昂。
- **核心瓶颈**：WAM 通过迭代扩散/流求解器生成动作序列（常同时生成未来表征），推理包含三层嵌套计算循环：
  - 外层 **闭环重规划循环**（新观测到达即重新求解动作段）；
  - 内层 **去噪循环**（逐步精化轨迹/表征）；
  - **Transformer 逐层前向**（DiT 反复处理中间状态）。
- **关键矛盾**：沿观测到动作路径存在大量高度相关的重复计算，直接推高 GPU 开销与观测到动作（O2A）延迟，限制控制频率。利用"上一轮推理状态"是天然的加速机会，但规划上下文、观测与中间表示不断变化，会使保留状态**迅速过时**。
- **核心论点**：因此需要的不是"原样复用"，而是**自适应调整（adapt）**。作者提出 WAM 推理具有**状态连续性（state continuity）**——中间状态跨重规划、跨去噪步、跨网络层仍保持信息量，同时随任务上下文演化。
- **整体含义**：将闭环 WAM 推理重新视为"持续演化的有状态过程（stateful process）"，把分散的复用机会统一为一个免训练的加速框架，为实时具身控制提供新的"执行资源"视角。

## 2. 方法论：WAMACHINE 免训练有状态推理框架

### 2.1 总体思想
在三个嵌套循环的各自尺度上"保留 + 适配"推理状态，并配合一致性检查，检查失败则回退到完整计算，从而在不重训练、不改架构的前提下减少冗余计算与暴露延迟。

### 2.2 关键技术一：Trajectory Remapping（跨重规划，§3.1）
- **动机证据**：相邻重规划在匹配的早期去噪阶段轨迹隐变量余弦相似度高、相对 L2 距离小；重映射初始化可用 3 步推理达到低动作 RMSE 并基本保持成功率。
- **做法**：设第 $t$ 次重规划的最终去噪输出为 $\bar{x}_t$，某阶段 $r$ 的中间隐变量为 $x_t^r$（噪声水平 $\sigma_r>0$），定义归一化去噪方向：
  $$d_t = \mathcal{N}\!\left(\frac{x_t^r-\bar{x}_t}{\sigma_r}\right)$$
  其中 $\mathcal{N}$ 为单位 RMS 归一化算子。$(\bar{x}_t, d_t)$ 构成保留的重规划状态。
- **重映射与初始化**：用算子 $A_t$（视频/动作分支各自定义，需要时做时序坐标平移对齐，否则保持槽位索引）把状态映射到新规划上下文。在入口阶段 $b_0$（噪声水平 $\sigma_{b_0}$）：
  $$x_{t+1}^{b_0}[j]=\begin{cases} A_t(\bar{x}_t)[j]+\sigma_{b_0}A_t(d_t)[j], & j\in M_t\\ \xi_{t+1}^{b_0}[j], & j\notin M_t\end{cases}$$
  即目标槽位集合 $M_t$ 用重映射状态，其余用新噪声。入口阶段越晚越省算力，但留给适应新上下文的步数越少。首次重规划从纯噪声开始。

### 2.3 关键技术二：Observation Rebinding（跨去噪步，§3.2）
- **动机证据**：未来感知 WAM 会预测下一观测；多数前瞻前缀能在动作执行窗口内完成。
- **做法**：
  1. 用上一轮预测的未来 $\hat{F}_t$、当前机器人状态 $s_t$、任务指令 $g$ 经编码器 $\psi$ 构造**预测条件** $\hat{c}_{t+1}=\psi(\hat{F}_t,s_t,g)$；
  2. 在动作执行期间推进一个**有界的前瞻前缀**（不发出机器人动作），只推进到预设的 rebinding 阶段，保留当前隐变量与求解器历史作为去噪状态；
  3. 真实观测到达后用 $\psi$ 构造真实条件 $c_{t+1}$，做**一致性检查**：
     $$e_m=\sqrt{\text{mean}\left[\left(\frac{\hat{u}_m-u_m}{\delta_m}\right)^2\right]},\quad S=\sqrt{\frac{\sum_{m\in V}w_m e_m^2}{\sum_{m\in V}w_m}}$$
     即对各分量（图像、机器人状态等）计算归一化 RMSE 后加权均方聚合；
  4. 当 $S<\tau$ 且连续接受次数 $\kappa<\kappa_{\max}$ 时，把保留去噪状态的条件从 $\hat{c}_{t+1}$ 换成 $c_{t+1}$ 继续推理；否则从重映射初始化在真实条件下**重开**。达到 $\kappa_{\max}$ 时强制在下一次重规划刷新并跳过期前缀，防止误差累积。

### 2.4 关键技术三：Residual Rescaling（跨 DiT 层，§3.3）
- **动机证据**：中间层 Action-DiT 相邻去噪步的隐状态相对 L2 变化小；自适应重缩放 + 刷新可控制输出相对 L2 误差（优于反复复用首步残差 $R_1$）。
- **做法**：将 $L$ 层 DiT 划分为 head $[0,q)$、浅探针 probe $[q,s)$、middle $[s,e)$、tail $[e,L)$。在第 $a$ 步完整计算后保留两组精确残差：
  $$p_a=h_s(a)-h_q(a),\qquad R_a=h_e(a)-h_s(a)$$
  第 $i$ 步只算 head + probe 得 $p_i=h_s(i)-h_q(i)$，用最小二乘拟合 $p_i\approx\alpha_i p_a$ 并截断：
  $$\alpha_i=\mathrm{clamp}\!\left(\frac{\text{mean}(p_i\odot p_a)}{\max(\text{mean}(p_a\odot p_a),\epsilon)},\alpha_{\min},\alpha_{\max}\right)$$
  **复用判据**：方向一致 $\cos(p_i,p_a)\ge\gamma_{\cos}$，且相对拟合误差 $\|p_i-\alpha_i p_a\|_2/\|p_i\|_2\le\gamma_{\mathrm{fit}}$。
  通过则跳过 middle 层，近似输出 $\hat{h}_e(i)=h_s(i)+\alpha_i R_a$；失败则从已算出的 $h_s(i)$ 恢复 middle 层完整计算并用精确 $p_i$、新 $R$ 刷新保留状态。视频与动作联合执行时需两分支同时通过。

### 2.5 三机制的协同（§3.4）
TR 提供重映射初始化 → OR 在动作执行期推进前瞻推理并保留去噪状态 → 在两条路径（前瞻与真实条件）中 RR 都用浅探针决定是否跳过 middle 层。任一环节检查失败都有明确回退路径（OR 失败回退到 TR 初始化，RR 失败回退到完整层计算），保证"保留有用状态"与"按需刷新"并存。

- **消融结论**（Fast-WAM-IDM + LIBERO，固定 200 子集，7 配置）：TR / OR / RR 三者均对加速有正向贡献，去掉任一机制都会同时削弱 GPU 推理加速与 O2A 延迟收益；CUDA Graphs 单独剥离后（Native+Graph）本身可带来约 **1.41×** 的工程加速，而完整 WAMACHINE 相对 Native+Graph 仍有显著增益，说明方法的核心收益来自算法层面的状态复用而非底层算子优化。此外，去掉 OR 主要影响 O2A 延迟（失去执行期算力重叠），去掉 RR 主要影响单步 DiT 计算量，二者的作用维度不同，验证了"跨循环尺度分别适配"的设计假设。
- **诊断分析验证**：附录三项诊断分别支撑三个机制的前提——跨重规划轨迹隐变量高相似（支撑 TR）、前瞻前缀能在执行窗口内完成（支撑 OR）、中间层状态跨去噪步变化小且自适应重缩放优于反复复用首步残差（支撑 RR）。
- **综合结论**：WAM 推理中"状态连续性"假设成立，据此设计的免训练有状态推理框架可在保持成功率接近原模型（96.69%–99.54%）的同时，将 GPU 推理时间压缩约 **2.2–3.3×**、O2A 延迟压缩约 **1.5–3.1×**，且这些收益在三种结构差异明显的 WAM 上可复现。

## 7. 局限与潜在问题

- **验证范围限于仿真**：LIBERO 与 RoboTwin 2.0 均为仿真环境，缺乏真机部署验证。真实系统中观测噪声、时序抖动、执行器延迟与硬件算力波动可能改变一致性检查的接受率，进而影响实际加速比与稳定性。
- **超参数敏感性**：一致性阈值 $\tau$、连续接受上限 $\kappa_{\max}$、方向一致性阈值 $\gamma_{\cos}$、拟合误差阈值 $\gamma_{\mathrm{fit}}$、重缩放截断区间 $[\alpha_{\min},\alpha_{\max}]$ 以及 DiT 层划分点 $q,s,e$ 均需人工设定。论文未充分报告这些超参的敏感性分析与自动选择策略，跨新模型迁移时可能需要重新调参。
- **复用开销与最坏情况**：一致性检查、浅探针计算、重映射算子 $A_t$ 本身引入额外开销；当检查频繁失败、连续触发回退时，单次推理可能反而慢于 Native。论文未给出最坏情况下的延迟上界或失败率的极端分布。
- **误差累积风险**：OR 通过 $\kappa_{\max}$ 强制刷新以抑制误差累积，但长期闭环下多次复用的复合误差是否在长程任务（如 LIBERO-Long）中系统性放大，缺少逐步误差传播的定量分析。
- **依赖预测质量**：OR 的收益前提是 WAM 能较准确预测未来观测；对预测能力弱或未来高度不确定的任务，前瞻前缀的利用率与接受率可能大幅下降，加速退化。
- **资源报告不完整**：未报告推理总时长、能耗、CUDA Graphs 准备开销及大样本评估总机时；同时保留去噪状态与前瞻隐变量带来的显存占用亦未量化。
- **基线公平性存疑**：四个对比方法原为不同策略架构设计，作者自行适配到各 WAM，部分基线（如 RTI-DP、RTC）表现异常（成功率骤降或慢于 Native），其对比结果可能部分源于适配不当，难以完全排除对方法本身评价的干扰。
- **效率口径需注意**：表 1 中 Native 基线是否启用 CUDA Graphs 未在主表同步标注，读者需借助表 3 消融推断口径，存在解读歧义。

## 8. 总体评价

- **核心贡献**：论文将闭环 WAM 推理重新概念化为"持续演化的有状态过程"，并在三个嵌套尺度（跨重规划、跨去噪步、跨 DiT 层）上统一"保留—适配—校验—回退"范式，提出免训练、免改架构的加速框架。这一视角具有方法论价值：把此前零散的缓存/复用技巧整合为有明确回退保障的系统。
- **方法优点**：免训练、可直接作用于冻结 checkpoint；三机制作用维度互补（初始化、算力重叠、单步计算量）；每层都有显式一致性检查与回退路径，兼顾加速与稳健；在三种结构差异明显的 WAM 上验证，泛化性较强；大样本成功率评估较扎实。
- **实证强度**：效率与精度指标定义清晰、边界明确（GPU 计算与 O2A 延迟分离报告），消融设计合理，可复现性较好；但受限于全仿真、无真机、超参未做敏感性分析、基线适配公平性存疑，结论的外部有效性仍需进一步验证。
- **适用场景与展望**：方法最适合推理代价高、需高频闭环重规划、且 WAM 具备一定未来预测能力的具身控制场景。后续工作可探索超参自适应、真机验证、长程误差传播分析、显存与能耗的完整度量，以及将该"有状态推理"视角推广到更广泛的迭代式生成模型（如视频生成、规划器）。
