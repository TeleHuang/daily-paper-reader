## 摘要
基于像素的规划不仅需要一个稳定且可预测的潜空间。规划器所评分的状态还必须按照动作如何推动系统来组织。联合嵌入预测架构（JEPA）通过预测未来表示来避免像素重建，但现有的动作条件 JEPA 让同一个嵌入同时服务于感知和控制。我们提出 H-JEPA，将二者分离。一个宽感知编码通过 Bures-Wasserstein 先验被正则化到尺度良好且各向同性的几何结构上，而该编码的一个固定正交归一化切片作为控制状态，它继承该编码的协方差，而无需自身的目标函数。该状态在相位条件耗散端口-哈密顿动力学下演化，其输入端口具有正交归一化列。端口逆一致性（PIC）通过该端口的转置将已执行动作读回。我们表明，这种读出恰好是投影到端口方向上的 rollout 误差，因此 PIC 是对预测误差的无参数重加权，而不是辅助动作解码器。将读出与端口解绑会破坏这一恒等式，并损失一半的增益。H-JEPA 在最多 10 个训练 epoch 后，在四个基于像素的控制基准上达到或超过无重建基线，包括动作解码的 Delta-JEPA；其最大增益出现在 OGB-Cube 上（91.9% 对 79.3%）。在 PushT 和 OGB-Cube 上的消融实验分别区分了结构化预测器、PIC、预测时域、状态秩和抗坍缩先验的贡献。

## Abstract
Planning from pixels needs more than a latent space that is stable and predictable. The state the planner scores must also be organized by how actions move the system. Joint-embedding predictive architectures (JEPAs) avoid pixel reconstruction by predicting future representations, but existing action-conditioned JEPAs ask one embedding to serve both perception and control. We introduce H-JEPA, which separates the two. A wide perceptual code is regularized toward a well-scaled isotropic geometry with a Bures-Wasserstein prior, and a fixed orthonormal slice of that code is the control state, which inherits the code's covariance without any objective of its own. The state evolves under phase-conditioned dissipative port-Hamiltonian dynamics whose input port has orthonormal columns. Port-inverse consistency (PIC) reads the executed action back through the transpose of that port. We show that this readout is exactly the rollout error projected onto the port directions, so PIC is a parameter-free reweighting of prediction error and not an auxiliary action decoder. Untying the readout from the port breaks this identity and loses half of the gain. H-JEPA matches or exceeds reconstruction-free baselines, including the action-decoding Delta-JEPA, on four pixel-based control benchmarks after at most $10$ training epochs, and its largest gain is on OGB-Cube ($91.9$ against $79.3$ percent). Ablations on PushT and OGB-Cube separate the contributions of the structured predictor, PIC, the prediction horizon, the state rank, and the anti-collapse prior.

## 1. 核心问题与研究动机

- **背景**：基于像素的规划需要一个稳定、可预测的潜空间，但仅此不够——规划器所评分的状态必须按照"动作如何推动系统"来组织。动作敏感性是学习动力学的核心属性。
- **现有 JEPA 的困境**：联合嵌入预测架构（JEPA）通过预测未来表示而非重建像素来避免浪费容量，但训练暴露于表示坍缩风险。LeWM 通过给被评分的嵌入附加 SIGReg（草图化高斯正则器）来解决坍缩。
- **关键观察——稳定性 ≠ 可控性**：匹配边缘嵌入分布只能证明没有方向"死亡"，却不能说明：
  1. 动作究竟移动哪些方向；
  2. 哪些坐标应进入规划度量；
  3. 控制需要多少容量。
- **由此带来的三个后果**：
  - LeWM 在完整嵌入中规划，排序度量混合了控制相关变化与仅满足先验的维度；
  - 正则器与预测损失作用于同一坐标，任何压力变化都需重新调平衡；
  - 潜空间 MSE 目标允许尺度退化解（缩小目标使预测变容易）。
- **Sub-JEPA 的局限**：虽将全空间先验放松为随机子空间并取得收益，但其子空间只是正则器的"视图"，而非被提取的控制状态。
- **本文主张**：将感知编码与控制状态分离，让控制状态**继承**感知编码的协方差几何，并用结构化（端口-哈密顿）动力学与端口逆一致性（PIC）实现动作敏感的预测。

## 2. 方法论

### 2.1 核心思想：两空间世界模型

- 一个宽感知编码 h ∈ R^D 由分布目标塑形；一个**固定的正交归一化切片** U 将协方差几何传递给面向规划器的控制状态 s = U^T h，状态本身无需任何目标函数。
- 统一设计规则：分布目标只作用于感知；编码与规划器之间的所有映射都是固定的或显式受约束的；该路径上不存在批统计量或可学习增益。

### 2.2 感知置于球面上

- 编码器为从零训练的 ViT-T/14 + MLP 投影器（D = 192），逐帧独立编码。
- 输出用无仿射的 LayerNorm（LN0）：逐样本跨坐标中心化并固定 ‖h‖₂ = √D，使每个编码满足 e^T h = 0（e = 1/√D）且落在公共球面上。
- 固定半径消除了尺度自由度（否则编码器可通过缩放过渡幅度而非改进几何来降低损失）。
- 动作取窗口内平均控制量（frameskip = m），归一化坐标，**不使用可学习动作嵌入**（实验中发现其会与动力学共适应而退化）。

### 2.3 具有继承协方差的控制状态

- s = U^T h ∈ R^r，U 由带种子 QR 分解一次性抽取，永不训练。
- **协方差继承**：Cov(s) = U^T Cov(h) U，因此施加于感知编码的协方差几何被状态自动继承，无需单独的状态空间目标或归一化。
- 在目标 Cov(h) = I − ee^T 下：Cov(s) = I_r − (U^T e)(U^T e)^T，即除一个特征值为 1 − ‖U^T e‖²₂ 的例外方向外各向同性；随机 U 下 ‖U^T e‖²₂ 集中于 r/D，偏差由相对状态维度直接控制。当 r = D 时状态有一个精确零方向。

### 2.4 Bures-Wasserstein 各向同性先验

- 对批次内所有编码，惩罚经验高斯与目标高斯之间的 2-Wasserstein 距离平方：
  L_iso(H) = (1/D) W₂²(N(μ̂, Σ̂), N(0, P)) = (1/D)[‖μ̂‖²₂ + Σ_{i=1}^{D−1}(√λ̂ᵢ − 1)²]，其中 P = I − ee^T。
- **为何选 BW（关键分析）**：设 σᵢ = √λᵢ。在 H-JEPA 中切片外的 D − r 个方向没有来自预测或 PIC 的梯度，必须靠先验独自撑开，因此关键在于 σᵢ → 0 时惩罚施加的力：
  - Bures-Wasserstein：∂/∂σ (σ−1)² = 2(σ−1) → −2（**恒定恢复力**）；
  - 欧氏 ‖Σ̂−I‖²_F：∂/∂σ (σ²−1)² = 4σ(σ²−1) → 0（力随 σ 线性衰减）；
  - SIGReg（Epps-Pulley 统计量）：T(σ) = T(0) − κσ² + O(σ⁴)，力 −2κσ → 0。
- 训练中观察到的坍缩正好对应 SIGReg 分数饱和、梯度可忽略的情形。

### 2.5 相位条件端口-哈密顿动力学

- 预测器取端口-哈密顿形式（作为归纳偏置，不假设潜坐标为物理位置/动量）：
  - J 为常数辛矩阵（反对称，连续时间下 J∇H 守恒能量）；
  - H_θ：由 MLP 从相位 c 计算标量能量，∇_s H 只对状态参数求梯度；
  - R_θ(c) = L_θ(c)L_θ(c)^T ⪰ 0（下三角 L 由 MLP 输出，构造上保证半正定，只能耗散能量）；
  - G_θ(c) ∈ R^{r×da} 为输入端口，经可微薄 QR 分解使列正交归一（Stiefel 流形）。
- 相位 c = [s, v]，v = s_t − s_{t−1} 为有限差分速度（单帧状态无运动信息），开环 rollout 中由预测值重新计算。
- 显式欧拉一步离散：ŝ_{t+1} = s_t + Δt[(J − R_θ(c_t))∇_s H_θ(s_t, v_t) + G_θ(c_t)ā_t]（Δt = 1）。
- **正交端口固定动作几何与尺度**：任意输入映射 B(c) 可写为 G(c)S(c)，增益 S 会与潜尺度及 PIC 读出相互权衡导致尺度漂移；正交约束使 ∂F/∂ā = Δt·G_θ(c) 的所有奇异值相等，一个单位归一化动作产生一个单位直接潜位移。

### 2.6 训练目标与 PIC

- 总损失：L = L_pred + L_PIC + L_iso(H)，无像素重建、无学习逆模型、无对比损失、无教师网络、无 s 的归一化。
- **开环预测** L_pred：从编码状态出发，用自身预测反馈滚动 K_p 步，与编码未来在每步匹配（坐标平均的平方误差）。K_p = 5 与规划时域一致。
- **端口逆一致性（PIC）**：从观测位移中减去被动流，再通过端口转置读回动作：
  û_{t+i} = G_θ(ĉ_{t+i})^T[(s_{t+i+1} − ŝ_{t+i})/Δt − (J − R_θ)∇_s H_θ]，并惩罚其与执行动作的距离。
- **核心恒等式**（附录 B 推导）：û_{t+i} − ā_{t+i} = (1/Δt) G_θ(ĉ_{t+i})^T δ_{t+i+1}，即 PIC 残差就是开环状态误差在端口子空间上的投影。
- 因此当 K_PIC = K_p 时：
  L_pred + L_PIC = (1/(|T|·K_p·r)) Σ Σ δ^T (I + (r/(da·Δt²)) G_{t+i−1}G^T_{t+i−1}) δ
  ——**PIC 不是独立任务，而是对同一 rollout 误差的度量重加权**，端口方向误差权重高出 1 + r/(da·Δt²) 倍（Two-Room 17、Reacher 33、PushT@r=192 为 97、OGB-Cube 7.4）。
- 两条捷径均不可行：(1) 缩放读出——动作是固定归一化单位、端口奇异值为 1、s 尺度是继承而非读出设定；(2) 把端口转离 rollout 出错方向——同一端口也负责注入动作，会使 L_pred 变差。

### 2.7 规划

- 测试时用 CEM 在 MPC 循环中规划：目标图像编码为 s_goal = U^T E(x_goal)，候选动作序列按式(6)滚动 K_p 步，以终端距离 ‖ŝ_{t+Kp} − s_goal‖²₂ 评分；相位条件化动力学但不进入代价。
