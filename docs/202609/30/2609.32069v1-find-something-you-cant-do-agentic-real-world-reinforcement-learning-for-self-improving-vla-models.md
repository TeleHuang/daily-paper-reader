## 摘要
视觉—语言—动作（VLA）模型为机器人操作提供了强大的先验，但通常以冻结策略的形式部署，无法从自身失败中改进。真实世界强化学习（RL）提供了持续改进的途径，但人工重置环境和任务成功监督阻碍了自主学习。我们提出 FIND，一种智能体式真实世界 RL 框架，在持久工作空间中闭环连接场景理解、弱点感知练习、自我评估与策略改进。FIND 将自主练习重新表述为一个以场景为条件、感知表现的任务选择问题：它在每次 rollout 后不再恢复预定义场景，而是利用执行后产生的场景来决定下一步练习什么。一个视觉—语言智能体从预定义任务库中识别可行任务，优先选择近期成功率较低的任务，并使用执行前与执行后的配对观测来评估结果。我们用冻结的 π_{0.5} VLA 和残差离策略 RL 实例化 FIND。在八项真实世界操作任务中，由人工独立评估的成功率从 55% 提升到 71.9%。一次代表性运行在 6 小时交互内完成了 456 个自主回合，仅需 30 次场景恢复干预，且在线学习期间无需人工提供奖励标签。消融实验与系统性评估进一步考察了关键设计选择、智能体评估准确率以及人工干预需求。我们的网站已公开提供：FIND.github.io。

## Abstract
Vision--language--action (VLA) models provide strong priors for robotic manipulation but are typically deployed as frozen policies, unable to improve from their own failures. Real-world reinforcement learning (RL) offers a path to continued improvement, yet manual environment resets and task-success supervision hinder autonomous learning. We introduce \textbf{FIND}, an agentic real-world RL framework that closes the loop between scene understanding, weakness-aware practice, self-evaluation, and policy improvement in a persistent workspace. FIND reframes autonomous practice as a scene-conditioned, performance-aware task-selection problem: instead of restoring a predefined scene after each rollout, it uses the resulting scene to determine what to practice next. A vision--language agent identifies feasible tasks from a predefined library, prioritizes those with lower recent success rates, and evaluates outcomes using paired pre- and post-execution observations. We instantiate FIND with a frozen $π_{0.5}$ VLA and residual off-policy RL. Across eight real-world manipulation tasks, the independent human-assessed success rate improves from $55\%$ to $71.9\%$. A representative run completes 456 autonomous episodes within 6 hours of interaction, requiring 30 scene-recovery interventions and no human-provided reward labels during online learning. Ablations and systematic evaluations further examine key design choices, agent evaluation accuracy, and human intervention requirements. Our website is made publicly available at: FIND.github.io.

## 1. 核心问题与研究背景

- **背景**：RT-2、OpenVLA、π0、π0.5 等 VLA 模型从大规模机器人数据中获得了语义与视觉运动先验，但在相机视角、标定、接触动力学、工作空间布局或物体几何发生变化时仍会失败。
- **根本瓶颈**：这类模型通常以**冻结策略**形式部署，失败后无法从自身经验中学习，只能依赖额外的人工演示与监督微调。
- **真实世界 RL 的两大障碍**：
  - **环境重置**：每次 rollout 后物体可能处于不适合下一次尝试的构型，需要人工恢复工作空间。
  - **成功判定**：任务是否成功往往依赖任务专用的奖励仪器或人工标注。
- **已有工作的局限**：Leave No Trace、MEDAL++、VaPRL、ASPIRE 等虽通过习得重置策略、正逆行为、多任务交互、成功分类器或 VLM 评估减轻了负担，但**任务选择、环境重置、结果评估与策略改进通常被当作彼此分离的过程**，难以支撑持续的自主真实世界学习。
- **核心论点**：自主机器人**不必重置世界，只要它能判断接下来该练什么**。能够重置任意场景的机器人，其实已经具备了它本应习得的大部分通用操作能力（从多样失败状态恢复物体往往比完成原任务更难）。
- **问题重构**：把真实世界学习从"反复重置环境"改写为**以场景为条件的任务选择问题**——一次任务的结果就是下一次任务的起始条件。

## 2. 方法论

### 2.1 核心思想

在**持久工作空间**中闭环连接四个环节：场景理解 → 弱点感知练习 → 自我评估 → 策略改进。

### 2.2 问题形式化

- 预定义语言条件任务库 `T = {τ₁, …, τ_N}`，每个任务 τᵢ 对应自然语言指令 lᵢ。
- 观测 `oₜ = (Iₜ, sₜ, lᵢ)`，策略 `aₜ ~ π(·|oₜ)`。
- 场景相关状态 `z_k` 下的可行任务子集 `F(z_k) = {τᵢ ∈ T | τᵢ 在 z_k 下可行}`。
- 二元结果 `r_k ∈ {0,1}`；rollout 后的物理构型直接定义下一回合状态 `z_{k+1}`。
- 交互链：`z_k → F(z_k) → τ_k → r_k → z_{k+1}`。
- 需回答三个问题：**能练什么**（可行性）、**该练什么**（按能力排序）、**是否成功**（自主评估）。

### 2.3 场景条件任务选择

- 每回合开始时，VLM 分析当前工作空间观测，推断任务相关场景状态 `z_k`，据此确定可行子集 `F(z_k)`。
- **任务库与可行性关系是预定义的**，不由 VLM 自由生成，以保证指令落在预训练 VLA 支持的任务空间内，并使工作空间状态间的转移显式可控。
- 机器人无需逆转上一步动作或恢复特定初始状态——任何在当前场景下有效的任务都可作为下一次练习。

### 2.4 性能感知课程

- 每个任务维护二元结果的滚动历史 `Hᵢ`，窗口 `K = 20`。
- 近期成功率估计：`p̂ᵢ = (1/|Hᵢ|) Σ_{r∈Hᵢ} r`。
- 任务权重：`wᵢ = max(ε, 1 − p̂ᵢ)`，即**近期成功率越低权重越高**；下界 ε 防止已解决任务被永久排除，并保留对性能回退的检测能力。
- **课程初始化**：用基策略评估 rollout 填充初始历史（而非均匀先验），随后被在线经验逐步替换。
- **采样分布**（联合场景可行性与策略能力）：
  - 若 `τᵢ ∈ F(z_k)`：`P(τᵢ|z_k) = wᵢ / Σ_{τⱼ∈F(z_k)} wⱼ`
  - 否则为 0。
- 效果：在"当前能执行的任务"中优先选择"仍需练习的任务"，分布随场景与策略持续演化。

### 2.5 配对图像自评估

- 执行前记录工作空间观测，rollout 结束后从**同一场景级视角**再采集一次。
- VLM 接收任务指令 + 执行前/后配对观测，输出二元结果 `r_k ∈ {0,1}`。
- 相比仅看最终场景，配对观测能让评估器**推理状态转移**，对"成功取决于物体或铰接部件相对初始构型如何变化"的任务尤为关键。
- 同一结果承担双重作用：作为稀疏奖励供策略改进使用，并写入历史 `Hᵢ` 更新课程。

### 2.6 残差强化学习实现策略改进

- **冻结 VLA 基动作**：`a^base_t = π_VLA(Iₜ, sₜ, l)`。
- **残差演员**：`Δaₜ = π_φ(h_img(Iₜ), s̃ₜ)`，从视觉特征与语言条件化机器人状态预测有界修正。
- **组合动作**：`a^comb_t = clip(a^base_t + αΔaₜ)`，α 限制残差幅度；残差演员初始化为零输出，起始时完全复现冻结 VLA 行为。
- **训练数据**：离线演示 + 自主采集轨迹的混合批次；离线基动作通过查询冻结 VLA 重建。
- **评论家**：REDQ 风格集成评论家，**10 个 Q 值头**，集成均值用于演员优化与执行门控。
- **异步 RL**：rollout 采集与 RL 优化在独立 Python 线程中并行；采集器通过有序 FIFO 队列传转移，通过"仅保留最新"队列回传参数；若采集器领先超过 **2000 环境步**则完成当前回合并暂停，以限制策略陈旧度。
- **语言条件化**：使用独立语言分支——冻结 Sentence-BERT 编码器 + 可训练投影 `z_l = g_θl(f_SBERT(l))`，`s̃ₜ = [sₜ; z_l]`；投影由评论家目标优化，演员更新时梯度被截断。
- **评论家门控残差执行**：
  - 残差优势 `A_res(xₜ) = Q̄(xₜ, a^comb_t) − Q̄(xₜ, a^base_t)`
  - 若 `A_res > δ` 执行 `a^comb`，否则回退到 `a^base`（δ 为门控阈值）。
